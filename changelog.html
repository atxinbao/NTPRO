验证与边界

本次只改变文档位置、导航和治理工具输入路径。不会修改运行时、交易语义、 adapter 行为、存储格式、发布 tag 或 v0.32.0 冻结边界。
  • 根目录 Markdown 集合必须精确等于 AGENTS.md 和 README.md。
  • project.html 与 changelog.html 必须互相链接并纳入 Git。
  • 当前治理检查读取迁移后的 roadmap 与 contributing 路径。
  • 历史发布和验证记录被移动保存，不作为当前能力声明。
