## Summary

V210-004 defines the order lifecycle read-model component under the v0.21
unified read model. It projects v0.20 production order lifecycle evidence into
a read-only order state that links submit candidate, durable attempt ledger,
approval id, response redaction, readback, cancel evidence, audit state, and
provenance references.

Plain Chinese summary: 本任务把 v0.20 的订单生命周期证据整理成只读 read model。
它覆盖 matched lifecycle、unknown response、readback mismatch、duplicate attempt、
missing ledger。失败场景必须 fail closed，且保持 no-retry、no-automatic-remediation、
no-new-submit/no-new-cancel。
