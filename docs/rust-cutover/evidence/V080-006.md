Executor: Codex

## 中文摘要

本任务让 Dashboard 能读取已经生成好的
`testnet/authenticated_readonly_probe.json`，并把里面安全的只读字段展示出来。
它没有让 Dashboard 读取环境变量 secret，也没有让 Dashboard 发起 Binance probe，
更没有增加下单、撤单、改单、真实资金或生产交易能力。

## 修改目标

- Dashboard 展示 authenticated read-only artifact 的状态、端点类型、请求方法和响应形状。
- Dashboard 展示 API key / secret 是否存在这类布尔值，但不展示任何 secret 值。
- Dashboard 展示 account mutation、real orders、production venue connection 等边界字段。
- 保持 Dashboard 只读：只消费本地 artifact，不新增联网 action route。

## 文件变更

- `crates/cli/src/dashboard.rs`
  - 扩展 `WorkflowArtifactStatus` 的 authenticated read-only 只读字段。
  - 扩展 workflow artifact reader，从 manifest 指向的
    `testnet/authenticated_readonly_probe.json` 读取安全字段。
  - 扩展 Dashboard 表格展示，只显示状态、布尔边界和脱敏形状信息。
  - 新增单元测试覆盖 artifact 读取和敏感字段不进入 snapshot。
- `docs/rust-cutover/tasks/V080-006.md`
  - 新增任务边界、验收标准和验证命令。
- `docs/rust-cutover/evidence/V080-006.md`
  - 记录本任务证据。

## 行为影响

- Dashboard 的 JSON snapshot 和静态 UI 多出 authenticated read-only artifact 的只读状态字段。
- Dashboard 不会启动 probe。
- Dashboard 不会读取 `NTPRO_BINANCE_TESTNET_API_KEY` 或
  `NTPRO_BINANCE_TESTNET_API_SECRET`。
- Dashboard 不会显示 API key value、API secret value、signature、signed URL、
  signed query、raw account body、balances 或 uid。
- 交易语义不变。

## Public API 影响

Dashboard snapshot DTO 增加只读字段；这是本地 Dashboard product surface 的扩展，
不是交易 API 或外部 adapter 行为变更。

## Migration note 状态

不需要迁移。旧 artifact 仍可被读取；缺少 authenticated artifact 时对应字段保持 unknown。

## Rollback plan

回滚本 PR 即可恢复旧 Dashboard DTO/UI。workflow artifact 生成逻辑没有变化。
