## Summary

This task adds the v0.18.0 cancel risk gate artifact. The gate reads one
v0.18 cancel request preview artifact and only becomes ready when the preview
is ready, the orphan risk is halted, new orders are blocked, manual review is
required, a known order identifier exists, and the expected symbol/account
scope matches the single v0.16 mutation candidate lineage.

Plain Chinese summary: 这次只处理 V180-004。它给“准备撤哪一笔”的预览证据加一道风控门禁。
大白话：必须证明只针对那一笔风险单，symbol 和 account 对得上，owner approval 仍然是必需的；
它不会真正撤单，不会触网，不会重试、批量撤单或打开 Dashboard 撤单按钮。

## Fail-Closed Requirements

The gate blocks if the preview is not ready, if required CLI confirmations are
missing, if symbol/account scope does not match, if the preview has unresolved
source issues, or if any forbidden request/control marker is true:

```text
multi_order_cancel_requested
cancel_all_requested
bulk_cancel_requested
strategy_driven_cancel_requested
retry_requested
replace_or_amend_requested
flatten_requested
dashboard_cancel_requested
```

The verifier also asserts the broader no-send/no-network boundary:

## Behavior Impact

- Produces a local/offline JSON evidence artifact only.
- Requires explicit `--expected-symbol` and `--expected-account-label`.

  release tag metadata.
