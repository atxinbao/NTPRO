# V070-005 Evidence - Dashboard read-only V07 probe artifact display

Date: 2026-06-15
Executor: Codex

## Task

V070-005 - Display V07 real testnet probe artifacts in Dashboard read-only mode.

## Goal

让本地 Dashboard 能读取并展示 V07 Binance testnet 探测 artifact 的关键字段，同时保持只读边界：

- 不启动 HTTP/WebSocket 探测。
- 不读取环境变量或凭证值。
- 不展示 API key、API secret、listen key、签名或原始凭证值。
- 不增加连接、下单、撤单、改单或生产交易控制。

## Files Changed

- `crates/cli/src/dashboard.rs`

## Implementation Summary

- `WorkflowArtifactStatus` 增加 V07 探测展示字段：
  - `network_permission_requested`
  - `probe_status`
  - `probe_latency_ms`
  - `probe_endpoint_class`
  - `probe_error_code`
  - `values_recorded`
  - `secrets_redacted`
  - `websocket_probe_status`
  - `websocket_error_code`
  - `websocket_attempted`
  - `websocket_subscription_attempted`
  - `websocket_message_count`
- Dashboard HTML 的 workflow artifact 表增加“探测”列，展示 HTTP 和 WebSocket artifact 读到的状态。
- 新增本地读取逻辑，只读取 workflow manifest 中声明的这些 artifact：
  - `testnet/connectivity_probe.json`
  - `testnet/credential_policy.json`
  - `testnet/ws_connectivity_probe.json`
- 新增 Dashboard 测试 fixture，证明 V07 字段能被本地 artifact 读取并进入 DTO。
