## Summary

V280-001 defines the v0.28.0 Backend Closure / Product Operations Runtime
Finalization boundary contract and source-controlled readiness matrix. The
matrix classifies dependency proof and the boundary contract as
`runtime-closed`, historical V270/V271 proof as `evidence-only`, V280-002
through V280-008 as `blocked`, and V280-009 release/handoff work as `deferred`.

Plain Chinese summary: 本任务建立 v0.28.0 的 backend closure 边界和 readiness
matrix。它只允许对已经有 evidence path 和 verification command 的条目做后端闭环声明；
blocked、deferred、evidence-only 条目不能被算作 v28 runtime closure。本任务不开放 submit、
订单 mutation、adapter send、live exchange request、retry scheduler、automatic
remediation、Dashboard/Admin 交易控件或 product-grade live trading terminal 声明。
