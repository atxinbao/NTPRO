## Summary

V220-006 adds executable runtime degradation and boundary tests for the
v0.22 Trader Terminal workbench. The tests assert that missing artifacts,
schema mismatch, component unavailable, stale source, redaction breach, and
provenance mismatch never render as healthy while operation controls remain
disabled. They also assert that every forbidden submit/cancel/retry/replace/
amend/flatten/order-ticket boundary flag fails closed individually.

Plain Chinese summary: 本任务补齐 Trader Terminal workbench 的运行时降级和边界
测试。缺 read model、schema 不匹配、组件不可用、来源 stale、redaction breach
或 provenance mismatch 时，workbench 不能显示 healthy，也不能启用任何操作。
任何 submit/cancel/retry/replace/amend/flatten/order-ticket 控制标记出现时，
门禁必须 fail closed。v0.22 仍然是 read-only first，不是产品级实盘交易终端。

## Behavior Impact

The change adds tests and release gate wiring for existing Trader Terminal
read-model runtime boundaries. It does not add operation routes, execution
algorithms, adapter calls, order submission, order cancellation, retry,
replace, amend, flatten, or product-grade live trading claims.

## Public API Impact

None. The change is limited to CLI dashboard tests, local release gate scripts,
workflow gate wiring, and release evidence documentation. No migration note is
required.
