## Summary

V270-003 defines the v0.27.0 persistent operation audit storage foundation. It
adds validator executable replay coverage for append-only audit sink semantics,
storage provenance, actor/role/scope lineage, sequence/hash lineage, redaction,
retention metadata, store/source reconciliation, and forbidden operation
triggers.

Plain Chinese summary: 本任务把 persistent operation audit storage 限定在证据和
runtime observability foundation。audit sink 必须 append-only，storage provenance、
actor/role/scope、sequence/hash lineage、redaction、retention metadata 和 store/source
reconciliation 必须完整；缺 lineage、mutable storage claim、缺 retention metadata、
payload 未脱敏、store/source drift 或任何 remediation/trading/adapter/Dashboard control
触发都会 fail closed。本任务不实现真实数据库，不执行审计动作，也不打开真实交易控制。
