## Summary

V231-004 hardens the v0.23.x release boundary so v0.23.0 is described as
evidence/replay/read-only observability only. It adds a release boundary note,
manifest runtime claim flags, and a v0.23.1 gate that rejects overclaims such
as production multi-node runtime, runtime-integrated execution, or
product-grade terminal readiness.

Plain Chinese summary: 本任务只收紧 v0.23.x 的发布声明和验证 gate。v0.23.0 可以
作为隔离契约、golden replay 和只读观测证据，但不能宣称已经是生产级多节点 runtime、
runtime integrated 执行系统或产品级交易终端。v0.24.0 也不能自动继承这些 runtime
能力。
