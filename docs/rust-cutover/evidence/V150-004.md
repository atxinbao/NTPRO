## Summary

Implemented a v0.15 production live-alpha kill-switch runtime gate. It consumes
the v0.13 kill-switch/manual-approval artifact, v0.14 risk preflight, and v0.15
request preview, then records whether the dry-run chain is allowed to continue.

Plain Chinese summary: 这一步证明 kill switch 不是只写在文档里，而是变成
execution dry-run 之前必须通过的一道本地 gate。开关打开、审批缺失、请求预览
没 ready 都会挡住后续 dry-run progression。

## Behavior Boundary

- New CLI command: `live production-live-alpha-kill-switch-runtime-gate`.
- Artifact schema: `ntpro.v150_live_alpha_kill_switch_runtime_gate.v1`.
- Execution dry-run now requires `--kill-switch-runtime-gate`.
- Closed runtime gates block the execution dry-run artifact before it can route
  to the local dry-run adapter.
