## 实现结果

- 新增 `GET /api/mvp/v1/event-correlation` 独立版本化只读投影；
- 事件 ID 从已验证 identity tuple 的三个独立编码组件和事件类型确定性生成，在同一运行
  实例内稳定且不受字段分隔符影响；动态业务、技术状态和观察时间只从共享状态响应
  读取，关联响应不重复动态事实；
- 响应仅包含无歧义编码的最小稳定身份、事件类型、双门户相对路径与关闭边界；业务
  影响和技术状态由两个门户从各自已验证的共享状态响应展示；
- 两个门户增加二级事件关联面板，不修改一级导航；
- 机构工作台提供“在控制中心查看技术根因”，控制中心提供“在机构工作台查看业务
  影响”；
- 两个方向使用同一个 URL 编码 `event_id` 和 `#event-correlation` 锚点；
- 任一身份、状态、路径、URL 参数或边界不一致时清空旧状态并 fail closed；重复
  `event_id` 参数无论顺序均阻断；
- 原始 Event Store、source path、错误正文、凭证、controls 和动作不进入关联响应。
