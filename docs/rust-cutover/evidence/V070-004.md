# V070-004 Evidence - Optional WebSocket Read-Only Probe Artifacts

Date: 2026-06-15
Executor: Codex
Task: V070-004 - Add optional WebSocket read-only Binance testnet probe artifacts

## Goal

Add a Binance testnet WebSocket read-only probe artifact without turning
WebSocket proof into a default CI or release blocker.

## What Changed

- Added `ntpro.v07_binance_testnet_ws_probe.v1` to the shared CLI/Dashboard
  workflow contract.
- Added `testnet/ws_connectivity_probe.json` to the Binance testnet workflow
  artifact set.
- Increased Binance testnet workflow artifact count from 9 to 10 and event
  count from 7 to 8.
- Added deterministic classified fixture evidence for WebSocket failure codes:
  `timeout`, `dns_error`, `handshake_error`, and `protocol_error`.
- Updated the v06/v07 offline smoke script so default local validation expects
  the WebSocket artifact but still requires `network_attempted=false`.
- Updated README wording to say the WebSocket artifact is manual-only and not a
  CI/release blocker.

## Boundary

This task does not open a WebSocket by default. It does not subscribe to public
or private streams. It does not read or persist credential values. It does not
submit, cancel, replace, amend, or reconcile real orders.

The default artifact records:

- `websocket_probe_gate=manual-online-only`
- `websocket_attempted=false`
- `network_attempted=false`
- `testnet_connection=false`
- `subscription_attempted=false`
- `message_count=0`
- `order_submission=disabled`
- `real_orders_submitted=false`
- `values_recorded=false`
- `secrets_redacted=true`
