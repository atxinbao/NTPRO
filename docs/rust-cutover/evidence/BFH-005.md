## Summary

BFH-005 replaces redundant and unbounded cleanup with explicit build and
generated-output allowlists. No cleanup target selects user-owned local state
or arbitrary Git-ignored content.

Plain Chinese summary: `make clean` 只清理明确的构建和报告输出；更深清理必须先
dry-run 并传入 `FORCE=1`，且仍只删除两个可重建 generated 目录。原来的
`git clean -fxd` 已删除，因此不会再误删 Codex/AgentFlow 状态、本地分析、报告或
大型测试数据。

## Cleanup Matrix

| Class | Paths | `clean` | Guarded generated cleanup | Disposition |
| --- | --- | --- | --- | --- |
| Rust build | `target/`, `target-v2/` | remove | remove through `distclean` | reproducible |
| Package build | `build/`, `dist/` | remove | remove through `distclean` | reproducible |
| Reports | `.coverage*`, `.benchmarks*` | remove | remove through `distclean` | reproducible |
| Generated audit | `release-publication-evidence/` | retain | remove with `FORCE=1` | reproducible |
| Generated analysis | `graphify-out/` | retain | remove with `FORCE=1` | reproducible |
| Local agent state | `.codex/`, `.agentflow/`, `.understand-anything/` | retain | retain | owned by user |
| Local report | `project.html` | retain | retain | owned by user |
| Test data | `tests/test_data/large/`, `tests/test_data/local/` | retain | retain | retained input |
| Other untracked/ignored | any path not listed above | retain | retain | no cleanup authority |
| Global caches | Cargo registry, Git, rustup, OS caches | retain | retain | out of scope |
