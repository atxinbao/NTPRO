# V200-003 Evidence - owner approval lifecycle for submit

Date: 2026-06-29
Executor: Codex
Task: `V200-003` / GitHub issue `#614`
Milestone: v0.20.0

## Summary

V200-003 adds a Rust owner approval lifecycle in `nautilus-risk`. Approval
requests bind digest, scope, owner, expiry, nonce, environment, and strict
release provenance to one production submit candidate. Only active, matching,
unexpired, unrevoked, unconsumed approval evidence can be exported to the
V200-002 pre-submit risk gate shape.

Plain Chinese summary: 这次把 owner approval lifecycle 本地实现出来。approval
只能绑定一笔订单 scope，不能跨订单、跨账户、跨环境复用；过期、撤销、owner 拒绝、
重复消费、digest 不匹配都会被拒绝并输出 evidence。没有 Dashboard approval button、
没有真实下单、没有网络、没有 adapter 调用。

## Behavior Impact

The new lifecycle is a local Rust API and evidence model. It does not persist
approvals and does not wire into live adapter execution. Later submit tasks can
consume only active approved evidence and can pass only active approval
evidence into V200-002's pre-submit risk gate shape.

## Rollback

Revert this PR to remove the V200-003 approval lifecycle API, tests, release
contract, and evidence. V200-006, V200-009, V200-010, V200-011, and V200-012
should remain blocked until a replacement owner approval lifecycle is merged.
