## Plain Chinese Summary

本次把本地 Dashboard 的控制面从 start/stop 扩展到 v0.3.0 需要的六个控制：
start、stop、pause、resume、reconnect data、reconnect execution。

大白话说：Dashboard 现在不只是“看状态”，也能对本地 sandbox 节点发起这些

但用户动作和结果会被本地 API/事件记录下来。

## Behavior Impact

The local Dashboard now exposes the v0.3.0 local supervisor control console
surface for sandbox-only nodes. Reconnect controls intentionally report
`not_supported` for real adapter reconnect capability instead of pretending
production reconnect is available.

## Public API Impact

The local Dashboard HTTP API adds four action endpoints:

- `POST /api/nodes/{node_id}/actions/pause`
- `POST /api/nodes/{node_id}/actions/resume`
- `POST /api/nodes/{node_id}/actions/reconnect_data`
- `POST /api/nodes/{node_id}/actions/reconnect_execution`

`ControlActionStatus` now includes `not_supported`.
