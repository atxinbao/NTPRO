## Plain Chinese Summary

这次把 supervisor 的本地控制能力接到了 `nautilus supervisor` CLI。

大白话说：现在可以用命令行注册本地 sandbox 节点、列出节点、启动节点、
停止节点，并查询节点的 status、connections、execution、risk、logs 和
metrics。所有命令都只走本地 registry 和 artifact 文件，不连接真实交易所，
不提交真实订单，也不做 Dashboard。

这一步不是完整控制台，也不是正式生产 live trading 控制面；它只是 v0.2
“本地多节点 runtime foundation”的命令行入口。

## Goal

Expose user-facing CLI commands for local supervisor controls through registry
and artifact paths.

- `crates/cli/src/opt.rs`

## Behavior Impact

`nautilus supervisor` now exposes local commands:

- `register`
- `list`
- `start`
- `stop`
- `status`
- `connections`
- `execution`
- `risk`
- `logs`
- `metrics`

The commands operate on local registry and artifacts. They do not connect to
external venues or submit orders. The start command launches a local
`ntpro-node` process using the already sandbox-only V02 node path.

## Public API Impact

This adds user-facing Rust CLI commands under `nautilus supervisor`. It does
not add Dashboard UI, HTTP control API, or production live venue controls.

## Migration Note Status

surface work.
