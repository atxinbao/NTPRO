## Summary

V230-005 adds executable Rust replay coverage for multi-node orchestration and
control-plane gating. It proves valid scoped intents remain read-only and
gated, cross-scope route mismatch fails closed, shared approval consumption
fails closed, and missing `isolation_scope_key` fails closed.

Plain Chinese summary: 本任务把 #716 的 orchestration/control-plane gate 落到 Rust
可执行 replay。有效 intent 必须带 `account_key`、`strategy_key`、`venue_node_key`、
`isolation_scope_key`、approval reference、approval consumption scope 和 provenance；
跨 scope routing mismatch、shared approval、缺失 `isolation_scope_key` 都会 fail
closed。本任务不新增实盘 submit、不新增 order mutation、不新增 automatic cancel/
remediation、不新增 Dashboard 操作控件。
