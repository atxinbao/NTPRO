Date: 2026-06-18
Executor: Codex
Task: V090-005 Define and Write Signal Artifact Contract

## Goal

Make Strategy Runtime signals auditable by defining the v0.9 signal JSONL
contract and proving every generated signal contains the required fields.

## Changes

- Added `docs/rust-cutover/release/v0_9_0_signal_artifact_contract.md`.
- Added the signal contract to `docs/rust-cutover/release/README.md`.
- Extended `StrategySignal` with the required public JSONL field
  `generated_at`.
- Kept `generated_at_unix_ms` as an additional numeric helper field.
- Added a regression test that parses every `strategy/signal.jsonl` line and
  verifies required fields:
  - `schema_version`;
  - `session_id`;
  - `strategy_id`;
  - `symbol`;
  - `signal`;
  - `confidence`;
  - `market_event_seq`;
  - `generated_at`.

## Boundary

This task only defines and verifies local strategy signal artifacts. A signal is
not an order intent, order request, exchange API call, Binance testnet order
proof, or production trading claim.

Order intent and risk decision artifacts remain separate V090 tasks.
