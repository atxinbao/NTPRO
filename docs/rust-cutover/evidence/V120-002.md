## Summary

V120-002 extends the existing `live production-account-snapshot-contract`
command with a v0.12 owner-gated manual-online path for Binance production
`GET /api/v3/account`.

The default path remains offline and fail-closed. The manual online path requires
all CLI/env owner gates plus env-only production read-only API credentials before
any network attempt. The output artifact records only bounded metadata such as
status, response shape, latency, and redaction flags.
