Task: V111-004 Harden Dashboard production shadow health
Risk level: medium

## Goal

Harden Dashboard production shadow health so missing required artifacts,
malformed artifacts, schema mismatches, missing counters, and any forbidden
submission/control values are visible degraded states.

Plain Chinese summary: 这次让 Dashboard 更严格。production shadow 只要缺文件、坏
JSON、schema 不对、counter 缺失，或者任意 JSONL 记录里出现生产提交/生产变更/
Dashboard 下单控件，就会降级。它仍然只是本地只读健康检查。

## Files Changed

- `crates/cli/src/dashboard.rs`
  - Adds direct production shadow artifact health audit for the five required
    v0.11 artifacts.
  - Scans every non-empty JSONL record, not only the latest record.
  - Degrades health for missing artifacts, invalid JSON/JSONL, schema mismatch,
    missing required zero counters, missing required false flags, non-zero
    counters, and true control/mutation flags.
  - Adds tests for missing required artifact degradation and all-record JSONL
    boundary scanning.
- `docs/rust-cutover/tasks/V111-004.md`
  - Records the task contract.
- `docs/rust-cutover/evidence/V111-004.md`
  - Records this evidence.

## Behavior Impact

Dashboard production shadow health is stricter and more explicit. It may now
show `Degraded` for artifact sets that were previously shown as healthy when
old logic ignored malformed/missing artifacts or earlier JSONL records.

No production network access, credential read, raw payload persistence, order
submission, order cancel/replace/amend, Dashboard order control, or trading
semantic behavior is added.

## Public API Impact

No new Dashboard fields and no CLI command syntax changes. Existing diagnostic
strings can now include `production_shadow_artifacts_degraded:*` reasons.

## Migration Note

No migration note is required. This is a stricter read-only health classification
for local artifacts.
