## Reachability Findings

- Tardis, HISTDATA, and ITCH Parquet caches are reachable through
  `nautilus-testkit`; ITCH also feeds bounded backtest tests.
- The active Betfair Rust manifest owns 55 existing crate-local fixture paths
  across parser and lifecycle tests.
- The legacy Betfair resource tree has 75 files and 46,515,368 bytes, with no
  active Rust path reference. Its two files above threshold are not
  byte-equivalent to the reduced active crate fixtures, so deletion is not
  authorized.
- The legacy Interactive Brokers resource tree has 10 files and 1,418,795
  bytes, with no active Rust path reference. The large `tick_data.json` remains
  quarantined pending an adapter-owned decision.
- All 14 tracked files above threshold currently have no active Rust consumer.
  Their hashes are fixed, and Git baseline reconstruction remains available.
- `tests/golden/` contains 59 active files and 1,068,211 bytes; no individual
  golden file reaches the threshold.
- Compressed fixtures contain 32 files and 3,086,154 bytes; the largest is
  997,238 bytes, so none requires an individual threshold entry.

## Deletion Decision

```text
size-only deletion = forbidden
live network response as replacement = forbidden
ignored active market-data caches = retain
tracked unreachable large fixtures = retain in quarantine
deduplication or externalization = separate owner issue required
```

Removal requires a deterministic replacement or external artifact, provenance,
license, content hash, complete consumer migration, targeted Rust owner tests,
offline reproducibility, and a passing backend-freeze gate.
