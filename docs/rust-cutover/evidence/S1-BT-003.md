## 交付边界

- `BacktestEngine` 同一次执行现在同时产生不可变 `summary.json` 和 `details.json`；
- `details.json` 投影 fill 级交易、最终持仓和账户余额总权益时间序列，不重新执行回测；
- 动态 Run 清单记录 details SHA-256，公开 Run 使用可空 `result.report_ref`；历史 Run 没有
  明细时保持 metrics-only，不推导文件路径；
- 新增机构用户与运维只读角色可访问的
  `GET /api/product/v1/runs/{run_id}/report`，其他方法返回 405；
- report 读取校验普通文件、nofollow、目录 containment、SHA-256、Run/StrategyVersion、配置、
  数据、时间范围、排序、方向、币种、数量、价格和全部禁止能力；任何漂移均 fail closed；
- OpenAPI、生成 TypeScript/Zod SDK、Product client 和 Run 详情页已同步；页面展示账户权益曲线、
  交易明细和持仓明细，历史 Run 显示明确的“仅汇总”状态；
- 不修改回测撮合与统计语义，不连接外部 Venue，不开放 Demo、Live、真实订单、订单修改、
  自动重试、自动补救或交易控件。
