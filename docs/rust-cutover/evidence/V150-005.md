Executor: Codex
Milestone: v0.15.0

## Summary

Implemented a v0.15 one-time manual approval lifecycle artifact and made it a
required input for production live-alpha request preview. The lifecycle binds
the approval to the exact run, strategy, symbol, notional, and expiry window.

Plain Chinese summary: 这一步不是开放实盘下单，而是给“请求预览”加人工审批门。
审批通过也只能生成本地 dry-run 预览文件；审批过期、撤销、已使用、未批准或字段不匹配
都会挡住 request preview。

## Behavior Boundary

Included:

- New CLI command:
  `live production-live-alpha-manual-approval-lifecycle`.
- Artifact schema:
  `ntpro.v150_live_alpha_manual_approval_lifecycle.v1`.
- Request preview now requires:
  `--manual-approval-lifecycle`.
- Manual approval states:
  `pending`, `approved`, `expired`, `revoked`, and `used`.
- Approval binding to:
  `run_id`, `strategy_id`, `symbol`, `notional`, and expiry.
- Blocked request-preview artifacts for invalid lifecycle states or mismatched
  binding fields.

Not included:

- Production order submission or mutation.
- Cancel, replace, amend, retry, correction, or automatic remediation.
- Network access.
- Execution adapter or production adapter calls.
- listenKey lifecycle.
- Dashboard order controls.
- Durable approval service or UI.
