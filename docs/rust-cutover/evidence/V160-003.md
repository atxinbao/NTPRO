## Summary

V160-003 adds the v0.16 production signing material approval artifact. The
artifact requires an owner-approved `production_live_alpha` request preview and
records approval metadata while keeping API key values, API secret values,
signatures, signed queries, signed URLs, raw request bodies, network access,
production order submission, and Dashboard order controls disabled.

Plain Chinese summary: 已加“生产 signing material 审批单”。大白话：它能证明 owner
批准本次 candidate 使用 env-only 的生产签名材料，但不会把 key、secret、signature、
signed query 或请求体写进文件，也不会发请求、联网或真实下单。即便 signing approval
ready，runtime gate 也只会推进到 `blocked_explicit_send_gate`。
