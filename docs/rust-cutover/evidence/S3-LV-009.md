## 实现证据

- Product API 从已停止且结果冻结的 Demo Run 读取最新订单意图，同时校验 StrategyVersion、
  manifest/result 哈希、风险拒绝和零真实发送；
- 策略意图作为不可变工件写入 Live candidate，三角色审批、最终 admission、Runtime config 和
  execution order state 均绑定其哈希；
- instrument、side、quantity 由来源意图锁定。策略工作台只读展示来源 Demo Run、intent、方向
  和数量，用户仅填写 LIMIT 价格、最大名义金额并明确确认；
- 工作区扫描阻止同一 Demo 结果中的同一 intent 被另一个 Live Run 重放；
- Runtime 在注册执行客户端前回读 `strategy-order-intent.json`，身份、数量、哈希或 schema 漂移
  均 fail closed；订单状态 v3 保留完整来源链；
- 追加订单、改单、自动重试、自动恢复和补偿交易继续关闭。
