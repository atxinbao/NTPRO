## Plain Chinese Summary

本次没有改运行时代码，只把 `pause` / `resume` 的语义正式写清楚。

大白话说：现在的 `pause` / `resume` 只是本地 Supervisor 控制台写
artifact 的状态标记。它不是 `SIGSTOP` / `SIGCONT`，不会冻结进程，也不是
真实交易 runtime 的暂停/恢复。节点 paused 时仍然可以看 status、metrics、
logs、events，也仍然可以 stop；但它不会控制真实 adapter、策略循环、执行
循环或真实订单。

## Semantics Clarification Result

The contract states that current `pause` and `resume` are local artifact-level
Supervisor lifecycle controls. It also states that they are not OS process
suspension, not production runtime suspension, not adapter controls, and not
real order controls.
