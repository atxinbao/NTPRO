## Summary

V280-003 closes the persistent audit storage backend module with a
deterministic runtime artifact and validator replay. The replay accepts
append-only write/read audit records and fails closed for missing storage, stale
audit source, broken lineage, unredacted payload, and forbidden operation
triggers. The v0.28.0 backend closure readiness matrix now records
`persistent_audit_storage_runtime_closure` as `runtime-closed`.

Plain Chinese summary: 本任务把 persistent audit storage runtime closure 推进为可复放的
backend artifact。它只验证审计写读和证据耐久语义；缺 storage、source stale、lineage
断裂、payload 未脱敏或 operation/remediation/trading trigger 都会 fail closed。本任务不实现
真实数据库，不执行订单或自动修复，也不开放 Dashboard/Admin 交易控件。
