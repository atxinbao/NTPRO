# V150-006 Evidence - Dry-run mutation golden traces

Date: 2026-06-22
Executor: Codex
Milestone: v0.15.0
Status: local validation passed; hosted smoke pending PR

## Summary

Added executable golden traces for the production live-alpha mutation dry-run
path. The traces replay rejection and preflight states through the CLI and
prove every case stays local, dry-run only, and mutation-free.

Plain Chinese summary: 这一步补的是“金标准回放证据”。它不是让系统真实下单，而是把
kill switch、审批、风控、网络禁用、Dashboard 控制禁用这些挡板用 trace 固定下来。
每条回放都必须证明生产下单数是 0、生产 mutation 次数是 0、没有联网、没有调用生产
execution adapter。

## Behavior Boundary

Included:

- CLI replay of the nine scoped golden trace cases.
- Release scope registration for all new cases.
- Local and hosted gate wiring for the new replay harness.

Not included:

- Production order submission or mutation.
- Cancel, replace, amend, retry, correction, or automatic remediation.
- Network access.
- Production execution adapter calls.
- listenKey lifecycle.
- Real funds.
- Production trading.
- Dashboard order controls.
