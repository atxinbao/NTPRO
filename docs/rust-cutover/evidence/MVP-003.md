Date: 2026-08-02
Executor: Codex
GitHub issue: #1203
Status: REVIEW_REQUIRED

## 实现结果

- 新增 `ntpro.mvp_identity_contract.v1` Rust 合同；
- 合同固定 `strategy_id`、`strategy_version`、`backtest_run_id`、`node_id`、
  `strategy_instance_id`、`account_id`、`venue_id` 和 `environment` 八类身份，另带
  `backtest_result_ref` 和配置 provenance；
- Supervisor `node_id` 与策略 `strategy_instance_id` 必须不同；
- market/execution Venue 必须一致，环境必须是 `sandbox`；
- `mvp serve` 成功启动后原子写入 `<workspace>/mvp/identity_contract.json`；
- 合同写入失败时，已启动节点会被停止，不留下运行进程；
- read-only、外部 Venue、提交、变更、重试、补救和真实订单边界均显式关闭。
