## Summary

V190-008 adds a read-only Dashboard view for the v0.19 actual-cancel audit
line. The view consumes existing local artifacts for risk gate, owner approval,
single-shot cancel attempt, post-cancel readback reconciliation, and failure
evidence. It does not add a Dashboard cancel button, approval button, retry
button, bulk action, or any executable order/cancel route.

Plain Chinese summary: 这次只给 Dashboard 增加“真实撤单审计只读视图”。大白话：页面只展示
approval、risk gate、真实撤单尝试、venue 响应、readback、最终 outcome 和 audit refs。证据缺失、
schema 不匹配、来源不匹配、unknown readback 或边界违规时不会显示 healthy/recovered；页面和数据模型
不提供撤单、审批、重试或批量操作入口。
