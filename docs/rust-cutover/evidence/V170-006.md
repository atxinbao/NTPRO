Executor: Codex
Milestone: v0.17.0

## Summary

V170-006 adds an offline restart recovery gate that reuses an existing local
order ledger from disk, resumes readback/classification/orphan detection, and
proves no duplicate submit, retry, cancel, or remediation occurs.

Plain Chinese summary: 这个任务证明重启后只读现有证据继续对账。大白话：系统重启后不会重新
发单，不会重试，不会自动撤单；它只读取本地账本继续回查和检测，状态没解决前阻断新单。
