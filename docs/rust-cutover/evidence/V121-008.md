## Summary

V121-008 hardens the v0.12 shadow portfolio runtime artifact by adding an
explicit `notional_preflight` section. Shadow intent notionals are now summed
with `rust_decimal::Decimal` and serialized as string evidence.

Plain Chinese summary: 这次不是新增实盘交易能力。它只是把 shadow portfolio 里的
notional 汇总从容易误解的 `f64` 展示口径，改成 Decimal/string 证据口径，并明确写出
`live_alpha_money_math_ready=false`。也就是说，这个数可以给 Dashboard/审计看，但
不能被当成风控或执行级金额计算来使用。

## Artifact Contract

The v0.12 shadow portfolio runtime now records:

```text
notional_preflight.status=shadow_decimal_string_evidence_only
notional_preflight.aggregation=rust_decimal_string_sum
notional_preflight.f64_aggregation_used=false
notional_preflight.live_alpha_money_math_ready=false
notional_preflight.risk_or_execution_grade=false
```

High precision string evidence is preserved before any future live-alpha work.
The targeted regression test verifies:

```text
0.100000000000000001 + 0.200000000000000002 = 0.300000000000000003
```
