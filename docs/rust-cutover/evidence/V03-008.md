## Plain Chinese Summary

这次给本地 Dashboard 增加了 Runtime Modules 诊断面板。页面现在能按节点显示
LiveNode、NautilusKernel、DataEngine、ExecutionEngine、RiskEngine、Portfolio、
Cache、MessageBus、Logging、Metrics writer 和 Supervisor 这些模块的状态、健康度、
最后可见时间、错误状态和证据来源。

这次没有读取 runtime 内部可变对象，没有展示 actor registry、cache 内容、message-bus
路由表、raw order、raw fill、交易所原始 payload、凭证或签名材料。没有稳定 artifact
的模块会明确显示 `not_supported` 或 `unknown`，并写入 dashboard `gaps`，不会假装健康。

## Implementation Summary

- Added a visible `Runtime Modules` section to the local dashboard page.
- Added `renderRuntimeModules` table rendering in the embedded dashboard JS.
- Expanded runtime module derivation from supervisor/status/metrics/log artifacts.
- Added fixed per-node module rows for:
  - `LiveNode`;
  - `NautilusKernel`;
  - `DataEngine`;
  - `ExecutionEngine`;
  - `RiskEngine`;
  - `Portfolio`;
  - `Cache`;
  - `MessageBus`;
  - `Logging`;
  - `Metrics writer`;
  - `Supervisor`.
- Added explicit `gaps` for unsupported module details and unavailable
  logging/metrics writer artifacts.
- Redacted runtime module last-error values as `present` instead of exposing raw
  error strings in the module panel data.
