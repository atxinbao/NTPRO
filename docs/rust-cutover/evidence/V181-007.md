## Summary

V181-007 adds Dashboard diagnostics regression coverage for the v0.18
preview-only cancel recovery panel. The tests prove that missing artifacts,
schema mismatches, source commit/tag provenance mismatches, stale artifacts, and
forbidden cancel/Dashboard approval flags degrade the panel instead of reporting
`healthy` or `ready`.

Plain Chinese summary: 这次补了 v0.18 Dashboard 撤单恢复只读面板的回归测试。大白话：
只要证据缺失、schema 不对、source commit/tag 对不上、证据过期，或者任何真实撤单 /

violation，不会误报健康。没有新增真实撤单入口，也没有新增 Dashboard 控制按钮。
