## Summary

V210-006 defines the unified risk state projection under the v0.21 read model.
It aggregates account, position, order, and fill component freshness, lineage,
source provenance, and mismatch risks into a read-only risk state with explicit
priority and lifecycle rules.

Plain Chinese summary: 本任务把 account、position、order、fill 的 read model
证据汇总成统一 risk state。它覆盖 healthy、risk_visible、manual_review、halted、
stale、mismatch。缺关键证据、过期来源、血缘不一致或 halted 状态都不能显示为
healthy/audit_closed。它不触发自动交易、不自动修复、不自动平仓，也不新增 Dashboard
操作控件。
