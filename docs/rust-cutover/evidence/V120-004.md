# V120-004 Evidence - Shadow Portfolio Runtime

Date: 2026-06-21
Executor: Codex
Task: V120-004 Implement shadow portfolio runtime

## Summary

V120-004 adds a local-only `live production-shadow-portfolio-runtime` command.
The command builds `shadow_portfolio_runtime.json` from redacted account snapshot
summaries and local `shadow_execution_intent.jsonl`, then optionally writes a
v0.11-compatible `shadow_portfolio_snapshot.json` for existing Dashboard
readers.

Plain Chinese summary: 这次只是把本地 shadow portfolio 证据真正生成出来。它不会连生产
网络，不会下单，不会改交易所状态，也不会保存原始账户响应或余额。

## Non-Mutating Boundary

- No production order submission.
- No production order mutation.
- No automatic correction order.
- No Dashboard order controls.
- No raw account response, balances, permissions, API key, secret, signature,
  signed query, or signed URL persistence.
- No production portfolio parity claim.

## Boundary Evidence

The runtime builder rejects:

- raw account `balances`;
- raw account response fields;
- raw account shape summaries with raw response/balance/permission flags set;
- API key, secret, signature, signed query, or signed URL persistence flags;
- shadow intents with `actual_submission=true`;
- shadow intents with execution adapter, order endpoint, mutation, or Dashboard
  control flags set.

The generated artifact records:

```text
actual_submission_count=0
production_orders_submitted=0
production_order_mutations_attempted=0
automatic_correction_orders_submitted=0
dashboard_order_controls_enabled=false
full_production_portfolio_parity_claimed=false
```
