## Summary

V290-004 promotes identity/permission sources from v0.28 runtime closure to
v0.29 backend production-readiness evidence. The deterministic artifact
validates source configuration, read/admin role mapping, freshness, revocation,
provenance, redaction, lineage, and forbidden trading permission boundaries.

Plain Chinese summary: 本任务把 permission source 提升为 v0.29 backend
production-readiness evidence。验证只允许 read/admin 权限；缺 provenance、permission
stale、revoked subject、role drift、unredacted identity 或 trading permission 打开都会
fail closed。本任务不接入真实 IdP/SSO、不授权 live operation，也不开放任何交易控件。
