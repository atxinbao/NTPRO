## Change Summary

- Added an env-only Binance testnet credential helper.
- Routed testnet workflow credential policy through the helper.
- Added `authenticated_read_only_probe_fail_closed` to the credential-policy
  artifact contract with serde defaults for old artifact compatibility.
- Added redaction-guarded JSON and event artifact writers for Binance testnet
  workflow outputs.
- Added targeted tests for missing-secret fail-closed behavior and synthetic
  secret leak prevention.

## Behavior Impact

Default offline workflow behavior is unchanged. Authenticated read-only probe
readiness is now explicitly fail-closed unless both API key and secret are
present. Artifact writing fails before persistence if a currently loaded env
secret value appears in a Binance testnet artifact body.

## Public API Impact

Additive artifact-schema field:

```text
authenticated_read_only_probe_fail_closed
```

The field has a serde default, so older artifacts remain deserializable.

## Migration Note Status

No user-facing migration is required. This is an additive artifact field and an
internal write guard.
