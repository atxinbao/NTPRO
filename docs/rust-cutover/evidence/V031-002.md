Date: 2026-06-12
Executor: Codex

## Plain Chinese Summary

这次只改 release 验证脚本，不改交易运行时代码。

大白话说：之前 `verify_release.sh` 已经构建了 `target/release` 里的
`nautilus` 和 `ntpro-node`，但后面的 v0.3 supervisor/dashboard smoke 仍然默认看
`target/debug`。这会让 release gate 看起来跑过了 v0.3 smoke，但实际不一定是在
验证 release binary。

现在两个 v0.3 smoke 脚本都支持显式传入 binary 路径。`verify_release.sh` 会把
刚构建出来的 release binary 传给它们；本地开发者不传变量时，仍然保留原来的
debug build/default path 行为。
