# V310-001 Evidence - production enablement boundary and explicit scoped approval contract

Date: 2026-07-13
Executor: Codex
GitHub issue: #1007
Milestone: v0.31.0
Status: PASS

## Summary

V310-001 defines the source-controlled v0.31.0 production enablement boundary
and explicit scoped approval contract. The contract keeps backend production
enablement in candidate/evaluation mode only: missing scoped approval fails
closed, inherited execution authority fails closed, and scoped approval alone
does not authorize runtime execution.

Plain Chinese summary: 本证据证明 v0.31.0 的生产启用边界已经写成可审计合同。
没有 scoped approval 会 fail-closed；任何继承 submit、mutation、adapter send、
live exchange、automatic remediation 或交易控件的尝试会 fail-closed；即使有
scoped approval，也仍必须等待后续 operator/risk/audit/go-no-go/canary/config/
telemetry/release gates。
