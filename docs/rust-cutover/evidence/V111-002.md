# V111-002 Evidence

Date: 2026-06-20
Executor: Codex
Task: V111-002 Add central EndpointClassifier API and deny tests
Risk level: medium

## Goal

Add a central Rust endpoint classifier so production read-only endpoints,
production authenticated account reads, production order mutation surfaces,
sandbox/testnet endpoints, websocket read-only surfaces, and unknown endpoints
cannot be mixed up.

Plain Chinese summary: 这次是加“endpoint 分类闸门”。它只判断 endpoint 类型和是否
允许只读；生产订单相关和未知 endpoint 默认拒绝。它不联网、不下单、不启用
Dashboard 订单控制。

- `Cargo.lock`

  - Routes v0.11 production public read and authenticated account snapshot

## Behavior Impact

The CLI gains a local endpoint-classification helper and deny tests. Existing
v0.11 production read artifacts keep the same public class strings and
fail-closed behavior. No network call, credential read, order submission, order
cancel, order replacement, or trading semantic behavior is added.

## Public API Impact

No external Rust library API or CLI command syntax changes. The classifier is a
private CLI crate module used to keep release artifacts consistent.

## Migration Note

No migration note is required because no external API or artifact schema changes.
