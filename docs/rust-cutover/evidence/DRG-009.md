## 中文总结

本任务把 G8 要求的 trace 从“有 schema / 有计划”推进到“本地 Rust 命令可执行且通过”。

这次新增了三类可执行 trace：

- market data / data source：用 `nautilus-model` 构造并回放 quote、trade、bar、order book delta、instrument status、catalog ordering。
- execution order lifecycle：用 `nautilus-execution` 测试 harness 和 Rust 订单事件构造器回放 submit accept/reject、modify、cancel、triggered fill、partial then filled。
- risk rejection：用真实 `RiskEngine` 在 halted trading state 下回放拒单，验证只产生 denied event，且不转发到 execution。

已有 backtest、live/sandbox、adapter payload trace 没有重写，只接入同一个标准命令继续验证。

## Goal

Promote required v0.2 trace areas into executable passing evidence for:

- backtest;
- live/sandbox lifecycle;
- data source / market data;
- execution order lifecycle;
- risk rejection;
- adapter payload.
