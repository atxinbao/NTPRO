## Source Requirements

The preview is ready only when the source chain proves:

```text
orphan_risk_detected = true
risk_halted = true
new_orders_blocked = true
manual_review_required = true
order_identifier_known = true
```

The command blocks if the orphan detector is clean/non-risk, missing required
manual gates, missing known order identifiers, or records any forbidden marker
for retry, cancel, network, remediation, Dashboard controls, raw exchange data,
API keys, secrets, signatures, signed query, or signed URL.
