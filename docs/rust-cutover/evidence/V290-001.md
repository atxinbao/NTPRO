## Summary

V290-001 defines the v0.29.0 Backend Production Readiness boundary contract and
source-controlled readiness matrix. The matrix classifies dependency proof and
the boundary contract as `production-ready`, historical V280/V281 proof as
`readiness-preview`, V290-002 through V290-009 as `blocked`, and V290-010
release/handoff work as `deferred`.

Plain Chinese summary: 本任务建立 v0.29.0 的 backend production readiness 边界和
readiness matrix。它只允许对已经有 evidence path 和 verification command 的条目做
production-readiness 证据声明；blocked、deferred、readiness-preview 条目不能被算作
v29 production-ready closure。本任务不开放 submit、订单 mutation、adapter send、live
exchange request、retry scheduler、automatic remediation、Dashboard/Admin/Trader
Terminal 交易控件、backend go-live 或 product-grade live trading terminal 声明。
