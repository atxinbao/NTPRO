## 本地环境限制

当前执行沙箱禁止绑定 loopback 端口，并以 `EPERM/SIGABRT` 阻止系统 Chrome headless
启动。因此完整 Dashboard 集中的 4 个既有 HTTP 用例，以及 MVP 集中的 2 个既有
listener 用例，均因 `PermissionDenied` 无法在本地执行；真实浏览器截图也无法生成。
MVP-005/006 的路由合同已改为不绑定端口的 Router service 测试，本地真实执行 GET
响应与 HEAD/POST/PUT/PATCH/DELETE/OPTIONS/CONNECT/TRACE 405 断言。JavaScript
语法和可复现 VM 行为验证也已通过。真实 1440/390 浏览器验收仍保持未完成，不写成
浏览器通过证据；`rust-cutover-smoke.yml` 已登记 hosted browser smoke，使用真实
`nautilus mvp serve`、系统 Chrome 和 Playwright Core 验证成功、HTTP 错误、边界违规、
旧数据清理、宽/窄视口和浏览器错误，并上传截图与 `result.json`。该 hosted job 尚未
执行，当前仍是最终阻塞。

新增测试改变了受控风险扫描统计；已通过同一 canonical scanner 把
`backend_runtime_risk_inventory.json` 从 29,132 / 1,217 更新为 29,289 / 1,221，
production ownership 仍为 2,697，变化仅属于 test / test_inline。
