# V141-004 Evidence - openOrders Empty Response Semantics

Date: 2026-06-22
Executor: Codex

## Summary

V141-004 separates endpoint shape validation from order lifecycle readiness for
production order-state read-only evidence.

Plain Chinese summary: 空的 `openOrders=[]` 是正常的交易所响应，但它只证明“只读接口格式对”，不证明
NTPRO 已经具备真实订单生命周期能力。只有看到非空有效订单条目时，才可以把
`order_lifecycle_readiness` 标成 true。

## Changed

- Added `endpoint_shape_validated`.
- Added `order_entries_observed`.
- Added `non_empty_order_state_observed`.
- Added `order_lifecycle_readiness`.
- Added openOrders empty, non-empty, and invalid-shape tests.
- Updated v14 and v141 order-state evidence verification scripts.
- Updated the v0.14.1 owner evidence contract wording.

## Required Semantics

```text
openOrders=[]
endpoint_shape_validated=true
order_entries_observed=0
non_empty_order_state_observed=false
order_lifecycle_readiness=false

openOrders=[valid order]
endpoint_shape_validated=true
order_entries_observed>=1
non_empty_order_state_observed=true
order_lifecycle_readiness=true

openOrders invalid shape
endpoint_shape_validated=false
order_entries_observed=0
non_empty_order_state_observed=false
order_lifecycle_readiness=false
```

## Not Changed

- No production order submission.
- No production order mutation, cancel, replace, amend, retry, or correction.
- No listenKey lifecycle.
- No Dashboard order controls.
- No automatic remediation.
- No real funds or real orders.
