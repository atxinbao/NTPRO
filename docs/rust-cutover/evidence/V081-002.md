## Scope

Move the v0.8 authenticated Binance testnet read-only proof permission into
the Rust runtime gate so the CLI cannot bypass the manual-online Bash gate.

No trading capability is expanded. This task does not add order submission,
cancel/replace/amend, account mutation, production Binance connectivity, real
funds, production trading, or Dashboard-started probes.

## Changes

- Added Rust runtime recognition for `NTPRO_V08_MANUAL_ONLINE=1`.
- Required that permission in `should_attempt_testnet_authenticated_read_only_probe`.
- Added a regression test proving that with network permission and credentials
  ready, but without the manual-online permission, the authenticated probe stays
  unattempted and records `manual_authenticated_probe_not_enabled`.

## Behavior Impact

Authenticated Binance testnet read-only probe execution now requires all of:

```text
mode = connectivity-probe
network gate = allowed
env-only testnet API key and secret = present
NTPRO_V08_MANUAL_ONLINE = 1
```

Without `NTPRO_V08_MANUAL_ONLINE=1`, the authenticated probe does not send a
signed request and records:

```text
status = authenticated_readonly_probe_manual_not_run
error_code = manual_authenticated_probe_not_enabled
network_attempted = false
testnet_connection = false
```

## Public API Impact

No public API is added. Runtime gating is stricter for an existing manual-only
authenticated read-only proof path.

## Migration Note Status

No migration note required. The release boundary already states authenticated
proof is manual-online-only.
