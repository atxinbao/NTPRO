offline contract readiness, and owner-gated online read allowance are reported
separately.

This task does not add production order submission, order mutation, real funds
handling, production trading readiness, Dashboard order controls, or trading

## Field Contract

```text
endpoint_read_allowed  = classified endpoint is a supported read-only GET surface
offline_contract_ready = offline release contract is ready and no network is opened
online_read_allowed    = owner online gates allow a real read-only GET attempt
read_allowed           = compatibility field, mirrors offline_contract_ready
contract_ready         = compatibility field, mirrors offline_contract_ready
```

## Expected Result

Offline artifacts should keep `read_allowed=true` only when
`offline_contract_ready=true`. Owner-run online artifacts should use
`online_read_allowed=true` while keeping `read_allowed=false` and
`contract_ready=false`.
