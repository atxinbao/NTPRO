Executor: Codex

## Summary

V160-007 adds the v0.16 post-submit order-state readback proof. It consumes the
v0.16 response-redaction artifact, derives only the known `orderId` and
`clientOrderId`, and prepares a bounded `GET /api/v3/order` readback contract.
Default validation stays offline and does not open network.

Plain Chinese summary: 已加“下单后读回订单状态证明”。大白话：它只用前一步响应脱敏
artifact 里已经允许保存的 order id / client order id 去准备 `GET /api/v3/order` 只读回查；
默认不联网、不读交易所。即使 manual-online 读回成功，也只证明“读到了订单状态”，不证明
策略成功，不触发重试、撤单、改单或 Dashboard 下单按钮。

## Boundary

The task intentionally remains readback-only:

```text
no production order submission
no production order mutation
no retry/cancel/replace/amend/flatten
no listenKey lifecycle
no Dashboard order controls
no raw response/header persistence
no strategy success inference
```

Manual online readback is allowed only when all owner CLI gates and v14
read-only env gates are present. The local verifier does not open network.
