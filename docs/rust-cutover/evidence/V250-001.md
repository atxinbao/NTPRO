## Summary

V250-001 defines the v0.25.0 monitoring / observability contract and adds
validator executable replay coverage for the required health, provenance,
freshness, redaction, truth-boundary, and no-side-effect rules.

Plain Chinese summary: 本任务把 v0.25.0 的监控只读合同落到文档、golden trace 和验证器。
只有 runtime/component provenance、freshness、redaction、component health 和
no-side-effect 边界全部完整时才允许 healthy；缺 provenance、stale/partial、redaction
问题、exchange/adapter truth 越界或任何 operation side effect 都会 degraded 或 fail
closed。本任务不新增真实交易执行、自动 remediation、adapter send、live exchange
request、Dashboard 操作控件或产品级交易终端声明。

## Contract Traceability

```text
runtime health = covered by healthy/degraded/fail_closed trace rows
component health = covered by account/orders/fills/risk/order_control_preview checks
freshness = covered by fresh and stale/partial rows
source provenance = required at runtime and component level
redaction = redacted required; breach fails closed
staleness = degraded, never healthy
monitoring truth boundary = exchange truth and adapter runtime truth claims are forbidden
operation side effect boundary = submit/cancel/replace/amend/flatten/retry/remediation/adapter-send/live-request all forbidden
V250 intake dependency proof = v0.24.1 tag must be ancestor of origin/main after v25 starts
```
