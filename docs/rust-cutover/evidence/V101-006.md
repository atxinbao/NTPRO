# V101-006 Evidence

Date: 2026-06-19
Executor: Codex
Task: V101-006 Add release-surface drift guard
Risk level: medium

## Goal

Add a lightweight local and CI-safe guard that catches stale public release
surface wording after a formal `ntpro-rust-only-v*` release. The first guarded
release is `ntpro-rust-only-v0.10.0`.

## Files Changed

- `scripts/ai/check_release_surface_current.sh`
  - Adds a no-network, no-credential release-surface guard.
  - Checks README, ROADMAP, `docs/versioning.md`, release index, current release
    notes, and current readiness report.
  - Defaults to:
    - current release: `v0.10.0`;
    - current tag: `ntpro-rust-only-v0.10.0`;
    - next patch: `v0.10.1`;
    - next capability track: `v0.11.0`.
  - Allows future release automation to override values with environment
    variables.
- `scripts/ai/verify_release.sh`
  - Adds the `release-surface-current-guard` stage and includes it in `all`.
- `.github/workflows/rust-cutover-smoke.yml`
  - Runs the guard on PR smoke.
  - Treats the guard script as a release-verification script so it does not
    trigger heavy Rust checks by itself.
- `.github/workflows/release-tag.yml`
  - Adds the guard to hosted release-tag verification.
- `docs/rust-cutover/evidence/V101-006.md`
  - Records this task evidence.

## Behavior Impact

No runtime behavior changed. The new guard only reads repository files and local
git tag metadata. It does not access the network, credentials, Binance, order
submission paths, or Dashboard controls.

## Public API Impact

No public Rust API change.

No migration note is required.
