## Summary

V251-004 hardens the v25 Dashboard monitoring surface release gate. The verifier
now resolves component `source_ref` values for monitoring, alert, incident,
runbook, and DR preview evidence against repository paths, JSONL case anchors,
Markdown anchors, and v25 release contract refs.

Plain Chinese summary: 本任务把 v25 Dashboard 的 `source_ref` 从“非空字符串”
提升为“可解析引用”。坏路径、坏 JSONL anchor、坏 Markdown anchor、空引用、跨版本引用
都会 fail closed。它没有改变 Dashboard 运行时，也没有新增 submit/cancel/retry/
replace/amend/flatten/order-ticket 控件。
