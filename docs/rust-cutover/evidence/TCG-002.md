# TCG-002 - Rust 1.95.0 工具链统一证据

Date: 2026-08-05
Executor: Codex
GitHub issue: #1234
GitHub PR: #1235
Status: REVIEW_REQUIRED

## 根因

仓库已有 1.95.0 rustup override，但当前登录环境把 `/opt/homebrew/bin` 放在
`$HOME/.local/bin` 之前。Homebrew `cargo/rustc` 不读取 rustup override，因此部分未加载
`toolchain_env.sh` 的治理脚本实际使用 Rust 1.87.0。

## 修复

- `toolchain_env.sh` 从 `rust-toolchain.toml` 读取版本，并要求与 Cargo.toml
  `rust-version` 完全一致；
- 环境变量不能覆盖 canonical 版本；rustc 与 cargo 都必须报告 1.95.0；
- 16 个直接调用 Cargo 的 shell 脚本全部绑定该环境；
- Makefile 默认 Cargo 固定为 `rustup run 1.95.0 cargo`，nightly 与 Miri 继续显式选择各自工具链；
- smoke、performance、release gate 和 release publication workflow 在 checkout 后读取 canonical 版本，不再复制
  `1.95.0` literal；
- `verify_fast.sh` 首先执行 toolchain pin guard；
- 不可跳过的负向测试拒绝环境覆盖、floating stable 和 Cargo.toml 版本不一致；
- workflow 工具链解析启用 `set -euo pipefail`，解析失败时不会回落到 floating stable。
- 最早执行的工具链 guard 仅依赖 runner 基础命令，不要求预先安装 ripgrep。
