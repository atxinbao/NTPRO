## Summary

V200-011 adds local executable golden traces for the v0.20 production order
lifecycle. The fixtures cover submit-before blocking, submit response states,
post-submit readback states, failure/no-retry evidence, and Dashboard read-only
audit consumption. The trace harness proves each case has stable state,
shared evidence refs, no hidden retry, and no raw credential or venue payload
leak.

Plain Chinese summary: 本任务把 v0.20 production order lifecycle 的关键路径做成
可执行 golden trace。覆盖 submit 前 owner approval 缺失阻断、accepted/rejected/
unknown response、readback matched/mismatch/missing、failure/no-retry 和
Dashboard 只读 audit。所有 case 都能从 candidate 追到 response、readback、
failure/audit 和 provenance；fixture 不保存真实 credential 明文，也不启用重试或
Dashboard 下单控件。
