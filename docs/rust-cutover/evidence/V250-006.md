## Summary

Implemented the v0.25.0 Dashboard / Trader Terminal read-only surface for
monitoring, alert, incident, runbook/audit, and DR preview evidence.

Plain Chinese summary: 本次把 v25 monitoring、alert、incident、runbook/audit 和 DR
preview 证据接入 Dashboard / Trader Terminal 的只读 Workbench。页面只显示状态、
provenance、freshness、redaction、ack、runbook evidence 和 DR preview 引用；没有新增
submit/cancel/retry/replace/amend/flatten/order-ticket 控件，也没有 live control API、
adapter send、live exchange request 或生产订单变更。
