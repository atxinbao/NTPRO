# V080-004 Evidence - Authenticated Binance Testnet Read-Only Probe Artifact

Date: 2026-06-16

Task: V080-004 Add authenticated Binance testnet read-only probe artifact

## Plain Chinese Summary

这个任务把 Binance testnet 认证只读账号探测写成了一个可审计 artifact：
`testnet/authenticated_readonly_probe.json`。默认离线和 CI 不需要真实
credentials，也不会联网；只有手动 online gate 打开、环境 opt-in 打开、
并且 env-only testnet API key/secret 都存在时，才会执行
`GET /api/v3/account`。即使执行成功，artifact 也只保存“账号响应 shape
验证通过”这类证明，不保存 raw account body、balances 明细、uid、API key、
secret、header value、signature、signed query 或 signed URL。这个任务没有下单、
没有账户变更、没有生产 Binance、没有真实资金或生产交易。
