# V170-008 Evidence - failure and incident semantics

Date: 2026-06-24
Executor: Codex
Milestone: v0.17.0
Status: local validation PASS; hosted smoke pending PR

## Summary

V170-008 integrates v0.16 production mutation failure semantics into v0.17
reconciliation and orphan-risk incident evidence. The reconciliation classifier
now traces the local ledger's `failure_ref`, records the failure incident
outcome, and the orphan detector carries incident risk halt state.

Plain Chinese summary: 这个任务让 v0.17 对账能理解 v0.16 的失败原因。大白话：失败不是被吞掉
或当成普通成功；系统会把 timeout、HTTP 失败、响应异常、readback mismatch、kill-switch
变化转成清楚的 incident 证据，同时继续禁止重试、撤单和自动补救。

## Evidence Contract

The failure/incident gate proves:

```text
timeout -> timeout_readback_required
http-4xx -> http_4xx_terminal_evidence
http-5xx -> http_5xx_readback_required
malformed-response -> malformed_response_manual_review
readback-mismatch -> readback_mismatch_risk_halt
kill-switch-transition -> kill_switch_transition_halt
readback-mismatch_orphan_outcome = failure_incident_risk_halt
kill-switch-transition_orphan_outcome = failure_incident_risk_halt
retry_attempted = false
cancel_attempted = false
remediation_attempted = false
dashboard_order_controls_enabled = false
```
