## Goal

Expose v0.10 Binance testnet order proof evidence in the local Dashboard as
read-only status and counter fields without adding any order or cancel controls.

## Changes

- Added read-only order proof fields to the Dashboard workflow snapshot DTO.
- Added manifest child artifact parsing for v0.10 risk preflight, order-test,
  execution artifact contract, submit ack, cancel ack, lifecycle, and
  reconciliation artifacts.
- Added a Dashboard workflow table column labelled `订单证明`.
- Added a snapshot test proving read-only order proof fields populate from
  v0.10 artifacts while order/cancel controls remain absent.
- Added `docs/rust-cutover/tasks/V100-009.md`.
- Added `docs/rust-cutover/release/v0_10_0_dashboard_readonly_order_proof.md`.
- Updated `docs/rust-cutover/release/README.md`.
