## Summary

V260-004 defines the v0.26.0 deployment topology and environment provenance
model. It adds validator executable replay coverage for a valid local/dev/
staging/prod-like topology matrix, missing artifact digest, unredacted config,
unknown environment truth, release tag mismatch, and cross-node scope mismatch.

Plain Chinese summary: 本任务把 deployment topology 和 environment provenance
model 落到文档、golden trace 和验证器。环境证据必须包含 environment id、classification、
truth source、release tag、runtime boundary、artifact digest、config provenance 和 node
scope。缺 digest/config provenance/release tag、secret/raw credential/signed payload、
unknown environment truth、tag mismatch 或 cross-node scope mismatch 都会 fail closed。
本任务不部署生产环境，不新增 Kubernetes/Terraform 等系统，也不证明 real-funds production
readiness。
