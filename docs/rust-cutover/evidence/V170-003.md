## Summary

V170-003 classifies local-vs-exchange order state outcomes from one v0.17
exchange readback mapper artifact for a single v0.16 production mutation
candidate lineage.

Plain Chinese summary: 这个任务只做对账分类。大白话：它告诉我们“本地账本”和“交易所只读
回查”之间属于哪一种结果；遇到未知、新单、缺失、本地没发送但交易所看到订单、回查失败，
一律要求人工复核并阻断新单。它不自动撤单、不重试、不修复。

## Outcomes
