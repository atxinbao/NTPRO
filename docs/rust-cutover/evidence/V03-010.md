## Plain Chinese Summary

这次做的是 v0.3 Dashboard MVP 的最终本地验收。大白话说：我加了一个可重复运行的 dashboard smoke 脚本，它会启动本地 sandbox supervisor 节点、打开本地 Dashboard 页面、检查所有要求的面板、用页面按钮启动一个节点并停止另一个节点，然后把浏览器验证结果记录下来。

过程中发现 Dashboard 页面少了明确的 “Logs / Metrics” 面板，移动端也有横向溢出。我在同一个任务里做了小范围修复：补上 Logs / Metrics 面板，并修了移动端宽度约束。没有做 release tag，没有发布 GitHub Release，也没有声明生产交易可用。
