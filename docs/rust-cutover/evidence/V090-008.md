## Goal

Make the local v0.9 Strategy Runtime Foundation auditable by recording lifecycle
events, risk decision events, and a summary artifact.

Plain Chinese summary: 这次补的是本地审计记录。策略 session 现在会写

生命周期事件和 risk decision rejection 事件。它没有接 Binance、没有发订单、没有进入
execution adapter，也不是 testnet 或实盘交易证明。

## Boundary Check

The implementation was reviewed against the v0.9.0 boundary:

- audit events are written to local `strategy/events.jsonl`;
- summary counts are written to local `strategy/summary.json`;
- risk decision events are local audit records only;
- `actual_submission_count` is `0`;
- no submit, cancel, replace, amend, execution adapter, exchange API, or Binance
  testnet call was added.

## Behavior Impact

The demo strategy session now writes:

```text
strategy/summary.json
```

and appends local risk decision rejection events to:

```text
strategy/events.jsonl
```

This is additive local artifact behavior. It does not change live execution,
adapter behavior, exchange order submission, account state, or trading
semantics.

## Public API Impact

Additive Rust CLI crate surface:

- `StrategySessionArtifactPaths.summary`
- `StrategySessionArtifacts.summary`
- `StrategySessionSummary`

No existing public field was removed. No Python, PyO3, Cython, exchange, or
adapter product surface was added.

## Migration Note

No migration is required. This is an additive v0.9.0 artifact contract. Existing
strategy session consumers can ignore the new summary artifact until they need
audit evidence.

## Rollback Plan

Revert the PR. That removes the `StrategySessionSummary` type,
`strategy/summary.json`, local risk decision audit events, release
documentation, and this evidence file while preserving the earlier signal,
order intent, and risk decision artifact contracts.
