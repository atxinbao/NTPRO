# V120-005 Evidence - Persistent Shadow Strategy Session

Date: 2026-06-21
Executor: Codex
Task: V120-005 Add persistent shadow strategy session

## Summary

V120-005 adds a local-only `live production-shadow-strategy-session` command.
The command reads v0.12 `shadow_portfolio_runtime.json`, optionally reads an
existing strategy session status artifact, and writes
`shadow_strategy_session.jsonl` with start, heartbeat, artifact-gap, and stop
events.

Plain Chinese summary: 这次只是把 production shadow 策略会话做成可观察的本地证据流。
它不会连生产网络，不会下单，不会改交易所状态，也不会把 shadow 状态说成交易所真实状态。

## Non-Mutating Boundary

- No production order submission.
- No production order mutation.
- No production order-state read.
- No listenKey lifecycle access.
- No automatic correction order.
- No Dashboard order controls.
- No real orders.
- No exchange-truth claim for shadow values.

## Boundary Evidence

The builder rejects v0.12 shadow portfolio runtime inputs with:

- `actual_submission_count > 0`;
- `production_orders_submitted > 0`;
- `production_order_mutations_attempted > 0`;
- `automatic_correction_orders_submitted > 0`;
- `dashboard_order_controls_enabled=true`;
- `full_production_portfolio_parity_claimed=true`;
- `real_orders_submitted=true`;
- `provenance.values_are_exchange_truth=true`.

The generated event stream records:

```text
production_order_submissions_attempted=0
production_orders_submitted=0
production_order_mutations_attempted=0
production_order_state_reads_attempted=0
listen_key_lifecycle_attempted=0
actual_submission_count=0
automatic_correction_orders_submitted=0
dashboard_order_controls_enabled=false
real_orders_submitted=false
values_are_exchange_truth=false
```

## Behavior Impact

Adds a local artifact-generation surface only. Existing `ntpro-node`,
StrategySession, Supervisor, Dashboard, and production read-only probe behavior
is not changed.

## Rollback

Revert the V120-005 PR. That removes the new CLI subcommand, tests, verification
script, and release/evidence docs without changing existing StrategySession
runtime semantics.
