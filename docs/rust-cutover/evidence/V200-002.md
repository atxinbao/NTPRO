# V200-002 Evidence - pre-submit risk gate

Date: 2026-06-29
Executor: Codex
Task: `V200-002` / GitHub issue `#613`
Milestone: v0.20.0

## Summary

V200-002 adds a Rust pre-submit risk gate in `nautilus-risk`. The gate returns
allow, deny, or blocked evidence before later V200 submit-builder work can
consume a production order intent.

Plain Chinese summary: 这次实现提交前风控门，只判断一笔生产订单意图是否能进入
后续 submit builder。它默认拒绝未知字段、未知账户/venue、缺字段、越限订单、
缺失或过期 approval、缺失 provenance、环境不匹配等情况，并输出稳定 code 和
evidence。没有真实下单、没有网络、没有 adapter submit、没有 retry、没有自动修复、
没有 Dashboard 下单按钮。

## Behavior Impact

The new gate is a local Rust API and evidence model. It does not wire into live
adapter execution in this task, so it cannot submit orders by itself. Later
V200 submit-builder tasks must require an allow evidence artifact from this
gate before constructing any guarded production submit candidate.

## Rollback

Revert this PR to remove the V200-002 gate API, tests, release contract, and
evidence. V200-005, V200-006, V200-011, and V200-012 would remain blocked until
a replacement pre-submit risk gate is merged.
