# V191-007 Evidence - standalone v19 release gate semantics

Date: 2026-06-29
Executor: Codex
Task: `V191-007` / GitHub issue `#610`
Milestone: v0.19.1

## Summary

`V191-007` hardens `scripts/ai/verify_v19_release_gates.sh` so standalone v19
gate runs cannot silently look like release evidence while using
`target/debug/nautilus`. The standalone gate now defaults to
`target/release/nautilus` and builds the release binary when no explicit
`NTPRO_V19_NAUTILUS_BIN` is supplied.

Plain Chinese summary: 这次只修 v19 发版 gate 的证据语义。以前单独跑
`verify_v19_release_gates.sh` 会默认用 debug binary，容易被误读成 release binary
验证。现在默认改成 release binary；如果显式传非 release binary，默认失败。只有明确设置
`NTPRO_V19_ALLOW_LOCAL_SMOKE_ONLY=1` 才允许本地 smoke，并且输出 `local smoke only`，
不能当作 release evidence。

## Gate Boundary

```text
standalone gate = scripts/ai/verify_v19_release_gates.sh
standalone default binary = target/release/nautilus
release dispatcher = scripts/ai/verify_release.sh v19-release-gates
strict provenance gate = scripts/ai/verify_release_strict.sh v19
non-release binary mode = rejected by default
explicit non-release escape = NTPRO_V19_ALLOW_LOCAL_SMOKE_ONLY=1
escape output marker = local smoke only
```
