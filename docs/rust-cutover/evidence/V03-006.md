## Plain Chinese Summary

这次把本地 Dashboard 首页从简单状态卡片扩成了可用的 Overview + Nodes
运维视图。页面现在能直接看到 registry 路径、节点总数、running/stopped/error/stale/unknown
统计、sandbox-only 状态、是否有外部交易所连接、是否提交过真实订单，以及每个节点的
lifecycle、process、pid、config、artifact root、启动/停止/最后切换时间和错误状态。

这次没有新增前端框架，没有做营销页，也没有显示可用的交易控制按钮。start/stop API
仍只是 V03-005 的 unsupported 占位，页面不会把它们展示成可点击交易控制。

## Implementation Summary

- Added `/api/server` metadata endpoint so the UI can show the active supervisor registry path.
- Extended `DashboardNodeSummary` with supervisor process state and pid.
- Rendered Overview from real `DashboardSnapshot` JSON.
- Rendered a dense Nodes table for desktop.
- Added mobile stacked-row rendering for node details, avoiding viewport clipping.
- Redacted visible error content as `present (redacted)` instead of showing raw error payloads.
- Kept unsupported start/stop controls out of the visible UI.
