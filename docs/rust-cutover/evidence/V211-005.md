## Summary

V211-005 connects the local Dashboard snapshot to the canonical unified read
model artifact at `v0_21/unified_read_model_snapshot.json` under each
supervisor node artifact root. The bridge reads the v0.21 contract fields,
source provenance, freshness, component state, blocking reasons, redaction
state, and read-only capability boundary into a new `read_model_runtime`
Dashboard section.

Plain Chinese summary: 本任务让 Trader Terminal 只读 Dashboard 读取真实的
canonical unified read model artifact，而不是只靠 contract/schema/trace 文案证明
foundation。缺 artifact、schema mismatch、stale、component missing、
component_unavailable 都会显示 degraded、stale 或 fail_closed，不会显示 healthy。
所有交易操作控件仍保持 false，不新增下单、撤单、重试、替换、改单、平仓或产品级实盘终端能力。

## Degradation Semantics

```text
missing artifact -> missing_artifact / degraded
schema mismatch -> schema_mismatch / fail_closed
stale freshness -> stale_artifact / stale
component missing -> component_missing / fail_closed
component unavailable -> component_unavailable / degraded
```

The bridge also records a Dashboard gap for any non-healthy read-model runtime
status so missing or invalid evidence remains visible to the operator.

## Behavior Impact

This is a read-only Dashboard/CLI bridge for local artifacts. It does not add
submit, approval, cancel, retry, replace, amend, flatten, automatic repair,
exchange connectivity, account mutation, or product-grade trading terminal
capability.

## Public API Impact

The Dashboard JSON snapshot adds the read-only top-level section
`read_model_runtime`. Existing Dashboard sections and supervisor controls are
unchanged.

## Rollback

Revert this PR to remove the `read_model_runtime` Dashboard section and the
V211-005 release gate. The v0.21 contract and schema artifacts remain intact.
