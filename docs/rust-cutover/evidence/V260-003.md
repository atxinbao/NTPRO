## Summary

V260-003 defines the v0.26.0 operation audit trail and immutable action
evidence model. It adds validator executable replay coverage for a valid audit
event chain, missing actor/lineage/hash evidence, sequence gaps, hash mismatch,
unredacted payloads, and forbidden trading actions.

Plain Chinese summary: 本任务把 operation audit trail 落到文档、golden trace 和验证器。
审计事件必须包含 actor、role、scope、intent、decision、evidence refs、timestamp、
sequence/hash lineage，并且 payload 必须 redacted。缺 actor/lineage/hash、sequence
gap、hash mismatch、secret/raw credential/signed payload、或 submit/cancel/replace/
amend/flatten/adapter-send/live-exchange/retry/remediation/Dashboard control 断言都会
fail closed。本任务不实现外部审计数据库，不执行 operation intent，也不新增 live control API。
