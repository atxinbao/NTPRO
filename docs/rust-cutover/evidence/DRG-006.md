## Code Changes

### Backtest exchange

- Added `ensure_matching_engine` to avoid panicking when a data event arrives for an instrument that is missing from cache and has no matching engine.
- Changed order book delta, order book deltas, depth10, quote tick, trade tick, bar, instrument status, and instrument close handling to log and return instead of panicking.
- Changed matching-engine processing errors from `unwrap()` to error logs.
- Changed trading command processing without an execution client from panic to error log and return.
- Changed missing cached order during `SubmitOrder` processing from `expect()` panic to error log and return.
- Added regression tests for:
  - unknown quote instrument does not panic;
  - command without execution client does not panic;
  - submit order missing from cache does not panic.

### Execution order manager

- Changed missing OTO/OCO/OUO linked order handling from panic to error log and skip/continue.
- Updated panic-oriented doc comments to describe logged skip behavior.
- Added regression tests for missing linked orders in:
  - `handle_contingencies`;
  - `handle_contingencies_update`;
  - `handle_order_filled`.

### Risk engine

- Changed unsupported command fallback in `deny_command` from panic to error log.
- Existing random-command test covers this path.

## Behavior Impact

本任务把已确认的核心产品可达 crash path 从“直接崩进程”改成“记录错误并跳过当前无效输入/缺失状态”。

- 对正常有效数据、正常订单、正常风险检查路径没有预期行为变化。
- 对缺失 instrument 的回测市场数据，当前事件会被忽略并记录错误。
- 对缺失 execution client 或缺失 cached order 的回测交易命令，当前命令会被忽略并记录错误。
- 对缺失 linked child/contingent order 的 execution order manager 路径，缺失项会被跳过，其他可处理项继续执行。
- 对 risk engine 不支持的 command deny fallback，记录错误而不是 panic。

这不是交易语义扩展，也不是 adapter 行为变更。
