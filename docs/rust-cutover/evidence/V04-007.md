## Behavior Impact

- Adds a deterministic local RSI smoke for the v0.4 Binance sandbox path.
- Reuses the same local Binance fixture identity and checksum as EMA.
- Validates the fixed v0.4 RSI sandbox strategy config before producing output.
- Emits deterministic `long` / `flat` threshold signals after warmup.
- Produces a stable summary artifact compatible with the EMA smoke style for later dashboard and readiness work.
- Explicitly stays inside local sandbox boundaries:
  - no external adapter call;
  - no real exchange connection;
  - no real order submission.
- Does not change live trading behavior, backtest engine semantics, risk engine semantics, matching behavior, portfolio accounting, or CLI command behavior.
