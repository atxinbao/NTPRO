## Summary

V220-005 defines the Trader Terminal manual operation entry contract as a
disabled, gated, display-only workbench surface over the existing v0.21.1
canonical Unified Read Model runtime bridge. It exposes intent preview, owner
approval reference, risk decision reference, audit evidence reference, blocked
states, and fail-closed ungated-attempt diagnostics without adding any real
submit, cancel, retry, replace, amend, flatten, or execution-control route.

Plain Chinese summary: 本任务只定义 Trader Terminal 人工操作入口合同。Workbench
可以显示一个 disabled/gated 的操作入口占位，但任何真实操作都必须先绑定 owner
approval、risk gate 和 audit gate。缺审批、缺风控门禁、缺审计证据、read model
stale 或 provenance mismatch 时入口必须 disabled/blocked；任何 ungated attempt
都 fail closed。本任务不实现执行算法、订单控制、真实下单、撤单、重试、改价、
改单或平仓。

## Behavior Impact

The dashboard gains a disabled/gated manual operation entry contract panel. It
does not submit orders, cancel orders, retry orders, replace orders, amend
orders, flatten positions, call execution adapters, connect to venues, or
change runtime trading behavior.

## Public API Impact

None. The change is a CLI dashboard UI/diagnostic surface over local
read-model artifacts. There is no Rust public API change and no migration note
is required.

## Rollback Plan

Revert the PR to remove the operation-entry read-model fields, workbench panel,
tests, and evidence docs. Reverting restores the V220-004 risk/alert/audit/
provenance panel state without altering the published
`ntpro-rust-only-v0.21.1` release or the V220-000 scope decision.
