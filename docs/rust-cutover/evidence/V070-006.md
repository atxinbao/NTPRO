# V070-006 Evidence - Dual gate verification for v0.7 offline and manual online paths

Date: 2026-06-15
Executor: Codex

## Task

V070-006 - Add dual-gate verification for offline default and manual online opt-in.

## Goal

建立 v0.7.0 双门禁验证：

- 默认 gate 保持本地和 CI 离线，不打开网络。
- manual online gate 只有在显式 opt-in 后才运行真实 Binance testnet 只读 HTTP probe。
- 所有路径都保持 `real_orders_submitted=false`、`values_recorded=false`、`secrets_redacted=true`。

## Files Changed

- `scripts/ai/verify_v07_default_offline_gate.sh`
- `scripts/ai/verify_v07_manual_online_gate.sh`
- `docs/rust-cutover/release/v0_7_0_readonly_testnet_boundary.md`

## Implementation Summary

- Added `verify_v07_default_offline_gate.sh`.
  - Unsets `NTPRO_ALLOW_TESTNET_NETWORK`.
  - Runs default dry-run and blocked connectivity-probe.
  - Asserts `network_attempted=false`, `testnet_connection=false`, no real orders, no credential values.
- Added `verify_v07_manual_online_gate.sh`.
  - Default mode proves fail-closed behavior with `--allow-testnet-network` but without the env opt-in.
  - Real online mode requires both:
    - `NTPRO_V07_MANUAL_ONLINE=1`
    - `NTPRO_ALLOW_TESTNET_NETWORK=1`
  - Real online mode runs only the public read-only HTTP testnet probe and asserts `network_attempted=true`.
- Updated v0.7 boundary documentation with exact gate commands and the local/CI vs manual-online split.
