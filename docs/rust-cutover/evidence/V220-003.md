## Summary

V220-003 fills the Trader Terminal workbench order and fill panels with
read-only data from the existing v0.21.1 canonical Unified Read Model runtime
bridge. It surfaces order lifecycle, request digest, attempt ledger, approval,
readback, audit, fill identity, execution identity, order linkage, dedupe,
partial-fill, reconciliation, risk-projection input, provenance, and lineage
diagnostics while preserving the no-operation boundary.

Plain Chinese summary: 本任务只把订单和成交信息接入 Trader Terminal workbench
的只读面板。它展示 order lifecycle、attempt ledger、readback、audit、fill /
execution identity、dedupe、partial fill、missing linkage 和 reconciliation 状态；
unknown response、readback mismatch、duplicate attempt、missing ledger、duplicate
fill、missing linkage 等场景会 degraded 或 fail_closed。面板不会把 schema-only
evidence 标成 runtime exchange truth，也不新增 submit、cancel、retry、replace、
amend、flatten、fill repair、reconciliation repair 或 execution algorithm 操作入口。

## Behavior Impact

The dashboard gains read-only order and fill workbench panels. It does not
submit orders, cancel orders, retry orders, replace orders, amend orders,
flatten positions, repair fills, repair reconciliation, run execution
algorithms, connect to venues, or change runtime trading behavior.

## Public API Impact

None. The change is a CLI dashboard UI/diagnostic surface over existing local
artifacts. There is no Rust public API change and no migration note is required.
