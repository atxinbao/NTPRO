# V080-001 Evidence - Credential Config Contract Split

Date: 2026-06-16
Executor: Codex
Task: V080-001 Migrate credential config contract for public vs authenticated probes

## Plain Chinese Summary

这个任务把 Binance testnet 配置里的凭据要求拆清楚：公开只读探测不需要 API
key，认证只读探测需要 API key/secret 只从环境变量读取。旧的
`required_for_network` 仍然能读，不会破坏 v0.7 配置，但它只作为兼容字段；
新字段优先，并且 artifact 会写出迁移提示。这个任务没有实现联网认证请求，没有下单、
没有账号修改、没有生产 Binance、没有真实资金或生产交易。

## Change Summary

- Added split credential config fields for public and authenticated read-only
  probes.
- Kept legacy `required_for_network` as a readable compatibility field.
- Added credential-policy artifact fields for split probe requirements.
- Added a migration-warning artifact field when the legacy field is present.
- Updated the checked-in Binance testnet dry-run config example.
- Added targeted tests for split-field priority and invalid config rejection.

## Behavior Impact

Public read-only probes remain credential-free. Authenticated read-only probes
remain manual-online-only and env-only. Existing configs using
`required_for_network` still parse, but artifacts now report that the field is
legacy and should be migrated to the split fields.

## Public API Impact

The testnet workflow credential-policy artifact schema gains additive,
serde-defaulted fields:

```text
required_for_public_read_only_probe
required_for_authenticated_read_only_probe
legacy_required_for_network_present
credential_config_migration_warning
```

Old artifacts can still deserialize because the new fields have defaults.

## Migration Note Status

Migration note is included in the artifact through
`credential_config_migration_warning` when `credentials.required_for_network`
is present.
