## Summary

V250-003 defines the incident lifecycle and operator acknowledgement evidence
contract for v0.25.0 and adds validator executable replay coverage for state
transitions, acknowledgement proof, ownership, source alert linkage, audit
trace, lineage, provenance, freshness, redaction, and no-automatic-action
boundaries.

Plain Chinese summary: 本任务把 #780 的 incident lifecycle 和 operator
acknowledgement 落到文档、golden trace 和验证器。incident 必须有 owner、
assignee、source alert、provenance、lineage、audit trace、freshness、redaction
和人工确认；非法状态迁移、缺 owner/source alert、resolved 未确认、stale、泄漏敏感
字段或触发自动操作都会 fail closed。本任务不接入真实工单系统，不自动停策略/撤单/
下单，也不改变交易 runtime。
