## Summary

V210-002 defines the account snapshot read-model component under the v0.21
unified read model. It records account snapshot source provenance, lineage,
freshness, redaction, redacted account summary data, and fail-closed rules for
stale snapshots, missing provenance, and redaction breaches.

划转、账户配置修改、下单权限控制或 Dashboard 操作按钮。
