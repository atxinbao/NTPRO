# SWB-006 - 左侧策略导航与独立策略页面证据

Date: 2026-08-16
Executor: Codex
GitHub issue: #1319
Status: LOCAL_VALIDATION_PASSED / REVIEW_REQUIRED

## 缺陷

- 左侧“策略”栏目没有路由，只显示“当前在总览中选择策略”的禁用提示；
- Router 没有独立策略页面，用户无法从主导航进入策略资源；
- 策略身份、不可变版本、固定参数和三种运行模式只能分散地从总览和 Run 页面理解。

## 修复

- 左侧“策略”改为 `/strategy-workbench/strategies` 正式导航；
- 新增独立只读策略页，复用现有 `useOverviewProductContext`，不增加 API 或数据副本；
- 展示策略目录摘要、当前策略身份、默认不可变版本、固定参数、数据要求，以及
  Backtest、Demo、Live 三种模式的 Run 摘要；
- Product API 验证失败时继续 fail closed，运行源降级时保留已验证的策略目录并明确提示；
- Run 查询未完成或运行源不可用时，数量和生命周期显示为未知，不再误报“来源新鲜”或
  `0 个 Run`；
- 桌面和移动端 production bundle 均验证导航、直达路由、内容区域和无横向溢出。
