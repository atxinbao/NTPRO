## 实现证据

- `ntpro-node` 支持严格的 `production-market-data` 配置模式，固定
  `Environment::Live`、Binance Spot 和环境凭证引用；
- Runtime 只向 `LiveNode` 注册 `BinanceDataClientFactory`，启动后验证 data client connected，
  并断言 execution client 列表为空；
- Product API 新增 `start_market_data`，以外部单调锚点记录 starting/running/stopping/stopped/
  failed，并由 Supervisor 绑定不可变 Run ownership；
- 启动失败会确认进程清理、写入 failed 终态、登记 Supervisor terminal anchor 并释放活动候选；
- OpenAPI、生成 SDK、严格 TypeScript 客户端和策略工作台展示真实 Runtime/行情/进程状态；
- 订单 endpoint、下单、撤改、成交对账、自动重试、自动修复、自动恢复和交易控件保持 false。
