reasons from each required component's lineage, source provenance, and
freshness, derives health from those reasons and component statuses, verifies
the snapshot claims, and requires explicit capability-boundary booleans.

fail-closed redaction evidence before producing their read-only projection.

fields back into the existing deterministic envelope.
