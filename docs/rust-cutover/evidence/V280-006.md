## Summary

V280-006 closes the Admin Workbench backend state bridge module with a
deterministic backend state artifact and validator replay. The replay accepts a
ready read-only bridge, classifies degraded, blocked, and stale component
states, and fails closed for missing components, malformed component state, and
forbidden operation/trading controls. The v0.28.0 backend closure readiness
matrix now records `admin_workbench_backend_state_bridge_closure` as
`runtime-closed`.

Plain Chinese summary: 本任务把 Admin Workbench backend state bridge 推进为可复放的

boundary 状态，验证 ready、degraded、blocked、stale，并在 missing/malformed component
或 operation/trading controls 打开时 fail closed。本任务不实现前端，不开放操作或交易控件，
