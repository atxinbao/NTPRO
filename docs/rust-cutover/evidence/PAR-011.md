## Review

Independent medium-risk review is required before merge. Auto-merge is not
used.

The first hosted smoke exposed a runner-only portability gap: the new register
validator assumed `rg` was installed. The corrective implementation uses
standard `find`, `awk`, and `grep`, and its negative cases use synthetic
fixtures so the hosted gate performs only one full repository scan.

The first independent review found two P2 parser-boundary gaps: commented
attributes and bare conditional `ignore` attributes were not both covered, and
a production signal after a module-closing brace on the same line could inherit
`test_inline` ownership. The corrective scanner shares lexical comment/string
handling across both audits and keeps module declaration/closing lines
conservatively production-owned.
