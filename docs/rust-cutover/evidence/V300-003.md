## Summary

V300-003 records the runtime enablement boundary and controlled feature flag
inventory for the v0.30.0 backend go-live candidate foundation. Runtime
switches are default-disabled, current runtime effects are closed, and any
future movement from preview to enabled requires explicit approval, audit
evidence, and a later scoped enablement issue.

Plain Chinese summary: 本任务把 runtime enablement 和 controlled feature flag
治理落成源控证据。它只建立默认禁用的 inventory 和 fail-closed verifier；任何缺失
approval、缺失 audit evidence、stale provenance、unsupported combination、submit /
mutation / adapter / live-exchange / trading-control flag 都会 fail closed。
