## Summary

V240-008 adds the Dashboard / Workbench read-only order-control preview panel,
render fixture, and release gate for v0.24.0. The panel displays preview status,
blocked reasons, scope, provenance, redaction, and evidence refs for the v24
order-control foundation. It keeps real submit/cancel/replace/amend/flatten,
manual entry, order ticket, live control API, network, adapter, and production
mutation paths out of scope.

Plain Chinese summary: 本任务只新增 Dashboard / Workbench 的 v24 只读预览面板。
它显示 preview 状态、blocked reason、scope、provenance、redaction 和证据引用；
缺 provenance 会 degraded_unavailable，不冒充 ready；forbidden control 只作为
fail-closed 证据显示，不会出现真实操作控件。
