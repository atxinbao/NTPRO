## Summary

Defined the v0.15.1 execution dry-run adapter boundary contract and added
explicit artifact fields proving the only allowed route is:

```text
StrategyIntent -> RiskDecision -> ExecutionCommand -> DryRunExecutionAdapter
```

Plain Chinese summary: 这项把 v0.15 的 dry-run execution 证据说清楚了：
策略意图可以经过风控，生成本地 dry-run 执行命令，但只能到本地 dry-run adapter
证据文件。生产 adapter 不能路由、不能实例化、不能调用。
