## Behavior Impact

Adds manual online behavior to an existing CLI command:

```bash
nautilus live production-public-read-probe --manual-online
```

The default path remains offline and fail-closed. Production network is
attempted only when every v0.12 owner gate is present. No credentials,
authenticated account reads, order endpoints, order mutation, real funds, or
Dashboard action controls are added.

## Public API Impact

No new CLI command. Existing `--manual-online` now has a v0.12 owner-gated
implementation for production public read-only `GET` probes.

## Migration Note

No migration note is required. This fills the previously blocked manual-online
public read path behind new v0.12 owner gates.
