## Plain Chinese Summary

这个任务加了一个离线的 synthetic secret 泄漏扫描。它会用假的 Binance
testnet API key、假的 API secret、假的 signature 跑默认离线 workflow，然后扫描
stdout、stderr、workflow artifacts、临时 dashboard snapshot、日志和 PR evidence
snippet。只要这些假 secret 出现在任何输出里，脚本就 hard fail。

这不是联机认证证明，不使用真实 credentials，不联网，不下单，不改账户，不连生产
Binance，不涉及真实资金或生产交易。
