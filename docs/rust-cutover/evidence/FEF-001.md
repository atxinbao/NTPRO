Playwright artifact 全部通过。失败来自现有 `v33-maintenance-release` 只识别普通提交祖先，
不能识别 GitHub PR 临时 merge checkout；后续空证据上传又产生级联误报。修复后，PR smoke
显式绑定真实 `pull_request.head.sha`，并验证该 head 是 v0.33.0 tag 后代且包含在当前
checkout 中。正式 tag/release workflow 未设置该 PR 专用输入，严格发布绑定保持不变。
若 Actions 的临时 checkout Git 图缺少 tag 到 PR head 的可达关系，PR 专用校验使用
GitHub Compare API 重建；只接受 `merge_base == tag`、`behind_by == 0`、状态为 ahead 或
identical 且最后一个 commit 等于 `pull_request.head.sha` 的响应。无令牌、API 失败或分叉历史均
继续 fail closed。
