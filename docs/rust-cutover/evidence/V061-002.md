## Behavior Impact

- `connectivity-probe` no longer looks like ordinary `dry_run_completed`.
- CLI output and artifacts now distinguish requested probe intent from real
  network activity.
- `--allow-testnet-network` records permission intent only for v0.6.1.
- Network behavior remains unchanged: no socket is opened.
- No real orders are submitted.
- No secret values are read or persisted.

## Public API Impact

Workflow artifact semantics are tightened:

- `summary.json.requested_mode` is added.
- `summary.json.network_permission_requested` is added.
- `manifest.json.summary` carries those same fields.
- connectivity-probe `runtime_status` becomes `offline_probe_validated`.
- CLI `workflow.run` output adds `requested_mode`,
  `network_permission_requested`, and `network_attempted`.

Revert this PR to restore the previous behavior where connectivity-probe was
