## Goal

Add automated v0.9 Strategy Runtime verification so PR and release gates can
prove the local strategy runtime starts, writes Strategy Session artifacts, and
stays inside the shadow/no-order boundary.

## Files Changed

- `scripts/ai/verify_v09_strategy_runtime_smoke.sh`
  - Runs `ntpro-node` with `configs/nodes/btc-ema-shadow.toml`.
  - Verifies Strategy Session, market stream, signal, order intent, risk
    decision, summary, status, and metrics artifacts.
  - Verifies no exchange order identity, no secrets, no external venue
    connection, and no real orders.
- `scripts/ai/verify_v09_shadow_mode_no_order_gate.sh`
  - Runs a dedicated no-order gate.
  - Verifies every order intent has `submission_allowed=false`.
  - Verifies every risk decision has `decision=rejected`,
    `order_submission=disabled`, and `actual_submission=false`.
- `scripts/ai/verify_release.sh`
  - Added `v09-strategy-runtime-smoke`.
  - Added `v09-shadow-mode-no-order-gate`.
  - Added both stages to `all`.
- `.github/workflows/rust-cutover-smoke.yml`
