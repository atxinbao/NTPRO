## Summary

V190-003 adds the v0.19 actual cancel owner approval execution lifecycle. It
creates a local/offline JSON artifact command that can authorize one future
actual cancel attempt only when the owner approval is approved, unexpired,
unused, single-use, and bound to the same V190-002 safety contract, release
manifest, cancel risk gate, order lineage, symbol, account label, and venue.

Plain Chinese summary: 这次把 v0.18 的撤单预览审批升级成 v0.19 的真撤单授权证据。大白话：
approval 只有在 owner 手工批准、没过期、没用过、绑定同一个订单、venue、risk gate 和 release
provenance 时，才会授权后续一个真实撤单尝试；它本身不发送撤单、不联网、不加 Dashboard approve/cancel
按钮。过期、复用、拒绝、审计后、缺 owner 证据、订单/venue/release mismatch 都会 fail closed。
