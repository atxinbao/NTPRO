## Summary

V291-005 hardens the v0.30.0 intake dependency proof. v0.29.0 publication
evidence remains required, but it is not sufficient to start v0.30.0. The new
gate requires exact V291 issue scope `#963-#968`, v0.29.1 release evidence,
v0.29.1 release closeout proof, and fail-closed behavior while any V291 issue
is open or the v0.29.1 release is missing.

Plain Chinese summary: 本任务把 v0.30.0 intake 的前置条件收紧到 v0.29.1 发布证据。
现在 v0.29.0 发布证据不能单独解锁 v0.30.0；只要 `#963-#968` 有任何 issue 未关闭，
或 v0.29.1 release evidence / closeout proof 缺失，v0.30.0 intake 必须 fail closed。它不改变
runtime，也不开放任何真实交易、下单、变更订单、adapter send、live exchange request、retry、
automatic remediation 或交易控件。
