# V091-004 Evidence - Node Session Market Lifecycle Mapping

Date: 2026-06-19
Executor: Codex
Task: V091-004 Correct Node Session Market Lifecycle Mapping
Risk level: high

## Goal

Make node, strategy session, and fixture market states report coherent lifecycle
values after the v0.9.1 strategy runtime boundary work.

## Files Changed

- `crates/cli/src/strategy_session.rs`
  - Added explicit market lifecycle state output for finite fixture/mock streams.
  - Records exhausted fixture/mock input as `exhausted` instead of a running
    stream label.
  - Marks market status as `stopped` during explicit strategy session shutdown.
- `crates/cli/src/live.rs`
  - Reports node data connection as `disconnected` when the strategy node has
    reached `stopped`.
  - Extends the node artifact test to assert final market status is stopped.
- `crates/cli/src/supervisor.rs`
  - Reads `strategy/market_status.json` `state` first and falls back to
    `connection` for older artifacts.
  - Updates fixture expectations from running stream labels to `exhausted`.
- `crates/cli/src/dashboard.rs`
  - Displays the market lifecycle `state` before falling back to legacy
    `connection`.
  - Adds display labels for lifecycle values: `starting`, `running`,
    `exhausted`, `paused`, `stopped`, and `failed`.
- `scripts/ai/verify_v09_strategy_runtime_smoke.sh`
  - Updates hosted v09 smoke assertions to expect final market lifecycle
    `stopped` instead of the old running fixture stream label.

## Behavior Impact

- Exhausted finite fixture/mock market input is no longer shown as a running
  market stream.
- Final node artifacts now align:
  - node lifecycle: `stopped`;
  - node data connection: `disconnected`;
  - strategy session: `stopped`;
  - strategy market status: `stopped`.
- Supervisor and dashboard read the new market `state` field while preserving a
  fallback for older artifacts that only contain `connection`.
- The no-order v0.9.1 boundary is unchanged:
  `external_venue_connection=false`, `real_orders_submitted=false`, and order
  submission remains blocked.

## Public API Impact

No CLI command shape changed. Strategy market status artifacts now include a
`state` field next to `connection`. Existing readers that only look at
`connection` still receive a coherent non-running value for exhausted/stopped
states.

## Migration Note

Consumers should prefer `strategy/market_status.json.state` for lifecycle
display. `connection` remains available as a compatibility field for this
artifact, but dashboard and supervisor now treat `state` as the canonical
runtime lifecycle value when present.
