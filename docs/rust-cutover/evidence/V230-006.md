## Summary

V230-006 adds executable Rust replay coverage and a real Dashboard JavaScript
render smoke for multi-account, multi-strategy, and multi-venue node
observability. It proves read-only aggregation, isolated filtering/drill-down,
cross-scope label mismatch fail-closed behavior, missing identity degradation,
and forbidden operation-control absence.

Plain Chinese summary: 本任务把 #717 的 Dashboard / Workbench observability
边界落到 Rust 可执行 replay 和 renderer smoke。Dashboard 可以只读聚合并按 account、
strategy、venue node、isolation scope 展示和过滤；跨 scope 标签错配会 fail closed；
缺失身份会 degraded unavailable；真实 renderer smoke 证明两条 scoped runtime row 可渲染，
且 21 个操作边界字段全部显式为 `false`。本任务不新增实盘 submit、不新增 order
mutation、不新增 manual operation、不新增 order ticket、不新增 Dashboard 操作控件。
