## Summary

V310-002 records the operator approval, freeze, and change-window lifecycle
required before controlled backend enablement can proceed. Missing approval,
expired approval, revoked approval, release mismatch, active freeze, and
outside-window attempts all fail closed. Approval evidence is immutable,
redacted, and provenance-bound.

Plain Chinese summary: 本证据证明 v0.31.0 的 operator approval / freeze /
change-window lifecycle 已写成可验证合同。它不开放 submit、mutation、adapter send、
live exchange、automatic remediation 或交易控件。
