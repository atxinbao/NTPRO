## Plain Chinese Summary

本次给本地 sandbox Supervisor 增加了 `pause` 和 `resume` 控制。

大白话说：节点启动后，现在可以通过 supervisor 把它标记为 paused，
再 resume 回 running。这个暂停不是系统级 `SIGSTOP`，不会冻结进程；它是
NTPRO 本地 sandbox 控制台自己的应用层状态，用 status、metrics 和 events
artifact 记录。节点 paused 时，底层进程仍保持 running，所以 stop 仍然可以
正常工作。

这次没有接入真实交易所，没有真实下单，没有生产 reconnect，也没有发布
tag 或 GitHub Release。

## Pause/Resume Behavior Proof

- `start_status_stop_process_roundtrip` now proves:
  - start reaches `LifecycleStatus::Running`;
  - pause keeps `SupervisorProcessState::Running`;
  - pause writes `LifecycleStatus::Paused`;
  - pause keeps `external_venue_connection=false`;
  - pause keeps `real_orders_submitted=false`;
  - pause increments metrics `state_transitions_total`;
  - resume writes `LifecycleStatus::Running`;
  - resume records `previous_lifecycle_state=Paused`;
  - events log contains `phase=pause status=ok` and
    `phase=resume status=ok`.
- `stop_accepts_paused_running_process` proves stop still works while the node
  is paused.
- `supervisor_command_handlers_control_fixture_node` proves the CLI command
  handlers can execute pause and resume against the fixture node.
