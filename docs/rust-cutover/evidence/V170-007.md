# V170-007 Evidence - Dashboard reconciliation and orphan panel

Date: 2026-06-24
Executor: Codex
Milestone: v0.17.0
Status: local validation PASS; hosted smoke pending PR

## Summary

V170-007 adds a read-only Dashboard panel for v0.17 reconciliation/orphan
evidence. The panel reads existing artifact files from the local supervisor node
artifact root and surfaces local state, exchange state, lineage, reconciliation
outcome, orphan risk, manual review, new-order blocking, and artifact paths.

Plain Chinese summary: 这个任务把 v0.17 的对账和孤儿单风险展示到 Dashboard。大白话：页面只
看证据，不做交易动作；发现孤儿单风险时让人复核、阻断新单，但不自动撤单、不重试、不修正。
