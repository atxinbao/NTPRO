## Summary

V290-010 adds the v0.29.0 release notes, readiness report, release manifest,
strict provenance, release gates, release surface updates, and v0.30.0 backend
production go-live candidate handoff. It also promotes the final V290 matrix
entry from deferred to production-ready readiness evidence while keeping all
backend go-live and trading boundaries closed.
