## Summary

V200-009 adds local Rust failure and no-retry evidence in `nautilus-risk`. It
normalizes submit-before, submit, response, readback, cancel follow-up, and
audit completion failures into a stable evidence model with category, code,
reason, source evidence pointer, and next allowed action.

Plain Chinese summary: 本任务把 production order lifecycle 的失败处理收敛成
failure / no-retry evidence。每类失败都有稳定 code、中文可解释的 reason 来源、
source evidence 和下一步允许动作。它不会隐式重试、撤单、改单、补单、平仓，不会自动
补救，也不会启用 Dashboard 订单操作控件。

## Behavior Impact

The new model is local Rust evidence logic only. It records terminal failure
evidence and next allowed operator/owner actions without performing any order
mutation, retry, remediation, network I/O, or Dashboard order-control action.

## Public API Impact

New Rust module:

```text
nautilus_risk::v20_failure_no_retry
```

New public entry:

```text
build_failure_no_retry_evidence(request)
```

No Python, PyO3, Cython, CLI, or Dashboard public API is changed.

## Migration Note

No user migration is required. Downstream V200-010 through V200-012 can consume
`FailureNoRetryEvidence` for read-only Dashboard audit, golden traces, and
release gates.
