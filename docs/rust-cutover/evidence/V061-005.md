## Plain Chinese Summary

本任务只加强本地 Dashboard 对 workflow artifact 的健康判断，不连接 Binance、
不下单、不读取真实密钥，也不改变 workflow artifact 的写入格式。

大白话说：以前 Dashboard 看到 `manifest.json` 写着成功，就基本相信它。现在它会
继续检查 manifest 里面列出的子文件：文件要存在，JSON/JSONL 要能解析，
`schema_version` 也要和 manifest 里声明的一致。少文件、坏 JSONL、schema 不一致
都会变成 Dashboard gap，并把这个 workflow 从 healthy 降成 degraded。
