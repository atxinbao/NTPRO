## Plain Chinese Summary

这次做的是“凭证不能落盘”的加固，不是真联网。

大白话说：后续如果要跑 Binance testnet 的可选在线只读 probe，API key
和 secret 只能从环境变量读。artifact 里只能写环境变量名和有没有配置，
不能写真实值。公开只读 probe 不需要凭证；需要凭证的 authenticated
read-only probe 只能走人工 online gate。

这个 PR 不打开 HTTP/WebSocket，不下单，不做生产交易能力声明。

## Goal

Harden the v0.7 Binance testnet credential policy so optional online mode can
distinguish public read-only probes from authenticated read-only probes without
persisting credential values.

## Behavior Impact

Default behavior remains offline. The workflow still does not create HTTP or
WebSocket clients in V070-002.

The credential policy artifact now makes the credential boundary explicit:

- env var names are recorded;
- env var value presence is recorded as booleans;
- credential values are not recorded;
- public read-only probe does not require credentials;
- authenticated read-only probe is manual-online-only.

## Public API Impact

The local workflow artifact contract changes additively for credential policy
and connectivity probe artifacts. The credential policy schema version is bumped
to `ntpro.v07_binance_testnet_credential_policy.v1`.

No Rust crate public API or CLI command shape changes.

## Migration Note

the new additive fields. Existing fields remain present.
