## Summary

V191-004 moves the GitHub Release publication guard default from
`v0.18.0` to `v0.19.0` and adds a dedicated v0.19.0 required-field family.
The guard now verifies the formal `ntpro-rust-only-v0.19.0` GitHub Release,
local release notes, local tag, release URL, draft/prerelease flags,
published timestamp, and reachability from `origin/main`.

Plain Chinese summary: 这次只加强发版校验。大白话：默认 publication guard 现在检查已经发布的
`ntpro-rust-only-v0.19.0`，并确认 GitHub Release body 和仓库内 release notes 都写清楚
v0.19.0 只包含 owner-approved single-shot actual cancel；它不新增下单生命周期、不新增自动或
批量撤单、不新增 Dashboard 撤单按钮，也不删除 v0.18.0 的显式校验支持。

## Remote Release Body Alignment

The first v0.19.0 guard run failed because the live GitHub Release body still
used a shorter release summary and did not include the full formal field
family. The release body was aligned to
`docs/rust-cutover/release/v0_19_0_release_notes.md` with:

```text
gh release edit ntpro-rust-only-v0.19.0 --repo atxinbao/NTPRO --notes-file docs/rust-cutover/release/v0_19_0_release_notes.md
```

This is external release metadata alignment only. It does not change the tag,
release commit, draft/prerelease flags, runtime behavior, order/cancel
behavior, or release assets.
