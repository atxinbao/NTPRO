## Summary

V300-004 records operator approval, freeze, unfreeze, emergency stop, and
change-window lifecycle evidence for the v0.30.0 backend go-live candidate
foundation. Approval is candidate governance evidence only and remains
separate from trading operation authorization.

Plain Chinese summary: 本任务把 operator approval、freeze、change-window 和
emergency stop 生命周期落成源控证据。候选操作缺 approval 或 active change window 会
fail closed；approval 证据不会授权 submit、cancel、replace、amend、flatten、
adapter send、live exchange request 或 automatic remediation。
