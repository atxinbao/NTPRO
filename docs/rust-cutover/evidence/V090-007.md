# V090-007 Evidence - Shadow Risk Decision Gate

Date: 2026-06-18
Executor: Codex
Task: V090-007 Add Shadow-Mode Risk Decision Gate

## Goal

Add a local shadow-mode risk decision gate after order intent generation. Every
v0.9 order intent must receive a risk decision, and every decision must reject
actual submission.

Plain Chinese summary: 这次只是给本地策略意图加了一道“影子风控判断”。每个 order
intent 都会生成一条 risk decision，但结果都必须是 rejected，并且
`actual_submission=false`。它没有接入交易所、没有调用 Binance、没有 testnet 下单，
也不是实盘能力。

## Files Changed

- `crates/cli/src/strategy_session.rs`
  - Added `StrategyRiskDecision`.
  - Added `strategy/risk_decision.jsonl` artifact path.
  - Generated one risk decision per order intent.
  - Defaulted decisions to `decision=rejected`.
  - Defaulted submission to `actual_submission=false`.
  - Recorded explicit rejection reasons for disabled submission, shadow mode,
    and missing account state.
  - Added tests for risk decision artifact shape and rejection rules.
- `docs/rust-cutover/release/v0_9_0_risk_decision_gate.md`
  - Documented the shadow risk decision schema and hard boundary.
- `docs/rust-cutover/release/README.md`
  - Added the risk decision gate to the release document index.
- `docs/rust-cutover/evidence/V090-007.md`
  - Recorded task evidence, validation, impact, and rollback plan.

## Boundary Check

The implementation was reviewed against the v0.9.0 boundary:

- risk decisions are generated from local order intents only;
- `strategy/risk_decision.jsonl` is a local artifact;
- every decision has `decision=rejected`;
- every decision has `actual_submission=false`;
- decisions include rejection reasons and do not include exchange or venue order
  identifiers;
- no submit, cancel, replace, amend, execution adapter, exchange API, or Binance
  testnet call was added.

## Behavior Impact

The demo strategy session now writes:

```text
strategy/risk_decision.jsonl
```

Each line is a JSON object using:

```text
schema_version = ntpro.v09_risk_decision.v1
```

This is additive behavior for the local Strategy Runtime demo path. It does not
change live execution, adapter behavior, exchange order submission, account
state, or trading semantics.

## Migration Note

No migration is required. This is an additive v0.9.0 artifact contract. Existing
strategy session consumers can ignore the new risk decision artifact until they
need shadow risk decision evidence.

## Rollback Plan

Revert the PR. That removes the `StrategyRiskDecision` type, the
`strategy/risk_decision.jsonl` output, release gate documentation, and this
evidence file while preserving the earlier signal and order intent artifact
contracts.
