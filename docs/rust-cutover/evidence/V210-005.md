## Summary

V210-005 defines the fill/execution read-model component under the v0.21
unified read model. It records fill identity, execution identity, order linkage,
quantity/price precision, duplicate detection, partial-fill state, source
freshness, source provenance, and read-only reconciliation state for downstream
risk projection.

Plain Chinese summary: 本任务把成交和执行回报纳入只读 read model。它覆盖
reconciled fill、partial fill、duplicate fill、missing order linkage、stale
execution source、ambiguous source。失败场景必须 fail closed；partial fill 只能
只读展示剩余数量。它不新增执行算法、不自动补单、不自动撤单、不自动修复，也不新增
Dashboard 操作控件。
