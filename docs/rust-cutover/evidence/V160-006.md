Date: 2026-06-23
Executor: Codex
Milestone: v0.16.0
Status: local validation PASS; hosted smoke pending PR

## Summary

V160-006 adds the response redaction contract and artifact builder for the
minimum owner-approved production order mutation candidate. It accepts a
guarded-send artifact plus a synthetic or manually supplied response JSON, then
persists only allowed order metadata and blocks forbidden response material.

Plain Chinese summary: 已加“生产下单响应脱敏合同”。大白话：响应里只允许留下订单
metadata，比如 symbol、side、type、GTC、order id、client order id、status 和时间戳
形状；raw response、headers、key、secret、signature、signed query、signed URL、账户
余额、fills 和任意 payload 都不能落盘。
