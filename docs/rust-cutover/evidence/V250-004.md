## Summary

V250-004 defines the runbook and audit evidence contract for v0.25.0 and adds
validator executable replay coverage for versioned source, input evidence,
manual decision output, audit trace, provenance, lineage, freshness, redaction,
and no-automatic-execution boundaries.

Plain Chinese summary: 本任务把 #781 的 runbook/audit evidence 落到文档、golden
trace 和验证器。每个 runbook step 必须有 version、owner、versioned source、input
evidence、decision output、audit trace、provenance、lineage、freshness 和
redaction；stale、缺 version、缺 audit trace、未经批准的真实 action、敏感字段泄漏或
自动执行边界都会 fail closed。本任务不执行 shell/runbook 自动化，不新增自动 cancel/
retry/remediation，也不改变交易 runtime。
