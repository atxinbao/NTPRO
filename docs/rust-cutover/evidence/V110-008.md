# V110-008 Evidence

Date: 2026-06-20
Executor: Codex
Task: V110-008 Expose read-only production shadow status in Dashboard
Risk level: medium after owner downgrade for automation

## Goal

Expose v0.11 production read-only/shadow evidence in Dashboard as read-only
status fields without adding order controls or credential inputs.

Plain Chinese summary: 这次让 Dashboard 多一个只读的 Production Shadow 表。它只显示
v0.11 本地工件状态和边界计数，比如实际提交次数、生产提交次数、生产变更次数、
Dashboard 下单控件是否启用。它没有新增任何下单、撤单、改单按钮，也没有新增凭证输入。

## Files Changed

- `crates/cli/src/dashboard.rs`
  - Adds `ProductionShadowStatus` to `DashboardSnapshot`.
  - Reads `artifact_root/v0_11` read-only/shadow artifacts when present.
  - Renders a read-only Production Shadow Dashboard table.
  - Adds a targeted test for read-only status population and forbidden controls.
- `docs/rust-cutover/tasks/V110-008.md`
  - Records the V110-008 task contract.
- `docs/rust-cutover/evidence/V110-008.md`
  - Records this evidence.

## Behavior Impact

Dashboard can now display local v0.11 production read-only/shadow evidence when
the artifacts exist. It does not mutate exchange state, connect to production,
submit orders, cancel orders, replace orders, amend orders, or collect
credentials.

## Public API Impact

The Dashboard snapshot JSON gains a read-only `production_shadow` array. No Rust
library API or trading semantics changed.

## Migration Note

No migration note is required because this only adds a read-only Dashboard
status section for new v0.11 artifacts.
