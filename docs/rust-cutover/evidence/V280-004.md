## Summary

V280-004 closes the deployment / upgrade / rollback orchestration backend
module with a deterministic runtime artifact and validator replay. The replay
accepts preview-only deploy, upgrade, rollback, blocked, degraded, and closed
state transitions when owner approval, fresh runbook provenance, and source
provenance are intact. It fails closed for missing approval, stale runbook,
source drift, automatic remediation, production execution, and forbidden
operation boundary opening.

Plain Chinese summary: 本任务把 deployment / upgrade / rollback orchestration 推进为
可复放的 backend artifact。它只验证 preview-only 状态转换、approval、runbook
provenance 和 source drift；缺 approval、runbook stale、source drift、automatic
remediation、production execution 或 operation/trading/control 边界打开都会 fail
closed。本任务不执行真实部署或回滚，不触发自动修复，不访问 adapter/live exchange，也不开放
Dashboard/Admin 交易控件。
