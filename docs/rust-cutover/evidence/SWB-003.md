# SWB-003 - 节点停止后策略目录可读与总览降级收口证据

Executor: Codex

Status: REVIEW_APPROVED / HOSTED_CHECKS_PENDING

## 缺陷复现

- 已注册策略为 `ema_cross_btcusdt_v1` / `v1`；
- 节点进程消失后 Supervisor 正确将 process 标为 `stale`，但节点最后状态仍为 `running`；
- 原 Product API 将静态目录与 `node_status` freshness 绑定，导致策略列表返回
  `product_source_stale`；
- 原前端又把 Run 错误合并为整页错误，因此用户无法区分“没有策略”和“运行源过期”。

## 实现边界

- Strategy/StrategyVersion 继续校验 workspace containment、identity、config projection、版本内容
  hash 和只读边界，但不再依赖运行态 freshness；
- 原 `load_product_source` 保持完整 status contract、node status 与 metrics 校验，所有 Run 和 Live
  调用点不变；
- 异常消失的节点继续是 `stale`，不会被错误收口为正常停止；
- 前端只在 catalog 完整验证后展示策略，Run 错误时清空旧 Run 数据并显示局部降级。
