# P1-004 Evidence - Dev Profile Safety

Date: 2026-06-11
Executor: Codex
Task: P1-004

## Plain Chinese Summary

这次只改 Cargo 开发构建配置，不改交易逻辑。以前默认 `dev` 构建为了快，把 debug assertions 和 overflow checks 关掉了；现在默认开发构建会打开这两个检查，更容易在本地发现越界、溢出和断言问题。如果以后确实要更快的本地构建，可以显式使用 `dev-fast` profile，而不是让默认开发构建静默少检查。

## Goal

Keep default development builds safer by enabling debug assertions and overflow checks, while preserving an explicit opt-in fast profile.

## Files Changed

- `Cargo.toml`
  - Set `[profile.dev] debug-assertions = true`.
  - Set `[profile.dev] overflow-checks = true`.
  - Added `[profile.dev-fast]` inheriting `dev` with those two checks disabled only when explicitly selected.
- `docs/rust-cutover/evidence/P1-004.md`
  - Records this evidence.

## Behavior Impact

Default local development builds now keep debug assertions and overflow checks enabled. This can catch more local bugs and may make some local dev builds slightly slower. Runtime trading semantics are unchanged.

## Public API Impact

No public API change.

## Migration Note Status

No migration note required. Developers who need the old faster behavior can explicitly build with `--profile dev-fast`.

## Rollback Plan

Revert the `Cargo.toml` profile changes and remove this evidence file.
