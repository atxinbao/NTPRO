## Plain Chinese Summary

这次在 `nautilus-live` 里新增了本地节点状态 DTO，没有接 Dashboard，也没有接
control API。

新增 DTO 能表达节点生命周期、连接状态、执行状态、风控状态和快照元数据。
缺失字段不会被伪装成 healthy，而是通过 `unknown`、`not_configured`、
`not_supported`、`stale` 这类状态显式表达。当前映射只从已有 `NodeState`
做 stopped/running/starting/stopping 的基础转换。

没有改交易逻辑、adapter 行为、CLI 命令或真实 live 连接。

## Goal

Add stable Rust DTOs and mapping helpers for local node status snapshots before
V02 supervisor/node implementation tasks begin.

## Changed Files

- `crates/live/src/status.rs`
  - Adds `NodeStatus`, `ConnectionStatus`, `ExecutionStatus`, `RiskStatus`,
    `LifecycleStatus`, `SnapshotValue`, and related enums.
  - Adds mapping from existing `NodeState` into contract lifecycle status.
  - Adds unit tests for stopped/running/unknown mappings and explicit missing
    field serialization.
- `crates/live/src/lib.rs`
  - Exposes the `status` module behind the existing `node` feature.
- `docs/rust-cutover/evidence/V02-003.md`
  - This evidence file.
- `.agentflow/state/task_status.json`
  - V02-003 execution state and previous task closeout state.
- `.agentflow/leases/V02-003.json`
  - V02-003 lease and validation summary.

## Behavior Impact

No runtime behavior changed. The new DTO module provides data structures and
mapping helpers only.

## Public API Impact

`nautilus-live` now exposes `status` DTOs behind the existing `node` feature.
This is an additive Rust API surface for V02 local status snapshots.

No CLI command, adapter behavior, trading semantic, persistence format, or
Dashboard/control endpoint changed.

## Migration Note Status

No migration note is required. This is additive and does not remove or change
