Date: 2026-06-18

Task: V090-003 Add Built-In Demo Strategy Runtime

## Goal

Add a deterministic built-in demo strategy runtime so the v0.9 Strategy Session
can process fixture market bars and produce auditable signal artifacts without
connecting to a venue or submitting orders.

## Changes

- Extended `crates/cli/src/strategy_session.rs` with fixture-driven market bars.
- Added `ema_cross_demo` runtime support through
  `StrategySession::run_ema_cross_demo`.
- Added `strategy/signal.jsonl` to the Strategy Session artifact paths.
- Added `StrategySignal` and `DemoStrategyRuntimeSummary` outputs.
- Added deterministic `ema_cross_demo_fixture_bars` input data.
- Added tests for:
  - signal artifact generation from fixture bars;
  - empty fixture rejection.

## Boundary

This task is limited to a built-in demo strategy over local fixture bars.
It does not connect to Binance, production venues, WebSocket streams, account
state, execution adapters, or any order API.

The runtime records `order_submission_allowed=false`; v0.9.0 remains strategy
runtime foundation only. Binance testnet order submission is deferred to the
v0.10.0 order proof bucket.

## Behavior Impact

Adds an internal deterministic strategy loop that can be reused by later V090
tasks. The loop consumes fixture bars, detects EMA crossovers, writes JSONL
signal artifacts, and stops cleanly.

No CLI command invokes this runtime yet, and no trading-semantic behavior or
adapter behavior changes.

## Public API Impact
