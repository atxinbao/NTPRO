## 实现结论

- Backtest 创建页在策略、Run 列表或本地数据目录失败时提供对应的显式恢复入口；
- Backtest mutation 固定 `retry: false`，失败文案明确不会自动重复提交；提交后不会声称支持
  服务端中途取消；
- 比较页现在区分策略目录验证、Run 列表验证和 Run 来源失败，未验证数据不会降级成空列表；
- Run 深链在顶层身份或来源读取失败时可原地重新加载当前失败层，不会刷新尚未启用的空 ID
  依赖查询；
- 确定性复现仍要求用户勾选确认，失败后只能再次显式提交；取消确认会清除错误和确认状态；
- Roadmap 已把 UPV1-002 标记为 PR #1328 已交付，并把当前任务推进到 UPV1-003。
