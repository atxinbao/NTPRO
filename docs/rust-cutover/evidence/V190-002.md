## Summary

V190-002 defines the v0.19 actual cancel safety contract. It establishes that a
future real cancel path is owner-approved, single-shot, manual-only, and scoped
to one approval, one order, one venue, and one execution attempt. It also
defines the required artifacts and fail-closed failure reasons for missing,
expired, reused, stale, or mismatched evidence.

Plain Chinese summary: 这次只写清 v0.19 真撤单边界。大白话：以后真的撤单也只能 owner
手工批准一次、只撤一个订单、只针对一个 venue、只发送一次；缺批准、批准过期、批准复用、订单或
venue 不匹配、adapter 能力证据缺失、release manifest 不匹配、批量/自动/Dashboard 操作或 retry
请求，全部必须在发送前失败关闭。本 PR 不实现撤单执行器、不改 adapter、不加 Dashboard 操作按钮。
