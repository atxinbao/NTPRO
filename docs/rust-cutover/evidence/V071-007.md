# V071-007 Evidence - Connection Field Clarification

Date: 2026-06-15
Executor: Codex
Task: V071-007 Clarify production/testnet/network connection fields

## Plain Chinese Summary

本任务不新增联网能力，只把 Dashboard 和文档里容易混淆的连接字段说清楚。

大白话：`production_venue_connection` 表示生产交易所连接，v0.7.1 必须一直是
false；`testnet_public_network_connection` 表示 Binance testnet 的公开只读探测成功；
`external_network_attempted` 表示确实尝试过外部网络。这样不会把 testnet 只读探测
误说成真实生产连接。

## Change Summary

- Added explicit connection fields to the Dashboard overview DTO and top-level
  overview tiles.
- Dashboard workflow read-model now derives read-only testnet and external
  network status from probe artifacts when explicit summary fields are absent
  or false in older local artifacts.
- Added tests that prove a successful read-only probe sets Dashboard
  `testnet_public_network_connection=true` and
  `external_network_attempted=true` while keeping
  `production_venue_connection=false`.
- Updated the v0.7 boundary document to require explicit field labels in the
  Dashboard overview and workflow artifact row.
