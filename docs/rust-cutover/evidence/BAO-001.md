## 中文摘要

本任务优化了直接运行 `cargo test` 时的本地构建产物。默认 `test`
profile 继续保留 debug assertions、overflow checks 和 incremental
compilation，但不再生成调试信息，并在产物中剥离 debuginfo。需要 LLDB/GDB
调试时可显式使用新的 `test-debugging` profile。

本任务没有修改 Rust 运行时代码、测试行为、CI workflow、v0.32.0 冻结文件、
交易能力边界、adapter 或持久化格式。

## Measurement Method

Baseline and optimized measurements used the same checkout, toolchain, machine,
package, target, and test filter:

```bash
source scripts/ai/toolchain_env.sh
cargo clean
/usr/bin/time -lp cargo test -p nautilus-cli --lib \
  dashboard::trader_terminal_api::tests -- --nocapture
```

After each cold build, the same command was immediately repeated for the
incremental measurement. Artifact metrics used:

```bash
find target -type f -exec stat -f '%z' {} +  # summed logical bytes
du -sk target                                # APFS disk usage in KiB
find target -type f | wc -l                  # regular file count
```

## Results

| Metric | Baseline | Optimized | Change |
| --- | ---: | ---: | ---: |
| Cold real time | 202.57 s | 167.42 s | -17.35% |
| Incremental real time | 0.84 s | 0.66 s | -21.43% |
| Logical artifact bytes | 6,527,301,189 | 2,655,084,050 | -59.32% |
| APFS disk usage | 5,854,380 KiB | 2,614,908 KiB | -55.33% |
| Regular files | 13,231 | 7,993 | -39.59% |

The artifact reduction is deterministic for these build outputs. Timing is
reported as observed evidence, not a universal performance guarantee; the
second cold build can benefit from operating-system and compiler input caches.
The measured result shows no compile-time regression.

## Full-Debug Profile

The opt-in profile was validated independently:

```bash
cargo test --profile test-debugging -p nautilus-cli --lib \
  dashboard::trader_terminal_api::tests --no-run
```

Result:

```text
pass
real = 193.03 s
target/test-debugging = 5,841,780 KiB
files = 13,228
```

Profile-scoped cleanup was checked with dry-run and real deletion:

```bash
cargo clean --profile test-debugging --dry-run
cargo clean --profile test-debugging
```

Cargo selected and removed only the `test-debugging` output: 13,228 files,
approximately 6.1 GiB logical size. The optimized default cache remained at
2,614,900 KiB and 7,991 files under `target/debug`.

## Behavior Impact

- Routine direct Cargo test builds use materially less local disk space.
- Test assertions, overflow checks, optimization levels, and incremental
  compilation are unchanged.
- Full debugger information remains available through an explicit profile.
- Rust runtime and public API behavior are unchanged.

## Migration Note

No product migration note is required. Developers who need debugger symbols for
tests should add `--profile test-debugging` to the Cargo test command.

## Rollback

`[profile.test-debugging]`, and remove the related testing-guide text. No data
