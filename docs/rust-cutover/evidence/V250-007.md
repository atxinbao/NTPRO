# V250-007 Evidence - SLO freshness and fail-closed diagnostics gate

Date: 2026-07-05
Executor: Codex
GitHub issue: `#784`
Milestone: `v0.25.0`

## Summary

Implemented the v0.25.0 SLO freshness diagnostics gate for the read-only
Dashboard / Trader Terminal monitoring surface.

Plain Chinese summary: 本次新增 v25 diagnostics gate，要求 monitoring、alert、
incident、runbook/audit 和 DR preview 证据具备 freshness threshold、SLO evidence、
staleness reason、diagnostic severity、artifact-only source truth、matched release
provenance 和显式 no-remediation/no-trading action flags。超过 freshness threshold、
缺组件、partial projection、unknown adapter truth、release provenance drift 或 action
flag 都不会显示 healthy，并保持所有交易/恢复动作禁用。

## Behavior impact

- Dashboard now exposes v25 SLO/freshness diagnostics fields.
- Stale source evidence cannot display healthy.
- Unknown source/adapter truth and release provenance drift fail closed.
- Partial projection degrades without a healthy claim.
- Diagnostics evidence cannot enable remediation or trading action flags.
