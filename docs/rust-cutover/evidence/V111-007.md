# V111-007 Evidence

Date: 2026-06-20
Executor: Codex
Task: V111-007 Normalize read_allowed contract fields
Risk level: medium

## Goal

Normalize `read_allowed`, `contract_ready`, `online_execution_supported`,
`network_attempted`, and `account_read_attempted` semantics so offline contracts
cannot be mistaken for live online reads.

Plain Chinese summary: 这次只把 v0.11 artifact 字段说清楚。`contract_ready=true`
代表离线合同就绪；`online_read_allowed=false` 和
`online_execution_supported=false` 继续证明没有开启生产线上读取。

## Files Changed

- `crates/cli/src/live.rs`
  - Adds `contract_ready` and `online_read_allowed` to production public read
    probe artifacts.
  - Adds the same fields to authenticated account snapshot contract artifacts.
  - Keeps existing `read_allowed` as a backward-compatible contract-ready flag.
  - Adds tests for blocked, ready, and manual-online blocked paths.
- `scripts/ai/verify_v11_public_read_probe.sh`
  - Asserts `contract_ready` and `online_read_allowed` in generated artifacts.
- `scripts/ai/verify_v11_authenticated_account_snapshot_contract.sh`
  - Asserts the same fields in blocked, missing-credential, and ready paths.
- `docs/rust-cutover/release/v0_11_0_public_read_probe.md`
  - Documents field semantics.
- `docs/rust-cutover/release/v0_11_0_authenticated_account_snapshot_contract.md`
  - Documents field semantics.
- `docs/rust-cutover/tasks/V111-007.md`
  - Records the task contract.
- `docs/rust-cutover/evidence/V111-007.md`
  - Records this evidence.

## Behavior Impact

v0.11 artifacts become less ambiguous. Existing `read_allowed` remains present,
but new fields distinguish local offline contract readiness from online read
permission.

No production network access, credential value persistence, account mutation,
order submission, order cancel/replace/amend, Dashboard order control, or
trading semantic behavior is added.

## Public API Impact

No CLI syntax change. JSON artifacts gain additive fields:

```text
contract_ready
online_read_allowed
```

## Migration Note

No migration note is required. This is additive artifact semantics hardening.
