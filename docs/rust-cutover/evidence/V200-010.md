## Summary

V200-010 adds a Dashboard snapshot/read-only HTML view for the v0.20 production
order lifecycle audit chain. The view consumes guarded submit candidate,
submit response redaction, submit readback reconciliation, failure/no-retry
evidence, and audit closeout artifacts. It exposes operator-scannable
submit/readback/failure/audit status, risk visibility, diagnostics, and
artifact paths without adding any Dashboard execution controls.

Plain Chinese summary: 本任务把 v0.20 production order lifecycle 的 evidence
串接进 Dashboard 只读视图。operator 可以快速看到 blocked/submitted/
readback_missing/mismatch/audit_closed 等状态。Dashboard 只读消费 evidence，
不提供下单、审批、撤单、重试、改单、补单、平仓按钮；unknown/missing/mismatch
会明确显示为风险，而不是成功。

## Behavior Impact

The Dashboard snapshot now includes `production_order_lifecycle_audit` entries
when v0.20 lifecycle evidence artifacts are present under a node artifact root.
The browser view renders the evidence in a read-only table. Unknown response,
missing readback, readback mismatch, readback failure, cancel-required, and
audit-incomplete evidence are explicitly marked as `risk_visible`.

## Public API Impact

No Python, PyO3, Cython, trading adapter, or production execution API changes.
The local Dashboard JSON snapshot adds a new read-only field:

```text
production_order_lifecycle_audit
```

## Migration Note

No user migration is required. Operators can use the new Dashboard section once
the expected v0.20 JSON evidence files exist under the node artifact root.
