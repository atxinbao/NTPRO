## Summary

V120-007 extends the local Dashboard production shadow read model. Dashboard now
prefers `artifact_root/v0_12` when v0.12 artifacts exist, while preserving the
existing v0.11 read-only artifact path.

Plain Chinese summary: 这次只是让 Dashboard 看懂 v0.12 的 production shadow 本地证据。
它不连生产网络，不读密钥，不下单，不撤单，不改单，也不加 Dashboard 下单按钮。

## Read-Only Fields Added

- artifact version;
- production public read-only probe status;
- authenticated account snapshot status;
- response-shape validation status;
- shadow portfolio runtime status;
- shadow strategy session state and heartbeat count;
- reconciliation classification and recommended local-only action;
- risk-halt, manual-review, and new-order-blocked status;
- production submission/mutation/order-state/listenKey/correction counters.
