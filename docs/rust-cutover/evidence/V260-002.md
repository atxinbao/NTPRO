## Summary

V260-002 defines the v0.26.0 operator permission model and role boundary
evidence. It adds validator executable replay coverage for a valid role matrix,
missing role/scope/provenance, missing required permission, cross-scope
permission, expired approval, role escalation, and forbidden trading controls.

Plain Chinese summary: 本任务把 operator permission model 落到文档、golden trace
和验证器。权限证据只允许 Dashboard / release gate 做只读展示和审计；缺 role、scope、
provenance、缺必需权限、跨 scope、approval 过期、role escalation，或任何 trading
control 打开都会 fail closed。本任务不接入真实 SSO/IAM，不实现生产交易授权，也不改变
owner approval lifecycle 的真实行为。
