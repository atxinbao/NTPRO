## Summary

V161-001 clarifies the v0.16 guarded-send evidence counters. The change keeps
the v0.16 single owner-approved tiny `LIMIT` `GTC` candidate boundary, but makes
the artifact distinguish request attempt, HTTP send attempt, exchange
acknowledgement, exchange order id/status observation, confirmed production
submission, and platform-level production trading semantics.

Plain Chinese summary: 这次只修“证据字段说清楚”。大白话：默认还是不联网、不发单；
如果 owner 手动在线发送并收到 HTTP 2xx ack，artifact 会明确把它算作一次 confirmed
submission，但仍不说 NTPRO 已经变成完整实盘交易平台。
