Task: V110-003 Add authenticated production read-only account snapshot contract
Risk level: medium after owner downgrade for automation

## Goal

Add a v0.11 authenticated production read-only account snapshot contract with
env-only credentials, redacted artifacts, no network access, no account
mutation, and no production order endpoint access.

Plain Chinese summary: 这次只是加“生产认证只读账户快照”的本地契约。它不会联网，
不会保存 API key/secret，不会签名或保存 signed query，不会读取账户，不会访问订单
endpoint，不会下单/撤单/改单，也不会给 Dashboard 增加下单按钮。

## Behavior Impact

Adds a CLI contract command:

```bash
nautilus live production-account-snapshot-contract
```

The command only writes local artifacts. It does not open network connections,
does not sign requests, and does not touch exchange state.

## Public API Impact

CLI surface added under `live`. No Rust library API, trading semantics, order
lifecycle, or adapter runtime behavior changed.

## Migration Note

No migration note is required because this is a new v0.11 CLI contract.
