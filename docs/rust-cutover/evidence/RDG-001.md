## 中文摘要

本任务把 NTPRO 根目录文档从分散的上游、治理、法律、路线图和历史验证入口，收敛
为四个项目级入口：`AGENTS.md`、`README.md`、`project.html` 和
`changelog.html`。非 Markdown 构建配置和 `LICENSE` 不受该入口规则影响。

持续有效的内容按职责迁移，历史内容保留但不再占用当前根目录权威面。Rust
governance 和 shell guard 同步读取新路径，避免仅移动文件却破坏当前发布与冻结
检查。
