## Summary

V190-005 adds the v0.19 actual cancel executor adapter boundary as a
local/offline evidence command. The command binds the V190-003 owner approval
lifecycle to an adapter capability declaration and records the one order / one
venue / one attempt request, response, readback, audit, and failure taxonomy
contract that the later V190-004 actual cancel command must consume.

Plain Chinese summary: 这次补上真撤单前必须经过的 adapter 边界。大白话：后续真正发送撤单
前，必须先证明 owner approval 已授权、adapter 明确支持这个 venue 和 order id 类型的单订单撤单、
只允许一次尝试，并且 request/response/readback/audit contract 都已写入证据。本任务不联网、不发撤单、
不加 Dashboard 按钮、不做 retry 或 bulk cancel。
