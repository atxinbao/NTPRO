## Plain Chinese Summary

本任务让 Dashboard 后端可以读取 v0.5 workflow manifest。

大白话说：Dashboard snapshot 现在会多一个 `workflow_artifacts` 字段。如果本地存在
`runs/workflows/<run-id>/manifest.json`，Dashboard 会把 run id、workflow、manifest
路径、artifact 数量和 sandbox-only 边界读出来。读坏了不会崩，会变成明确的 gap。

这只是只读本地文件，不会启动 workflow，不会连接 Binance，不会提交真实订单。
