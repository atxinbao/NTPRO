## Summary

BPO-003 extracts only command dispatch and loopback HTTP transport from the
two largest CLI modules. The implementation and policy owners remain in the
parent modules.

Plain Chinese summary: 当前改动是纯代码组织调整。`live` 子模块只负责把命令转发给
原函数；dashboard 子模块只负责本地 HTTP 服务和路由。原有只读、fail-closed、
禁止交易控件和 artifact schema 行为不变。
