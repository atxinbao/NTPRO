## 中文摘要

根目录九个 TOML 文件中，`.taplo.toml` 只有 CODEOWNERS 元数据引用，
`.typos.toml` 没有任何活动消费者；Taplo 和 typos 工具也未安装。两者属于上游
遗留配置，可以删除。

其余七个 TOML 均有 Cargo、rustup、Clippy、rustfmt、security workflow、
Makefile 或安装脚本消费者，继续保留。

`rust-toolchain.toml` 原来同时声明自定义 `version = "1.95.0"` 和标准
`channel = "stable"`。仓库脚本读取 version，但 rustup 读取 stable，导致没有
目录 override 时版本可能漂移。本任务改为标准固定 channel，并让脚本读取相同
字段。
