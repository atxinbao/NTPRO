## Summary

V250-005 defines the disaster-recovery preview drill evidence contract for
v0.25.0 and adds validator executable replay coverage for scenario, affected
scope, snapshot refs, expected recovery point, readback refs, audit trace,
operator approval, provenance, snapshot lineage, freshness, redaction, and
no-actual-recovery boundaries.

Plain Chinese summary: 本任务把 #782 的 disaster-recovery preview drill evidence
落到文档、golden trace 和验证器。DR preview 必须带 scenario、affected scope、
snapshot refs、expected recovery point、readback/audit refs、operator approval、
provenance、snapshot lineage、freshness 和 redaction；缺 snapshot、recovery point
stale、scope mismatch、未经批准的 restore、声称 actual execution 或泄漏敏感字段都会
fail closed。本任务不自动重启服务，不执行数据恢复，不修改生产订单或 exchange state。
