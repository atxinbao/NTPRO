## Summary

V270-004 defines the v0.27.0 deployment / upgrade / rollback runtime
orchestration foundation. It adds validator executable replay coverage for
ready preview states, stale environment provenance, missing approval,
tag/source mismatch, failed preflight, unsafe automation requests, and forbidden
operation boundary opening.

Plain Chinese summary: 本任务把 deployment / upgrade / rollback orchestration
限定为 preview-first 状态模型。所有 deploy、upgrade、rollback、post-check 状态都必须
有 fresh environment provenance、owner approval、release gate evidence、rollback plan
lineage 和 execution disabled 边界。环境证据过期、缺 approval、tag/source mismatch、
preflight 失败、不安全自动化请求，或任何 deploy/rollback/remediation/trading/adapter/
Dashboard control 打开都会 fail closed。
