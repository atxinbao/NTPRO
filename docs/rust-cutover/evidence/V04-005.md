## Plain Chinese Summary

这次只做一件事：给 v0.4 的 Binance sandbox 打好一条本地、可重复的行情回放输入。它不会连接真实 Binance，也不会下单，只是把一份提交进仓库的 BTCUSDT 1 分钟 bar fixture 变成 Rust 可以加载、校验和总结的 replay payload，后续 EMA、RSI、mock order、risk 和 dashboard 任务可以复用同一份输入。

本 PR 没有改 CLI 行为、没有改交易语义、没有新增真实交易所连接，也没有把 fixture replay 宣称成生产级市场数据。

## Behavior Impact

- Adds a local Binance fixture replay data source that can be loaded from Rust without network access.
- Validates fixture shape before constructing the replay:
  - required CSV header;
  - six fields per row;
  - strictly increasing timestamps;
  - positive numeric OHLCV fields;
  - at least one bar.
- Produces a stable summary artifact that later v0.4 smokes can consume for diagnostics and dashboard state.
- Does not change order execution, risk, portfolio, matching, live-node startup, or CLI behavior.

## Public API Impact

Public Rust adapter API additions under `nautilus_binance::replay`:

- `load_v04_binance_spot_bar_replay`
- `replay_from_csv`
- `BinanceFixtureReplay`
- `BinanceReplayBar`
- `BinanceReplaySummary`
- v0.4 fixture constants for fixture ID, fixture path, instrument ID, and bar type.

No Python/PyO3/Cython API is added. No CLI command contract is changed in this task.
