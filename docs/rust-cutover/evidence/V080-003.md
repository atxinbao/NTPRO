# V080-003 Evidence - Signed Authenticated GET Request Builder Without Persistence

Date: 2026-06-16
Executor: Codex
Task: V080-003 Implement signed authenticated GET request builder without persistence

## Plain Chinese Summary

这个任务只补 Binance testnet 认证只读请求的“内存构造器”：它可以为
`GET /api/v3/account` 准备 timestamp、recvWindow、签名 query 和
`X-MBX-APIKEY` header，但这些敏感内容只在内存里短暂存在，不写进 artifact、
日志、diagnostic 或 debug 输出。非 GET、非 allowlist endpoint、以及
`/api/v3/order` 这类订单变更端点都会直接失败。这个任务没有联网读取账号、
没有下单、没有生产 Binance、没有真实资金或生产交易。

## Change Summary

- Added an in-memory authenticated read-only request builder for Binance testnet
  `GET /api/v3/account`.
- Reused the existing Binance adapter `SigningCredential` instead of adding a
  new signing implementation.
- Kept API key, API secret, signature, signed query, signed URL, and response
  body out of redacted diagnostics and debug output.
- Added hard-fail checks for non-GET methods, non-allowlisted endpoints, and
  order mutation endpoints.
- Added unit tests for construction, rejection paths, missing-secret fail-closed
  behavior, and redaction.

workflow can prepare an authenticated read-only signed GET request in memory.

API key header value, secret, or response body is persisted.
