## Summary

V290-007 promotes monitoring, alerting, and incident readiness to v0.29 backend
production-readiness evidence. The deterministic artifact validates alert
taxonomy, severity, owner routing, acknowledgement semantics, SLO breach
handling, audit requirements, escalation paths, and manual incident state
transitions without production incident generation.

Plain Chinese summary: 本任务只验证 monitoring/alert/incident readiness evidence；
stale alert source、missing owner routing、missing acknowledgement semantics、
missing audit requirements、unsafe auto-remediation claim 或 forbidden operation
boundary 打开都会 fail closed。SLO breach 只会降级为 manual/audit handoff，不触发
自动 remediation、策略停止或交易动作。
