## 交付边界

- `BacktestEngine` 同一次执行现在产生不可变 `summary.json`、`details.json` 和
  `analysis.json`，新增分析产物不修改既有汇总与明细 v1 合同；
- `analysis.json` 从账户权益序列确定性计算风险摘要和逐点回撤，并从运行边界、权益、成交、
  持仓投影有序结构化事件，不读取或解析终端 stdout；
- 来源链绑定 StrategyVersion 内容、数据、请求配置、summary 与 details 的 URI 和 SHA-256；
  动态 Run 清单记录 analysis SHA-256，历史 Run 通过可空 `analysis_ref` 保持可读；
- 新增机构用户与运维只读角色可访问的
  `GET /api/product/v1/runs/{run_id}/analysis`，其他方法返回 405；
- analysis 读取校验普通文件、nofollow、目录 containment、可信 SHA-256，并独立重算完整风险、
  回撤、事件、来源和禁止边界；任何重新签名后的语义漂移仍 fail closed；
- OpenAPI、生成 TypeScript/Zod SDK、Product client 和 Run 详情页已同步；页面展示风险摘要、
  回撤曲线、结构化运行记录与来源明细，analysis 单独失败不会遮蔽 Run、metrics 或 report；
- 不修改回测撮合、账户与统计语义，不连接外部 Venue，不开放 Demo、Live、真实订单、订单修改、
  自动重试、自动补救或交易控件。
