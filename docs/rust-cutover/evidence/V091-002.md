# V091-002 Evidence - StrategyNode Config Validation

Date: 2026-06-18
Executor: Codex
Task: V091-002 Unify StrategyNode Config Validation

## Goal

Make `config validate --kind strategy-session` and the `ntpro-node` Strategy
Runtime path use the same `StrategyNodeConfig` load and validation contract.

## Files Changed

- `crates/cli/src/config.rs`
  - Removed the separate hand-written `strategy-session` TOML validation path.
  - Routed `ConfigKind::StrategySession` to the `ntpro-node` strategy node
    validation entrypoint.
  - Updated strategy-session validation fixtures to include the fields required
    by the node runtime.
  - Added a multi-symbol rejection regression test.
- `crates/cli/src/live.rs`
  - Added `validate_strategy_node_config_file` as the shared crate-local
    validation entrypoint.
  - Added explicit rejection for multi-symbol strategy configs until the V091
    queue adds support.
  - Kept external venue connection and order submission disabled for the
    v0.9.1 Strategy Runtime path.

## Behavior Impact

- A config accepted by `config validate --kind strategy-session` now uses the
  same parser and validation rules as `ntpro-node`.
- `node.node_id` is required by the shared runtime contract.
- `node.mode` must be `shadow`.
- `execution.order_submission` must be `disabled`.
- `execution.external_venue_connection = true` remains rejected.
- `market.symbols` must contain exactly one symbol for v0.9.1.
- No Binance network connection or real order submission path is enabled.

## Public API Impact

No Rust public API or CLI command shape changed. The validation behavior is
stricter for `config validate --kind strategy-session` because it now matches
the actual `ntpro-node` runtime contract.

## Migration Note

Existing strategy-session configs that passed CLI validation without
`node.node_id`, with `node.mode = "dry-run"`, or with multiple symbols must be
updated before using the v0.9.1 node runtime path. The supported v0.9.1
configuration is a single-symbol shadow strategy session with order submission
disabled.
