## Goal

Make `ntpro-node` a headless Strategy Session runtime host while preserving the
v0.9.0 boundary: strategy runtime only, no exchange order submission, no real
funds, and no production trading.

## Behavior Impact

`ntpro-node` now supports two local node config families:

- existing `live-init-smoke` configs keep the existing sandbox simulated
  execution start/stop smoke;
- new strategy-session configs use local fixture market data, run the built-in
  demo strategy, write signal / order intent / risk decision artifacts, and
  stop with a `stopped` Strategy Session status.

## Public API Impact

No Rust crate public API removal. The `ntpro-node` binary accepts the same
command-line flags and now also accepts the v0.9 strategy-session config shape.

## Migration Note

No user migration is required for existing `live-init-smoke` configs. Users who
want the v0.9 Strategy Runtime Foundation path can start from
`configs/nodes/btc-ema-shadow.toml`.

## Boundary Check

- `external_venue_connection=false`
- `real_orders_submitted=false`
- `order_submission=disabled`
- `order_intent.submission_allowed=false`
- `risk_decision.actual_submission=false`

This PR does not implement Binance testnet order submission, cancel/replace,
amend, production Binance, real funds, production trading, or Dashboard order
controls.

## Rollback Plan

Revert the V090-009 PR. That removes the `ntpro-node` strategy-session branch,
default config, tests, and documents while preserving the existing
`live-init-smoke` node path.
