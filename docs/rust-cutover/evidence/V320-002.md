## Summary

V320-002 records the owner/operator approval, production freeze, and production
change-window closeout lifecycle required before any later backend production
execution path can be considered. Missing approval, expired approval, revoked
approval, wrong owner/operator, release mismatch, scope reuse, active freeze,
and outside-window attempts all fail closed. Approval evidence is immutable,
redacted, source-provenance-bound, and linked to rollback, risk, audit, and
telemetry references.

Plain Chinese summary: 本证据证明 v0.32.0 的 owner/operator approval、production
freeze 和 change-window closeout 已写成可验证合同。它不开放 submit、mutation、
adapter send、live exchange、automatic remediation、frontend completion、
backend go-live 或交易控件。
