## Plain Chinese Summary

这次新增了一个本地 Dashboard HTTP 服务入口。用户可以运行
`nautilus dashboard serve --registry <registry> --bind 127.0.0.1:5173`，
然后打开本地页面查看 supervisor artifact 聚合出来的系统状态。

这次没有接真实交易所、没有提交真实订单、没有实现远程部署，也没有新增
React/Vue/Next/Vite 等前端构建系统。Dashboard 的数据只来自本地
supervisor registry/status/metrics/log artifacts。

## Implementation Summary

- Added `dashboard serve` CLI command.
- Added local loopback HTTP server backed by `axum`.
- Added static embedded dashboard shell at `/` and `/dashboard`.
- Added static embedded CSS and JavaScript assets.
- Static JavaScript escapes local artifact text before rendering it into the
  dashboard shell.
- Added JSON API endpoints:
  - `GET /api/snapshot`
  - `GET /api/nodes`
  - `GET /api/nodes/{node_id}`
  - `GET /api/nodes/{node_id}/metrics`
  - `GET /api/nodes/{node_id}/logs`
  - `POST /api/nodes/{node_id}/actions/start`
  - `POST /api/nodes/{node_id}/actions/stop`
- Start/stop endpoints return explicit unsupported placeholder responses with
  HTTP 501. They do not start or stop a node in V03-005.
- The server rejects non-loopback bind addresses for the v0.3 local MVP.
- Missing registry and invalid/missing node artifacts continue to surface as
  explicit dashboard gaps through the V03-004 aggregator.

## HTTP Endpoint Evidence

The new dashboard test starts an actual local axum server on `127.0.0.1:0`
and verifies:

- `/dashboard` returns HTTP 200 and serves the shell.
- `/api/snapshot` returns HTTP 200 and a `DashboardSnapshot`.
- `/api/nodes/sandbox-a/metrics` returns node metrics.
- `/api/nodes/sandbox-a/actions/start` returns HTTP 501 with an explicit
  unsupported response.

- the embedded local dashboard shell/assets;
- the local JSON API routes;
- the `axum` dependency from `nautilus-cli`.

this server is rolled back.
