## Summary

V220-004 fills the Trader Terminal workbench risk, alerts, audit, and
provenance drill-down panels with read-only data from the existing v0.21.1
canonical Unified Read Model runtime bridge. It surfaces risk priority,
risk-visible/manual-review/halted/stale/mismatch states, alert severity,
missing/stale/schema/redaction/forbidden-control diagnostics, audit evidence
completeness, release provenance, artifact digest, artifact sha, and component
lineage while preserving the no-automatic-action boundary.

Plain Chinese summary: 本任务只把风控、告警、审计和 provenance drill-down 接入
Trader Terminal workbench 的只读面板。它展示 healthy、risk_visible、
manual_review、halted、stale、mismatch 的优先级状态，以及 missing evidence、
stale source、schema mismatch、redaction breach、forbidden control request 的告警
严重度。`audit_closed` 只有在 required components/evidence 和 release
provenance/digest 完整时才保持通过；任何自动修复、自动撤单、自动平仓、retry 或
provenance repair 入口都保持 absent/false。

## Behavior Impact

The dashboard gains read-only risk, alerts, audit, and provenance workbench
panels. It does not submit orders, cancel orders, retry orders, replace orders,
amend orders, flatten positions, repair risk state, repair audit/provenance,
repair fills, repair reconciliation, connect to venues, or change runtime
trading behavior.

## Public API Impact

None. The change is a CLI dashboard UI/diagnostic surface over existing local
artifacts. There is no Rust public API change and no migration note is
required.
