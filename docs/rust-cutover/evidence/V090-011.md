## Behavior Impact

Dashboard snapshots now include a `strategy_runtime` array when a registered
node has local Strategy Session artifacts under `strategy/`.

The Dashboard displays:

- strategy session state;
- strategy ID and session ID;
- symbol;
- market stream status;
- signal count and latest signal;
- latest order intent;
- latest risk decision;
- rejection reason;
- order submission boundary fields;
- local artifact paths.

Nodes without Strategy Runtime artifacts remain valid and render an empty
Strategy Runtime panel.

## Public API Impact

The Dashboard snapshot JSON adds a new top-level field:

```text
strategy_runtime
```

This is a read-only status DTO for local Dashboard consumers. It does not add a
trading API, order route, cancel route, credential input, production connection,
or strategy hot-reload route.

## Migration Note

No migration is required. Existing Dashboard clients can ignore the new
`strategy_runtime` field. v0.9 Strategy Runtime nodes gain read-only visibility
when their local artifacts exist.
