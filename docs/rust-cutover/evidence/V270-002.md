## Summary

V270-002 defines the v0.27.0 external identity and permission integration
foundation. It adds validator executable replay coverage for valid IdP-backed
role mapping, missing IdP provenance, stale role mapping, unknown role,
cross-scope action, v26 permission boundary mismatch, and forbidden trading
permissions.

Plain Chinese summary: 本任务把 external identity / permission integration 限定在
read/admin foundation 证据层。外部 IdP 证据和 role mapping 必须带 provenance、
freshness、redaction、lineage，并且映射到 v26 permission boundary。缺 IdP
provenance、role mapping 过期、未知角色、跨 scope、v26 权限边界不匹配，或任何真实交易/
adapter/Dashboard trading control 权限打开都会 fail closed。本任务不接入真实 SSO/IAM
runtime，也不授权真实操作。
