strategy state, market state, risk state, latest signal, latest rejection, and
artifact paths without adding any trading controls.

## Behavior Impact

Supervisor commands remain read-only. Strategy Session fields are derived from
local `strategy/*` artifacts under the node artifact root.

For nodes without Strategy Session artifacts, supervisor status/log output
continues to work and reports the strategy fields as `none` or `unknown`.

## Public API Impact

The serialized `NodeMetrics` JSON adds defaulted fields:

- `strategy_signal_count`
- `strategy_rejection_count`

Existing metrics artifacts can still be read because the fields have serde
defaults.

## Migration Note

No migration is required. Existing supervisor nodes remain valid. v0.9 Strategy
Runtime nodes gain extra read-only status and metrics fields.
