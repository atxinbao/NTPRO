## 审计发现

- README 的第一产品定位仍是“一个平台、两个门户、一个共享控制平面”；
- `project.html` 与 Roadmap 把远期 Live 和机构平台能力放在当前可用产品之前；
- Backtest 页面必须从已有 Backtest Run 读取 `data_ref` 和 `venue_ref`，无法表达首次使用；
- 当前服务端只支持内置确定性 `synthetic-quotes`，不能描述为真实市场历史数据。

## 实现边界

- 仅在策略、版本和空 Run 列表均已验证时解析首次创建来源；
- Run 查询 pending、stale 或 invalid 时继续 fail closed；
- 不修改后端合同、真实交易能力或冻结发布文件；
- 真实历史数据目录进入后续独立任务。
