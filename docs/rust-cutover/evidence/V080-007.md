## 中文摘要

本任务把 v0.8 authenticated read-only proof 纳入 release/PR 门禁，但默认仍然不联网、
不需要真实 Binance credentials。新增的 authenticated gate 默认只做 preflight：用
synthetic env credentials 证明网络 gate 关闭时不会开 socket、不会泄露 synthetic
secret，也不会产生订单或账户变更。只有显式设置 `NTPRO_V08_MANUAL_ONLINE=1`、
`NTPRO_ALLOW_TESTNET_NETWORK=1` 和真实 Binance testnet env credentials 时，才会跑真实
authenticated read-only `GET /api/v3/account` 证明。

## 修改目标

- 新增 v0.8 authenticated read-only preflight/manual online gate。
- 让 `verify_release.sh` 暴露 v08 default offline 和 authenticated preflight stage。
- 让 GitHub release tag workflow 执行 v08 default/preflight hosted stages。
- 让 PR smoke 在 v08 scripts/docs/config 路径变化时执行 v08 gates。

  - 记录本任务证据。
