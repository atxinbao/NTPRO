# V150-002 Evidence - Live order request dry-run builder

Date: 2026-06-22
Executor: Codex
Milestone: v0.15.0
Status: local validation passed; hosted smoke pending PR

## Summary

Implemented a v0.15 production live-alpha request preview builder. It consumes a
local dry-run order gate artifact and a one-time manual approval lifecycle
artifact, uses the endpoint classifier for `POST /api/v3/order` preview scope,
and writes only redacted request metadata.

Plain Chinese summary: 这一步只是把“未来实盘下单请求的形状”做成本地干跑预览。
它没有发请求，没有调用交易执行 adapter，没有真实下单，也没有把签名、完整 query、
signed URL、key 或 secret 写入文件。

## Behavior Boundary

Included:

- New CLI command: `live production-live-alpha-order-request-preview`.
- Redacted artifact schema: `ntpro.v150_live_alpha_order_request_preview.v1`.
- Required manual approval lifecycle input before ready preview creation.
- Memory-only signing proof when all owner/manual gates and env-only credentials
  are present.
- Zero production mutation counters.

Not included:

- Production request execution.
- Production order submission or mutation.
- Cancel, replace, amend, retry, correction, or automatic remediation.
- listenKey lifecycle.
- Execution adapter or production adapter calls.
- Dashboard order controls.
- Secret, signature, signed query, signed URL, or raw query persistence.
