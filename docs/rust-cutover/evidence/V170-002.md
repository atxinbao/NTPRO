## Summary

V170-002 maps redacted Binance order/openOrders readback metadata into a
normalized exchange order state artifact for one v0.16 mutation candidate
lineage.

Plain Chinese summary: 这个任务只把交易所只读回查结果翻译成统一状态。大白话：它能看懂
NEW、FILLED、CANCELED、REJECTED、missing、malformed、empty openOrders，但还不判断
孤儿单，也不自动撤单或重试。
