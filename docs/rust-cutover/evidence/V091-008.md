# V091-008 Evidence - Surface Strategy Artifact Errors

Date: 2026-06-19
Executor: Codex
Task: V091-008 Surface Artifact Errors In Supervisor And Dashboard
Risk level: medium

## Goal

Make Supervisor and Dashboard show degraded health when Strategy Session
artifacts are missing, corrupt, or internally inconsistent.

## Files Changed

- `crates/cli/src/strategy_session.rs`
  - Added a read-only Strategy Session artifact audit helper.
  - Validates `strategy/manifest.json`, manifest schema, child artifact
    presence, byte lengths, `blake3:` checksums, JSONL record counts, and simple
    node/session/market state conflicts.
- `crates/cli/src/supervisor.rs`
  - Adds `strategy_health`, `strategy_manifest`, and `strategy_diagnostic` to
    `supervisor status` output.
  - Reports missing Strategy Session manifest as degraded instead of silently
    returning unknown values.
- `crates/cli/src/dashboard.rs`
  - Adds Strategy Runtime `health`, `diagnostic`, and `manifest_path` fields.
  - Dashboard table remains read-only and now displays Strategy Runtime health.
  - Adds regression coverage for missing manifest, invalid manifest JSON,
    corrupted child artifact checksum, and node/session state conflict.

## Behavior Impact

- Supervisor and Dashboard now surface degraded Strategy Runtime health for
  broken artifact sets.
- Healthy Strategy Runtime artifacts remain visible as healthy.
- Dashboard remains read-only; no order controls were added.
- No order submission path was enabled; `actual_submission_count=0` remains
  enforced by the v09 strategy runtime smoke.

## Public API Impact

Dashboard Strategy Runtime DTO now includes:

```text
health
diagnostic
manifest_path
```

`supervisor status` output now includes:

```text
strategy_health
strategy_manifest
strategy_diagnostic
```

Existing Strategy Session artifact files and CLI command names are unchanged.

## Migration Note

Consumers should treat `health=degraded` plus `diagnostic` as the owner-visible
indicator that the Strategy Session artifact set needs inspection. This is a
read-only status/reporting change.
