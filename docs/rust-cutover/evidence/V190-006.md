## Summary

V190-006 adds the v0.19 actual-cancel readback reconciliation command. The
command consumes a recorded V190-004 actual cancel attempt plus redacted
post-cancel readback metadata, then emits Dashboard-consumable reconciliation
evidence for venue/order state, fill state, remaining quantity, residual risk,
and local audit state.

Plain Chinese summary: 这次实现真撤单后的回读对账证据。大白话：真实撤单请求发出后，必须再把
交易所状态、订单状态、成交/部分成交、剩余数量、残余风险和本地审计状态对齐并落成证据。
unknown、timeout、partial fill 或不一致状态都会明确标成 degraded/error，不会假装已恢复，也不会触发
第二次撤单、retry 或 Dashboard 操作按钮。
