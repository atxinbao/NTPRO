# V111-003 Evidence

Date: 2026-06-20
Executor: Codex
Task: V111-003 Add production shadow manifest contract
Risk level: medium

## Goal

Add and audit the `v0_11/manifest.json` contract for local production shadow
artifacts.

Plain Chinese summary: 这次给 production shadow 工件加 manifest 清单。它只检查本地
文件是否齐、记录数和 checksum 是否对、有没有越界字段；不联网、不下单、不启用
Dashboard 订单控制。

## Files Changed

- `crates/cli/src/dashboard.rs`
  - Adds the v0.11.1 production shadow manifest schema constant.
  - Adds manifest status, artifact count, and path to the Dashboard production
    shadow DTO and UI table.
  - Audits manifest schema, `generated_at`, artifact count, child file
    existence, checksum, record count, and forbidden payload/secret/mutation
    flags.
  - Adds tests for valid manifest display and checksum mismatch degradation.
- `scripts/ai/verify_v11_offline_release_gates.sh`
  - Runs the full `production_shadow` Dashboard test filter.
  - Includes the manifest contract in v11 release boundary grep checks.
- `docs/rust-cutover/release/v0_11_1_production_shadow_manifest.md`
  - Defines the manifest schema, artifact entries, summary fields, Dashboard
    audit behavior, and forbidden behavior.
- `docs/rust-cutover/tasks/V111-003.md`
  - Records the task contract.
- `docs/rust-cutover/evidence/V111-003.md`
  - Records this evidence.

## Behavior Impact

Dashboard reads `artifact_root/v0_11/manifest.json` when present and degrades
the Production Shadow section if manifest integrity checks fail. If the
manifest is absent, existing direct artifact display stays compatible and the
manifest status is unknown.

No production network access, credential read, raw payload persistence, order
submission, order cancel/replace/amend, Dashboard order control, or trading
semantic behavior is added.

## Public API Impact

Dashboard snapshot JSON gains read-only manifest fields under
`production_shadow[]`:

```text
manifest_status
manifest_artifact_count
manifest_path
```

No CLI command syntax changes.

## Migration Note

No migration note is required. The manifest is additive and optional for old
v0.11 artifact directories.
