## Summary

V281-005 hardens `runtime-closed` terminology. The v0.28.x meaning is now
`deterministic_artifact_replay_closure` only, with explicit false claims for
backend service runtime integration, live external integration, production
execution runtime, and product-ready live trading.

Plain Chinese summary: 本任务把 `runtime-closed` 收紧为 artifact replay closure。

live service、production trading runtime 或 product-ready live trading。
