## Summary

BPO-004 adds checked interpolation and yield-curve APIs, removes two runtime
`unwrap` calls from the backtest event loop, and records path-scoped ownership
decisions for panic, lint-exception, generated, test, and FFI signals.

不匹配和 tenor 顺序错误现在可以通过 `try_*` API 返回结构化错误；旧 API 签名继续
保留。没有增加重试、恢复、交易发送或实盘控制能力。

## Behavior And API Impact

Valid interpolation outputs and backtest ordering remain unchanged. Checked
callers now receive typed errors for malformed inputs. Existing panic-style APIs
remain source compatible, but reject unsorted and non-finite curve data more
explicitly through their checked implementation.

This is an additive public API change. No migration note is required because no
existing signature, config schema, persistence format, CLI syntax, or adapter
contract was removed or changed.
