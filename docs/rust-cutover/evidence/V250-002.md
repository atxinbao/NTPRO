## Summary

V250-002 defines the alert taxonomy and routing evidence contract for v0.25.0
and adds validator executable replay coverage for required fields, redaction,
provenance, dedupe, read-only routing, and no-automatic-action boundaries.

Plain Chinese summary: 本任务把 #779 的告警 taxonomy 和 routing evidence 落到
文档、golden trace 和验证器。告警必须带 severity/category/source/scope/dedupe
key/freshness/provenance/redaction/routing target；缺 required 字段、包含 secret/raw
credential/signed payload/未脱敏交易敏感字段，或 routing 触发自动交易/修复动作都会
fail closed。本任务不接入外部 paging、不执行 remediation、不改变 order lifecycle。
