Task: V090-002 Implement StrategySession State Machine

## Goal

Add an offline `StrategySession` lifecycle state machine that can write
`session_status.json` and `events.jsonl` artifacts for later v0.9 strategy
runtime tasks.

## Changes

- Added `crates/cli/src/strategy_session.rs`.
- Registered the module in `crates/cli/src/lib.rs`.
- Added `StrategySessionState` with:
  - `created`;
  - `validated`;
  - `starting`;
  - `running`;
  - `paused`;
  - `risk_halted`;
  - `stopping`;
  - `stopped`;
  - `failed`.
- Added local artifact writing for:
  - `strategy/session_status.json`;
  - `strategy/events.jsonl`.
- Added tests for the happy path, illegal transition rejection, and terminal
  state rejection.

## Boundary

This is an offline state machine only. It does not start a strategy loop,
connect to an exchange, submit orders, cancel orders, replace orders, or alter
live node behavior.
