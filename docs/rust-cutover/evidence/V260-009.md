## Summary

V260-009 fixes the first `ntpro-rust-only-v0.26.0` hosted release gate failure.
The failure was in `verify-release (full-golden-traces-files)` for run
`28834962271`, job `85516694468`.

Plain Chinese summary: 这次修复只处理发布门禁文件分类问题。v26 的
release-provenance JSONL 不是运行时 golden trace，不能放在顶层
`tests/golden/*.jsonl` 里让通用 schema 校验误扫。修复后它仍由 v26 release
gate 和 strict provenance 单独校验。

## Root Cause

`scripts/ai/verify_full.sh golden-traces-files` calls
`scripts/ai/run_golden_traces.sh`, whose default `TRACE_GLOB` is
`tests/golden/*.jsonl`. That stage expects each top-level JSONL row to conform
to the common `golden-trace-v1` schema.

The v26 release-provenance fixture used a release-specific schema and was
therefore rejected with missing `schema_version`, `description`, `input`,
`expected`, and `tolerances` fields.

## Change

- Moved `tests/golden/v260_release_gates_strict_provenance.jsonl` to
  `tests/golden/v260/release_gates_strict_provenance.jsonl`.
- Updated v26 release gates, strict provenance, release manifest, release replay
  scope, task evidence, and verification references.
