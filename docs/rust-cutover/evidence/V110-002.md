## Goal

Add a v0.11 production public read-only probe contract for non-authenticated
Binance Spot production endpoints while keeping the default path offline and
fail-closed.

Plain Chinese summary: 这次只是加“生产公开只读探针”的本地契约和验证脚本。
它不会联网，不会使用 API key，不会读取账户，不会下单/撤单/改单，也不会给 Dashboard
增加下单按钮。


The command only writes local artifacts. It does not open network connections
and does not touch exchange state.
