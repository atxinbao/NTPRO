## Plain Chinese Summary

这次给本地 Dashboard 增加了三块运行状态面板：Data Sources、Execution
Gateways 和 Risk Engine。操作员现在可以在同一个页面看到本地 supervisor artifact
里暴露的数据连接、执行网关和风控汇总状态。

这次没有接真实交易所，没有做下单、改单、撤单，也没有显示 raw order、raw fill、
原始交易所 payload、完整账户对象、凭证或签名材料。账户引用、执行错误和风控拒绝原因
在页面上只显示为 redacted/present，不显示原始内容。

## Implementation Summary

- Added visible Dashboard sections for:
  - `Data Sources`;
  - `Execution Gateways`;
  - `Risk Engine`.
- Rendered data source alias, kind, provider, connection, freshness, lag, health,
  and redacted last-error state.
- Rendered execution gateway alias, venue, connection, started state, redacted
  account reference, order-count summary, last report, and redacted last-error
  state.
- Rendered risk trading state, health, command/event counts, rejection count,
  redacted last rejection, and redacted last-error state.
- Added JS helpers for dashboard value redaction and unavailable-state rendering.
- Added unit coverage for panel mount points, redaction helpers, HTTP snapshot
  panel data, and forbidden raw/secret DTO keys.
