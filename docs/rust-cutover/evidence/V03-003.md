## Plain Chinese Summary

本任务把 Dashboard 顶层数据包里的“泛用状态”继续细化成具体面板 DTO。

大白话说：V03-002 先定义了 Dashboard 要读一个统一 JSON 包；这次把这个包里的数据源、执行网关、风控、运行模块、日志、指标、控制状态和控制响应都拆成明确字段。后续 UI 和 HTTP API 不需要猜字段，也不会把缺失信息误当成健康状态。

这次没有实现读取 supervisor artifacts，没有启动 HTTP server，没有写 UI，也没有做真实交易或控制节点。

## Goal

Define detailed Dashboard status DTOs for data sources, execution gateways, risk, runtime modules, logs, metrics, alerts, gaps, controls, and local lifecycle action responses.
