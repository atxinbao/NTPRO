## Files Changed

- `scripts/ai/verify_v10_manual_tiny_submit_cancel.sh`
  - Default mode is closed and CI-safe.
  - Real mode requires every owner/manual gate and Binance spot sandbox
    credentials.
  - Uses only allowlisted spot sandbox endpoints:
    `https://testnet.binance.vision` or `https://demo-api.binance.com`.
  - Reads `/api/v3/time` from the selected endpoint and signs requests with
    Binance server-time offset.
  - Writes redacted `testnet_order_proof/*` artifacts.
  - Attempts immediate cancel after submit.
  - Writes failure artifacts and exits non-zero if submit/cancel/reconciliation
    does not satisfy the proof.
- `docs/rust-cutover/release/v0_10_0_tiny_submit_cancel.md`
  - Documents command usage, required gates, artifact set, and release boundary.
- `docs/rust-cutover/release/README.md`
  - Adds the manual proof runner document to the release index.
