# V200-004 Evidence - signing material env-only gate

Date: 2026-06-29
Executor: Codex
Task: `V200-004` / GitHub issue `#615`
Milestone: v0.20.0

## Summary

V200-004 adds a Rust env-only signing material gate in `nautilus-risk`. The
gate blocks production submit readiness unless required credential material is
present, non-empty, in the expected environment, and declared as env-sourced.
Evidence records only env var names, material kind, source, presence, and
non-secret fingerprints.

Plain Chinese summary: 这次实现签名材料 env-only gate。缺少 env、env 为空、运行环境
不匹配、材料来源不是 env 都会 blocked，并输出稳定 evidence。证据、artifact、日志字段
不包含 key、secret、token、signature material 明文；也没有新增 secret storage、
远程密钥管理或 Dashboard credential UI。

## Behavior Impact

The new gate is a local Rust API and evidence model. It does not read process
environment directly, persist secrets, call a remote secret manager, or submit
orders. Later builder/submit tasks can require only `ready` evidence before
using production signing material.

## Rollback

Revert this PR to remove the V200-004 signing material gate API, tests, release
contract, and evidence. V200-005, V200-006, V200-007, V200-011, and V200-012
should remain blocked until a replacement env-only signing material gate is
merged.
