## Summary

V290-002 promotes persistent audit storage from v0.28 runtime closure to v0.29
backend production-readiness evidence. The new deterministic artifact validates
source-controlled sandbox storage configuration, schema/migration policy,
retention, redaction, idempotency, write/read replay, and source/store lineage.
It fails closed for missing config, stale audit source, schema drift, broken
lineage, unredacted payload, and forbidden operation/control paths.

Plain Chinese summary: 本任务把 persistent audit storage 提升为 v0.29 backend
production-readiness evidence。验证只使用 source-controlled sandbox fixture，
不写真实生产存储；缺 config、source stale、schema drift、lineage 断裂、payload 未脱敏
或自动修复/交易路径都会 fail closed。本任务不执行订单、不发送 adapter 请求、不访问 live
exchange、不开放 Dashboard/Admin/Trader Terminal 交易控件。
