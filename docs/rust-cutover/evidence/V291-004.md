## Summary

V291-004 adds a post-publication closeout gate for the published v0.29.0
release. The gate rejects release-gate-ready-only artifacts after publication,
rejects generated-evidence-only proof, requires `source_tree_plus_github_remote`
reconstruction, and preserves normalized release body hash semantics.

Plain Chinese summary: 本任务把 v0.29.0 的发布后状态从“预发布 gate ready”收口到
`Status: RELEASED` 和 source-controlled closeout。新的 gate 会拒绝只靠
`release_gate_ready`、只靠 generated evidence、或缺少 GitHub Release / hosted gate /
milestone closeout / release body hash / tag commit / publication-after-gate
ordering 的状态。它不改变 runtime，也不开放任何交易操作能力。
