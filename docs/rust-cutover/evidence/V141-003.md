# V141-003 Evidence

Date: 2026-06-22
Executor: Codex

## Summary

V141-003 renames live-alpha risk preflight decisions from ambiguous
`approved` / `rejected` values to explicit dry-run values and adds a separate
execution decision field.

Plain Chinese summary: 以前 artifact 里写 `risk_decision=approved`，容易被误解成“允许真实执行”。
现在它只会写 `dry_run_approved` 或 `dry_run_rejected`，同时明确写
`execution_decision=blocked_no_production_mutation`。大白话：风控干跑能过，也还是不能实盘下单。

## Changed

- `live production-live-alpha-risk-preflight` now writes
  `risk_decision=dry_run_approved|dry_run_rejected`.
- Risk preflight artifacts now include
  `execution_decision=blocked_no_production_mutation`.
- Dashboard live-alpha dry-run readiness requires the blocked execution
  decision before showing `live_alpha_dry_run_ready`.
- The Dashboard read-only panel shows the execution decision next to the
  dry-run risk decision.
- The v14 risk preflight verification script checks the new dry-run decision
  values.
- The live-alpha reconciliation golden trace fixture now expects the same
  dry-run decision values.
- v14 forbidden-field scans use `grep -E` so hosted runners without `rg` still
  execute the mutation-field guard.

## Not Changed

- No production order submission.
- No production order mutation, cancel, replace, amend, retry, or correction.
- No execution adapter call.
- No production network access.
- No listenKey lifecycle.
- No Dashboard order controls.
- No real funds or real orders.
