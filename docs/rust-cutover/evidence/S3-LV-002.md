## 交付证据

- Product API 新增显式 POST 账户检查命令，页面加载不会自动访问生产网络；
- 复用现有 Binance `/api/v3/account` 签名读取器，并通过 `spawn_blocking` 隔离同步 HTTP；
- 源能力、五项运行门禁和两个环境凭证全部满足才可执行一次读取；
- Rust 二次门禁测试逐项移除五个门禁，证明 HTTP 闭包均未调用；
- Rust 二次凭证测试分别移除 API Key 与 Secret，证明 reader 返回
  `credential_state_changed` 且 HTTP 闭包未调用；
- 认证 reqwest client 禁止 3xx 重定向；本地双监听器恶意 Location 测试证明没有第二次请求，
  API Key、签名查询和 Referer 不会离开首个 origin；
- 响应只投影状态码、延迟和结构摘要，不包含凭证、签名、请求或原始账户数据；
- OpenAPI 是权威合同，TypeScript/Zod SDK 已重新生成，严格客户端拒绝身份、端点、门禁、
  原始数据和全部交易边界漂移；
- React 页面只增加显式账户连接检查，没有 Live Run、下单、撤单、改单或平仓入口；
- 页面加载 refresh 请求数为 0，点击后严格为 1；仅机构用户可 POST，Operator 返回 403；
- 错误方法返回 `405 Allow: POST`，缺失门禁和凭证时返回 blocked 且零网络。
