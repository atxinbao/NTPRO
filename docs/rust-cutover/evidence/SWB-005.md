## 缺陷复现

- `GET /api/product/v1/runs/ema-cross-btcusdt-baseline-v1`：200；
- `GET /api/product/v1/runs/ema-cross-btcusdt-baseline-v1/metrics`：503；
- 错误码：`product_source_unavailable`；字段：`result_run_root`；
- 静态配置声明 `completed/available`，但工作区不存在同名结果目录；
- React 详情上下文把 `metrics.error` 提升为顶层错误，因此整页不可用。

## 修复证据

- 节点配置通过 `[mvp].baseline_backtest_config` 绑定默认 Backtest 配置，并固定
  `summary.json`、`details.json`、`analysis.json` 三个不可变 SHA-256；
- 全新工作区启动时先在受控暂存目录生成默认基线，逐文件校验哈希和 `run_id` 后原子发布；
- `artifacts`、`backtests`、Run 目录和三个文件均通过 no-follow 目录句柄访问；父目录、
  Run 目录或单文件符号链接都会 fail closed，且不会改写外部目标；
- 已存在目录只验证、不覆盖。篡改内容、缺失单文件和符号链接均阻断启动；
- 并发首次启动只允许一个调用者原子发布完整三文件结果，失败调用者只清理自己的暂存目录；
  中断遗留的非本调用暂存目录保持不动，不会被误删或误发布；
- MVP 重启测试确认基线字节保持不变，四个 Run 读取入口均返回 200；
- 前端把指标错误和重试加载都限制在结果区域；Run 身份、环境和生命周期持续显示，
  延迟重试期间只渲染局部加载状态；
- production bundle 浏览器结果中
  `product_run_baseline_bootstrap=1`、`product_run_metrics=1`、
  `product_run_metrics_mobile=1`。
