## 实现结果

- AWS-LC CSPRNG 每次服务启动生成两个独立 256-bit 本地 token；
- 机构和运维 bootstrap URL 分别换取独立 HttpOnly、SameSite=Strict 会话；
- bootstrap 303 Location 删除 token，页面和 API 响应设置 `Cache-Control: no-store` 与
  `Referrer-Policy: no-referrer`；
- Axum 服务端将共享只读投影与运维专属路由分组，旧 Dashboard、v28、node 查询和
  lifecycle API 全部进入 operator guard，不能从机构会话绕过；
- 未授权、错角色、伪造、空值、重复 token 全部返回 403 脱敏错误信封；
- 两个角色 Cookie 可在同一浏览器中独立共存，跨门户 event link 不携带 token，目标角色
  未建立会话时保持 403；
- 现有测试专用 Router 明确关闭访问校验，只用于投影/生命周期单测；真实 `serve_dashboard`
  始终生成并启用访问策略，真实进程 Chrome smoke 已验证该路径。
