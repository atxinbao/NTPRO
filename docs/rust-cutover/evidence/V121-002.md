# V121-002 Evidence - Release Surface Stale Current Wording Guard

Date: 2026-06-21
Executor: Codex

## Summary

V121-002 hardens `scripts/ai/check_release_surface_current.sh` so current
release wording in the public release surface cannot point at an older release
line than `NTPRO_CURRENT_RELEASE_VERSION`.

Plain Chinese summary: 这次只加强发布面检查脚本。它会继续允许历史版本说明，但如果
README、ROADMAP 或 versioning 里的“current / 当前发布”语义又指回旧版本，就会失败。
没有改交易逻辑，没有新增生产下单、撤单、改单、订单状态读取、listenKey、真实资金交易
或 Dashboard 下单按钮。

## Scope

Changed:

- `README.md`
- `scripts/ai/check_release_surface_current.sh`

Not changed:

- no runtime behavior;
- no adapter behavior;
- no production order submission;
- no production order mutation;
- no production order-state reads;
- no listenKey lifecycle;
- no real funds;
- no production trading;
- no Dashboard order controls.

## Notes

The guard keeps cross-line scanning only for explicit current-release lead-in
phrases such as `current public milestone is` and
`current published release line is`. Historical sections remain allowed to
mention older formal releases.
