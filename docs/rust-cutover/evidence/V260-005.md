## Summary

V260-005 defines upgrade, rollback, and release operation runbook evidence. It
adds validator executable replay coverage for good path preview, missing
approval blocked preview, tag/source mismatch, failed preflight, rollback
recommendation, and stale environment evidence.

Plain Chinese summary: 本任务把 upgrade / rollback / release operation runbook
evidence 落到文档、golden trace 和验证器。runbook 只能输出 preview 或 blocked preview；
缺 owner approval、tag/source/env provenance 不一致、preflight failed、stale environment
evidence 都会阻断。本任务不执行真实部署或回滚，不接入 CD 系统，不改变 release publication
workflow，也不触发 trading operation 或 automatic remediation。
