## Plain Chinese Summary

本任务修的是 v0.7 HTTP probe 的“成功条件”，不是新增网络或交易能力。

大白话：只拿到 HTTP 200 不能算 Binance testnet 只读连通性证明。必须确认
`/api/v3/time` 返回的是 Binance 预期的 JSON shape，并且 `serverTime` 是正数。
如果 HTTP 200 但 `serverTime` 无效，就只能记录为 `response_shape_invalid`，不能
把 `testnet_connection` 写成 true，也不能把原始响应体写进诊断。

  keeps `testnet_connection=false`.
