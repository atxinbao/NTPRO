# V120-006 Evidence - Production Read-Only Reconciliation Engine

Date: 2026-06-21
Executor: Codex
Task: V120-006 Add production read-only reconciliation engine

## Summary

V120-006 adds a local-only `live production-readonly-reconciliation` command.
The command reads local read-only/shadow artifacts and writes
`reconciliation_events.jsonl` with a classification, severity, and local-only
recommended action.

Plain Chinese summary: 这次只是把 production shadow reconciliation 做成本地证据分类。
它不会连生产网络，不会读取生产订单状态，不会下纠错单，不会撤单、改单或补单。

## Classifications

- `ok`;
- `missing_account_snapshot`;
- `portfolio_unavailable`;
- `shadow_intent_without_portfolio`;
- `production_mutation_forbidden`;
- `manual_review_required`.

## Non-Mutating Boundary

- No production order submission.
- No production order mutation.
- No production order-state read.
- No listenKey lifecycle access.
- No automatic correction order.
- No Dashboard order controls.
- No real orders.
- No exchange-truth claim for shadow values.
