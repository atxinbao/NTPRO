## Summary

V260-006 defines SLO, runbook, and long-run stability evidence. It adds
validator executable replay coverage for a valid long-run window, stale or
unredacted samples, missing components with restart recommendation, exhausted
error budget, stale runbook evidence, and release drift.

Plain Chinese summary: 本任务把 SLO / runbook / long-run stability evidence 落到
文档、golden trace 和验证器。缺 sample provenance、freshness 或 redaction 不会显示
healthy；missing components 只能 degraded 并输出 restart recommendation preview；
error budget exhausted 和 release drift 会 fail closed。本任务不执行真实 soak test、
自动恢复、自动重启、停止策略、撤单、下单或 trading recovery。
