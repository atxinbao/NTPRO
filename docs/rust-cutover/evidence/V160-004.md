## Summary

V160-004 adds the local/offline v0.16 request builder artifact for one
owner-approved, tiny, single `LIMIT GTC` production order candidate. It builds
the request object in memory after the runtime gate and signing approval are
ready, but it persists only redacted metadata and keeps the explicit send gate
closed.

Plain Chinese summary: 已加“生产下单请求对象构造器”。大白话：它能在本地构造一笔
`LIMIT GTC` 请求对象，用来证明请求形状已经准备好；但 key、secret、signature、
signed query、signed URL、timestamp 值和请求体都不落盘，也不联网、不发请求、不真实
下单。现在仍然只是 v0.16 candidate 的 evidence，不是实盘交易入口。
