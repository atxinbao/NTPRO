Task: V090-001 Add Strategy Session Config Contract

## Goal

Add a `strategy-session` config validation contract so `ntpro-node` can later
load a scoped strategy runtime configuration without enabling order submission.

## Changes

- Added `ConfigKind::StrategySession`.
- Extended `config validate --kind` to accept `strategy-session`.
- Added TOML validation for:
  - `node.mode`;
  - `strategy.strategy_id`;
  - `market.symbols`;
  - `execution.order_submission`;
  - `risk.kill_switch`.
- Added targeted unit tests for valid and invalid strategy-session configs.

## Contract

`node.mode` may only be:

```text
dry-run
shadow
```

`execution.order_submission` must be:

```text
disabled
```

`strategy.strategy_id` and `market.symbols` must be non-empty. `risk.kill_switch`
must exist as a boolean.
