## Negative-Path Coverage Summary

Dashboard/API coverage now verifies:

- missing node returns HTTP 404 with `error_code=node_not_found`;
- stopped node rejects stop, pause, resume, reconnect data, and reconnect
  execution with HTTP 409 and `error_code=invalid_lifecycle_state`;
- unknown control action returns HTTP 501 semantics through the internal
  control response path with `error_code=unsupported_control_action`;
- running node still rejects duplicate start through existing coverage.

Supervisor coverage now verifies:

- missing node is rejected for stop, pause, resume, and reconnect data;
- stopped/not-running node rejects stop, pause, and resume;
- a running process with stopped lifecycle rejects pause, resume, reconnect
  data, and reconnect execution with lifecycle mismatch errors.
