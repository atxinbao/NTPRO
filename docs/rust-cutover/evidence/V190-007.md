## Summary

V190-007 adds the v0.19 actual-cancel failure and partial-success evidence
command. The command consumes V190-006 readback reconciliation plus redacted
request, response, readback, and audit references, then emits a structured
outcome artifact for Dashboard read-only audit views and release gates.

Plain Chinese summary: 这次实现真撤单后的失败/部分成功证据模型。大白话：真实撤单之后，
结果可能是被拒绝、超时、未知、部分成交、已撤单、venue 不可用或 adapter 失败。现在这些结果都会
落成结构化 evidence；unknown 不会被当成 recovered，partial fill 会显示 residual risk，并且不会触发
retry、补偿交易、二次撤单、联网读取或 Dashboard 下单/撤单按钮。
