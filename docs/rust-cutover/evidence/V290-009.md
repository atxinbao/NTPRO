## Summary

V290-009 hardens v0.29 backend production readiness with a deterministic
fail-closed replay artifact. The replay accepts complete backend readiness
evidence while keeping backend go-live and trading readiness `not_ready`,
degrades partial readiness, blocks stale readiness, and fails closed for missing
components, source drift, backend go-live claims, live trading claims, forbidden
controls, and missing required-false boundary fields.

Plain Chinese summary: 本任务把 v0.29 backend production readiness 的 fail-closed
汇总层固化为可复放 artifact。partial 只能 degraded，stale 只能 blocked，missing
component、source drift、backend go-live claim、live trading claim、forbidden
control、missing required-false boundary 都会 fail closed。backend production
readiness health 仍然和 go-live / trading readiness 分离；本任务不开放任何交易或
生产执行能力。
