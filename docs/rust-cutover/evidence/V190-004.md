## Summary

V190-004 implements the owner-approved single-shot actual cancel command. The
command is offline by default and can only attempt one `DELETE /api/v3/order`
when owner approval, risk gate, release provenance, adapter boundary, adapter
capability, owner-supplied order identity, CLI confirmations, and manual online
env gates all match. Before an attempted send it atomically marks the source
owner approval lifecycle as `used`, and a second run with the same owner
approval path fails closed before any executor call.

Plain Chinese summary: 这次实现真正撤单命令，但不是自动撤单。大白话：默认运行只会生成
ready/no-send artifact；只有 owner 明确开启 `--manual-online`、提供 raw order id，并且所有前置证据和
环境变量闸门都匹配时，才会发送一次撤单请求。任何缺失、过期、复用、不匹配、adapter 不支持、
Dashboard/自动/bulk/retry 路径都会在发送前失败关闭。
