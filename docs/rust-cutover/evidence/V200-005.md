## Summary

V200-005 adds a local Rust single-shot production order request builder in
`nautilus-risk`. The builder requires V200-002 risk allow evidence, V200-003
active owner approval evidence, and V200-004 signing readiness evidence before
it emits a deterministic request digest and redacted request preview.

Plain Chinese summary: 这次实现单次 production submit request builder。它只生成
digest 和 redacted preview，不做真实提交、不联网、不签名、不 retry、不自动补全字段。
缺少 risk allow、owner approval、env readiness，或者 candidate 与 evidence 不匹配，
都会拒绝输出 submit request。

## Behavior Impact

The new builder is a local Rust API and evidence model. It does not sign,
submit, send, retry, or persist raw request payloads. V200-006 can consume only
the built evidence as the guarded submit candidate input.

## Rollback

Revert this PR to remove the V200-005 builder API, tests, release contract,
and evidence. V200-006, V200-007, V200-008, V200-011, and V200-012 should
remain blocked until a replacement single-shot request builder is merged.
