## Summary

V220-001 adds the first Trader Terminal workbench shell to the Rust CLI
dashboard. The shell reuses the existing v0.21.1 canonical Unified Read Model
runtime bridge and adds read-only navigation, summary status, component panel
slots, foundation/read-only/gated-operation boundaries, and an artifact/
provenance drawer.

Plain Chinese summary: 本任务只增加 Trader Terminal workbench 的只读外壳和导航。
它从现有 `read_model_runtime` 读取 v0.21.1 canonical read model 工件；缺少工件
时 shell 显示 degraded/missing_artifact，不显示 healthy。不新增 submit、cancel、
retry、replace、amend、flatten 或平仓操作按钮，也不宣称产品级实盘交易终端。

## Behavior Impact

The dashboard gains a read-only workbench shell and navigation surface. It does
not submit orders, cancel orders, retry orders, replace orders, amend orders,
flatten positions, connect to venues, mutate accounts, or change runtime
trading behavior.

## Public API Impact

None. The change is a CLI dashboard UI/diagnostic surface over existing local
artifacts. There is no Rust public API change and no migration note is required.

## Rollback Plan

Revert the PR to remove the workbench shell section, renderer, tests, and
evidence docs. Reverting restores the v0.21.1 read-model runtime table without
altering the already-published `ntpro-rust-only-v0.21.1` release or the
V220-000 scope decision.
