# V131-003 Evidence - Bounded local shadow preflight wording

Date: 2026-06-21
Executor: Codex

## Summary

V131-003 normalizes v0.13 shadow-session wording to "bounded local shadow
preflight loop".

Plain Chinese summary: v0.13 的 shadow preflight 只是本地有边界的预检循环。它有
heartbeat、stop-file 和 stale-data 证据，但不是生产长期运行服务，不提交订单，不撤改
订单，不读生产订单状态，也不启用 Dashboard 下单控件。

## Wording Contract

Use:

```text
bounded local shadow preflight loop
bounded local artifact evidence
heartbeat / stop-file / stale-data evidence
```

Avoid for v0.13 capability claims:

```text
long-running production shadow service
production shadow service
production shadow runtime
live-alpha runtime
```

Historical v0.12 "Persistent Shadow" release names remain unchanged because
they are already published version names and are not v0.13 capability claims.
