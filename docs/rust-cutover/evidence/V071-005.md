# V071-005 Evidence - Manual-Online Proof Semantics

Date: 2026-06-15
Executor: Codex
Task: V071-005 Tighten manual-online proof semantics

## Plain Chinese Summary

本任务修的是 manual-online gate 的证明口径，不是让 CI 默认联网。

大白话：真实 online proof 只有一种通过方式：确实发起 read-only testnet HTTP
请求，并且拿到 `error_code=none`、`testnet_connection=true`、
`response_shape_validated=true`。如果只是超时、连接失败、HTTP 非 2xx、响应格式不对，
这些都只能叫“分类诊断”，不能叫“连通性证明”。

## Change Summary

- Updated `scripts/ai/verify_v07_manual_online_gate.sh` so stable HTTP failures
  fail with `classified_failure connectivity_proof=false`.
- Reordered proof assertions so the script classifies stable failures before
  checking success-only proof fields.
- Updated v0.7 boundary and readiness docs to distinguish classification
  evidence from connectivity proof.
