## Summary

V181-004 adds a strict binary provenance gate for the v0.18 release line. The
new `scripts/ai/verify_release_strict.sh v18` command builds or verifies the
release `nautilus` binary and binds the binary path, binary sha256, byte count,
toolchain versions, source commit, source tree, baseline release tag, and
baseline release commit into a machine-readable manifest.

Plain Chinese summary: 这次新增严格 binary provenance gate。大白话：发版前要能证明
`nautilus` binary 是从哪个 source commit、哪个 toolchain、哪个 baseline tag 构建出来的，
并且 manifest 里的 hash/bytes/path 与实际 binary 一致；不上传 binary、不签名、不做真实撤单。
