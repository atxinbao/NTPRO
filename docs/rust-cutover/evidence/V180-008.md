## Plain Chinese Summary

这次只处理 V180-008。它新增撤单恢复预览的 incident/audit closeout 合同：
把 cancel risk gate、人工 owner approval、cancel response redaction、post-cancel
readback 四个证据串起来，记录为什么需要恢复、谁批准、门禁结果、脱敏状态、回查状态、
最终动作建议和剩余风险。它仍然不发真实撤单、不触网回查、不重试、不自动补救，也不开
Dashboard 撤单控件。

## Scope

- Added `nautilus live production-mutation-cancel-recovery-incident-audit-closeout`.
- Added schema `ntpro.v180_cancel_recovery_incident_audit_closeout.v1`.
- The command consumes these ready v0.18 artifacts:
  - `ntpro.v180_cancel_risk_gate.v1`
  - `ntpro.v180_manual_owner_approval_lifecycle.v1`
  - `ntpro.v180_cancel_response_redaction.v1`
  - `ntpro.v180_post_cancel_readback.v1`
- The artifact records source paths, run IDs, hashes, source refs, lineage checks,
  risk reason, gate result, approval state, redaction state, readback state,
  terminal action recommendation, and remaining risk.

The terminal action recommendation is derived from post-cancel readback state:

```text
terminal_canceled -> close_incident_cancel_confirmed
terminal_filled -> manual_position_and_fill_review
terminal_rejected -> close_incident_rejected_no_retry
terminal_expired -> close_incident_expired_no_retry
ambiguous_missing -> manual_exchange_and_local_ledger_review
ambiguous_unknown -> manual_exchange_state_review
```
