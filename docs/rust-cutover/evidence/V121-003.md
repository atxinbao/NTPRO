## Scope

Added a dedicated release publication guard for the current formal release.
The guard checks the local tag, origin/main ancestry, GitHub Release flags,
release URL, release name, published timestamp, and key body fields.

This task does not change trading behavior, production connectivity, order
submission, order mutation, live funds handling, or Dashboard controls.

formal GitHub Release is published. The offline fallback path must only pass
when `NTPRO_RELEASE_PUBLICATION_ALLOW_OFFLINE=1` is explicitly set.
