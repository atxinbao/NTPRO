Date: 2026-07-31
Executor: Codex
GitHub issue: #1197
Status: REVIEW_REQUIRED

## 实现结果

- 新增 `nautilus mvp serve` 产品入口；
- 自动注册并启动唯一一个本地沙盒节点；
- 等待节点指标工件可读取后再启动 Dashboard；
- MVP 就绪事件以追加方式写入，不覆盖既有 Supervisor 生命周期日志；
- Ctrl-C、Dashboard 绑定失败和可观测性初始化失败时均回收节点；
- 已停止的同一工作区可以再次启动，注册表仍只包含一个节点；
- Dashboard 仅允许绑定 loopback 地址和非零端口；
- 浏览器不再请求缺失 favicon；
- 移动端表格内容不再撑宽页面；
- 外部交易场所连接、真实订单和实际订单提交继续保持禁用。

## 已知边界

本任务交付单 Supervisor + 单节点 + 单策略的本地运行与观测闭环，不交付完整
交易员终端。当前节点不会生成 `v0_21/unified_read_model_snapshot.json`，因此
Dashboard 的 Unified Read Model 面板保持 `missing_artifact` 并阻止操作入口。
该状态符合 fail-closed 边界，不影响本任务的节点运行、策略状态、日志和指标验收。
