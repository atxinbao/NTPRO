## Summary

Implemented a v0.15 production live-alpha execution dry-run isolation artifact.
It consumes local order gate, risk preflight, and request preview artifacts, then
records whether the strategy intent reaches only the local dry-run execution
adapter artifact path.

Plain Chinese summary: 这一步证明“策略意图最多只能到本地 dry-run adapter”。
它不实例化生产 adapter，不调用生产 adapter，不发网络请求，不提交或修改生产订单。

## Behavior Boundary

Included:

- New CLI command: `live production-live-alpha-execution-dry-run`.
- Artifact schema: `ntpro.v150_live_alpha_execution_dry_run.v1`.
- Local artifact chain:
  `order gate -> risk preflight -> request preview -> kill-switch runtime gate -> dry-run execution adapter`.
- Explicit production adapter isolation fields.

Not included:

- Production adapter implementation.
- Production adapter instantiation or call.
- Production request execution.
- Production order submission or mutation.
- Cancel, replace, amend, retry, correction, or automatic remediation.
- listenKey lifecycle.
- Dashboard order controls.
- Network access.
