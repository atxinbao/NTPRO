Executor: Codex

## Summary

V170-001 adds a local production order ledger artifact for one v0.16 mutation
candidate lineage. It links request builder, guarded send, response redaction,
order-state readback, audit trail, and failure semantics evidence into one
restart-readable JSON artifact.

Plain Chinese summary: 这个任务只把 v0.16 那一笔候选订单的本地证据串成账本。大白话：
它不再下单、不重试、不撤单，只是给后续对账任务提供一条能重启后继续读取的本地记录。
