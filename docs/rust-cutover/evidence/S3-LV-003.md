## 交付证据

- 复用 S3-LV-002 唯一显式 refresh 路由和 Binance `/api/v3/account` 读取器，没有新增网络、
  签名或凭证实现；
- Rust 投影只保留账户类型、三个交易所权限标志和非零资产的 `asset/free/locked/total`；
- `free + locked = total` 使用 `Decimal` 精确计算，零余额过滤，资产按代码稳定排序；
- 余额使用 `Decimal::from_str_exact`，超过可表示精度或可能把非零值舍入为零的输入直接失败；
- 重复资产、负数、NaN、非法代码、超量条目和缺失结果全部 fail closed；
- JSON 解析前实施 1 MiB 响应体硬上限，声明 `Content-Length` 与未知长度流式超限测试通过；
- Product API v2 明确原生资产单位和无估值状态，不跨币种伪造组合总值；
- 严格客户端使用 `BigInt` 对齐小数位后复核逐资产精确加法，不使用 JavaScript 浮点数；
- connected、blocked、failed 与结果存在性严格绑定，账户结果不持久化；
- 本地真实 HTTP fixture 证明 UID、commission、updateTime、API Key 和签名不进入产品投影；
- Live 页面展示账户摘要和资产表，不存在 Live Run、下单、撤单、改单或平仓入口。
