## Summary

V280-005 closes the telemetry/SLO ingestion backend module with a deterministic
runtime artifact and validator replay. The replay accepts healthy telemetry
ingestion and audited SLO breach degradation, then fails closed for stale
telemetry, missing provenance, malformed metrics, unredacted payloads, and
forbidden operation triggers. The v0.28.0 backend closure readiness matrix now
records `telemetry_slo_ingestion_runtime_closure` as `runtime-closed`.

Plain Chinese summary: 本任务把 telemetry/SLO ingestion 推进为可复放的 backend
artifact。它只验证 telemetry source、sampling、freshness、lineage、SLO transition audit
和 redaction；stale telemetry、missing provenance、malformed metrics、unredacted
payload 或 operation/trading/control 边界打开都会 fail closed。telemetry event 仍然只是
observability input，不会触发 submit、retry、remediation、adapter send 或交易控件。
