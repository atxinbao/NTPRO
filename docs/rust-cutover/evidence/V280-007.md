## Summary

V280-007 closes the Trader Terminal backend API contract handoff module with a
deterministic read-only API/artifact contract and replay validator. The replay
accepts the ready backend API contract, classifies stale and degraded responses
as degraded read-only states, and fails closed for missing source references,
malformed response schemas, unredacted payloads, and forbidden operation or
trading controls. The v0.28.0 backend closure readiness matrix now records
`trader_terminal_backend_api_contract_handoff` as `runtime-closed`.

Plain Chinese summary: 本任务把 Trader Terminal 后续交接需要的 backend API 合同固化为
可复放的只读 artifact。它定义 backend closure status、provenance drill-down、
audit entries、telemetry health、permissions、deployment state 的 response schema、
redaction、freshness 和 failure semantics，并验证 missing/malformed/unredacted/
forbidden controls 会 fail closed。本任务不实现 UI，不开放 order ticket、submit/cancel/
retry/replace/amend/flatten，也不声明 product-grade trading terminal readiness。
