# V090-004 Evidence

Date: 2026-06-18
Executor: Codex
Task: V090-004 Add Fixture/Mock Market Stream Adapter for Strategy Session

## Goal

Give Strategy Session a local market input stream so v0.9 strategy runtime work
can consume fixture/mock market events instead of treating strategy execution as
a one-shot artifact.

## Changes

- Extended `crates/cli/src/strategy_session.rs` with market stream artifacts:
  - `strategy/market_status.json`;
  - `strategy/market_events.jsonl`.
- Added fixture bar stream recording with
  `market_status.connection = fixture_stream_running`.
- Added mock bar and mock tick stream recording surfaces.
- Added market stream status/event schemas:
  - `ntpro.v09_market_stream_status.v1`;
  - `ntpro.v09_market_stream_event.v1`.
- Updated `ema_cross_demo` so it records and consumes the fixture market stream
  before generating signals.
- Added tests for fixture market stream artifacts, mock tick events, and demo
  strategy market-event consumption.

## Boundary

This task is local-only. It does not open Binance WebSockets, production data
connections, credentials, exchange adapters, or any order API.

The stream is a fixture/mock artifact source for v0.9 Strategy Runtime
Foundation only. Real market data and testnet order proof remain outside v0.9.
