## Summary

Added an aggregate v0.15 release gate that wires the guarded live-alpha mutation
scope into local release verification, PR smoke, and tag-triggered release
gates. The gate runs the existing v0.15 dry-run, manual approval, execution
isolation, kill-switch, rollback, Dashboard read-only, and golden trace checks
as one release-stage bundle.

golden trace 一起跑，并继续证明没有真实下单、没有生产改单、没有联网、没有真实资金、

only checks local artifacts, local tests, release documents, and no-mutation
markers. It does not change runtime trading behavior.

release gates run `scripts/ai/verify_release.sh v15-release-gates`, which uses
release CLI binaries.
