## Plain Chinese Summary

本次补强 pre-submit notional 一致性校验：生产 LIMIT/GTC submit 在进入
submit builder 前，必须满足 `request.notional == quantity * price`。当前 scope
没有 instrument precision contract，因此默认 exact fail closed；低报、高报和缺失
notional consistency evidence 都会拒绝，不会打开 retry、replace、amend、flatten、
bulk submit、strategy-driven submit 或 Dashboard 下单控件。
