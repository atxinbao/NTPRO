## Summary

V311-003 hardens the v31 publication guard so the published GitHub Release body
must be a released-state body and must match tracked v31 release notes under
both normalized and raw SHA-256 checks.

Plain Chinese summary: 本证据证明 v31 publication guard 不再接受发布后的
`RELEASE GATE READY` body。live GitHub Release body 已用源码内 v31 release notes 更新，
默认 guard 现在验证 `Status: RELEASED`，且 normalized/raw hash 都匹配。该任务不 retag、
不改变 runtime，也不开放 backend go-live、真实下单、订单变更、adapter send、live exchange、
retry、automatic remediation 或交易控件。
