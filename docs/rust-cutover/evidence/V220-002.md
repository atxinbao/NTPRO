## Summary

V220-002 fills the Trader Terminal workbench account and position panels with
read-only data from the existing v0.21.1 canonical Unified Read Model runtime
bridge. It surfaces account status, freshness, source provenance, redaction,
risk state, balance summary, position side, quantity, notional, precision, and
lineage while preserving the no-operation boundary.

Plain Chinese summary: 本任务只把账户和持仓信息接入 Trader Terminal workbench
的只读面板。数据来自现有 v0.21.1 canonical read model 工件；stale、missing
provenance 或账户/持仓 account_id 不一致时显示 degraded 或 fail_closed。不新增
资金划转、账户配置修改、自动平仓或持仓修复入口。

## Behavior Impact

The dashboard gains read-only account and position workbench panels. It does not
transfer funds, mutate account configuration, auto-flatten positions, repair
positions, submit orders, cancel orders, connect to venues, or change runtime
trading behavior.

## Public API Impact

None. The change is a CLI dashboard UI/diagnostic surface over existing local
artifacts. There is no Rust public API change and no migration note is required.
