## Summary

This task adds the v0.18.0 manual owner approval lifecycle artifact for one
cancel candidate. The lifecycle reads one ready cancel risk gate artifact,
binds manual owner approval to that single candidate, enforces one-time and
non-reusable approval semantics, records expiry, and keeps all send/network
fields disabled.

Plain Chinese summary: 这次只处理 V180-005。它记录 owner 对这一笔撤单候选的人工审批生命周期。
大白话：approval 只能对应这一笔、只能一次、会过期、不能复用，也不能由策略、后台、Dashboard 或
incident handler 自动批准；它不会真正撤单，不会触网，也不会打开 Dashboard 撤单按钮。

## Fail-Closed Requirements

The lifecycle blocks if the cancel risk gate is not ready, if required CLI
confirmations are missing, if approval is pending/expired/revoked/used, if
manual owner evidence is missing, or if a prior lifecycle was already recorded
for the same risk gate.

The verifier also asserts that automatic approval paths remain disabled:

```text
strategy_auto_approval_allowed = false
background_auto_approval_allowed = false
dashboard_auto_approval_allowed = false
incident_handler_auto_approval_allowed = false
```

## Behavior Impact

- Adds `nautilus live production-mutation-manual-owner-approval-lifecycle`.
- Produces a local/offline JSON evidence artifact only.
- Requires a ready `ntpro.v180_cancel_risk_gate.v1` source artifact.
- Requires `approval_state=approved`, `--manual-approval-id`, `--approved-by`,
  positive `--now-unix-ms`, and positive `--expires-at-unix-ms`.
- Blocks pending, expired, revoked, used, missing-confirmation, and already
  lifecycle-recorded source cases.
- Does not submit, cancel, retry, replace, amend, flatten, remediate, approve
  automatically, or call a network endpoint.
