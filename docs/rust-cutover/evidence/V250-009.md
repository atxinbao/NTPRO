# V250-009 Evidence - v25 tag gate base provenance scoping

Date: 2026-07-06
Executor: Codex
GitHub issue: `#804`
Milestone: none

## Summary

Fixed the v0.25.0 tag release gate scoping bug found by hosted run
`28762387835`. The v25 intake gate still requires v0.24.1 publication evidence,
but it no longer asks the historical v0.24.1 strict provenance gate to enforce
the current v25 tag's `NTPRO_RELEASE_GATE=1` HEAD/tag constraint.

Plain Chinese summary: 这次修的是发布门禁继承问题，不是放宽 v25 本身的门禁。v25
tag gate 仍会校验当前 HEAD 必须等于 `ntpro-rust-only-v0.25.0`；只有在验证
v0.24.1 已发布基线时，才清掉当前 tag gate 的 HEAD 约束，避免旧版本 gate 在新版本
tag 上误失败。
