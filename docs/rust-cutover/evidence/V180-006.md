## Summary

This task adds the v0.18.0 cancel response redaction contract for one manually
approved cancel candidate. The command reads a valid manual owner approval
lifecycle artifact, accepts a synthetic or future cancel response input, and
writes only redacted cancel metadata. It blocks raw bodies, headers, signatures,
API key material, unrestricted payloads, balances, fills, and consumed or invalid
approval lifecycle sources.

Plain Chinese summary: 这次只处理 V180-006。它定义未来撤单响应落盘前怎么脱敏。
大白话：只允许保存脱敏后的撤单元数据；raw response、headers、body、API key、secret、
signature、payload、balance、fills 都不能写入。它不会真正撤单，不会触网，也不会打开
Dashboard 撤单按钮。

## Fail-Closed Requirements

The command blocks when CLI confirmations are missing, when the source manual
owner approval lifecycle is not valid/approved/unconsumed, or when the response
contains forbidden raw or sensitive markers.

The persisted identifier fields use v0.18 hash-shaped values:

```text

cancel_client_order_id = cancel_client_order_id:sha256:<prefix>:len=<n>

```
