## Summary

V300-010 records a source-controlled go/no-go runbook and live readiness
decision record for the v0.30.0 backend go-live candidate foundation. It
requires every candidate decision input to be present, fresh, linked, and
passing before the ready record can advance.

Plain Chinese summary: 本任务把 go/no-go runbook、required inputs、decision
owners、checklist gates、freeze/abort criteria、rollback references 和 ready /
degraded / blocked / aborted decision records 落成源控证据。Ready 只代表
candidate-ready，不代表 actual production go-live；decision record 不会开启
production execution、adapter send、live exchange request、automatic remediation、
retry 或 trading controls。
