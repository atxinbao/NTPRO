## Summary

V181-005 clarifies the verification boundary so default
`scripts/ai/verify_fast.sh` cannot be read as release validation. The script
now prints the four distinct lanes: fast smoke, compile/lint check, release
gate, and strict binary provenance gate. Release-facing v0.18/v0.18.1 docs now
keep `verify_fast.sh` as auxiliary local preflight only and point release
evidence to `verify_release.sh` plus strict provenance where applicable.

Plain Chinese summary: 这次只修验证语义。大白话：`verify_fast.sh` 默认只是快速
本地 smoke，不能当 release gate；发布证据要看 `verify_release.sh`，v0.18.1
还要看 strict provenance gate。不改运行时、不发 tag、不新增撤单能力。

## Verification Boundary

```text
fast smoke = scripts/ai/verify_fast.sh
compile/lint check = VERIFY_FAST_CARGO_CHECK=1 VERIFY_FAST_CLIPPY=1 scripts/ai/verify_fast.sh
full test check = scripts/ai/verify_full.sh
release gate = scripts/ai/verify_release.sh
strict provenance gate = scripts/ai/verify_release_strict.sh v18
```

Default `verify_fast.sh` covers only:

```text
pinned Rust toolchain output
cargo fmt --check
```

Default `verify_fast.sh` does not cover:

```text
workspace cargo check
clippy
golden traces
release gates
strict binary provenance
hosted release gate evidence
```
