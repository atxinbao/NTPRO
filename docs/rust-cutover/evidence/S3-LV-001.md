## 交付证据

- Rust Product API 新增嵌套只读 Live admission 资源，严格绑定 strategy/version；
- 配置目标固定为 Binance Spot production endpoint 和现有 Binance adapter 产品引用；
- 凭证只投影环境变量引用与 `present/missing`，响应结构没有 secret value 字段；

- endpoint、credential ref、owner/network/account/Run/order/retry/remediation/recovery 任一权限
  true、人工停机 false 或未知配置字段均 fail closed；

- OpenAPI 是权威合同，TypeScript/Zod SDK 由合同重新生成，客户端拒绝未知、默认化或越权字段；
- 冻结源只触达 `server.rs` 与节点配置，freeze manifest 已登记精确 SHA，19 项禁止能力未修改。
