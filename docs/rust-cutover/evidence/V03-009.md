## Plain Chinese Summary

这次给本地 Dashboard 增加了节点生命周期控制。大白话说：页面现在可以对 supervisor 已注册的本地 sandbox 节点执行 Start 和 Stop，但不能下单，不能改单，不能撤单，也不能做策略热加载或生产 reconnect。

按钮状态按节点状态显示：

- stopped 节点只允许 Start；
- running 节点只允许 Stop；
- pause、resume、reconnect data、reconnect execution 先显示为不支持且禁用。

实现过程中还修了一个真实验证暴露的问题：`ntpro-node` 的 status artifact 里可能写的是配置运行名，例如 `LiveInitSmoke`，但 Dashboard 控制必须使用 supervisor registry 里的节点 ID，例如 `sandbox-a`、`sandbox-b`。现在控制按钮和 API action 都使用 registry node id，避免按钮指向错误节点。
