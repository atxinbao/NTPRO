## Plain Chinese Summary

这次改动把 v0.2.0 关键发布风险前移到 PR 检查里。以前 PR smoke 主要跑
`verify_fast.sh`，虽然已经打开了 workspace `cargo check`，但没有强制 clippy、
CLI 单元测试、Rust-only/Cython gate 和 v0.2 两节点 supervisor smoke。现在只要
PR 打到 `main`，这些检查都会一起跑，能更早发现会影响 v0.2 tag/release 的问题。

这次没有创建 tag，没有发布 GitHub Release，没有改交易语义，也没有连接真实交易所。
release tag workflow 继续使用 P0-002 已建立的强 release gate：
`scripts/ai/verify_release.sh`。

## Goal

release gate before any v0.2 release decision.
