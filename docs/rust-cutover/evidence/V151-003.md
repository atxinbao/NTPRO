# V151-003 Evidence - Synthetic signing material default

Date: 2026-06-23
Executor: Codex
Milestone: v0.15.1
Status: local validation PASS; hosted smoke pending PR

## Summary

Defaulted the v0.15 production live-alpha request-preview signing path to
synthetic signing material and added explicit owner-gated production signing
material handling for dry-run previews.

Plain Chinese summary: 请求预览默认只用假的 synthetic 签名材料，不再默认读取生产
key/secret。只有明确选择 `production_live_alpha`，并打开两个 owner gate，才会读取生产
signing env 做内存签名预览。仍然不发请求、不联网、不调用生产 adapter、不真实下单。

## Behavior Boundary

Included:

- request preview artifacts now record `credential_material`;
- default request preview path uses `credential_material=synthetic`;
- default synthetic path does not read production signing env values;
- `production_live_alpha` signing material records:
  - `production_signing_material_gate_required`
  - `production_signing_material_gate_open`
  - `production_signing_material_env_read`
  - `production_signing_material_missing_gate_env_vars`
- production signing material remains fail-closed until both gate env vars are
  set to `1`.

Not included:

- production request sending;
- production order submission;
- production order-test submission;
- production order mutation;
- production execution adapter call;
- real funds;
- production trading;
- Dashboard order controls.
