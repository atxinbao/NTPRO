## Summary

V131-002 hardens the v0.13 owner-run read-only proof-pack wording and manifest
contract.

Plain Chinese summary: proof pack 的 wrapper 是已经实现的，但 v0.13.0/v0.13.1
默认发版证据不等于 owner 已经真实联网跑成功。默认 CI 仍是 offline/fail-closed。
只有 owner 显式开 gate 并成功完成 production public GET 和 authenticated account GET，
才算 owner-run online success evidence included。

## Manifest Fields

The proof-pack manifest now records:

```text
wrapper_implemented = true
owner_run_online_success_evidence_required_for_release = false
owner_run_online_success_evidence_included = false by default
owner_run_online_success_evidence_status = not_included_default_offline_preflight by default
```

If owner-run online mode is explicitly enabled and both read-only probes pass,
the manifest records:

```text
owner_run_online_success_evidence_included = true
owner_run_online_success_evidence_status = included
```

If owner-run online mode is explicitly enabled but the online read proof does
not pass, the manifest records:

```text
owner_run_online_success_evidence_included = false
owner_run_online_success_evidence_status = not_included_classified_failure
```
