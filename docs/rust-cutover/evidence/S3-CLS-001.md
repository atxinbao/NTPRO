## 产品声明边界

S3 收口证明代码具备生产账户和 Venue 的独立授权单笔交易路径，并且异常和恢复场景 fail closed。
所有自动验证使用 fixture、内存锚点或 loopback 服务；本任务不声明在真实资金账户执行过订单，
也不替代机构上线时的账户授权、额度、变更窗口和人工 go/no-go。

连续策略自动下单、追加订单、批量订单、改单、自动重试、自动修复、自动恢复和未审批 Live
订单继续为 false。它们不从 Backtest、Demo、S3 milestone 或文档状态自动继承。
