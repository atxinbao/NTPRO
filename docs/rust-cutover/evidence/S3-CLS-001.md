## 产品声明边界

S3 技术路径具备生产账户和 Venue 的独立授权单笔交易能力，并且异常和恢复场景 fail closed。
但所有自动验证使用 fixture、内存锚点或 loopback 服务，不能满足正式退出条件中的真实资金账户
端到端交易。Issue #1312 已登记为 owner-gated blocker；milestone #39 必须保持开放。

连续策略自动下单、追加订单、批量订单、改单、自动重试、自动修复、自动恢复和未审批 Live
订单继续为 false。它们不从 Backtest、Demo、S3 milestone 或文档状态自动继承。
