# V151-002 Evidence - Manual approval consume artifact

Date: 2026-06-23
Executor: Codex
Milestone: v0.15.1
Status: local validation in progress; hosted smoke pending PR

## Summary

Implemented one-time manual approval consumption for the v0.15 request-preview
path. A valid approval is now written back as consumed after request-preview
creation, and reuse of the same approval fails closed.

Plain Chinese summary: 这次把“人工审批只能用一次”做成真实状态变化。第一次生成请求
预览后，审批文件会变成 `used`；第二次复用同一个审批文件会被挡住，后续 dry-run
execution 也只能看到 blocked source artifact。没有联网，没有实盘下单，没有生产
adapter 调用。

## Behavior Boundary

- request preview success consumes the manual approval lifecycle artifact;
- consumed approval artifacts record:
  - `approval_state=used`
  - `approval_used=true`
  - `approval_consumed=true`
  - `request_preview_created=true`
  - `approval_lifecycle_valid=false`

  - `manual_approval_used=true`

  - `manual_approval_consume_transition=approved_to_request_preview_created_to_used`
