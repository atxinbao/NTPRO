## Plain Chinese Summary

这次把 workflow 工件的 JSON 合约抽成了 `nautilus-cli` crate 内部的共享类型。
以前 CLI 写工件和 Dashboard 读工件各自维护一套相似结构，后续容易字段漂移。
现在 writer 和 reader 使用同一组 `WorkflowManifest`、`WorkflowSummary`、
`WorkflowEvent` 和 v0.6 testnet artifact DTO。

没有改变工件文件名、JSON 字段名、run_id 规则、Dashboard 展示边界，也没有加入真实
Binance testnet 联网能力。v0.6.1 仍然是 offline-only。

## Goal

Extract shared workflow artifact DTO/schema definitions for CLI writer and
Dashboard reader, and prove CLI-generated v0.6 artifacts deserialize through the
shared contract.
