## 实现证据

- `configs/backtests/ema-cross-btcusdt-product.toml` 使用真实 BTCUSDT instrument、精度正确的
  quote size 与 trade size，真实 BacktestEngine 结果为 120 iterations、5 orders、5 positions；
- 产品绑定时写入 `ntpro.backtest_result.v1`，非有限浮点转为稳定字符串，map 使用排序键；
- 结果绑定实际 Backtest 配置 SHA-256 与实际输入 quotes SHA-256；节点 Run 清单独立登记
  配置、输入和完整结果 SHA-256、trade size、quotes、fast/slow 参数，API 逐项验证；
- 结果使用 `create_new` 临时文件写满并 `fsync`，再以 `hard_link` 原子抢占最终路径；已存在
  相同结果允许幂等重放，内容不同、损坏、身份不同或并发输家的结果禁止覆盖；
- metrics API 只读取 `artifacts/backtests/{run_id}/summary.json`，并校验 canonical workspace、
  Run/StrategyVersion/参数/数据/引用/时间/边界；使用 Bytecode Alliance `cap-std` 与
  `cap-fs-ext` 在 Unix/Windows 逐级 no-follow 打开目录与结果文件，对同一文件句柄读取的
  原始字节先校验可信结果哈希再解析，文件/目录 symlink、reparse point、路径替换和原地篡改
  均 fail closed；
- Sandbox/Live 不提供 metrics；全部非 GET 方法返回稳定 405；
- OpenAPI 生成 TypeScript/Zod SDK，前端 Product client 严格验证 path identity，Run 详情仅对
  completed/available Backtest 加载指标；页面展示 PnL/收益统计并明确“研究结果，不代表
  Live 准入”。
