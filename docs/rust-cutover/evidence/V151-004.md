## Summary

Tightened the v0.15 production live-alpha dry-run order gate to accept only
`LIMIT` order intents and reject `MARKET` before request-preview construction.

Plain Chinese summary: dry-run order gate 现在只接受 `LIMIT`，`MARKET` 会直接失败。
这个变更只收紧本地预览门禁，不联网、不发生产请求、不调用生产 adapter、不真实下单。
