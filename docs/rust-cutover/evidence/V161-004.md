# V161-004 Evidence - non-marketable price safety preflight

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.1
Status: local validation PASS; hosted smoke PASS

## Summary

V161-004 adds non-marketable price safety evidence to the v0.16 production
mutation request builder. The builder now requires market reference source and
reference price evidence, computes the LIMIT price distance from the reference,
blocks missing/unsafe references, blocks crossing prices, and requires owner
acknowledgement that v0.16 has no automatic cancel path.

Plain Chinese summary: 这次只加 request-builder 的价格安全口径。大白话：因为 v0.16
没有自动撤单，构建请求对象前必须证明价格不是明显 marketable；缺参考价或会跨价差就直接
阻断，不进入发单考虑。
