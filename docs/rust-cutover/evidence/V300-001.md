## Summary

V300-001 defines the v0.30.0 Backend Production Go-Live Candidate boundary
contract. The contract separates backend production readiness, backend go-live
candidate evidence, and actual backend production go-live. Candidate artifacts
are evidence-only and cannot carry runtime effects, default enablement, or
ambiguous `backend_go_live=true` claims.

Plain Chinese summary: 本任务建立 v0.30.0 的 backend go-live candidate 边界。
它只允许为后续 go/no-go 审查收集候选证据；任何 backend_go_live=true、默认 production
execution、产品级实盘交易终端、submit、mutation、adapter send、live exchange request、
automatic remediation 或交易控件声明都会 fail closed。
