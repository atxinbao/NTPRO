## Scope

Included:

- define account identity, strategy identity, venue node identity, and the
  composite isolation scope key;
- define isolation boundaries for accounts, strategies, venues, nodes, adapters,
  dashboards, logs, and evidence artifacts;
- define allowed read paths and future owner-approved control paths;
- define explicit non-goals and release claims for v0.23.0;
- define validation and evidence requirements for downstream V230 tasks;
- add traceability from #713-#718 to the contract sections they must satisfy.

Not included:

- runtime implementation;
- adapter implementation;
- dashboard implementation;
- live trading capability expansion;
- submit, cancel, replace, amend, flatten, retry, or automatic remediation;
- bypassing v0.22.1 required-false runtime boundary hardening.
