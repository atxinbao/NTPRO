# P0-001 - Public Surface Cleanup

Milestone: M0 - Public messaging and release gate convergence
Priority: P0
Owner role: Rust Product Surface Agent
Review role: Verification Release Gatekeeper
Risk: medium

## Goal

Unify the public v0.2.0 product wording around Local Multi-Node Runtime Foundation and remove misleading production/live/release claims.

## Dependencies

- None

## Scope

- Keep v0.2.0 scoped to Local Multi-Node Runtime Foundation.
- Preserve sandbox/local-only boundaries unless this task explicitly says otherwise.
- Create task evidence under `docs/rust-cutover/evidence/`.

## Non-goals

- Do not create release tags or publish GitHub Releases from this task.
- Do not claim production live trading readiness.
- Do not connect to real exchanges or submit real orders.
- Do not add manual order entry, Dashboard UI scope, or distributed multi-server orchestration unless the task explicitly asks for it.
- Do not introduce Python, PyO3, or Cython product surfaces.

## Implementation guidance

README must state Current source tag: ntpro-rust-only-v0.2.0 and Capability: Local Multi-Node Runtime Foundation. CLI help for live, supervisor, and ntpro-node must say sandbox-only/local-only. Public docs must list Dashboard, production exchange connectivity, real account connectivity, real order submission, manual order entry, distributed deployment, and release artifact delivery as not included.
