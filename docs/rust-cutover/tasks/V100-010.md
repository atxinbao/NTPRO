# V100-010 Wire Offline and Manual Release Gates

Date: 2026-06-19
Executor: Codex
Status: IN PROGRESS

## Goal

Wire v0.10.0 Binance Testnet Order Proof gates into local, PR, and tag release
verification while keeping all default automation offline and fail-closed.

## Scope

- Add a default offline v0.10 release gate bundle.
- Add a separate manual order-proof preflight gate.
- Add PR smoke path detection for v0.10 gate and release-script changes.
- Add tag release matrix stages for the v0.10 offline and manual preflight
  gates.
- Document the release gate boundary and evidence.

## Out Of Scope

- No real Binance testnet submit.
- No real Binance testnet cancel.
- No production Binance endpoint.
- No real funds.
- No Dashboard order controls.
- No automatic completion of V100-006.
- No tag or GitHub Release.

## Acceptance

- Default CI and release gates do not require Binance credentials.
- Default CI and release gates do not open Binance network connections.
- Offline gates cover fail-closed behavior, schema checks, redaction checks,
  reconciliation/orphan fixtures, and read-only Dashboard proof display.
- Manual order proof remains a separate explicit owner-gated artifact package
  validator.
- `scripts/ai/verify_release.sh` exposes v0.10 gate stages.
- `.github/workflows/rust-cutover-smoke.yml` and
  `.github/workflows/release-tag.yml` include the v0.10 gates.
