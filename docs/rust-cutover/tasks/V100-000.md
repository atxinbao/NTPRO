## Goal

Define the v0.10.0 Binance Testnet Order Proof boundary before any order-path
implementation starts.

Plain Chinese summary: 本任务只把 v0.10.0 的“Binance testnet 小额下单再撤单证明”
边界写清楚。默认本地、CI 和自动化都必须离线失败关闭；真正 `POST /api/v3/order`
和 `DELETE /api/v3/order` 只能在 owner 明确批准、手动在线 gate 打开、使用 testnet
凭据时执行。

## Scope

- Define the v0.10.0 product claim and non-claim.
- Define allowed Binance testnet order-proof endpoints.
- Define forbidden production, real-funds, Dashboard-control, and strategy-driven
  production execution surfaces.
- Define one-symbol, tiny-notional, cancel-after-submit, redaction, and recovery
  rules.
- Define offline automation vs manual online proof boundaries.

## Non-Goals

- No real Binance production endpoint use.
- No real funds.
- No production trading.
- No Dashboard order buttons or cancel buttons.
- No automatic CI order submission.
- No tag or GitHub Release creation.

## Acceptance

- Create `docs/rust-cutover/release/v0_10_0_order_boundary.md`.
