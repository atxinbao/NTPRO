# V03-007 - Data source / execution / risk panels

Milestone: v0.3 Dashboard MVP
Priority: P1
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk: medium

## Goal

Implement Dashboard panels for Data Sources, Execution Gateways, and Risk
Engine status.

Plain language: the operator should see whether data is flowing, execution is
started, and risk is allowing or blocking activity.

## Dependencies

- `V03-006`

## Scope

- Data Sources panel shows:
  - source alias;
  - source kind;
  - provider or venue;
  - connection;
  - freshness or lag when available;
  - health;
  - redacted last error.
- Execution panel shows:
  - gateway alias;
  - venue;
  - connection;
  - started state;
  - redacted account reference;
  - open, in-flight, and closed order count summary;
  - redacted last error.
- Risk panel shows:
  - trading state;
  - health;
  - command count;
  - event count;
  - rejections total;
  - redacted last rejection;
  - redacted last error.

## Non-goals

- Do not add order entry.
- Do not add order modification or cancellation.
- Do not display raw orders, raw fills, raw venue payloads, full account
  objects, credentials, or signing material.
- Do not imply real exchange connectivity when v0.3 evidence is sandbox/local.

## Implementation guidance

If v0.3 cannot derive a field from v0.2 artifacts, show
`unknown`, `not_configured`, `not_supported`, `stale`, or `redacted` visibly.
Do not hide unavailable state.

## Verification criteria

- Browser or Playwright verifies Data Sources, Execution, and Risk panels render
  for two sandbox nodes.
- Missing fields are visible as explicit unavailable states.
- The rendered page contains no raw order, raw fill, raw venue payload, full
  account object, credential, or signing material.
- Tests cover panel rendering with unknown and not configured states.
