# PAR-003 Risk Reducing Order-List Fixture Repair

Date: 2026-07-29
Executor: Codex
GitHub issue: #1171
Risk: high
Classification: separately-scoped-runtime-maintenance
Status: REVIEW_REQUIRED

## Goal

Restore the ignored BUY and SELL order-list regressions for
`TradingState::Reducing` with real portfolio state and precision-stable
fixtures.

中文摘要：旧测试只发送了一个“开仓命令”，但没有产生真实持仓，所以它们验证的
前提并不存在。本任务使用已成交订单构造 LONG/SHORT Position，写入 Cache 并初始化
Portfolio，随后证明会扩大同向敞口的订单列表逐单拒绝，而且不会进入执行队列。

## Scope

- restore the two order-list REDUCING tests to the default risk suite;
- use the existing `OrderFilled -> Position -> Cache -> Portfolio` fixture path;
- assert every order-list member receives an `OrderDenied` event;
- assert a rejected order-list never reaches the execution queue;
- replay BUY+LONG and SELL+SHORT rejection through the existing Rust risk
  golden-trace harness;
- verify standard and high-precision configurations;
- update both ignored-test registers until PAR-011 unifies them.

## Non-Goals

- no production `RiskEngine` behavior change unless a new failing regression
  proves one is required;
- no change to TradingState transitions or portfolio accounting;
- no adapter, CLI, public API, order submission, or mutation capability;
- no edit to frozen `docs/rust-cutover/release/v0_32_0_*` files.

## Behavior Contract

1. A BUY order-list is denied when Portfolio is net LONG for its instrument.
2. A SELL order-list is denied when Portfolio is net SHORT for its instrument.
3. Every initialized member of the rejected list receives the same directional
   REDUCING denial reason.
4. No rejected list command is forwarded to execution.
5. Position and order quantities use exact decimal strings and pass the
   standard and high-precision builds.
6. The executable risk trace compares normalized event payloads, instrument,
   direction, reason, timestamps, and forwarding state.

## Acceptance

- both former ignored tests run in the default suite;
- BUY+LONG produces two denial events and zero execution commands;
- SELL+SHORT produces three denial events and zero execution commands;
- `risk_rejection_schema.jsonl` contains executable BUY and SELL list cases;
- standard/high-precision risk tests, Clippy, golden trace, risk inventory,
  current governance, backend freeze, and fast smoke pass;
- independent review and hosted checks approve the high-risk change.
