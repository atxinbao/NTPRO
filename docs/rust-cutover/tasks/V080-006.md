# V080-006 Display authenticated read-only probe artifacts in Dashboard read-only mode

Date: 2026-06-16
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: AUTO_MERGE_ELIGIBLE_AFTER_OWNER_DOWNGRADE

## Goal

Expose the authenticated Binance testnet read-only probe artifact in the local
Dashboard read model and UI. The Dashboard must remain an artifact viewer only.

Plain language: the Dashboard can show that an authenticated read-only proof
artifact exists and what safe redacted status it recorded, but it cannot read
secrets, start a probe, connect to Binance, or submit/cancel orders.

## Scope

- Read completed `testnet/authenticated_readonly_probe.json` artifacts through
  the existing local workflow manifest reader.
- Display only redacted/safe fields:
  - authenticated probe status;
  - endpoint kind;
  - request method;
  - response shape;
  - response shape validation flag;
  - API key / secret presence booleans;
  - secrets redacted flag;
  - account mutation flag;
  - real orders submitted flag;
  - production venue connection flag.
- Add Dashboard tests proving the artifact is consumed read-only.
- Keep all output free of raw secret values, raw account response bodies,
  signatures, signed URLs, signed queries, balances, and uid values.

## Non-Goals

- No Dashboard credential input.
- No Dashboard action route to start HTTP, WebSocket, or authenticated probes.
- No env secret read from Dashboard code.
- No order submission, cancel, replace, amend, or account mutation.
- No production Binance connectivity.
- No real funds.
- No production trading.

## Acceptance

- Dashboard snapshot can consume `testnet/authenticated_readonly_probe.json`.
- Dashboard UI renders authenticated read-only status and safe boundary flags.
- Dashboard output does not include raw secret values, raw account body,
  signatures, signed query, signed URL, balances, or uid.
- No new network/probe/order route is added.
- Validation commands are recorded in evidence.
- PR is auto-merge eligible after explicit owner downgrade.
