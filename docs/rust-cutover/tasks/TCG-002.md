# TCG-002 - 统一并强制 Rust 1.95.0 工具链解析

Date: 2026-08-05
Executor: Codex
GitHub issue: #1234
Risk: medium
Owner role: Verification & Release Gatekeeper

## 目标

以 `rust-toolchain.toml` 为唯一版本权威，消除 Homebrew Rust 1.87.0 抢占 NTPRO 验证
脚本的问题，并保证 Cargo.toml MSRV、Rust/Cargo 可执行文件、Makefile 和所有直接 Cargo
治理入口统一使用 1.95.0。

## 范围

- `scripts/rust-toolchain.sh`；
- `scripts/ai/toolchain_env.sh`；
- `scripts/ai/check_rust_toolchain_pin.sh`；
- `scripts/ai/ntpro_governance.sh`；
- `scripts/ai/check_product_path_lints.sh`；
- `scripts/ai/run_backend_benchmark_workload.sh`；
- `scripts/ai/verify_fast.sh`；
- `Makefile`；
- `.github/workflows/rust-cutover-smoke.yml`；
- `.github/workflows/backend-performance.yml`；
- `.github/workflows/release-tag.yml`；
- `.github/workflows/release-publish.yml`；
- `docs/rust-cutover/verification/toolchain.md`；
- `docs/rust-cutover/tasks/TCG-002.md`；
- `docs/rust-cutover/evidence/TCG-002.md`。

## 非目标

不升级 Rust，不修改产品运行时、API、依赖或 v0.32.0 冻结文件，不卸载 Homebrew Rust，
不改变 NTPRO 之外项目的默认工具链。

## 验收

```bash
bash -n scripts/rust-toolchain.sh scripts/ai/toolchain_env.sh \
  scripts/ai/check_rust_toolchain_pin.sh scripts/ai/ntpro_governance.sh \
  scripts/ai/check_product_path_lints.sh scripts/ai/run_backend_benchmark_workload.sh \
  scripts/ai/verify_fast.sh
ruby -e 'require "yaml"; Dir[".github/workflows/*.yml"].each { |f| YAML.load_file(f) }'
scripts/ai/check_rust_toolchain_pin.sh
scripts/ai/verify_fast.sh
scripts/ai/check_backend_hygiene.sh
scripts/ai/check_backend_freeze_baseline.sh
cargo metadata --no-deps --format-version 1
cargo clippy -p ntpro-governance --all-targets -- -D warnings
git diff --check
```

最终 head 独立复审、hosted checks 通过后手动合并，不启用 auto-merge。
