# V031-006 - pause and resume semantics contract

Milestone: v0.3.1 Local Supervisor Control Console Hardening
Priority: P1
Owner role: Control & Scope Agent
Review role: Verification & Release Gatekeeper
Risk: low

## Goal

Document the exact `pause` and `resume` semantics for the local Supervisor
control console so users do not mistake them for production runtime suspension.

Plain language: write down what pause/resume do, and just as importantly what
they do not do.

## Dependencies

- `V031-005`

## Scope

- Create a local pause/resume contract document for the Supervisor path.
- State explicitly that pause/resume are not OS signal suspension.
- State explicitly that pause/resume are not production live-trading runtime
  suspension.
- State what remains observable and controllable while paused.
- Align the contract wording with current local artifact behavior.

## Non-goals

- Do not implement runtime-level pause/resume.
- Do not claim adapter, strategy, or execution-loop suspension.
- Do not create new control APIs.
