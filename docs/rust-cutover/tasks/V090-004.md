## Goal

Give Strategy Session a sustained market input stream rather than a one-shot
workflow artifact.

## Automation Scope

This is a medium-risk automation slice because it uses local fixture/mock input
only and must not introduce credentials, networking, or exchange submission.

## Scope

- Support fixture bar stream.
- Support mock tick/bar stream.
- Write `market_status.json`.
- Write `market_events.jsonl`.
- Record `last_event_at` and `event_count`.

## Non-Goals

- No Binance WebSocket.
- No production market data.

## Acceptance

- `market_status.connection = fixture_stream_running`.
- `market_events.jsonl` contains events.
- Strategy runtime consumes market events.
