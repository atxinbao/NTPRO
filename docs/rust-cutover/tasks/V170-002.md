# V170-002 - Add exchange readback mapper

Date: 2026-06-24
Executor: Codex
Milestone: v0.17.0 production reconciliation and orphan recovery
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Map redacted Binance `GET /api/v3/order` and `GET /api/v3/openOrders`
readback metadata into normalized exchange order state for one v0.16 mutation
candidate lineage.

Plain Chinese summary: 这个任务只做“交易所只读回查结果标准化”。大白话：把已经脱敏的
订单状态和 openOrders 结果翻译成统一字段，例如订单是 open、filled、canceled、rejected，
以及 openOrders 里还能不能看到这笔订单。它不判断是不是孤儿单，也不自动处理。

## Scope

Included:

- add `live production-mutation-exchange-readback-mapper`;
- consume the V170-001 local order ledger;
- consume redacted `order` and `openOrders` readback metadata fixtures;
- output `exchange_order_state`, `exchange_order_status`,
  `open_order_observed`, and `terminal_state_observed`;
- cover `NEW`, `FILLED`, `CANCELED`, `REJECTED`, missing order, malformed
  readback, and empty openOrders;
- keep classification and orphan detection for later tasks.

Not included:

- network readback execution;
- reconciliation classifier;
- orphan detection;
- automatic cancel, retry, replace, amend, correction, flatten, or remediation;
- Dashboard order/cancel controls;
- multi-account or multi-venue readback;
- release tag creation.

## Acceptance Criteria

- Mapper artifact uses
  `schema_version=ntpro.v170_production_mutation_exchange_readback_mapper.v1`.
- Ready mapper sets `exchange_readback_mapped=true`.
- Ready mapper keeps `reconciliation_classified=false` and
  `orphan_risk_detected=false`.
- `NEW` maps to `exchange_order_state=open`.
- `FILLED`, `CANCELED`, and `REJECTED` map to terminal states.
- Missing order maps to `exchange_order_state=missing`.
- Malformed readback writes a blocked artifact, not raw response material.
- Empty openOrders maps `open_order_observed=false`.
- API keys, secrets, signatures, signed query/URL, raw exchange response,
  response body, and response headers are not persisted.
- Duplicate submit, retry, cancel, remediation, and Dashboard order controls
  remain disabled.
