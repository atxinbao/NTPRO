# V160-003 - Add production signing material approval artifact

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.0 minimum owner-approved production order mutation candidate
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Add the v0.16 signing material approval artifact required before the production
mutation runtime gate can move past `blocked_signing_approval`.

Plain Chinese summary: 这个任务加的是“生产 signing material 使用审批单”。大白话：
owner 必须明确批准本次 candidate 可以使用 `production_live_alpha` 的 env-only
签名材料，系统才会生成 ready artifact。但这个 artifact 只证明“签名材料被批准可用于
候选请求预览链路”，不允许发请求、不允许联网、不允许真实下单。

## Scope

Included:

- add `live production-mutation-signing-approval`;
- write `ntpro.v160_production_mutation_signing_approval.v1` artifact;
- require explicit owner signing-material confirmation flags;
- require a v0.15 request preview using `credential_material=production_live_alpha`;
- require production signing material gate evidence from the request preview;
- record only environment variable names and approval metadata, not secret
  values;
- keep signatures, signed queries, signed URLs, raw request bodies, network,
  production order submission, mutation, listenKey lifecycle, and Dashboard
  order controls disabled;
- allow the v0.16 runtime gate to accept a ready signing approval artifact, then
  stop at `blocked_explicit_send_gate`.

Not included:

- production HTTP send path;
- production order submission;
- production order-test submission;
- cancel, replace, amend, retry, correction, or flatten;
- response redaction after real send;
- post-submit readback;
- listenKey lifecycle;
- Dashboard order controls;
- trading engine semantic changes.

## Acceptance Criteria

- Synthetic request preview produces `blocked_request_preview`.
- Missing signing approval confirmations produce `blocked_missing_gate`.
- Production live-alpha request preview with owner confirmations produces
  `ready_signing_material_approval`.
- Ready signing approval records:
  - `credential_material=production_live_alpha`;
  - `owner_approved_signing_material=true`;
  - `signing_approval_ready=true`;
  - `production_signing_material_gate_open=true`;
  - `production_signing_material_env_read=true`;
  - `api_key_value_recorded=false`;
  - `api_secret_value_recorded=false`;
  - `signature_recorded=false`;
  - `signed_query_recorded=false`;
  - `signed_url_recorded=false`;
  - `request_body_recorded=false`;
  - `raw_request_body_recorded=false`;
  - `request_sent=false`;
  - `network_attempted=false`;
  - `production_orders_submitted=0`;
  - `production_order_mutations_attempted=0`;
  - `dashboard_order_controls_enabled=false`.
- Runtime gate with ready signing approval produces
  `blocked_explicit_send_gate`, with `runtime_gate_open=false` and
  `send_consideration_allowed=false`.
