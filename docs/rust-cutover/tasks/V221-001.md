## Goal

Close out the completed `v0.21.1` and `v0.22.0` release governance records and
write auditable evidence for the transition into `v0.22.1`.

Plain Chinese summary: 本任务只做发布治理收口。`v0.21.1` 和 `v0.22.0` 已经
发布、tag 存在、hosted release gate 成功，GitHub milestone 也已关闭。本任务把这些
live GitHub 事实写回源码仓库，作为 `v0.22.1` runtime boundary hardening 和
read-model replay 扩展的起点。它不改 runtime，不新增交易能力，也不启动 `v0.23.0`
实现。

## Scope

Included:

- record `v0.21.1` release URL, tag commit, tree, hosted release gate, and
  closed milestone state;
- record `v0.22.0` release URL, tag commit, tree, hosted release gate, and
  closed milestone state;
- record closed V211 and V220 issue sets;
- record current open issue/PR state after the `v0.22.1` and `v0.23.0`
  planning issues were created;
- state that `v0.22.0` is a Trader Terminal Workbench / runtime bridge release,
  not a complete executable read-model runtime and not a product-grade live
  trading terminal;
- preserve the hard blocker chain from `v0.22.1` to `v0.23.0`.

Not included:

- runtime behavior changes;
- dashboard rendering changes;
- release workflow changes;
- tag creation or GitHub Release publication;
- multi-account, multi-strategy, or multi-venue node implementation;
- submit, cancel, retry, replace, amend, flatten, or automatic remediation.

## Acceptance Criteria

- `docs/rust-cutover/release/v0_22_1_release_closeout_evidence.md` records the
  live release, milestone, issue, and workflow evidence for `v0.21.1` and
  `v0.22.0`.
- `docs/rust-cutover/evidence/V221-001.md` records the task evidence and
  validation commands.
- `docs/rust-cutover/release/README.md` links the closeout evidence.
- The evidence explicitly states the `v0.22.0` capability boundary.
- No runtime or adapter files are changed.
