## Goal

Expose v0.12 production online read-only and persistent shadow evidence in the
local Dashboard as a read-only status panel.

Plain Chinese summary: 这次不是给 Dashboard 加下单按钮，也不是让 Dashboard 去连生产
交易所。它只把本地已有的 v0.12 artifacts 展示出来：生产只读探测、账户快照、
shadow portfolio runtime、shadow strategy session、reconciliation 分类和 risk halt 状态。

## Scope

- Extend `DashboardSnapshot.production_shadow` with v0.12 read-only status
  fields.
- Prefer `artifact_root/v0_12` artifacts when present.
- Preserve existing `artifact_root/v0_11` compatibility.
- Show:
  - production public read-only probe status;
  - authenticated account snapshot status;
  - response-shape validation status;
  - shadow portfolio runtime status;
  - shadow strategy session state and heartbeat count;
  - reconciliation classification and recommended local-only action;
  - risk-halt, manual-review, and new-order-blocked status;
  - invariant zero/false boundary counters.
- Keep Dashboard order controls absent.

## Non-Goals

- No production cancel, replace, amend, retry, or correction orders.
- No production order-state reads.
- No listenKey lifecycle access.
- No credential input fields.
- No production network probe launched by Dashboard.
- No real-funds trading.
