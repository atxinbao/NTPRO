Date: 2026-06-21
Executor: Codex

## Goal

Harden the v0.13 proof-pack evidence wording so users and agents do not confuse
an implemented owner-run wrapper with included owner-run online success
evidence.

Plain Chinese summary: 这个任务是把 proof pack 说清楚：脚本和 wrapper 已经有了，但
默认 release/CI 不联网，也不包含 owner 真实跑成功的线上证据。只有 owner 显式开 gate
并成功完成 public GET + account GET 时，才算 included owner-run success evidence。
