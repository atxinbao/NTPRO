# V080-005 Add Synthetic Secret Leak Regression Scanner

## Goal

Add a CI-safe synthetic secret leak scanner for the authenticated Binance
testnet read-only proof track. The scanner must prove that env-only synthetic
credentials and synthetic signatures do not appear in stdout, stderr, workflow
artifacts, dashboard snapshots, logs, or PR evidence snippets.

## Scope

- Add a reusable scanner script for synthetic Binance testnet secret tokens.
- Add a v0.8 default offline gate that runs the workflow with synthetic
  env-only credentials and a closed network gate.
- Scan generated command output, workflow artifacts, generated dashboard
  snapshot fixture, generated logs, and generated PR evidence snippet.
- Wire the v0.8 offline gate into release verification.
- Wire PR smoke so v0.8 scanner/gate changes run the v0.8 offline gate.

## Non-Goals

- No real Binance credentials.
- No network connection.
- No authenticated online proof.
- No order submission, cancel, replace, amend, or account mutation.
- No production Binance connectivity.
- No real funds.
- No production trading.

## Acceptance

- Synthetic API key, API secret, and signature tokens cause a hard failure if
  they appear in scanned outputs.
- The scanner includes a self-test proving an intentional leak fails.
- The v0.8 default offline gate runs without network access and scans generated
  stdout/stderr, artifacts, dashboard snapshot, logs, and evidence snippet.
- Release verification exposes a `v08-default-offline-gate` stage.
- PR smoke runs the v0.8 gate when v0.8 scanner/gate files change.
