## Goal

Add the v0.25.0 read-only Dashboard / Trader Terminal surface for monitoring,
alert, incident, runbook/audit, and DR preview evidence while keeping every
trading operation control disabled.

Plain Chinese summary: 本任务把 v0.25.0 的 monitoring、alert、incident、
runbook/audit 和 DR preview 证据接入 Dashboard / Trader Terminal 只读面板。它只展示
状态、provenance、freshness、redaction、ack、runbook evidence 和 DR preview 引用；
不新增 submit/cancel/retry/replace/amend/flatten/order-ticket 控件，不新增 live
control API，也不把 Dashboard 声称为产品级实盘终端。

## Scope

Included:

- Extend the existing Trader Terminal Workbench read-model bridge with v25
  monitoring, alert, incident, runbook/audit, and DR preview component fields.
- Add a v25 Workbench tab and Unified Read Model table fields for read-only
  Dashboard visibility.
- Fail closed when v25 surface artifacts have missing provenance, missing
  redaction, forbidden control markers, live exchange request markers, adapter
  send markers, order-ticket markers, or operation boundary violations.
- Degrade or stale the surface for missing/stale artifacts without claiming
  healthy readiness.
- Add golden trace and release verifier coverage for ready, malformed/stale,
  and forbidden-control ingestion cases.

Not included:

- Submit, cancel, retry, replace, amend, flatten, order-ticket, or funds
  transfer controls.
- Live control API or adapter send.
- Production order mutation, live exchange request, retry scheduler, or
  automatic remediation.
- Product-grade live trading terminal readiness claim.

## Acceptance Criteria

- Dashboard / Trader Terminal renders monitoring health, alert route, incident
  state, acknowledgement status, runbook evidence, and DR preview status.
- Missing provenance, freshness, or redaction never renders as healthy.
- Forbidden operation control markers fail closed.
- The renderer contains no buttons, forms, fetch action, workbench action, or
  order-control endpoint for the v25 surface.
- `scripts/ai/verify_release.sh v25-dashboard-monitoring-surface` passes.
- Existing v25 prerequisite release stages still pass.
