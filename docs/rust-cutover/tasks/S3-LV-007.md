# S3-LV-007 - 真实执行适配器、订单生命周期与独立下单准入

Date: 2026-08-12

Review role: Verification & Release Gatekeeper
Status: DONE

## 目标

在 S3-LV-006 的 Live Run 候选和生产行情基础上，增加一个不从行情权限继承的真实执行准入。
首个执行切片只允许一个经 owner、risk、operator 三方确认的 Binance Spot `LIMIT/GTC`
订单，由现有 `BinanceExecutionClientFactory` 发送，并将 submission_requested、submitted、
accepted、rejected、denied、partially_filled、filled、canceled、expired 和 submission_failed
投影为可审计结果。

## 状态机

```text
created -> preflight_ready(rev1, blocked)
              -> owner/risk/operator approvals (workspace anchors, still blocked)
              -> preflight_ready(rev2, authorized and externally anchored)
                  -> starting(rev3) -> market_data_running(rev4)
                         |                     |
                         +------ failed -------+
```

- `start_market_data` 保持 S3-LV-006 只读边界，不获得执行客户端；
- owner、risk、operator 三个审批端点分别写入不可替代的审批工件和外部回执；前两份审批不会
  改写 Run revision，三份齐全后才写入一次性准入工件和新的外部锚定状态 revision；
- `start_execution` 只允许从已锚定准入的 `preflight_ready` 进入，并启动同时包含行情与执行客户端的
  `Environment::Live` 节点；
- 准入工件绑定 Run、StrategyVersion、account、venue、订单、幂等键、风险上限和失效时间；
- 同一准入只能消费一次，失败或未知状态阻断新订单并要求人工停止和审查。

## 独立准入

- owner、risk、operator 必须分别持有机构用户、风控和运维会话；三个审批端点只接受对应角色
  cookie，任一角色不能替其他角色代签；
- risk 权威来自版本绑定的 `[risk]` 配置，订单请求上限只能收紧、不得超过配置上限；
- owner、risk、operator 的权威引用必须非空且互不相同；每次角色审批都必须显式确认同一份
  不可变订单提案；
- `NTPRO_S3_LIVE_RUN_EXECUTION_SINGLE_SHOT=1` 是独立执行 gate，不从行情 gate 继承；
- kill switch 必须显式为 `false`；
- 账户只读 preflight、可交易能力、StrategyVersion 和来源引用必须继续有效；
- 订单只允许 manifest 中的单个 Binance Spot instrument；
- 首个切片只允许 `LIMIT/GTC`、正数 price/quantity、notional 不超过准入上限；
- 准入必须包含唯一幂等键和未来失效时间；
- 外部审计锚点写入失败、回退或身份漂移均 fail closed；
- 节点只接受与 externally anchored `starting` 状态精确绑定的 Runtime 配置和 artifact root；
- 节点在注册执行客户端前必须通过 compare-and-append 消费一次 starting authority；即使本地
  claim 工件丢失，远端最新锚点也会阻止第二个 Runtime 重放；
- admission 派生的确定性 client order ID 与发送前落盘状态共同保证重启不重放；
- API key/secret 只从环境读取，不写入配置、工件、响应或日志。

## 强制边界

- 不允许 market-data-only Runtime 自动升级；
- 不允许页面加载、Demo 结果或信号自动创建准入或发送订单；
- cancel、replace、批量订单、自动重试、自动修复、自动恢复和补偿交易继续关闭；
- 测试不得访问真实订单 endpoint；真实路径只通过执行适配器和显式生产准入可达；
- 不修改 `docs/rust-cutover/release/v0_32_0_*`，不关闭 S3 milestone。
