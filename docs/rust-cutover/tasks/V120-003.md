## Goal

Validate production read-only account snapshot response shapes without storing
raw responses.

Plain Chinese summary: 这次不是继续扩大联网能力，而是把生产只读账户快照返回值的
“形状检查”做细。NTPRO 只记录字段是否存在、字段类型是否正确、数组长度等聚合信息，
不保存账户原文、资产名、余额值、权限值、key、secret、signature 或 signed URL。

## Scope

- Add a redacted account snapshot response shape summary.
- Validate `accountType`, `balances`, `permissions`, `canTrade`,
  `canWithdraw`, and `canDeposit` shape.
- Treat unknown or incompatible shape as `response_shape_invalid`.
- Keep production online execution owner-gated by V120-002 gates.
- Add fixture tests for accepted and rejected shapes.
- Add `docs/rust-cutover/release/v0_12_0_response_shape.md`.
- Add `scripts/ai/verify_v12_response_shape.sh`.

## Non-Goals

- No new production endpoint.
- No production order submission.
- No production cancel, replace, amend, retry, correction, or listenKey
  lifecycle mutation.
- No open-order or order-state reads.
- No raw account response persistence.
- No raw balances, asset symbols, permissions, UID, headers, API key, secret,
  signature, signed query, or signed URL persistence.
- No Dashboard action controls.
