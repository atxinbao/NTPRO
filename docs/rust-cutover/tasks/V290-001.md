## Goal

Define the v0.29.0 Backend Production Readiness boundary before
implementation. The contract declares the subsystem readiness matrix, backend
claim rules, and required-false no-trading-control/no-go-live boundary.

Plain Chinese summary: 本任务定义 v0.29.0 的 Backend Production Readiness 边界合同和
readiness matrix。当前只证明 v0.28.1 发布依赖和 v0.29.0 边界矩阵本身可收口；
persistent audit、telemetry、permissions、read-only backend API、deployment/runbook、
monitoring/incident、canary/DR、fail-closed hardening 和 release gates 仍分别由后续
issue 关闭。本任务不声明 backend go-live，不声明产品级实盘交易终端，也不开放任何真实
交易控制。

## Dependency

- Depends on `V290-000` intake gate and its `start_gate_status = satisfied`
  proof.
- Hard-blocked by v0.28.1 issue closeout and published release evidence.
- Does not inherit submit, mutation, adapter-send, live-exchange, remediation,
  Dashboard/Admin/Trader Terminal trading-control, backend go-live, or
  product-grade terminal capability from v0.28.0 or v0.28.1.

## Scope

Included:

- Define the v0.29.0 backend production readiness boundary contract.
- Define the source-controlled readiness matrix.
- Classify each v0.29.0 subsystem as `production-ready`,
  `readiness-preview`, `blocked`, or `deferred`.
- Define what can be claimed as backend production-readiness evidence and what
  remains backend go-live or product work.
- Add a validator that recomputes matrix status and fail-closed violations.
- Add a release stage for the validator.

Not included:

- production order submission;
- cancel, replace, amend, flatten, or any production order mutation;
- execution adapter call, adapter send, or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal operation controls or trading controls;
- backend go-live;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- v0.29.0 cannot be described as production go-live or product-grade live
  trading.
- The readiness matrix is source-controlled and release-gated.
- Every production-readiness claim maps to evidence and verification commands.
- Blocked, deferred, and readiness-preview modules cannot be counted as v29
  production-ready closure.
- Any forbidden boundary flag set to `true` or missing fails closed.
