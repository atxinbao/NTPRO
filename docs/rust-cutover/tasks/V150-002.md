# V150-002 - Live order request dry-run builder

Date: 2026-06-22
Executor: Codex
Milestone: v0.15.0
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Add a production live-alpha order request dry-run builder that can construct a
redacted `POST /api/v3/order` request preview artifact without sending the
request, persisting signing material, calling an execution adapter, or enabling
production order mutation.

Plain Chinese summary: 这个任务只做“实盘下单请求长什么样”的本地预览。它可以用
env-only 的假 key/secret 在内存里签一次，证明请求形状能构造；但不能把 signature、
signed query、signed URL、API key、API secret 写进文件，也不能发网络请求，更不能
真实下单。

## Scope

Allowed:

- Add a Rust CLI command for v0.15 production live-alpha order request preview.
- Reuse the existing v0.14 dry-run order gate artifact as the input intent.
- Classify `POST /api/v3/order` and `/api/v3/order/test` through the central
  endpoint classifier.
- Build a memory-only signature when all owner/manual gates and env-only
  credentials are present.
- Write a redacted JSON artifact with request shape, classifier decision, and
  zero production mutation counters.
- Add local and CI-safe verification.

Out of scope:

- Sending any HTTP request.
- Calling any execution adapter or production adapter.
- Production order submission, cancel, replace, amend, retry, correction, or
  automatic remediation.
- listenKey lifecycle.
- Dashboard order controls.
- Persisting signature, signed query, signed URL, API key, API secret, or raw
  request body.

## Acceptance

- `live production-live-alpha-order-request-preview` writes a redacted artifact.
- Missing owner gates and credentials produce a blocked artifact.
- Ready path records:
  - `request_preview_built=true`
  - `request_sent=false`
  - `network_attempted=false`
  - `execution_adapter_called=false`
  - `production_adapter_called=false`
  - `production_orders_submitted=0`
  - `production_order_mutations_attempted=0`
  - `dashboard_order_controls_enabled=false`
- Artifact does not contain API key values, API secret values, `signature=`,
  signed query, signed URL, or raw query values.
