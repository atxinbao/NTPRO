## Goal

Add a v0.26.0 Dashboard / Trader Terminal product hardening read-only admin
boundary surface that displays permission, operation audit, deployment
provenance, upgrade/rollback preview, and stability/SLO evidence while keeping
all trading and remediation controls closed.

provenance drill-down、stale/degraded/fail-closed diagnostics；不新增 submit、
cancel、retry、replace、amend、flatten、order-ticket、live control API 或任何交易控件。

- Extend the Trader Terminal read-model bridge with v26 product hardening
  admin surface fields.

  evidence as read-only rows.

- Artifact ingestion tests cover ready, stale/degraded, fail-closed, and
  forbidden-control v26 surface cases.
