# S2-DM-003 - Demo 模拟成交、持仓、资金曲线与跨环境比较

Date: 2026-08-11
Executor: Codex
GitHub issue: #1284
Risk: high
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Status: REVIEW_REQUIRED

## 目标

让同一个不可变 `StrategyVersion` 的 Demo Run 通过仓库现有模拟执行引擎产生明确标注为
模拟的成交、持仓和资金曲线，并在策略工作台与 Backtest Run 统一比较。

## 范围

- 复用 `BacktestEngine`、`SimulatedVenue` 与 `EmaCross`，处理同一 Demo fixture stream；
- 为策略 session 增加模拟成交、持仓和权益工件，并纳入 manifest 的路径、记录数、字节数
  与 SHA-256 绑定；
- 扩展 Demo snapshot 的 running/frozen 结果，返回模拟执行摘要和明细；
- 将 `/api/product/v1/run-comparisons` 从 Backtest-only 提升为 Backtest/Demo 统一只读比较；
- 策略工作台 Run 详情展示模拟成交、持仓和资金曲线，比较页同时选择两种环境；
- 更新 OpenAPI、生成 TypeScript/Zod SDK、迁移说明、Roadmap、测试和证据。

## 非目标与硬边界

- 模拟成交不得冒充真实成交；
- 不开放真实 Live、外部 Venue、真实订单、撤改单、自动重试、自动补救或交易控件；
- Demo 结果不得自动产生 Live 权限；
- 不实现多节点调度或远程 Supervisor；
- 不修改 `docs/rust-cutover/release/v0_32_0_*` 冻结发布文件。

## 完成条件

Rust 模拟执行、Product API、前端、浏览器、风险清单、MVP freeze、current governance、
backend freeze 和 Rust-only gates 全部通过。任务为 high risk，必须取得独立 Gatekeeper 的
`REVIEW_APPROVED`，hosted checks 全绿后手动合并；禁止 auto-merge。

## 实施结论

本地实现和自动验证已完成。Demo Run 现在通过真实 `BacktestEngine + SimulatedVenue`
生成明确标注为模拟的成交、持仓和资金曲线；策略工作台可查看这些结果，并与 Backtest Run
做来源独立验证后的统一比较。当前状态为 `REVIEW_REQUIRED`，在独立审查、hosted checks
和手动合并完成前不得标记 `DONE`。
