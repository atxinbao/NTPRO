# V090-003 Add Built-In Demo Strategy Runtime

Date: 2026-06-18
Executor: Codex
Owner role: Rust Core Runtime Agent
Review role: Verification & Release Gatekeeper
Risk level: high
Status: BACKLOG
Depends on: V090-002

## Goal

Add a simple built-in strategy runtime so the node can run a strategy loop
instead of only smoke workflows.

## Strategy

```text
builtin: ema_cross_demo
input: fixture/mock bars
output: signal
```

## Scope

- Load strategy config.
- Initialize strategy state.
- Process market events.
- Generate signal artifact entries.

## Non-Goals

- No real market data.
- No order submission.
- No broad strategy framework.

## Acceptance

- Strategy processes a fixture stream.
- At least one signal is generated.
- Signal is written to `strategy/signal.jsonl`.
