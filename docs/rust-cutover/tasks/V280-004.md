## Goal

Move deployment / upgrade / rollback orchestration from the v0.27 preview
foundation into a v0.28 backend runtime closure artifact. The task validates
deploy, upgrade, rollback, blocked, degraded, and closed state transitions
without executing deployment, rollback, automatic remediation, adapter send, or
live exchange access.

Plain Chinese summary: 本任务把 deployment / upgrade / rollback orchestration 推进为
v0.28.0 backend runtime closure。它只用 source-controlled artifact 和 verifier
复放状态转换、owner approval、runbook provenance、source drift 和禁用边界；不执行真实部署、
不执行回滚、不触发自动修复、不访问 adapter/live exchange，也不开放 Dashboard/Admin 交易控件。

## Scope

Included:

- Define deploy, upgrade, rollback, blocked, degraded, and closed state
  transitions for deterministic preview replay.
- Require owner approval, fresh runbook provenance, linked runbook lineage, and
  no source drift before any operation preview can classify as ready.
- Add fail-closed cases for missing approval, stale runbook, source drift,
  forbidden automatic remediation, and forbidden production execution.
- Promote `deployment_upgrade_rollback_orchestration_runtime_closure` to
  `runtime-closed` in the v0.28 backend closure readiness matrix.

Not included:

- production deployment execution;
- rollback execution;
- automatic remediation;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler enablement;
- Dashboard/Admin trading controls;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- Orchestration state validates through a deterministic, source-controlled
  replay path.
- Missing owner approval fails closed.
- Stale runbook provenance fails closed.
- Source drift fails closed.
- Automatic remediation and production execution fail closed.
- No orchestration state can trigger trading operations, adapter sends, live
  exchange requests, retry scheduling, Dashboard/Admin trading controls, or
  product-grade terminal claims.
- `scripts/ai/verify_release.sh v28-deployment-orchestration-runtime-closure`
  passes.
- `scripts/ai/verify_release.sh v28-backend-closure-boundary-contract` reports
  runtime-closed=5, evidence-only=2, blocked=4, deferred=1.
