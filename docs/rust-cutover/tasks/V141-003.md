# V141-003 Rename Risk Decision Semantics

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Rename live-alpha risk preflight decision semantics so a dry-run risk approval
cannot be misread as permission to submit a production order.

Plain Chinese summary: 这个任务把“风控预检通过”改成更准确的“风控干跑通过”。通过只说明本地
dry-run 风控条件没挡住，不代表可以调用 execution adapter，也不代表可以真实下单。

## Scope

Included:

- change `risk_decision=approved` to `risk_decision=dry_run_approved`;
- change `risk_decision=rejected` to `risk_decision=dry_run_rejected`;
- add `execution_decision=blocked_no_production_mutation`;
- require Dashboard readiness to see both `dry_run_approved` and
  `blocked_no_production_mutation`;
- update the v0.14 live-alpha risk preflight verification script;
- update the live-alpha reconciliation golden trace expected decisions;
- keep v14 forbidden-field scans executable on hosted runners without `rg`;
- update V140-004 task/evidence wording to match the current artifact
  semantics.

Not included:

- production order submission;
- production order mutation, cancel, replace, amend, retry, or correction;
- execution adapter calls;
- network access;
- listenKey lifecycle;
- Dashboard order controls;
- real funds or real orders.

## Acceptance

- Approved dry-run path writes `risk_decision=dry_run_approved`.
- Rejected dry-run path writes `risk_decision=dry_run_rejected`.
- Every risk preflight artifact writes
  `execution_decision=blocked_no_production_mutation`.
- Dashboard live-alpha dry-run readiness requires
  `execution_decision=blocked_no_production_mutation`.
- Existing no-production-mutation counters remain false/zero.
- Live-alpha reconciliation golden trace replay uses the same dry-run decision
  semantics.
- Targeted tests, v14 risk preflight verification, fast verification,
  formatter, and diff hygiene pass.
