# V120-006 Add Production Read-Only Reconciliation Engine

Date: 2026-06-21
Executor: Codex

Status: BACKLOG
Depends on: V120-005

## Goal

Generate local v0.12 production read-only reconciliation events from redacted
account snapshots, shadow portfolio runtime, shadow strategy session events, and
shadow execution intents.

Plain Chinese summary: 这次不是做自动纠错，也不是把 NTPRO 接到生产订单读写上。它只是把
本地 shadow 证据做分类：正常、缺账户快照、缺 shadow portfolio、有 shadow intent 但没有
portfolio、发现生产 mutation 痕迹、需要人工复核。所有结果都只写本地
`reconciliation_events.jsonl`。

## Scope

- Add `live production-readonly-reconciliation`.
- Read optional redacted account snapshot JSON.
- Read optional v0.12 shadow portfolio runtime JSON.
- Read optional v0.12 shadow strategy session JSONL.
- Read optional local shadow execution intent JSONL.
- Write `v0_12/reconciliation_events.jsonl`.
- Classify:
  - `ok`;
  - `missing_account_snapshot`;
  - `portfolio_unavailable`;
  - `shadow_intent_without_portfolio`;
  - `production_mutation_forbidden`;
  - `manual_review_required`.
- Preserve invariant zero counters for production order submission, production
  mutation, order-state reads, listenKey lifecycle, and correction orders.

## Non-Goals

- No production order submission.
- No production cancel, replace, amend, retry, correction, or listenKey
  lifecycle mutation.
- No production order-state read.
- No production network probe.
- No real-funds trading.
- No Dashboard order controls.
- No automatic remediation.
- No change to execution/risk/portfolio trading semantics.
