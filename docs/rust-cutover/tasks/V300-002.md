## Goal

Create source-controlled production deployment plan and environment readiness
evidence for the v0.30.0 backend go-live candidate foundation.

Plain Chinese summary: 本任务把 v0.30.0 的生产部署计划和环境 readiness 证据落到源控。
它只做 dry-run/preview 证据，不执行生产部署，不开放 backend go-live，不开放 submit、订单
mutation、adapter send、live exchange request、automatic remediation 或
Dashboard/Admin/Trader Terminal 交易控件。

## Dependency

- Depends on `V300-000` intake gate and `V300-001` backend go-live candidate
  boundary contract.
- Hard-blocked by published v0.29.1 release evidence and closed v0.29.1
  milestone.
- Does not inherit submit, mutation, adapter-send, live-exchange, remediation,
  Dashboard/Admin/Trader Terminal trading-control, backend go-live, or
  product-grade terminal capability from v0.29.0 or v0.29.1.

## Scope

Included:

- Define deployment targets and environment inventory for the candidate plan.
- Bind artifact provenance to the published `ntpro-rust-only-v0.29.1` release
  evidence.
- Bind config provenance to source-controlled v30 plan evidence and prior v29
  deployment/readiness evidence.
- Record migration/upgrade prerequisites and rollback checkpoints as
  preview-only candidate evidence.
- Add a validator that rejects missing, stale, or mismatched environment
  evidence and any production deployment execution flag.
- Add a release stage for the validator.

Not included:

- production deployment execution;
- backend production go-live;
- default production submit;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal operation controls or trading controls;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- Deployment plan is reconstructable from source-controlled artifacts.
- Deployment targets, environment inventory, artifact provenance, config
  provenance, migration/upgrade prerequisites, and rollback checkpoints are
  represented in deterministic JSON.
- Missing, stale, and mismatched environment evidence fail closed.
- No production deployment is executed by this task.
