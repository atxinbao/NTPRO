Date: 2026-06-15
Executor: Codex

Review role: Control & Scope Agent
Risk level: medium
Status: PR_REQUIRED

## Goal

Clean current v0.7 workflow artifact identity leftovers that could make the
published v0.7 read-only testnet proof look like a v0.6 runtime foundation
artifact.

## Scope

- Keep current v0.7 workflow identities on stable generic names:
  - `binance-testnet-readonly-connectivity-foundation`;
  - `binance-testnet-readonly-no-order-lifecycle-{run_id}`;
  - `binance-testnet-artifact-only-reconciliation-{run_id}`.
- Update current Dashboard test fixtures from `v06-smoke` to
  `v07-readonly-smoke`.
- Add v07 offline gate checks that reject old runtime-foundation identity
  strings in current artifact payloads.
- Preserve explicit legacy config-declared run id fixtures where the test is
  intentionally proving config override behavior.

## Non-Goals

- No historical v0.6 release documentation rewrite.
- No artifact schema change.
- No authenticated account access.
- No account mutation.
- No order submission.
- No real funds.
- No production Binance connectivity.
- No production trading claim.
- No v0.8 capability work.
- No tag creation.
- No GitHub Release publication.

## Acceptance

- Current v0.7 Dashboard/workflow test fixtures no longer present `v06-smoke`
  as the workflow run identity.
- v07 default offline gate asserts current artifact identities use the
  `binance-testnet-readonly-*` naming.
- v07 default offline gate rejects `v06-binance-testnet-runtime-foundation` in
  current artifact identity payloads.
- v06 historical release docs/stage names are not rewritten.

## Required Validation

```bash
cargo fmt --check
cargo test -p nautilus-cli workflow --lib
cargo test -p nautilus-cli dashboard --lib
scripts/ai/verify_v07_default_offline_gate.sh
scripts/ai/verify_fast.sh

```

The second `rg` command is expected to find the release-gate sentinel string in
`scripts/ai/verify_v07_default_offline_gate.sh`; that match proves the gate is
checking for the old identity rather than emitting it as a current artifact.
