# V100-003 Add Order Risk Preflight

Date: 2026-06-19
Executor: Codex
Status: IN PROGRESS

## Goal

Add an offline, fail-closed order risk preflight before any future v0.10 Binance
testnet order request path.

## Scope

- Add a local CLI preflight command.
- Read a local preflight input JSON snapshot.
- Check session state, market freshness, account readability, kill switch,
  symbol allowlist, notional/open-order/clock limits, and endpoint boundary.
- Keep network access and order submission disabled.

## Out Of Scope

- No Binance API calls.
- No request signing.
- No `/api/v3/order/test`.
- No real submit/cancel.
- No Dashboard order controls.
- No production Binance endpoint.

## Acceptance

- Passing input produces a pass report.
- Missing manual gates fail before preflight evaluation.
- Stale market data fails closed.
- Active kill switch fails closed.
- Production endpoint fails closed.
- Limit violations fail closed.
- Output always records `network_attempted=false` and
  `real_orders_submitted=false`.
