# V241-006 - v24.1 release gates and strict provenance

Date: 2026-07-05
Executor: Codex
GitHub issue: #775

## Goal

Add the v0.24.1 patch release gate and strict provenance gate for the
Execution Algorithms And Order Control Foundation hardening patch.

## Scope

- Add `scripts/ai/verify_release.sh v24.1-release-gates`.
- Add `scripts/ai/verify_release.sh v24.1-strict-provenance`.
- Publish the v0.24.1 release manifest, release notes, and readiness report.
- Require V241-001 through V241-007 task and evidence files.
- Include v0.24.0 post-release closeout, tag/main/release-body provenance
  reconciliation, stale pre-tag cleanup, v24 schema replay classification,
  Dashboard artifact ingestion hardening, and fixture reference integrity.
- Keep v0.25.0 hard-blocked until all V241 issues are closed and v0.24.1
  release evidence is published.

## Acceptance

- Any missing V241 evidence fails the v0.24.1 release gate.
- Any true production submit, mutation, adapter send, live exchange request,
  retry scheduler, Dashboard operation control, order-ticket, or product-grade
  live trading boundary fails the gate.
- `NTPRO_RELEASE_GATE=1` requires the v0.24.1 tag to match `HEAD`, issue #775
  to be closed, and the v0.24.1 milestone to be closed.
- `NTPRO_V241_RELEASE_REQUIRE_PUBLICATION=1` reconstructs the public GitHub
  Release from the source-tree notes and live remote state.
- `NTPRO_V241_STRICT_REQUIRE_PUBLICATION=1` runs strict release-body
  provenance after publication.
- `v0.25.0` start gate fails closed until v0.24.1 release evidence is
  published.
