# V130-003 - Owner-run production online read-only proof pack

Date: 2026-06-21
Executor: Codex

## Goal

Define and verify the v0.13 owner-run production online read-only proof pack.

Plain Chinese summary: 这个任务不是打开实盘交易。它只是把“owner 手动运行的生产
只读证明包”整理成固定格式：默认 CI 不联网，只检查 fail-closed；owner 真要跑线上
GET 只读证明时，必须显式开 gate，生成的 artifacts 必须红action，不得包含密钥、签名、
raw account response、raw balances，也不能被误认为交易能力已经可用。

## Scope

Included:

- `scripts/ai/verify_v13_online_readonly_proof_pack.sh`;
- default offline/fail-closed proof-pack preflight;
- optional owner-run production public `GET /api/v3/time` proof packaging;
- optional owner-run authenticated production `GET /api/v3/account` proof
  packaging;
- manifest schema `ntpro.v130_online_readonly_proof_pack.v1`;
- artifact redaction checks for credentials, signatures, signed URLs, raw
  account response fields, and balances;
- explicit no-production-mutation and no-Dashboard-order-control fields.

Not included:

- default CI production network access;
- production order submission;
- production cancel / replace / amend / retry / correction;
- production order-state reads;
- listenKey lifecycle management;
- signed WebSocket user stream runtime;
- Dashboard order controls or credential entry;
- automatic remediation;
- real funds or production trading.
