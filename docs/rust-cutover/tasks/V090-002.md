# V090-002 Implement StrategySession State Machine

Date: 2026-06-18
Executor: Codex
Owner role: Rust Core Runtime Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V090-001

## Goal

Add a `StrategySession` state machine distinct from plain node lifecycle.

## Automation Scope

This is a medium-risk automation slice because it is limited to a default-off,
offline state machine and must not connect to live adapters or submit orders.

## States

```text
created
validated
starting
running
paused
risk_halted
stopping
stopped
failed
```

## Scope

- Define `StrategySessionStatus`.
- Define legal state transitions.
- Write `session_status.json`.
- Write state changes to `events.jsonl`.

## Acceptance

- `created -> validated -> starting -> running -> stopped` runs successfully.
- Illegal state transitions hard fail.
- `session_status.json` can be read by Dashboard / Supervisor code.
