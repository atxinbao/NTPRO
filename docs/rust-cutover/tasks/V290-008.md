## Goal

Define canary, rollback, and disaster-recovery preflight readiness for the
v0.29 backend production readiness line.

Plain Chinese summary: 本任务把 canary/rollback/DR preflight readiness 推进为
v0.29 backend production-readiness evidence。它定义 canary eligibility、rollback
triggers、DR drill evidence、freshness、provenance 和 owner approval requirements，
并用 deterministic preflight replay 验证 canary/rollback/DR plans；缺 canary
eligibility、缺 owner approval、stale DR evidence、unsafe rollback plan、ambiguous
go-live claim、forbidden execution 或 forbidden operation boundary 都会 fail
closed。本任务不执行真实生产 canary、rollback 或 disaster recovery。

## Scope

Included:

- Define canary eligibility, rollback triggers, DR drill evidence, freshness,
  provenance, owner approval, and preflight validation requirements.
- Add deterministic preflight validation for canary, rollback, and DR plans.
- Fail closed on missing canary eligibility, missing owner approval, stale DR
  evidence, unsafe rollback plan, ambiguous go-live claims, forbidden
  execution, and forbidden operation boundaries.

Not included:

- production canary execution;
- production rollback execution;
- disaster recovery execution or data restore;
- automatic remediation or strategy stop;
- adapter send or live exchange request;
- Dashboard/Admin/Trader Terminal trading controls;
- backend go-live or product-grade terminal readiness claims.
