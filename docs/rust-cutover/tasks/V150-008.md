# V150-008 Dashboard Live Alpha Mutation Preflight Panel

Date: 2026-06-22
Executor: Codex
Risk: medium
Auto-merge: allowed

## Goal

Add a read-only Dashboard surface for the v0.15 live-alpha mutation preflight
artifact chain.

Plain Chinese summary: 这个任务不是增加交易按钮，也不是让 Dashboard 能下单。它只是
让监督器控制台能看见 v0.15 的人工审批、请求预览、dry-run 执行和 kill switch
runtime gate 状态，方便 owner 在人工复核前判断现在是 blocked 还是 ready for owner
review。

## Scope

Allowed:

- display live-alpha mutation preflight readiness;
- display missing gates, risk reason, approval state, kill switch state, and
  order-state age;
- display redacted request preview metadata;
- display v0.15 artifact paths;
- add Dashboard tests proving the panel remains read-only.

Not allowed:

- production order submission;
- cancel, replace, amend, retry, reconnect, correction, or remediation controls;
- production adapter calls;
- real funds;
- production trading;
- trading semantic changes.

## Acceptance

The task is done when:

- `crates/cli/src/dashboard.rs` reads the v0.15 local artifacts;
- `/api/snapshot` exposes the preflight fields as read-only DTO values;
- the static Dashboard renders the fields without adding control buttons;
- a control/request-sent trace degrades the panel to boundary violation;
- local targeted Dashboard tests pass;
- release evidence is recorded under `docs/rust-cutover/evidence/V150-008.md`.
