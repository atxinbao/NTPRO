## Goal

Add the redacted artifact for authenticated Binance testnet read-only account
shape proof. The artifact path is:

```text
testnet/authenticated_readonly_probe.json
```

The schema is:

```text
ntpro.v08_binance_testnet_authenticated_readonly_probe.v1
```

## Scope

- Execute authenticated `GET /api/v3/account` only when the manual online gate
  is open and env-only testnet credentials are present.
- Validate account response shape without persisting the raw account body.
- Record a redacted artifact for both offline/deferred and online/manual proof
  states.
- Add the artifact to testnet manifest and event streams.
- Keep all sensitive material and account details out of artifacts:
  API key value, secret, header value, signature, signed query, signed URL,
  raw response body, balances, and uid.

## Non-Goals

- No default online call in CI.
- No production Binance connectivity.
- No order submission, cancel, replace, amend, or account mutation.
- No balances detail persistence.
- No uid persistence.
- No signed URL or signed query persistence.
- No raw account response persistence.
- No real funds.
- No production trading.

## Acceptance

- `authenticated_readonly_probe.json` is generated by the workflow.
- Manual online success records `response_shape_validated=true`.
- Deferred/offline state records no network attempt.
- `raw_response_recorded=false`.
- `balances_recorded=false`.
- `uid_recorded=false`.
- `account_mutation=false`.
- `order_submission=disabled`.
- `real_orders_submitted=false`.
- `production_venue_connection=false`.
- `real_funds=false`.
- `production_trading=false`.
- PR is auto-merge eligible after explicit owner downgrade.
