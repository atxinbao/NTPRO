# V090-001 Add Strategy Session Config Contract

Date: 2026-06-18
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V090-000

## Goal

Define a strategy session config so `ntpro-node` knows which strategy, market,
and allowed actions are in scope.

## Scope

- Add a strategy-session config contract.
- Validate `node.mode`, `strategy_id`, `market.symbols`, `execution.order_submission`,
  and `risk.kill_switch`.
- Support config validation for `strategy-session` kind.

## Hard Rules

- `node.mode` only allows `dry-run` or `shadow`.
- v0.9.0 `order_submission` must be `disabled`.
- `strategy_id` must be non-empty.
- `market.symbols` must be non-empty.
- `risk.kill_switch` must exist.

## Acceptance

- `config validate` supports strategy-session kind.
- Missing `strategy_id` hard fails.
- `order_submission != disabled` hard fails.
- `mode = live` hard fails.
