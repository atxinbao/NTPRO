## Goal

Replace the v0.21/v0.21.1 Python `jsonschema` validator with deterministic
Draft 2020-12 validation in the Rust governance CLI.

Plain Chinese summary: 本任务把 v0.21 read-model schema、36 个匹配合同版本的
snapshot 和 8 个 fail-closed 负向 mutation 迁移到 Rust。v0.25+ 的其他
read-model 合同和 event-only 事件不再被错误送入 v0.21 schema；旧 Python
validator 和 shell 中的 Python/uv 回退被删除。

## Scope

- use the maintained Rust `jsonschema` crate with Draft 2020-12;
- disable external HTTP and file resolution features;
- preserve schema strategy and capability-boundary checks;
- validate snapshots matching the schema contract version;
- preserve all eight negative mutations with intended-reason assertions;
- migrate the v0.21.1 boundary gate and delete the Python validator.

## Acceptance Criteria

- the schema passes Draft 2020-12 meta-schema validation;
- all 36 `ntpro.v210.unified_read_model.v1` snapshots pass;
- all eight negative mutations fail for the intended path or field;
- malformed snapshot payloads fail closed;
- no executable caller references the retired Python validator or Python
  `jsonschema` import;
- v0.32.0 frozen release files remain unchanged.
