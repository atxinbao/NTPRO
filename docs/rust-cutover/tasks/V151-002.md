# V151-002 - Implement manual approval consume artifact

Date: 2026-06-23
Executor: Codex
Milestone: v0.15.1 mutation dry-run semantics / approval / evidence hardening
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Harden v0.15 one-time manual approval semantics so a valid approval is consumed
after request-preview creation and cannot be reused for a second request preview
or downstream dry-run execution path.

Plain Chinese summary: 人工审批不能只是“写着 one-time”。第一次成功生成请求预览后，
审批文件必须变成已使用；第二次拿同一张审批单再生成预览必须被挡住。这个任务仍然不
联网、不发生产请求、不调用生产 adapter、不真实下单。

## Scope

Included:

- consume the manual approval lifecycle artifact after successful request
  preview creation;
- write the state transition `approved_to_request_preview_created_to_used`;
- mark consumed approval artifacts as `approval_state=used`;
- make second request preview reuse fail closed;
- make dry-run execution with the blocked second preview fail closed;
- keep all no-network/no-production-mutation evidence fields.

Not included:

- production order submission;
- production order-test submission;
- production HTTP request execution;
- production execution adapter calls;
- real funds;
- production trading;
- Dashboard order controls;
- durable server-side approval storage.

## Acceptance Criteria

- A successful request preview records:
  - `manual_approval_used=true`
  - `manual_approval_consumed=true`
  - `manual_approval_consume_status=approval_consumed_after_request_preview_created`
  - `manual_approval_consume_transition=approved_to_request_preview_created_to_used`
- The source manual approval lifecycle artifact is atomically written back with:
  - `approval_state=used`
  - `approval_used=true`
  - `approval_consumed=true`
  - `request_preview_created=true`
  - `approval_lifecycle_valid=false`
- Reusing the same approval for another request preview yields
  `status=blocked_manual_approval_lifecycle`.
- Dry-run execution using the blocked second request preview yields
  `status=blocked_source_artifact` and does not call any adapter.
- All paths preserve:
  - `request_sent=false`
  - `network_attempted=false`
  - `production_orders_submitted=0`
  - `production_order_mutations_attempted=0`
  - `dashboard_order_controls_enabled=false`
