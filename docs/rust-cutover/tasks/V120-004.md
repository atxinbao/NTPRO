## Goal

Implement a local shadow portfolio runtime artifact for v0.12.0 from redacted
production account snapshot summaries and local shadow execution intents.

Plain Chinese summary: 这次不是做真实组合账本，也不是实盘交易。它只是把已经脱敏的
生产账户只读摘要和本地 shadow intent 合在一起，生成一个本地
`shadow_portfolio_runtime.json`，告诉用户哪些字段是观察到的、哪些是本地推导的、
哪些目前不可用。

## Scope

- Add `live production-shadow-portfolio-runtime`.
- Read redacted account snapshot report JSON.
- Read local `shadow_execution_intent.jsonl`.
- Write `v0_12/shadow_portfolio_runtime.json` shaped evidence.
- Optionally write a v0.11-compatible `shadow_portfolio_snapshot.json` for
  current Dashboard readers.
- Preserve explicit zero counters for production order submission, production
  order mutation, automatic correction orders, and Dashboard order controls.
- Add targeted runtime tests and a release verification script.

## Non-Goals

- No production order submission.
- No production cancel, replace, amend, retry, correction, or listenKey
  lifecycle mutation.
- No open-order or order-state read.
- No raw account response persistence.
- No raw balances, asset names from the production account response,
  permissions, API key, secret, signature, signed query, signed URL, or headers.
- No production portfolio parity claim.
- No changes to `crates/portfolio` accounting semantics.
- No Dashboard order controls.
