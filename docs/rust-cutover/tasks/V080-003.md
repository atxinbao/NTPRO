# V080-003 Implement Signed Authenticated GET Request Builder Without Persistence

Date: 2026-06-16
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: high
Status: REVIEW_REQUIRED_AFTER_PR

## Goal

Add the in-memory request builder needed for the authenticated Binance testnet
read-only proof. The builder may prepare the signed `GET /api/v3/account`
request, but it must not persist or log the API key value, API secret, HMAC
signature, signed query string, signed URL, or response body.

## Scope

- Construct `timestamp` and `recvWindow` query values.
- Sign the query through the existing Binance adapter signing credential.
- Add the `X-MBX-APIKEY` header value in memory only.
- Allow only `GET /api/v3/account`.
- Hard-fail non-GET methods, non-allowlisted endpoints, and order mutation
  endpoints.
- Provide a redacted preview that is safe for diagnostics and future artifact
  work.
- Add tests proving construction, hard-fail behavior, and redaction.

## Non-Goals

- No authenticated network call.
- No real Binance account response.
- No persisted signed URL.
- No persisted signed query string.
- No persisted HMAC signature.
- No persisted API key header value.
- No raw response body artifact.
- No order submission, cancel, replace, amend, or account mutation.
- No production Binance connectivity.
- No real funds.
- No production trading.

## Acceptance

- `GET /api/v3/account` can be constructed by the request builder.
- Non-GET methods hard fail.
- Non-allowlisted endpoints hard fail.
- `/api/v3/order` mutation endpoints hard fail with a clear error.
- Redacted preview/debug output contains no API key, secret, signature, signed
  query, or signed URL.
- Default offline workflow behavior remains unchanged.
- PR stops at `REVIEW_REQUIRED`; no auto-merge.
