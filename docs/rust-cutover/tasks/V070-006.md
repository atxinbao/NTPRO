# V070-006 - Add dual-gate verification for offline default and manual online opt-in

Milestone: v0.7.0 deferred queue
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Control & Scope Agent
Risk: medium

Risk override: the owner approved V070-003 through V070-007 for automated
execution and auto-merge on 2026-06-14. Keep this task scoped to verification
gates and release evidence; do not create a release tag.

## Goal

Create dual-gate verification for v0.7.0: default local/CI coverage remains
offline and fail-closed, while manual online opt-in can run real read-only
testnet probes without submitting orders.

## Scope

- Add or update verification scripts for:
  - offline default gate;
  - manual online opt-in gate.
- Default gate must prove no network attempt when opt-in is missing.
- Manual online gate must require both `--allow-testnet-network` and
  `NTPRO_ALLOW_TESTNET_NETWORK=1`.
- Release documentation must separate guaranteed local coverage from external
  opt-in coverage.

## Non-goals

- Do not make manual online probe required in default CI.
- Do not submit, cancel, replace, or amend orders.
- Do not store or print credential values.
- Do not create a tag or GitHub Release.

## Required Evidence

- default offline verification script output
- manual online verification dry-run or classified opt-in output
- `scripts/ai/verify_fast.sh`
- `git diff --check`

## Acceptance

- Default gate proves `network_attempted=false`.
- Manual online gate records `network_attempted=true` when the real probe is
  attempted, and either `testnet_connection=true` or a stable `error_code`.
- All gate evidence keeps `real_orders_submitted=false`, `values_recorded=false`,
  and `secrets_redacted=true`.
- Release docs distinguish default CI coverage from manual online coverage.
