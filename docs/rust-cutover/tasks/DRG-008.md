# DRG-008 - High-impact ignored tests closure

Milestone: v0.2 Design Readiness
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Rust Core Runtime Agent
Risk: high

## Goal

Close every high-impact ignored-test risk before product design depends on the
runtime behavior those tests cover.

## Scope

- Review `docs/rust-cutover/verification/ignored_tests_risk_register.md`.
- For every high-impact `OPEN` item, choose one outcome:
  - fix and enable the test;
  - split into a blocker task;
  - record a formal release-gate exemption.
- Keep manual/API-key/slow tests separate from high-impact product blockers.

## Non-goals

- Do not delete ignored tests.
- Do not mark high-impact tests resolved without evidence or a formal exception.

## Required evidence

```bash
rg -n "#\\[ignore\\]" crates tests
cargo test -p <affected-crate>
scripts/ai/verify_fast.sh
```

## Acceptance

- `G7 Ignored test closure` is `PASS`.
- No high-impact ignored-test item remains `OPEN`.
- High-risk work stops at `REVIEW_REQUIRED`.
