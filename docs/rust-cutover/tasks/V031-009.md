# V031-009 - ignored tests closure batch 1

Milestone: v0.3.1 Local Supervisor Control Console Hardening
Priority: P1
Owner role: Verification & Release Gatekeeper
Review role: Control & Scope Agent
Risk: medium

## Goal

Close or replace the first batch of high-risk ignored tests that still sit near
the current local release boundary.

Plain language: stop carrying silent test debt where the patch release depends
on the same behavior.

## Dependencies

- `V031-008`

## Scope

- Triage the highest-risk ignored tests from the current risk register batch 1.
- Re-enable tests that are now deterministic.
- Replace still-useful but flaky coverage with deterministic tests where
  practical.
- If a test stays ignored, document why the current release claim does not rely
  on it.

## Non-goals

- Do not promise closure of every ignored test in one patch release.
- Do not broaden the product claim to justify weak evidence.
- Do not silently leave high-risk ignored tests unexplained.

## Implementation guidance

Prioritize the ignored tests that overlap release-gate, local supervisor,
Dashboard, and Rust-only product-surface behavior before touching wider future
coverage.

## Verification criteria

- Batch-1 ignored tests are either re-enabled, replaced, or explicitly scoped
  out with evidence.
- Evidence records which tests changed and why.
- The patch release no longer depends on unexplained ignored coverage in this
  batch.
