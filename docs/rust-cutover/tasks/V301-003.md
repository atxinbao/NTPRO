# V301-003 post-publication closeout gate for v30

## Goal

Add a post-publication closeout gate so the published v0.30.0 release cannot
remain represented by pre-publication-only source states.

Plain Chinese summary: 本任务给已经公开发布的 v0.30.0 增加发布后 closeout gate。
发布公开后，manifest、readiness report 和 release notes 不能继续只停留在
`release_gate_ready` / `RELEASE GATE READY` 状态；源码树必须写入
`published_release`、`post_publication_closeout`、source-controlled closeout
evidence、hosted release gate、milestone/issue closeout、release body hash 和
publication-after-gate 事实。它不改变 runtime，不开放 backend go-live，也不开放任何
交易操作能力。

## Dependency

- Depends on V301-001 source-controlled v0.30.0 closeout evidence.
- Depends on V301-002 v30 publish-after-gate current-release binding.
- Blocks all v0.31.0 capability work until the full v0.30.1 patch release is
  published and reconstructable.

## Scope

Included:

- Mark v0.30.0 release notes/readiness as `Status: RELEASED`.
- Populate `published_release` and `post_publication_closeout` in the v0.30.0
  release manifest.
- Add source-controlled post-publication closeout gate metadata to the v0.30.0
  manifest.
- Add `verify_v30_1_post_publication_closeout_gate.sh` with source and live
  validation modes.
- Keep pre-publication v30 release gates usable while separating published
  release closeout validation into the v30.1 patch gate.

Not included:

- backend go-live;
- production submit or production order mutation;
- execution adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal trading controls;
- product-grade live trading claim.
