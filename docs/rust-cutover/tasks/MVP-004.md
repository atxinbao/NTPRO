## 目标

在 `ntpro.mvp_identity_contract.v1` 基础上建立 Rust 生成的
`ntpro.mvp_status_contract.v1`，把研究状态、运行状态、技术健康和交易就绪分别
表达，并为每个维度提供来源、时效、错误、缺失和降级原因。

## 范围

- 原子写入 `<workspace>/mvp/status_contract.json`；
- 运行期间按节点心跳间隔刷新合同，停止后写入最终状态；
- 用 status/metrics `generated_at`、心跳阈值和代际一致性判断新鲜度；
- 启动前清除旧合同，并验证当前身份合同与内存身份一致；
- 研究状态只确认回测引用已经绑定，不声明研究验收通过；
- 运行状态同时读取 Supervisor 进程状态和节点生命周期；
- 技术健康同时读取节点 status、metrics 和错误，不以 HTTP 或进程存活代替；
- 顶层、execution、risk 与 metrics 错误均进入错误信封；
- Unified Read Model 缺失或未经本合同验证时，交易就绪保持 `blocked`；
- 节点干净停止后写入 `stopped` / `not_running`；
- 所有交易、变更、重试和补救边界保持 false。

## 非目标

- HTTP API、前端页面、双门户投影或多节点编排；
- 真实交易、生产准入或研究收益判断；
- 修改 v0.32.0 冻结发布文件。
