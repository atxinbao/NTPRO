# BAO-001 - Cargo Test Artifact Footprint Optimization

Date: 2026-07-27
Executor: Codex
GitHub issue: `#1149`
Status: `REVIEW_REQUIRED`
Risk: `medium`

## Goal

Reduce the local disk footprint produced by direct `cargo test` runs while
preserving normal test behavior and an explicit full-debug test profile.

## Owner And Review

- Owner role: Rust Product Surface Agent
- Review role: Verification & Release Gatekeeper
- Dependencies: none

## Allowed Paths

- `Cargo.toml`
- `docs/developer_guide/testing.md`
- `docs/rust-cutover/tasks/BAO-001.md`
- `docs/rust-cutover/evidence/BAO-001.md`

## Prohibited Paths

- Rust runtime implementation under `crates/**`
- GitHub workflow definitions
- v0.32.0 frozen release files
- release tags, manifests, trading controls, adapters, or persistence formats

## Acceptance Contract

1. Measure cold and incremental time, logical size, disk usage, and file count
   for the same targeted CLI library test command.
2. Disable debug information in the default `test` profile and strip debug
   information from its artifacts.
3. Add an explicit opt-in profile for full-debug test builds.
4. Document `--lib` targeting and Cargo profile/feature cache alignment.
5. Prove a material artifact reduction without a material compile-time
   regression.
6. Validate the default and full-debug profiles, current governance, and the
   frozen backend baseline.
