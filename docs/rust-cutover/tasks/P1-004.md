# P1-004 - Dev Profile Safety

Milestone: M3 - CI, lint, regression hardening
Priority: P1
Owner role: Verification Release Gatekeeper
Review role: Control Scope Agent
Risk: medium

## Goal

Make default development builds keep debug assertions and overflow checks enabled, with an explicit fast profile if needed.

## Dependencies

- `P0-003`

## Scope

- Keep v0.2.0 scoped to Local Multi-Node Runtime Foundation.
- Preserve sandbox/local-only boundaries unless this task explicitly says otherwise.
- Create task evidence under `docs/rust-cutover/evidence/`.

## Non-goals

- Do not create release tags or publish GitHub Releases from this task.
- Do not claim production live trading readiness.
- Do not connect to real exchanges or submit real orders.
- Do not add manual order entry, Dashboard UI scope, or distributed multi-server orchestration unless the task explicitly asks for it.
- Do not introduce Python, PyO3, or Cython product surfaces.

## Related files

- `Cargo.toml` (TO_MODIFY): Cargo dev profile settings
- `docs/rust-cutover/evidence/P1-004.md` (CREATE): Task evidence

## Implementation guidance

Set [profile.dev] debug-assertions=true and overflow-checks=true. If disabling is needed, add explicit profile.dev-fast inheriting dev.

## Verification criteria

- `cargo build -p nautilus-cli`
- `scripts/ai/verify_fast.sh`

Evidence must record changed files, commands run, command output summary, behavior impact, public API impact, migration note status, rollback plan, and a plain Chinese non-expert summary.

## Evidence required

Create `docs/rust-cutover/evidence/P1-004.md`.
