# V131-005 - Money Price Quantity contract draft

Date: 2026-06-22
Executor: Codex

## Goal

Draft the Money/Price/Quantity contract required before future live-alpha
preflight can become risk/execution-grade money math.

Plain Chinese summary: 这个任务只把以后要做实盘金额、价格、数量计算时必须满足的合同
写清楚。它不实现真实下单金额计算，不开放实盘交易，也不把 v0.13.1 宣称成
risk/execution-grade money math ready。

## Scope

Included:

- define required Money, Price, and Quantity representation fields;
- require plain decimal strings and reject binary-float transport;
- document asset/quote precision, price precision, quantity precision, tick
  size, step size, min/max notional, and rounding mode requirements;
- record fee and slippage fields as future required contract inputs;
- explicitly preserve the v0.13.1 non-claim boundary.

Not included:

- production order submission;
- production cancel / replace / amend / retry / correction;
- production order-state reads;
- listenKey lifecycle management;
- signed WebSocket user stream runtime;
- Dashboard order controls or credential entry;
- automatic remediation;
- real funds or production trading;
- risk/execution-grade live-alpha money math implementation.

## Acceptance

- Contract doc names decimal-string representation for Money/Price/Quantity
  values.
- Contract doc covers asset/quote precision, tick size, step size, min/max
  notional, and rounding mode.
- Contract doc marks v0.13.1 as not risk/execution-grade money math ready.
- Release index links the contract without expanding the v0.13.1 capability
  claim.
- Diff hygiene passes: `git diff --check`.
