# V090-011 Display Strategy Runtime Artifacts in Dashboard Read-Only Mode

Date: 2026-06-18
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V090-010

## Goal

Dashboard displays strategy runtime state without becoming a trading control
surface.

## Allowed Display

- strategy session state;
- strategy ID;
- symbol;
- market stream status;
- signal count;
- latest signal;
- latest order intent;
- latest risk decision;
- rejection reason;
- artifact paths.

## Forbidden Controls

- order button;
- cancel button;
- live enable button;
- credential input;
- strategy hot reload;
- production connect.

## Acceptance

- Dashboard displays Strategy Session status.
- Dashboard has no order-control action route.
