# V100-001 Add Execution Config Contract

Date: 2026-06-19
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium for offline automation; manual online submit proof remains explicit owner-gated
Status: BACKLOG
Depends on: V100-000

## Goal

Add the v0.10.0 Binance testnet order execution config contract while keeping
the checked-in default configuration disabled and fail-closed.

Plain Chinese summary: 本任务只加“配置长什么样、怎么校验”。默认配置仍然不能下单，
真实 Binance testnet 下单必须等后续手动 gate 和 owner 批准。

## Scope

- Add a checked-in `[testnet_order]` section to
  `configs/nodes/btc-ema-shadow.toml`.
- Validate that the config is disabled by default.
- Require testnet-only base URL.
- Require string decimal `price`, `quantity`, and `notional` fields.
- Require one-symbol / one-instrument alignment with the strategy-session market
  symbol.
- Require owner/manual gates and forbid Dashboard order controls.

## Non-Goals

- No signed order request.
- No `/api/v3/order/test` call.
- No real Binance network call.
- No submit/cancel lifecycle proof.
- No Dashboard order control.
- No release tag or GitHub Release.

## Acceptance

- `config validate --kind strategy-session --config configs/nodes/btc-ema-shadow.toml`
  accepts the fail-closed config.
- Invalid production endpoint is rejected.
- Enabled testnet order config is rejected until manual gates are implemented.
- Non-string/non-decimal quantity format is rejected.
- Evidence records local validation commands and behavior impact.
