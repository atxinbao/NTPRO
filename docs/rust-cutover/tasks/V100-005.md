# V100-005 Add /order/test Preflight

Date: 2026-06-19
Executor: Codex
Status: IN PROGRESS

## Goal

Add an offline, fail-closed `POST /api/v3/order/test` preflight before any
future manual Binance testnet order-test call.

## Scope

- Add a dedicated local CLI preflight command for `/api/v3/order/test`.
- Reuse the signed request preview layer from V100-004.
- Require the existing v0.10 manual CLI and environment gates.
- Read API key and secret from environment variable names only.
- Write a redacted local report showing request shape readiness.
- Explicitly record that Binance order-test acceptance is not attempted
  offline.
- Explicitly record `matching_engine_submission=false`.

## Out Of Scope

- No Binance API calls.
- No online `/api/v3/order/test` execution.
- No submit/cancel lifecycle.
- No matching-engine lifecycle proof.
- No production Binance endpoint.
- No Dashboard order controls.
- No strategy-driven production execution.

## Acceptance

- Missing manual gates fail before request construction.
- Missing API key or secret fails closed.
- Production base URL fails closed.
- Passing preflight writes a report for `POST /api/v3/order/test`.
- Report does not include API key value, secret, signature, signed query,
  signed URL, or request body.
- Report records `binance_order_test_acceptance=not_attempted_offline_manual_only`.
- Report records `matching_engine_submission=false`,
  `network_attempted=false`, and `real_orders_submitted=false`.
