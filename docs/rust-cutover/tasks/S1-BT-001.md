# S1-BT-001 - Backtest 不可变结果与 Run metrics 纵向切片

Date: 2026-08-09
Executor: Codex
GitHub issue: #1270
Risk: high
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Status: REVIEW_APPROVED_HOSTED_PENDING

## 目标

把真实 `BacktestEngine` 的确定性结果写入不可变产品产物，并通过只读 Product API 接入
策略工作台 Run 详情页，形成 S1 Backtest 产品化的首个端到端切片。

## 范围

- 新增专用 BTC/USDT EMA Backtest 产品配置，不修改 MVP 冻结配置；
- `backtest run` 在显式产品绑定下写入确定性 `summary.json`；
- 可信 Run 清单绑定配置、输入与完整结果 SHA-256，读取使用 capability/no-follow 路径；
- 相同 Run 允许幂等重放，不允许覆盖内容不同的既有结果；
- 新增 `GET /api/product/v1/runs/{run_id}/metrics`；
- 严格校验 Run、策略版本、数据、配置、结果引用和只读能力边界；
- 更新 OpenAPI、生成的 TypeScript/Zod SDK、Product API client 和 Run 详情页；
- 覆盖正常、身份错配、损坏、缺失、路径逃逸、非 Backtest、403、404、405 与响应式页面。

## 非目标

- 不修改 BacktestEngine 撮合、统计或交易语义；
- 不新增 Run mutation、结果比较、持仓、订单、成交或事件 API；
- 不开放 Sandbox/Live 写操作、真实 Venue、订单提交、自动重试、自动补救或交易控件；
- 不修改 v0.32.0 发布冻结文件；MVP 冻结来源只允许按下述 post-freeze 例外更新两个精确哈希。

## Post-freeze 例外

`crates/cli/src/dashboard/server.rs` 与 `configs/nodes/btc-ema-shadow.toml` 属于 MVP frozen
source。Issue #1270 已明确登记为独立 post-freeze 只读扩展例外；本任务只增加位于既有
Product read-only access layer 内的 GET 路由，并为 Backtest Run 增加结果校验所需的预期
配置/数据哈希与参数；freeze manifest 仅更新这两个来源的 SHA-256。任务集合、拓扑、状态、
验收合同和 19 个禁止能力边界保持不变。

## 完成条件

本任务为 high risk。必须通过本地合同/单元/浏览器/治理验证，取得独立 Gatekeeper 的
`REVIEW_APPROVED`，通过 hosted checks 后手动合并；禁止 auto-merge。
