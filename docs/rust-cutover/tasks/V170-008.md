# V170-008 - Integrate failure and incident semantics

Date: 2026-06-24
Executor: Codex
Milestone: v0.17.0 production reconciliation and orphan recovery
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Feed v0.16 production mutation failure semantics into v0.17 reconciliation and
orphan-risk incident outcomes.

Plain Chinese summary: 这个任务把 v0.16 的失败证据接到 v0.17 对账里。大白话：如果之前出现
timeout、HTTP 失败、响应异常、readback mismatch 或 kill-switch 变化，v0.17 不会把它当成
普通成功状态，而是输出对应 incident 结论；但仍然不重试、不撤单、不自动补救。

## Scope

Included:

- let reconciliation classifier trace `local_ledger_ref -> failure_ref`;
- add failure incident fields to reconciliation classifier output;
- propagate incident risk fields to orphan detector output;
- map:
  - `timeout` to readback required;
  - `http-4xx` to terminal evidence;
  - `http-5xx` to readback required;
  - `malformed-response` to manual review;
  - `readback-mismatch` to risk halt;
  - `kill-switch-transition` to halt;
- add local/offline verifier and evidence.

Not included:

- new CLI parameters;
- retry, cancel, replace, amend, correction, flatten, or remediation;
- new network/exchange request execution;
- Dashboard order/cancel controls;
- release tag creation.

## Acceptance Criteria

- Reconciliation classifier emits:
  - `failure_mode`;
  - `failure_state`;
  - `terminal_action`;
  - `failure_incident_outcome`;
  - `failure_incident_severity`;
  - `readback_required`;
  - `terminal_evidence_required`;
  - `incident_risk_halted`;
  - `incident_manual_review_required`;
  - `incident_new_orders_blocked`.
- Orphan detector carries failure incident state and halts risk for
  `readback-mismatch` and `kill-switch-transition`.
- Failure mappings do not enable retry/cancel/remediation.
- Dashboard order/cancel controls remain disabled.
