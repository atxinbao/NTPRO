# S2-DM-002 - Demo 实时状态与运行结果产品化

Date: 2026-08-11
Executor: Codex
GitHub issue: #1282
Risk: high
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Status: REVIEW_REQUIRED

## 目标

让策略工作台从真实 Sandbox node 工件读取同一 Demo Run 的实时市场、信号、订单意图、
风险拒绝、技术健康和终态结果，并在 Run 停止或失败后保存不可变、可校验的历史快照。

## 范围

- 新增 `GET /api/product/v1/runs/{run_id}/demo-snapshot` 只读合同；
- created Run 返回稳定的 `not_started`，running Run 返回实时 `running`，终态 Run 返回
  不可变 `frozen`；
- 严格读取策略 session status、market status、market events、signals、order intents、
  risk decisions、summary 和 manifest 八类工件；
- 校验 schema、Run/Strategy 身份、路径 containment、记录数、字节数、校验和、时间和
  禁止能力边界；
- 终态发布 `demo-result.json`，并由 `terminal-state.json` 和 Supervisor terminal anchor
  建立结果哈希链；
- 策略工作台 Run 详情展示 Demo 实时/冻结结果，running 时每 2 秒轮询，终态停止轮询；
- 同步权威 OpenAPI、生成 TypeScript/Zod SDK、严格 Product client、Vitest 和 Playwright；
- 覆盖创建、运行、停止、节点复用、并发终态化、篡改、未知字段和禁止能力负向验证。

## 非目标

- 不交付模拟成交、持仓、资金曲线或 Backtest/Demo 比较；
- 不开放真实 Live、外部 Venue、真实订单、撤改或交易控件；
- 不实现自动重试、自动补救、自动恢复或多节点调度；
- 不修改 `docs/rust-cutover/release/v0_32_0_*` 冻结发布文件。

## Post-freeze 例外

`crates/cli/src/dashboard/server.rs` 和 `crates/cli/src/mvp.rs` 是 MVP frozen source。Issue
#1282 只新增受既有产品访问控制保护的 Demo snapshot GET 路由，并让 MVP 测试节点生成
严格 snapshot 验收所需的 Sandbox 策略工件；freeze manifest 同步更新两个文件的精确
SHA-256。MVP 单 Supervisor + 单 Sandbox node 拓扑及 19 项禁止能力边界保持不变。

取得独立 Gatekeeper 的 `REVIEW_APPROVED`，通过 hosted checks 后手动合并；禁止 auto-merge。
