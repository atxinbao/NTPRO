# WFG-002 Post-Release PR Smoke Hardening

Date: 2026-07-24
Executor: Codex

GitHub PR: #1146

Owner: Verification & Release Gatekeeper
Reviewer: Control & Scope Agent
Status: REVIEW_REQUIRED

## Goal

Allow required PR smoke checks after the frozen v0.33.0 release without
weakening tag-push publication provenance.

中文摘要：修复 v0.33.0 发布后 PR smoke 必然要求冻结 tag SHA 等于新 PR HEAD
的矛盾。post-release 模式只接受 tag commit 的后代，并且不再从 PR HEAD
重新生成 v0.33.0 strict provenance。

## Boundary

- change only PR smoke, the v33 maintenance guard, and WFG-002 evidence;
- do not edit v0.32.0 or v0.33.0 release artifacts;
- do not edit `release-tag.yml` or `release-publish.yml`;
- do not change runtime, adapter, schema, API, or trading behavior;
- do not relax tag-push event, ref, SHA, or gate-before-publish binding.

## Acceptance

- equal tag and HEAD passes without an override;
- a default mismatch fails closed;
- an invalid override value fails closed;
- a non-descendant HEAD fails closed even with the override;
- an explicit descendant post-release PR HEAD passes;
- PR smoke does not run v33 strict provenance against the PR HEAD;
- local and hosted governance checks pass;
- independent reviewer approves before merge.
