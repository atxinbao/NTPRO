## Goal

Make repository cleanup predictable and prevent build cleanup from deleting
user-owned local state or arbitrary untracked files.

Plain Chinese summary: 本任务把 clean 改为明确路径白名单，删除三个重复 target 和
`git clean -fxd`。普通 clean 只删可重建构建输出；generated output 需要
`FORCE=1`；两层都有 dry-run；用户本地分析状态、报告和大型测试数据永远不进入删除
集合。

## Dependency

BFH-003 (`#1114`) is closed through merged PR `#1129`.

## Scope

- replace overlapping build-artifact cleanup with one explicit allowlist;
- separate build/report output from generated audit/analysis output;
- add dry-run targets for normal and guarded cleanup;
- require `FORCE=1` before any generated-output deletion;
- remove arbitrary untracked/ignored deletion through `git clean`;
- prove protected local state and tracked files survive in a disposable
  worktree;
- document the supported cleanup interface and evidence.

## Not In Scope

- global Cargo registry, Git object, toolchain, or operating-system cache purge;
- deleting `.codex`, `.agentflow`, `.understand-anything`, `project.html`,
  `tests/test_data/large`, or `tests/test_data/local`;
- local service, database, credential, log, container, or volume cleanup;
- runtime, dependency, schema, public API, or capability changes;
- modifying `docs/rust-cutover/release/v0_32_0_*`.

## Acceptance Criteria

- `make clean` deletes only documented reproducible build/report output;
- failed `make distclean` without `FORCE=1` deletes nothing;
- guarded cleanup deletes only its documented build/generated allowlist;
- dry-run targets delete nothing and name protected paths;
- arbitrary untracked files, user state, test data, and tracked files survive;
- help, backend-freeze, zero-Python, and fast gates pass.
