## Goal

Define the v0.28.0 Backend Closure / Product Operations Runtime Finalization
boundary before implementation. The contract declares the module readiness
matrix, backend claim rules, and required-false no-trading-control boundary.

Plain Chinese summary: 本任务定义 v0.28.0 的 backend closure 边界合同和 readiness
matrix。当前只证明 v0.27.1 发布依赖和 v0.28.0 边界矩阵本身可收口；identity、
audit、deployment、telemetry、Admin Workbench、Trader Terminal API 和 fail-closed
hardening 仍分别由后续 issue 关闭。本任务不声明后端已整体完成，不声明前端/产品已完成，
也不开放任何真实交易控制。

## Dependency

- Depends on `V280-000` intake gate and its `start_gate_status = satisfied`
  proof.
- Hard-blocked by v0.27.1 issue closeout and published release evidence.
- Does not inherit submit, mutation, adapter-send, live-exchange, remediation,
  Dashboard/Admin trading-control, or product-grade terminal capability from
  v0.27.0 or v0.27.1.

## Scope

Included:

- Define the v0.28.0 backend closure boundary contract.
- Define the source-controlled readiness matrix.
- Classify each v0.28.0 module as `runtime-closed`, `evidence-only`,
  `blocked`, or `deferred`.
- Define what can be claimed as backend closed and what remains frontend or
  product work.
- Add a validator that recomputes matrix status and fail-closed violations.
- Add a release stage for the validator.

Not included:

- production order submission;
- cancel, replace, amend, flatten, or any production order mutation;
- execution adapter call, adapter send, or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin operation controls or trading controls;
- frontend product completion;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- v0.28.0 cannot be described as product-grade live trading unless explicitly
  proven by later scoped releases.
- The readiness matrix is source-controlled and release-gated.
- Every backend closure claim maps to evidence and verification commands.
- Blocked, deferred, and evidence-only modules cannot be counted as v28 backend
  runtime closure.
- Any forbidden boundary flag set to `true` or missing fails closed.
