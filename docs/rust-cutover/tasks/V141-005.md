# V141-005 Fix CLI Help Text

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Update `nautilus live` help text so production read-only and dry-run proof
commands are not presented as sandbox-only smoke commands.

Plain Chinese summary: `live` 下面现在不只包含本地 sandbox smoke，还包含生产只读证据和
live-alpha dry-run 证据命令。帮助文案必须让用户一眼看懂：这些生产相关命令只能读、只能
dry-run，不能提交或修改生产订单。

## Scope

Included:

- update the `live` command group summary;
- update production read-only command descriptions;
- update live-alpha dry-run command descriptions;
- add help-rendering unit coverage for the no-production-mutation wording;
- record task evidence.

Not included:

- production order submission;
- production order mutation, cancel, replace, amend, retry, or correction;
- listenKey lifecycle;
- Dashboard order controls;
- real funds or real orders;
- runtime behavior changes.

## Acceptance

- `nautilus live --help` no longer says the whole group is sandbox-only.
- Production read-only commands state the no-production-mutation boundary.
- Live-alpha dry-run commands state the no-production-mutation boundary.
- Help tests prevent the old group wording from returning.
- No trading behavior changes.
