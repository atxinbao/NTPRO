# V090-010 Expose Strategy Session Status Through Supervisor

Date: 2026-06-18
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V090-009

## Goal

Supervisor status should include strategy session state, not only process/node
state.

## Scope

- Add strategy session fields to supervisor status.
- Add signal/rejection counts to supervisor metrics.
- Make supervisor logs point to session artifacts.

## Acceptance

Supervisor status shows:

- `node_state`;
- `strategy_session_state`;
- `strategy_id`;
- `market_state`;
- `risk_state`;
- `last_signal_at`;
- `last_rejection_reason`.
