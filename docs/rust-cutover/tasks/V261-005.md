## Goal

Add a post-publication strict gate proving the remote GitHub Release body,
release tag, hosted release gate, publish workflow, milestone closeout, and
source closeout facts are mutually consistent.

Plain Chinese summary: 本任务新增发布后的 strict gate。它会实时读取 GitHub Release、
tag、hosted gate run、publish run 和 milestone，并与源码树里的 release notes、
closeout evidence、manifest proof 字段比对。未跟踪的 `release-publication-evidence/`
仍只是 generated artifact，不作为唯一权威证明。

- Route the post-publication strict gate through v26 release gates and strict
  provenance inputs.
