# V090-007 Add Shadow-Mode Risk Decision Gate

Date: 2026-06-18
Executor: Codex
Owner role: Rust Core Runtime Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V090-006

## Goal

Every order intent must pass through a risk gate and be rejected by default in
v0.9.0 shadow mode.

## Automation Scope

This is a medium-risk automation slice because the risk gate is shadow-only and
must keep order submission disabled.

## Artifact

```text
strategy/risk_decision.jsonl
schema_version = ntpro.v09_risk_decision.v1
```

## Rules

- `order_submission = disabled` rejects.
- `kill_switch = true` rejects.
- `mode = shadow` rejects actual submission.
- Missing account state rejects.
- Missing market state rejects.

## Acceptance

- Every order intent has a risk decision.
- `decision = rejected`.
- `actual_submission = false`.
