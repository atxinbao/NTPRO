## Goal

Define deployment configuration, environment provenance, and operator runbook
readiness for backend production readiness.

Plain Chinese summary: 本任务把 deployment config/runbook 推进为 v0.29 backend
production-readiness evidence。它定义 required config/env inputs、provenance、
redaction、rotation expectations、validation commands、operator handoff、rollback
criteria 和 escalation paths，并用 source-controlled artifact 验证 deploy/upgrade/
rollback config readiness；缺 config、unsafe defaults、stale runbook、ambiguous
production claim 或 forbidden execution 都会 fail closed。本任务不执行真实部署或回滚。

## Scope

Included:

- Define required deployment config/environment inputs.
- Define provenance, redaction, rotation expectations, and validation commands.
- Add runbook evidence for operator handoff, rollback criteria, and escalation.
- Fail closed on missing config, unsafe defaults, stale runbook, ambiguous
  production claims, and forbidden execution.

Not included:

- production deployment execution;
- rollback execution;
- automatic remediation;
- adapter send or live exchange request;
- Dashboard/Admin/Trader Terminal trading controls;
- backend go-live or product-grade terminal readiness claims.
