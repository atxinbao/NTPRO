# V131-004 - Kill switch dry-run runtime propagation

Date: 2026-06-22
Executor: Codex

## Goal

Propagate the v0.13 kill-switch dry-run approval artifact into local
Supervisor, metrics, risk, and Dashboard status surfaces without enabling any
production mutation path.

Plain Chinese summary: 这个任务只把 kill switch dry-run 的本地证据显示出来，让运维
和交易员能看到 kill switch 是否激活、是否 dry-run、是否记录人工审批、以及生产提交、
撤改、订单状态读取、listenKey 和 Dashboard 下单控件是否仍然关闭。它不增加实盘下单
能力。

## Scope

Included:

- read `v0_13/kill_switch_approval_artifact.json` from each node artifact root;
- expose kill-switch dry-run status through node metrics;
- show kill-switch boundary fields in `supervisor risk` and `supervisor metrics`;
- show kill-switch status and boundary fields in the read-only Dashboard
  production-shadow panel;
- treat v0.13 kill-switch-only artifacts as local evidence, not production
  trading readiness;
- add targeted supervisor and Dashboard tests.

Not included:

- production order submission;
- production cancel / replace / amend / retry / correction;
- production order-state reads;
- listenKey lifecycle management;
- signed WebSocket user stream runtime;
- Dashboard order controls or credential entry;
- automatic remediation;
- real funds or production trading.

## Acceptance

- Supervisor metrics expose kill-switch dry-run artifact status and no-mutation
  counters.
- Supervisor risk output includes kill-switch dry-run status and disabled
  mutation/Dashboard controls.
- Dashboard production-shadow status includes kill-switch state and disabled
  production boundary fields.
- v0.13 kill-switch artifact gate passes.
- v0.13 no-production-mutation gate passes.
- Dashboard forbidden order-control boundary remains enforced.
- Diff hygiene passes: `git diff --check`.
