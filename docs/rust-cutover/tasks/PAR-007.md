# PAR-007 Production Mutation Executor Retirement

Date: 2026-07-29
Executor: Codex
GitHub issue: #1175
Risk: critical
Classification: backend-freeze-exception
Status: REVIEW_REQUIRED

## Goal

Remove the dormant production mutation HTTP executors, credential inputs, and
signing reachability that remained compiled behind the v0.32.0 freeze wrapper.
Keep historical artifacts readable and reproducible without providing a
current execution path.

中文摘要：BFR-001 已在最外层拒绝两个历史 `--manual-online` 入口，但当前产品
二进制仍编译了真实生产 POST/DELETE、凭证读取和签名实现。本任务彻底删除这些
executor，并把原命令收紧为纯离线历史工件评估。

## Scope

- remove guarded-send POST and actual-cancel DELETE executor functions;
- remove the corresponding signed request and HTTP result types;
- remove online and credential CLI inputs from both legacy commands;
- keep historical timestamps, recv-window metadata, schemas, readers, and
  downstream audit fixtures;
- make current artifacts explicitly report retired, offline-only execution;
- add parser and source-level negative tests;
- update the operator migration note and risk inventory.

## Non-Goals

- no edit to frozen `docs/rust-cutover/release/v0_32_0_*` files;
- no removal or rewriting of historical release/evidence facts;
- no submit, cancel, mutation, adapter-send, live-exchange, retry,
  remediation, or trading-control authorization;
- no unrelated `live.rs` ownership split; PAR-008 owns that work.

## Behavior Contract

1. The current CLI rejects `--manual-online`, `--api-key-env`, and
   `--api-secret-env` for both retired commands.
2. Neither command reads credential material, signs a request, calls an HTTP
   executor, consumes approval, or records a network attempt.
3. Current artifacts preserve their historical schema while explicitly
   reporting retired offline evaluation and zero mutation counters.
4. Test-only historical attempt fixtures remain distinguishable from current
   runtime output and are used only to verify downstream readers.

## Acceptance

- no production mutation executor marker remains in current CLI source;
- all targeted and complete `nautilus-cli` library tests pass;
- both precision modes compile and Clippy passes;
- golden replay, runtime risk inventory, current governance, backend freeze,
  and fast verification pass;
- independent critical review and all hosted checks approve the change.
