# V130-007 - No-production-mutation release gate for live-alpha preflight

Date: 2026-06-21
Executor: Codex

## Goal

Wire the v0.13 Guarded Live Alpha Preflight evidence into release and PR gates
as a no-production-mutation gate.

Plain Chinese summary: 这个任务是给 v0.13 发版加门禁。v0.13 可以有 live alpha
前置证据，但默认 gate 必须证明：不下生产订单、不撤单、不改单、不读生产订单状态、不
开 listenKey、不启用 Dashboard 下单控件、不做实盘金额计算。

## Scope

Included:

- add `scripts/ai/verify_v13_no_production_mutation_gate.sh`;
- wire `verify_release.sh v13-no-production-mutation-gate`;
- wire the release tag matrix to run the v13 gate;
- wire the PR smoke workflow to classify and run v13 gate changes;
- document the v0.13 release gate boundary and evidence.

Not included:

- production order submission;
- production cancel / replace / amend / retry / correction;
- production reconnect or automatic remediation;
- production order-state reads;
- listenKey lifecycle management;
- live-alpha risk/execution-grade money math;
- real funds or production trading;
- Dashboard order controls.
