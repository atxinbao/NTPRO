# V231-004 harden evidence replay only boundary for v0.23.x

Date: 2026-07-04
Executor: Codex
GitHub issue: `#740`
Milestone: `v0.23.1`
Status: LOCAL VALIDATION PASSED

## Goal

Harden the v0.23.x release boundary so release documents, roadmap text, and
machine-readable release metadata state that v0.23.0 is an evidence/replay and
read-only observability release surface only.

Plain Chinese summary: 本任务把 v0.23.x 的能力声明收紧为“证据、回放、只读观测”。
它防止文档把 v0.23.0 说成生产级多节点 runtime、runtime integrated 执行系统或产品级
交易终端，同时说明 v0.24.0 只是未来合约和 gated implementation，不自动继承 runtime
能力。

## Scope

- Update release notes, readiness report, release README, top-level README, and
  roadmap language with evidence/replay-only boundary wording.
- Add a dedicated v0.23.0 evidence/replay-only boundary note.
- Add a v0.23.1 release gate that fails closed on forbidden overclaim wording.
- Add manifest fields for capability class, runtime claims, and v0.24.0 entry
  semantics.

## Non-Goals

- Do not implement a production multi-node runtime.
- Do not add adapter, supervisor, or execution runtime capability.
- Do not add submit, cancel, retry, replace, amend, or flatten capability.
- Do not enable Dashboard operation controls.
- Do not make v0.24.0 inherit runtime capability from v0.23.0.
