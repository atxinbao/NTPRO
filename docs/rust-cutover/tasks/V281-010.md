# V281-010 v28.1 nested base-gate tag-scope isolation

Date: 2026-07-09
Executor: Codex
GitHub issue: #948
Milestone: v0.28.1
Status: READY FOR PR

## Goal

Fix `v28.1-release-gates` tag-gate mode so historical v0.28.0 base release
checks do not inherit the outer v0.28.1 `NTPRO_RELEASE_GATE=1` tag-scope
requirement, and register v0.28.1 in the release-publication guard used by the
prepublish tag gate.

Plain Chinese summary: 本任务修复 v0.28.1 tag gate 中嵌套 v0.28.0 base gate 的作用域，
并把 v0.28.1 注册进 release-publication guard。v0.28.1 需要证明 v0.28.0 已发布，
但不应要求当前 HEAD 等于 v0.28.0 tag；当前 HEAD 只需要等于 v0.28.1 tag。

## Scope

- Run nested v0.28.0 release gates with `NTPRO_RELEASE_GATE=0`.
- Run nested v0.28.0 strict provenance with `NTPRO_RELEASE_GATE=0` and
  `NTPRO_RELEASE_STRICT_REQUIRE_HEAD_TAG=0`.
- Keep the outer v0.28.1 tag/HEAD check unchanged.
- Add the v0.28.1 release-notes marker set to `check_github_release_published.sh`
  so prepublish tag gate no longer fails with an unsupported release version.
- Register `V281-010` / #948 in the v0.28.1 release manifest, readiness report,
  strict provenance, v29 intake gate, and release index.

## Non-goals
