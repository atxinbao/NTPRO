## Goal

Record source-controlled post-publication closeout evidence for the published
`ntpro-rust-only-v0.31.0` release and move the v31 release manifest, release
notes, and readiness report from release-gate-ready wording to released
semantics.

Plain Chinese summary: 本任务把 v0.31.0 已公开发布后的真实 GitHub 状态写回源码树。
它记录 tag、GitHub Release、hosted release gate、publish workflow、milestone、issue
set 和 release body hash，并把 v31 manifest/notes/readiness 改成 `RELEASED`。这只是
发布治理收口，不开放 backend go-live、submit、mutation、adapter send、live exchange
或交易控件。

## Dependency

- Part of the v0.31.1 release governance closeout patch.
- Blocks v0.32.0 backend production closeout until all V311 issues close and
  `ntpro-rust-only-v0.31.1` release evidence is published.
- Does not grant v0.32.0 execution authority; v0.32.0 remains the backend
  closeout version after v0.31.1 publication evidence exists.

## Scope

Included:

- Add source-controlled v0.31.0 release closeout evidence.
- Mark v0.31.0 manifest `release_status` as `released`.
- Record published GitHub Release facts, hosted release gate facts, publish
  workflow facts, tag object/peeled commit, milestone closeout, exact issue set,
  and release body hashes in the v31 manifest.
- Mark v0.31.0 release notes and readiness report as `Status: RELEASED`.
- Add a targeted V311-001 validation script with source and live modes.

Not included:

- backend go-live;
- product-grade live trading claim;
- production submit or production order mutation;
- execution adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal trading controls;
- GitHub Release body reconciliation, which is tracked by V311-003 / #1038.
