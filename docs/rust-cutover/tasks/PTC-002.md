## Goal

Replace the active Python golden-trace validator and release-scope reconciler
with tested Rust governance tooling before removing the Python implementations.

Plain Chinese summary: 本任务把 golden trace JSONL 校验、可选 replay 对比和
release-scope manifest 对账迁移到 Rust。所有实际调用点改用同一个 Rust CLI，旧的
两个 Python 验证器随后删除；历史发布文档和历史文件清单中的脚本名称继续作为审计
记录保留。

## Scope

- add the `ntpro-governance` workspace crate and launcher;
- preserve validate-only, replay, and release-scope behavior;
- add positive and fail-closed negative unit tests;
- migrate active workflow and shell callers;
- delete `golden_trace_runner.py` and
  `validate_golden_trace_release_scope.py`;
- retain historical release records and frozen v0.32.0 evidence.

## Acceptance Criteria

- Rust validation covers required JSONL fields, duplicate cases, categories,
  timestamps, replay mismatches, and extra or missing cases;
- release-scope counts and status-specific contracts match the retired Python
  behavior;
- blank governance evidence fields fail closed;
- no executable caller references either retired Python file;
- the real release-scope fixture reports 286 exact cases;
- v0.32.0 frozen release files remain unchanged.
