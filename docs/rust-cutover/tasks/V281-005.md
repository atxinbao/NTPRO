## Goal

Harden `runtime-closed` terminology so deterministic artifact/replay closure
cannot be mistaken for live backend service integration.

Plain Chinese summary: 本任务把 `runtime-closed` 明确定义为 artifact replay closure。
它保留 v0.28.0 后端证据收口价值，但禁止把确定性 artifact 证据说成 live IdP、真实部署执行、
live adapter send、production trading runtime 或 product-ready live trading。

## Scope

- Define the terms for deterministic artifact replay closure, backend service
  runtime, live external integration, and production execution runtime.
- Add source-controlled terminology markers to the v0.28.0 boundary contract,
  readiness matrix, readiness report, release README, and evidence ledgers.
- Add a v0.28.1 release-gate stage for runtime-closed terminology.
- Extend the v28 backend closure boundary gate so forbidden positive
  live-service/product-ready claims fail closed.
