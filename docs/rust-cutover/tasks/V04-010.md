# V04-010 - Dashboard exchange / strategy / order / risk panels

Milestone: v0.4.0 Binance Sandbox Product Foundation
Priority: P0
Owner role: Rust Product Surface Agent
Review role: Control & Scope Agent
Risk: medium

## Goal

Extend the local Dashboard with business-facing Binance sandbox panels.

Plain language: once the underlying sandbox state is real, show exchange,
strategy, order, and risk status on the Dashboard in a way operators can use.

## Dependencies

- `V04-007`

## Scope

- Add exchange, strategy, order, and risk panels to the local Dashboard.
- Consume real sandbox business state rather than placeholder values.
- Keep the Dashboard local-only and no-framework.
- Keep operational density and clear status labels.

## Non-goals

- Do not add remote or multi-user Dashboard support.
- Do not add manual order entry.
- Do not create a trading terminal.
- Do not introduce a frontend framework.

- `crates/cli/src/dashboard.rs` (TO_MODIFY): panel rendering and state mapping.

## Implementation guidance

Dashboard work comes last in this queue for a reason. Do not let the UI invent
business state that the runtime and tests have not already proved.

## Verification criteria

- Dashboard shows exchange, strategy, order, and risk panels.
- Panels read real sandbox state, not placeholder data.
- Layout remains usable on desktop and mobile widths.
