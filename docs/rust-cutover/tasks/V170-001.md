# V170-001 - Add local production order ledger

Date: 2026-06-24
Executor: Codex
Milestone: v0.17.0 production reconciliation and orphan recovery
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Add a local, restart-readable production order ledger artifact for one v0.16
owner-approved mutation candidate lineage.

Plain Chinese summary: 这个任务只加“本地账本”。大白话：把 v0.16 那一笔 owner 批准的
小额订单候选，从请求构造、guarded send、响应脱敏、订单读回、审计、失败语义串成一条
本地记录，后续 v0.17 才能拿它和交易所只读回查做对账。

## Scope

Included:

- add `live production-mutation-local-order-ledger`;
- record `order_lineage_id`;
- record `request_builder_ref`, `guarded_send_ref`, `response_redaction_ref`,
  `readback_ref`, `audit_ref`, and `failure_ref`;
- write `current_local_state=local_ledger_pending_exchange_reconciliation`;
- prove restart readability by reloading the ledger JSON;
- keep duplicate submit, retry, cancel, remediation, listenKey lifecycle, and
  Dashboard order/cancel controls disabled.

Not included:

- exchange readback mapping;
- reconciliation classification;
- orphan detection;
- automatic cancel, retry, replace, amend, correction, flatten, or remediation;
- Dashboard controls;
- multi-order, multi-account, or multi-venue ledger;
- release tag creation.

## Acceptance Criteria

- Ledger artifact uses
  `schema_version=ntpro.v170_production_mutation_local_order_ledger.v1`.
- Ledger records `lineage_scope=single_v16_mutation_candidate`.
- Ledger records all six source refs with path, hash, schema, artifact type,
  status, and ready flag.
- Ready ledger sets `local_ledger_ready=true` and `restart_readable=true`.
- Ready ledger sets `exchange_readback_mapped=false` and
  `reconciliation_classified=false`; those are later tasks.
- Missing confirmations block with `blocked_missing_gate`.
- Source artifact mismatches block with `blocked_source_artifact`.
- Ledger does not persist API key, secret, signature, signed query, signed URL,
  raw exchange response, response body, or response headers.
- Ledger keeps `duplicate_submit_attempted=false`, `retry_attempted=false`,
  `cancel_attempted=false`, and `remediation_attempted=false`.
