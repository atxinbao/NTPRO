## Goal

Define and verify the v0.23.0 publication evidence audit path so release facts
can be reconstructed from source-tree records plus GitHub remote state, without
requiring an untracked local `release-publication-evidence/` directory.

Plain Chinese summary: 本任务把 publication evidence 的来源讲清楚。未跟踪的本地
JSON 只是生成物，不是唯一证据；审计者可以用源码树里的 manifest / closeout evidence /
audit path，再读取 GitHub Release、Actions run、tag ref 来复核 v0.23.0 发布事实。

## Scope

- Add a tracked v0.23.0 publication evidence audit path document.
- Add manifest policy fields that distinguish tracked audit proof from generated
  local publication evidence.

- Add a v0.23.1 gate that validates source-tree policy and live GitHub remote
