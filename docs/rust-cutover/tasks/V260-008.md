## Goal

Add the v0.26.0 release gates and strict provenance package for the Product
Hardening Foundation release.

Plain Chinese summary: 本任务收口 v0.26.0 的发布门禁和 strict provenance。它聚合
V260-000 到 V260-007 的证据、golden trace、Dashboard render smoke、artifact
ingestion test 和 no-trading-controls 边界；缺任何一项都会 fail closed。它不发布
production trading runtime，不开放真实交易操作，也不把 v0.26.0 声明成产品级实盘系统。

## Dependency

- Depends on `V260-000` through `V260-007`.
- Hard-blocked by v0.25.1 release evidence publication, already proven by
  `V260-000`.
- Keeps the v0.26.0 boundary as product hardening foundation only.

## Scope

Included:

- Add `v26-release-gates` and `v26-strict-provenance` verifier stages.
- Add a v0.26.0 release manifest, release notes, and readiness report.
- Aggregate V260 evidence, v26 validator traces, Dashboard smoke, artifact
  ingestion tests, release surface current guard, publication guard, and
  gate-before-publish governance.
- Add validator replay rows for release-gate success and fail-closed cases.
- Wire v26 release gates into `verify_release.sh` and hosted tag gates.
- Update current source release surface to `ntpro-rust-only-v0.26.0`.

Not included:

- production trading runtime;
- submit/cancel/retry/replace/amend/flatten/order-ticket controls;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard trading controls;
- product-grade live trading terminal readiness.

## Acceptance Criteria

- Missing any V260 evidence file or release input fails closed.
- Any forbidden trading capability set to `true` fails closed.
- Missing Dashboard smoke or artifact ingestion evidence fails closed.
- Public GitHub Release publication before hosted release gate success fails
  closed through the publish-after-gate workflow.
- `NTPRO_RELEASE_GATE=1` requires the v0.26.0 tag to match `HEAD`, `#820` to be
  closed, and the `v0.26.0` milestone to be closed.
- `scripts/ai/verify_release.sh v26-release-gates` passes.
- `scripts/ai/verify_release.sh v26-strict-provenance` passes.
- `docs/rust-cutover/golden_trace/RELEASE_REPLAY_SCOPE.json` records the
  V260-008 release cases as validator executable replay.
