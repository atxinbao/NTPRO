# V091-004 Correct Node Session Market Lifecycle Mapping

Date: 2026-06-18
Executor: Codex
Owner role: Rust Core Runtime Agent
Review role: Verification & Release Gatekeeper
Risk level: high
Status: BACKLOG
Depends on: V091-003

## Goal

Make node, strategy session, and fixture market states report coherent
lifecycle values.

## Scope

- Add market states such as `starting`, `running`, `exhausted`, `paused`,
  `stopped`, and `failed`.
- Stop reporting exhausted fixture input as `fixture_stream_running`.
- Report node data connection as disconnected after node shutdown.

## Acceptance

- Fixture exhaustion is visible as exhausted, not running.
- Node stop produces disconnected/stopped state.
- Supervisor and Dashboard do not show conflicting node/session/market states.
