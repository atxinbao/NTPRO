## Goal

Establish ownership, reachability, disposition, and reconstruction policy for
large tracked and ignored backend test fixtures before any fixture cleanup.

Plain Chinese summary: 本任务逐文件登记所有不小于 1 MiB 的测试 fixture，并核对
Betfair、market data、Parquet、compressed 和 golden 数据的代码可达性。当前不删除
fixture：有消费者的数据继续保留；无 Rust 消费者的大文件进入 quarantine，后续只有在
等价替代、hash、provenance、离线复现和 owner tests 全部成立后才能删除或外置。

## Dependency

BFH-001 (`#1112`) is closed through merged PR `#1127`.

## Scope

- inventory every file under `tests/` at or above 1 MiB;
- record size, format, Git state, owner, consumer, reachability, disposition,
  hash, and reconstruction policy;
- audit Betfair active manifest paths and legacy resource reachability;
- audit ignored large market-data checksum and metadata authority;
- summarize Parquet, compressed, and golden fixture groups;
- define a fail-closed deletion and externalization gate;
- run targeted owner tests without changing fixture content.

## Not In Scope

- fixture deletion, compression, rewriting, or format conversion;
- replacing deterministic input with a live network response;
- changing runtime, adapter behavior, dependencies, schema, or public API;
- modifying `docs/rust-cutover/release/v0_32_0_*`;
- creating a new backend patch or capability.

## Acceptance Criteria

- every fixture at or above 1 MiB has all required authority fields;
- the machine inventory reproduces local size, hash, and Git state;
- every active Betfair manifest path resolves;
- every ignored large cache hash matches its checksum and metadata sidecar;
- golden and compressed groups have no unclassified file above threshold;
- targeted testkit and adapter fixture tests pass;
- backend-freeze, current-governance, zero-Python, and fast gates pass;
- fixture files changed or deleted equals zero.
