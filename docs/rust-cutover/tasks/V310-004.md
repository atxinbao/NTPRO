## Goal

Define the canary enablement, rollback, and disaster-recovery execution boundary
for v0.31.0.

Plain Chinese summary: 本任务定义 canary、rollback、DR 边界。Canary readiness
不能绕过 rollback 或 DR evidence；缺失 rollback path、陈旧 DR evidence、扩大 canary
scope 都必须 fail-closed。

## Scope

- Model canary scope, blast-radius limits, rollback checkpoints, and DR
  readiness evidence.
- Require canary/rollback/DR evidence before any controlled enablement candidate
  can be marked ready.
- Add fail-closed cases for missing rollback path, stale DR evidence, and
  widened canary scope.

## Not Included

- No default production submit capability.
- No production order mutation.
- No adapter send or live exchange request.
- No retry scheduler or automatic remediation.
- No automatic recovery.
- No Dashboard/Admin/Trader Terminal trading controls.
- No backend go-live claim.
