## Goal

Publish v0.32.0 as the backend production closeout version only after all v32
gates prove scoped backend closeout readiness.

Plain Chinese summary: 本任务负责把 v0.32.0 作为后端收尾版本发布。它要求 V320-000
到 V320-008 的 gate 和 evidence 全部可追溯，hosted release gate 成功后才能发布
`ntpro-rust-only-v0.32.0`。v0.32.0 是 backend closeout，不是 frontend completion，
也不是 product-grade live trading terminal。

- Depends on `V320-008` fail-closed negative tests.
- Requires GitHub issue `#1050` to be closed before this gate can pass its live
  dependency check.

## Scope

Included:

- Add v0.32.0 release notes, readiness report, release manifest, release
  closeout evidence, release gates, and strict provenance.
- Require V320-000 through V320-008 to be closed before the tag gate passes.
- Add workflow release-stage entries for v32 release gates and strict
  provenance.
- Update release surface defaults to v0.32.0 with v0.32.1 as next patch and
  v0.33.0 as the next separately scoped capability track.

Not included:

- v0.33.0 capability inheritance;
- frontend completion;
- product-grade live trading terminal readiness;
- unscoped/default production submit, mutation, adapter send, live exchange,
  retry scheduler, automatic remediation, or trading controls.

## Acceptance Criteria

- Hosted v32 release gate succeeds.
- GitHub Release `ntpro-rust-only-v0.32.0` is published after hosted gate
  success.
- Release body, manifest, surface guard, publication guard, and source
  closeout evidence agree.
- v0.32.0 is documented as backend closeout, not frontend/product-grade
  trading-terminal completion.
