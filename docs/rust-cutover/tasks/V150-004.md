# V150-004 - Kill switch runtime enforcement

Date: 2026-06-22
Executor: Codex
Milestone: v0.15.0
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Promote the kill switch from a standalone evidence artifact into a runtime
mutation gate for the production live-alpha dry-run chain. If the kill switch is
active, missing approval, or paired with a blocked request preview, the gate must
hard-block dry-run progression before any adapter, network, or production order
mutation path can be reached.

Plain Chinese summary: 这个任务把 kill switch 从“单独证明文件”升级成“后续
dry-run 执行前必须经过的一道门”。开关打开、审批缺失、请求预览没 ready 时，
后面的 dry-run execution 也不能继续，更不能碰真实交易所、真实 adapter 或真实订单。

## Scope

Allowed:

- Add a Rust CLI command for v0.15 production live-alpha kill-switch runtime
  enforcement.
- Reuse existing local artifacts:
  - v0.13 kill-switch/manual-approval artifact.
  - v0.14 risk preflight.
  - v0.15 request preview.
- Require the new runtime gate artifact as an input to
  `live production-live-alpha-execution-dry-run`.
- Write stable JSON evidence proving the gate status and zero mutation counters.
- Add local and CI-safe verification.

Out of scope:

- Production order submission, cancel, replace, amend, retry, correction, or
  automatic remediation.
- Production adapter implementation, instantiation, or calls.
- Network requests.
- listenKey lifecycle.
- Dashboard order controls.
- Trading semantic changes in `crates/execution` or live runtime.

## Acceptance

- `live production-live-alpha-kill-switch-runtime-gate` writes a runtime gate
  artifact with schema `ntpro.v150_live_alpha_kill_switch_runtime_gate.v1`.
- `kill_switch_active=true` produces `blocked_kill_switch_active`.
- `kill_switch_active=false` without approved manual approval produces
  `blocked_missing_manual_approval`.
- A blocked request preview produces `blocked_request_preview`.
- A ready gate records:
  - `runtime_gate_open=true`
  - `kill_switch_active=false`
  - `manual_approval_recorded=true`
  - `request_preview_built=true`
- `live production-live-alpha-execution-dry-run` requires
  `--kill-switch-runtime-gate`.
- A closed runtime gate blocks execution dry-run progression before any local
  dry-run adapter artifact is written.
- All paths record:
  - `production_orders_submitted=0`
  - `production_order_mutations_attempted=0`
  - `network_attempted=false`
  - `dashboard_order_controls_enabled=false`
