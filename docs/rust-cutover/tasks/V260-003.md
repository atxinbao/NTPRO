# V260-003 operation audit trail and immutable action evidence

## Goal

Define the v0.26.0 operation audit trail and immutable action evidence model so
manual operation intent, approval evidence, denial, observation, release action,
and rollback recommendation records are traceable as an audit chain.

Plain Chinese summary: 本任务定义 operation audit trail 和 immutable action
evidence model。它只记录人工操作意图、审批证据、拒绝、观察、发布 gate 操作和 rollback
recommendation 的审计链；审计证据不能触发真实交易、自动 remediation、live control API
或 Dashboard 交易控件。

## Dependency

- Depends on `V260-001` product hardening boundary contract.
- Depends on `V260-002` operator permission model and role boundary evidence.
- Keeps the V260 evidence-only boundary intact.
- Does not implement an external audit database.
- Does not execute any operation intent.
- Does not add a live control API.

## Scope

Included:

- Define audit event schema fields: actor, role, scope, intent, decision,
  evidence refs, sequence/hash lineage, and timestamp.
- Cover operator ack, runbook decision, release gate action, permission denial,
  and rollback recommendation event types.
- Add fail-closed golden trace rows for missing actor/lineage/hash, sequence
  gap, hash mismatch, unredacted payload, and forbidden trading action.
- Add a verifier that recomputes audit-chain status from the trace.
- Register the trace rows in release replay scope as validator executable
  replay.

Not included:

- external audit database implementation;
- operation intent execution;
- live control API;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard trading controls.

## Acceptance Criteria

- Audit event chain missing lineage, hash, actor, role, or scope fails closed.
- Audit event chain with sequence gaps fails closed.
- Audit event chain with hash or previous-hash mismatch fails closed.
- Audit evidence containing secret, raw credential, signed payload, signed URL,
  or unredacted payload fails closed.
- Audit evidence asserting submit, cancel, replace, amend, flatten, adapter send,
  live exchange request, retry scheduler, automatic remediation, or Dashboard
  trading controls fails closed.
- Dashboard may display audit evidence only and must not provide execution
  controls through this model.
- `scripts/ai/verify_release.sh v26-operation-audit-trail` passes.
- `docs/rust-cutover/golden_trace/RELEASE_REPLAY_SCOPE.json` records the
  V260-003 cases as validator executable replay.
