## Goal

Define production config provenance and venue connectivity readiness evidence
for the backend go-live candidate.

Plain Chinese summary: 本任务定义 v0.30.0 production config provenance 和 venue
connectivity readiness。它记录 config source、redaction、digest、environment
binding、venue endpoint class、credential-material handling boundary 和 read-only/probe
mode；不会发 live exchange request、不会 adapter send、不会授予 send orders 权限。

## Scope

Included:

- Record config source, redaction, digest, environment binding, venue endpoint
  class, credential-material handling boundary, and read-only/probe mode.
- Distinguish connectivity readiness from live trading or adapter send.
- Reject unredacted sensitive fields, missing provenance, stale config,
  environment mismatch, credential material, adapter send attempts, live
  exchange request attempts, and order-send permission.
- Add deterministic JSON and executable verifier.

Not included:

- live exchange request;
- adapter send;
- production order submit or mutation;
- credential material storage;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal trading controls;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- Config and venue readiness can be audited without live exchange mutation.
- Readiness proof cannot be treated as permission to send orders.
- Sensitive material and live connectivity attempts fail closed.
