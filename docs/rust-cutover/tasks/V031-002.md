# V031-002 - release binary smoke support

Milestone: v0.3.1 Local Supervisor Control Console Hardening
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Rust Product Surface Agent
Risk: medium

## Goal

Make the v0.3 supervisor control smoke and dashboard smoke runnable against
release binaries from `scripts/ai/verify_release.sh`.

Plain language: release gate behavior should prove release binaries, not only
whatever debug build happened to exist.

## Dependencies

- `V031-001`

## Scope

- Add binary-path overrides for v0.3 smoke scripts.
- Wire `scripts/ai/verify_release.sh` to pass release binary paths explicitly.
- Preserve local developer defaults so the smoke can still run against debug
  binaries outside release verification.
- Keep the smoke sandbox-only and local-only.

## Non-goals

- Do not broaden the product claim beyond v0.3.0.
- Do not add production reconnect behavior.
- Do not remove the local debug smoke path.

## Related files

- `scripts/ai/verify_release.sh` (TO_MODIFY): release gate entrypoint.
- `scripts/ai/v03_supervisor_control_smoke.sh` (TO_MODIFY): supervisor smoke.
- `scripts/ai/v03_dashboard_smoke.sh` (TO_MODIFY): dashboard smoke.
- `docs/rust-cutover/evidence/V031-002.md` (CREATE): task evidence.

## Implementation guidance

Use explicit environment variables or arguments instead of hardcoding another
path twice. The release gate should fail clearly if release binaries are
missing.

## Verification criteria

- v0.3 smoke scripts can run with caller-provided binary paths.
- `verify_release.sh` passes release binary paths into both v0.3 smoke scripts.
- Local debug default still works when no override is provided.

bash -n scripts/ai/verify_release.sh scripts/ai/v03_supervisor_control_smoke.sh scripts/ai/v03_dashboard_smoke.sh
scripts/ai/verify_release.sh
