# V111-002 Add Central EndpointClassifier API and Deny Tests

Date: 2026-06-20
Executor: Codex
Owner role: Control & Scope Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V111-001

## Goal

Introduce a reusable Rust endpoint classifier for sandbox, testnet, production
public read-only, production authenticated read-only, production mutation
forbidden, websocket read-only, and unknown forbidden classes.

Plain Chinese summary: 这次把“这个 URL 到底是什么类型”写成统一 Rust 分类器。
生产只读、生产账号只读、生产订单变更、sandbox/testnet、未知 endpoint 都要分清楚；
生产下单、撤单、改单和未知 endpoint 必须默认拒绝。

## Scope

- Add `EndpointClass`, `EndpointDecision`, and
  `EndpointClassifier::classify(method, url, auth_kind)` under the CLI crate.
- Route existing v0.11 production public read and authenticated account
  snapshot contracts through the classifier where practical.
- Add explicit deny tests for production mutation and unknown endpoints.
- Update endpoint classifier release-surface documentation and task evidence.

## Non-Goals

- No production network connection.
- No production online read runtime.
- No production order submission.
- No production cancel, replace, amend, retry, or correction.
- No Dashboard order controls.
- No change to testnet/sandbox order behavior.
- No public API promise outside the CLI crate.
- No new release tag or GitHub Release publication.

## Acceptance

- `cargo test -p nautilus-cli endpoint_classifier --lib` passes.
- Production public read probe still emits `production_public_read_only`,
  `read_allowed` only under existing gates, and `mutation_allowed=false`.
- Production account snapshot contract still emits
  `production_authenticated_read_only`, requires API key/signature, and never
  attempts network or order endpoints.
- Production order mutation endpoints classify as
  `production_mutation_forbidden` with `decision=deny`.
- Unknown endpoints classify as `unknown_forbidden` with `decision=deny`.
- `scripts/ai/verify_fast.sh` passes.
- `git diff --check` passes.
