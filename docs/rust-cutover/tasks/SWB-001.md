## 目标

将项目文档已经确认的策略工作台框架落到真实 Rust/Axum 产品入口。页面以策略为主对象，
固定展示 Strategy、StrategyVersion、Backtest / Demo / Live 模式和当前 Run 上下文。

## 路由

```text
GET /strategy-workbench
GET /assets/strategy-workbench.css
GET /assets/strategy-workbench.js
GET /api/mvp/v1/status
```

前三个页面路由只允许 GET；HEAD 和其他方法返回 405。页面只消费现有共享状态 API，
不新增写接口。

## 页面框架

- 左侧导航：总览、策略、Backtest、Demo、Live、运行、数据、风险、系统状态；
- 顶部栏目：策略、版本、模式、账户、Venue 和刷新；
- 主画布：当前 Run 摘要、模式状态、表现指标和运行记录；
- 右侧隐藏栏：当前选择、准入边界和来源；
- 底部 Dock：持仓、活动、成交、日志；
- 底部状态栏：数据、账户、Venue、风险、节点与更新时间。

## 边界

- Backtest、Demo 和 Live 使用同一策略版本语义，但本任务不创建 Run；
- Live 入口必须可见并明确标记未开放；
- 页面不得包含 submit、cancel、replace、amend、flatten、retry 或 remediation 控件；
- API、schema、身份或只读边界异常时清空旧状态并 fail closed；
- 不修改旧机构工作台、控制中心、共享 API 或 Supervisor/node 行为；
- 不修改 `docs/rust-cutover/release/v0_32_0_*`。

## 冻结例外

`crates/cli/src/dashboard/server.rs` 属于 M4 冻结哈希集合。本任务经用户明确授权，只允许
增加策略工作台 shell 与静态资产路由，并按 post-freeze policy 更新 manifest 中该文件
的 SHA-256。旧路由和能力边界必须保持不变。
