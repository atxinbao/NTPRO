## Goal

Close the v0.32.0 backend production approval lifecycle with owner/operator
ownership, freeze windows, production change windows, revocation, and
auditability.

Plain Chinese summary: 本任务定义 v0.32.0 后端收尾所需的 owner/operator approval、
production freeze 和 change-window closeout 合同。它只记录授权生命周期证据，不授权
实际生产执行，不开放 submit、mutation、adapter send、live exchange request、retry
scheduler、automatic remediation、Dashboard/Admin/Trader Terminal 交易控件、
frontend completion、backend go-live 或产品级实盘交易终端声明。

## Dependency

- Depends on `V320-000` intake gate and `V320-001` backend closeout boundary.
- Requires GitHub issues `#1042` and `#1043` to be closed before this lifecycle
  gate can pass its live dependency check.
- Hard-blocked by published `ntpro-rust-only-v0.31.1` release evidence through
  `V320-000`.

## Scope

Included:

- Define owner/operator approval artifact schema for backend closeout.
- Define approval, freeze, and production change-window states.
- Define fail-closed behavior for missing approval, expired approval, revoked
  approval, wrong owner/operator, release mismatch, scope reuse, active freeze,
  and attempts outside the approved window.
- Require immutable, redacted, source-provenance-bound audit records that link
  approval to release, operator, owner, environment, venue, account, strategy,
  change window, rollback plan, risk decision, audit evidence, and telemetry
  gate.
- Keep approval as evidence only until downstream v32 gates complete.

Not included:

- shared approval consumption across unrelated strategies, venues, accounts, or
  releases;
- default production submit;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal operation controls or trading controls;
- backend go-live execution;
- product-grade live trading terminal readiness.

## Acceptance Criteria

- Backend closeout remains blocked without active scoped approval.
- Active freeze or outside-window attempts fail closed.
- Wrong owner/operator and broader-scope approval reuse fail closed.
- Approval evidence is redacted, immutable, provenance-bound, and linked to the
  release, operator, environment, venue, and rollback plan.
- Runtime and trading boundary flags remain explicitly false.
