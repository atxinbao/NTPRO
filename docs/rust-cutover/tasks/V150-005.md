# V150-005 - Manual approval lifecycle

Date: 2026-06-22
Executor: Codex
Milestone: v0.15.0
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Define and enforce a one-time, short-lived manual approval lifecycle for the
production live-alpha request preview path. The approval only permits building a
dry-run request preview artifact. It never permits production order submission,
network access, execution adapter calls, or production order mutation.

Plain Chinese summary: 这个任务给 v0.15 的“实盘下单请求预览”补一张人工审批单。
审批必须绑定具体 run、策略、交易对、金额和过期时间；只能用一次；只能让系统生成
dry-run 预览文件，不能真实下单、不能联网、不能调用生产 adapter。

## Scope

Allowed:

- Add a Rust CLI command for v0.15 manual approval lifecycle artifact creation.
- Support lifecycle states: `pending`, `approved`, `expired`, `revoked`, and
  `used`.
- Bind approval to:
  - `run_id`
  - `strategy_id`
  - `symbol`
  - `notional`
  - `expires_at_unix_ms`
- Require the lifecycle artifact as an input to
  `live production-live-alpha-order-request-preview`.
- Block request preview if approval is missing, pending, expired, revoked, used,
  mismatched, or records forbidden production mutation evidence.
- Add local and CI-safe verification.

Out of scope:

- Production order submission, cancel, replace, amend, retry, correction, or
  automatic remediation.
- Any production HTTP request execution.
- Any production adapter implementation, instantiation, or call.
- listenKey lifecycle.
- Dashboard order controls.
- Durable server-side approval storage.
- Trading semantic changes in live runtime, risk, portfolio, execution, or
  adapters.

## Acceptance

- `live production-live-alpha-manual-approval-lifecycle` writes an artifact with
  schema `ntpro.v150_live_alpha_manual_approval_lifecycle.v1`.
- A valid approval records:
  - `approval_state=approved`
  - `approval_lifecycle_valid=true`
  - `manual_approval_recorded=true`
  - `one_time_approval=true`
  - `dry_run_request_preview_only=true`
- `live production-live-alpha-order-request-preview` requires
  `--manual-approval-lifecycle`.
- Invalid approval lifecycle inputs produce
  `status=blocked_manual_approval_lifecycle`.
- Tests cover:
  - missing/manual lifecycle not ready through blocked preview paths
  - `pending`
  - `expired`
  - `revoked`
  - `used`
  - mismatched `run_id`
  - mismatched `symbol`
  - mismatched `notional`
  - valid dry-run approval
- All paths record:
  - `request_sent=false`
  - `production_orders_submitted=0`
  - `production_order_mutations_attempted=0`
  - `network_attempted=false`
  - `dashboard_order_controls_enabled=false`
