# V031-008 - negative control API tests

Milestone: v0.3.1 Local Supervisor Control Console Hardening
Priority: P1
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk: medium

## Goal

Add explicit negative-path tests for invalid, missing, or out-of-state local
Supervisor control requests.

Plain language: prove the console fails honestly when the request is wrong.

## Dependencies

- `V031-007`

## Scope

- Add negative-path coverage for invalid lifecycle transitions.
- Add missing-node coverage.
- Add unsupported or unknown-action coverage where applicable.
- Keep status codes and error payloads deterministic.
- Cover both CLI-side and Dashboard/API-side paths where the current contract
  promises an explicit result.

## Non-goals

- Do not invent new controls.
- Do not broaden the product boundary.
- Do not weaken existing positive-path smoke coverage.

## Related files

- `crates/cli/src/supervisor.rs` (TO_MODIFY): supervisor negative-path tests.
- `crates/cli/src/dashboard.rs` (TO_MODIFY): Dashboard/API negative-path tests.
- `docs/rust-cutover/evidence/V031-008.md` (CREATE): task evidence.

## Implementation guidance

Keep the test matrix tied to actual local control semantics. Avoid asserting
production meanings that the product does not claim.

## Verification criteria

- Invalid start/stop/pause/resume/reconnect transitions are tested.
- Missing-node and unsupported-action paths are tested.
- Dashboard/API and supervisor tests pass together.
