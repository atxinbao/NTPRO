# V090-000 Define Strategy Runtime Boundary and Product Contract

Date: 2026-06-18
Executor: Codex
Owner role: Control & Scope Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: none

## Goal

Define the v0.9.0 product boundary: `ntpro-node` may host strategy runtime, but
must not submit orders.

## Scope

- Define Strategy Runtime Foundation.
- Define Strategy Session lifecycle.
- Define Shadow Mode.
- Define Signal / Order Intent / Risk Decision / Audit artifacts.
- Define node / supervisor / dashboard responsibility boundaries.
- Define the v0.10.0 deferred order bucket.

## Non-Goals

- No Binance testnet order submission.
- No production read-only connectivity.
- No production live trading.
- No Dashboard order controls.

## Acceptance

- Create `docs/rust-cutover/release/v0_9_0_strategy_runtime_boundary.md`.
- Clearly state:
  - `v0.9.0 = strategy runtime only`;
  - `v0.10.0 = testnet order proof`;
  - `v0.11.0 = production-readonly + shadow`;
  - `v0.12.0 = guarded live alpha`.
