# V100-004 Build Signed Binance Order Request Layer

Date: 2026-06-19
Executor: Codex
Status: IN PROGRESS

## Goal

Add an offline, fail-closed signed Binance testnet order request preview layer
for the future v0.10 manual order proof.

## Scope

- Add a local CLI request-preview command.
- Restrict request construction to:
  - `POST /api/v3/order/test`
  - `POST /api/v3/order`
  - `DELETE /api/v3/order`
- Require the existing v0.10 manual CLI and environment gates.
- Read API key and secret from environment variable names only.
- Keep API key values, API secrets, signatures, signed queries, signed URLs,
  and request bodies out of artifacts.
- Keep network access and real order submission disabled.

## Out Of Scope

- No Binance API calls.
- No online `/api/v3/order/test` execution.
- No submit/cancel execution.
- No production Binance endpoint.
- No Dashboard order controls.
- No strategy-driven production execution.

## Acceptance

- Missing manual gates fail before request construction.
- Missing API key or secret fails closed.
- Non-allowlisted endpoints fail closed.
- Production base URL fails closed.
- `DELETE /api/v3/order` requires `--orig-client-order-id`.
- Output preview records no signed URL, no signed query, no signature, no API
  key value, and no request body.
- Output always records `network_attempted=false` and
  `real_orders_submitted=false`.
