# V160-004 - Add single LIMIT GTC production order request builder

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.0 minimum owner-approved production order mutation candidate
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Add the v0.16 request-builder artifact for the minimum owner-approved
production order mutation candidate.

Plain Chinese summary: 这个任务加的是“真实生产下单请求对象的本地构造器”。大白话：
它在 owner approval、signing approval、runtime gate 都 ready 后，用 env-only
签名材料在内存里构造一笔极小的 `LIMIT GTC` 生产订单请求对象，但只输出脱敏证据，不发
HTTP 请求、不联网、不真实下单。

## Scope

Included:

- add `live production-mutation-request-builder`;
- write `ntpro.v160_production_mutation_request_builder.v1` artifact;
- require v0.16 runtime gate status `blocked_explicit_send_gate`;
- require ready v0.16 signing approval artifact;
- require v0.15 production live-alpha request preview with
  `credential_material=production_live_alpha`;
- build only one `POST /api/v3/order` `LIMIT GTC` request object in memory;
- record query shape and redacted request metadata only;
- keep API key value, API secret value, signature, signed query, signed URL,
  timestamp value, and raw body unrecorded;
- reject missing owner/env gates and non-`LIMIT` request preview inputs;
- keep request sending, network, production order submission, mutation, retry,
  cancel, replace, amend, flatten, listenKey, and Dashboard order controls
  disabled.

Not included:

- production HTTP send;
- production order-test send;
- production order submission;
- cancel, replace, amend, retry, correction, or flatten;
- response redaction after real send;
- post-submit readback;
- listenKey lifecycle;
- Dashboard order controls;
- strategy-driven production execution;
- trading engine semantic changes.

## Acceptance Criteria

- Ready source artifacts produce `ready_request_object_built_no_send`.
- Missing owner/env gates produce `blocked_missing_gate`.
- Non-`LIMIT` request preview input produces `blocked_source_artifact`.
- Ready request builder records:
  - `request_object_built=true`;
  - `runtime_gate_status=blocked_explicit_send_gate`;
  - `signing_approval_ready=true`;
  - `explicit_send_gate_open=false`;
  - `request_method=POST`;
  - `request_target=/api/v3/order`;
  - `order_type=LIMIT`;
  - `time_in_force=GTC`;
  - `single_order_candidate=true`;
  - `tiny_notional_gate_ready=true`;
  - `api_key_value_recorded=false`;
  - `api_secret_value_recorded=false`;
  - `signature_recorded=false`;
  - `signed_query_recorded=false`;
  - `signed_url_recorded=false`;
  - `request_body_recorded=false`;
  - `raw_request_body_recorded=false`;
  - `request_sent=false`;
  - `network_attempted=false`;
  - `production_orders_submitted=0`;
  - `production_order_mutations_attempted=0`;
  - `dashboard_order_controls_enabled=false`.
