# V161-006 - Fix CLI and classifier wording drift

Date: 2026-06-24
Executor: Codex
Milestone: v0.16.1 guarded production mutation hardening
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Align CLI help and endpoint classifier messages with the v0.16/v0.16.1
owner-gated production mutation candidate boundary.

Plain Chinese summary: 这个任务只修“说法漂移”。大白话：v0.16 之后已经不是绝对
“没有任何 production mutation 相关入口”，而是默认关闭、owner 手动 gate、单次候选路径。
所以 CLI 和 classifier 不能继续写成旧的 v0.15-only 或绝对 no-mutation 口径。

## Scope

Included:

- update the `live` command help summary;
- update endpoint classifier deny reasons that still referenced v0.15-only
  request-preview candidates;
- add regression tests for current wording;
- document validation evidence.

Not included:

- new production mutation capability;
- request execution behavior changes;
- classifier decision or authorization changes;
- Dashboard order controls;
- cancel, replace, amend, retry, correction, flatten, or remediation;
- release tag creation.

## Acceptance Criteria

- CLI help describes `live` as production read-only, dry-run proof, and
  owner-gated mutation-candidate commands.
- Current classifier reason strings no longer use stale v0.15-only wording for
  v0.16/v0.16.1 mutation candidate scope.
- Deny/allow decisions remain unchanged.
- Default posture remains fail-closed.
- No production network request, order submission, cancel, retry, or Dashboard
  order control is introduced.
