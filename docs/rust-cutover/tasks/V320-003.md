# V320-003 risk gate, audit gate, and go/no-go closeout contract

Date: 2026-07-15
Executor: Codex
GitHub issue: #1045
Milestone: v0.32.0
Status: READY FOR PR

## Goal

Close backend production readiness only when risk, audit, and go/no-go gates
are explicit, replayable, and fail-closed.

Plain Chinese summary: 本任务定义 v0.32.0 后端收尾所需的 risk gate、audit gate
和 go/no-go closeout 合同。缺失、失败、陈旧或自相矛盾的 risk/audit/go-no-go
输入必须 fail-closed；即使 operator go，合同也不授权 submit、mutation、adapter
send、live exchange、automatic remediation、frontend completion、backend go-live
或交易控件。

## Dependency

- Depends on `V320-001` backend closeout boundary and `V320-002`
  owner/operator approval change-window closeout.
- Requires GitHub issues `#1043` and `#1044` to be closed before this gate can
  pass its live dependency check.
- Hard-blocked by published `ntpro-rust-only-v0.31.1` release evidence through
  `V320-000`.

## Scope

Included:

- Define risk gate inputs and required pass/fail evidence for backend closeout.
- Define audit gate outputs and immutable evidence requirements.
- Define go/no-go decision record with approver, timestamp, release identity,
  gate run, rollback reference, risk decision reference, audit evidence
  reference, and stable decision digest.
- Add deterministic reason codes for missing, failed, stale, contradictory,
  blocked, degraded, and approved closeout states.
- Require evidence to be source-controlled or remotely reconstructable with
  stable identifiers.

Not included:

- automatic remediation;
- strategy-driven production execution;
- default production submit;
- production order mutation;
- adapter send or live exchange request;
- Dashboard/Admin/Trader Terminal operation controls or trading controls;
- frontend completion;
- backend go-live execution;
- product-grade live trading terminal readiness.

## Acceptance Criteria

- A failed or stale risk/audit/go-no-go state blocks backend closeout.
- Missing risk, missing audit, stale go/no-go, and contradictory decision state
  fail closed.
- Evidence is source-controlled or remotely reconstructable with stable
  identifiers.
- Approved closeout state remains bounded by v32 non-execution rules.
