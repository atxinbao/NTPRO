# V221-006 - v0.22.1 release gates and strict provenance

Date: 2026-07-03
Executor: Codex
GitHub issue: `#710`
Milestone: `v0.22.1`
Risk: critical release governance
Owner role: Verification & Release Gatekeeper
Review role: Control & Scope Agent
Auto-merge: allowed after local validation and hosted checks pass

## Goal

Prepare and verify the `v0.22.1` hardening patch release package, including
release notes, readiness report, machine-readable manifest, release gates,
strict provenance, and the gate-before-publish sequence.

Plain Chinese summary: 本任务是 `v0.22.1` 的最终发布收口。它把 V221-001 到
V221-005 的证据纳入 release notes、readiness report、manifest、release gates 和
strict provenance，并要求公开 GitHub Release 必须在 hosted release gate 成功之后
发布。

## Scope

Included:

- add `v0.22.1` release notes, readiness report, release manifest, task file,
  and evidence ledger;
- add dedicated `v0.22.1` release gate and strict provenance scripts;
- wire the new stages into `scripts/ai/verify_release.sh`;
- wire the new hosted release stages into `.github/workflows/release-tag.yml`;
- verify V221-001 through V221-005 evidence, boundary fields, executable replay
  coverage, render smoke, and gate-before-publish governance;
- keep `v0.23.0` blocked until `v0.22.1` is published and issue `#710` is
  manually closed with release evidence.

Not included:

- implementing any `v0.23.0` multi-account, multi-strategy, or multi-venue
  capability;
- enabling submit, cancel, retry, replace, amend, flatten, funds transfer,
  automatic action, or production mutation;
- claiming complete executable read-model runtime coverage;
- publishing a public release before the hosted release gate succeeds.

## Acceptance Criteria

- `docs/rust-cutover/release/v0_22_1_release_notes.md` records the final
  release boundary and validation commands.
- `docs/rust-cutover/release/v0_22_1_readiness_report.md` records readiness,
  issue dependency, and publication-order evidence requirements.
- `docs/rust-cutover/release/v0_22_1_release_manifest.json` records the V221
  evidence chain, boundary flags, gates, and `v0.23.0` dependency.
- `scripts/ai/verify_release.sh v22.1-release-gates` passes locally and in the
  hosted release gate.
- `scripts/ai/verify_release.sh v22.1-strict-provenance` passes locally and in
  the hosted release gate.
- The `ntpro-rust-only-v0.22.1` public GitHub Release is published only after a
  successful hosted `Rust Cutover Release Gate` run for the same tag commit.
