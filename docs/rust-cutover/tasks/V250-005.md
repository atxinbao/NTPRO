## Goal

Define the v0.25.0 disaster-recovery preview drill evidence contract so restart,
read-model rebuild, artifact replay, rollback recommendation, and data
consistency checks are auditable without executing production recovery.

Plain Chinese summary: 本任务定义 v0.25.0 的 DR preview drill evidence。DR preview
可以记录 scenario、affected scope、snapshot refs、expected recovery point、
readback/audit refs、operator approval status 和 snapshot lineage；但它只提供预览/
审计证据，不自动重启服务，不执行数据恢复，不发送 live request，也不修改生产订单或
exchange state。

## Scope

Included:

- DR preview artifact contract: scenario, affected scope, snapshot refs,
  expected recovery point, readback refs, audit trace, operator approval,
  source provenance, snapshot lineage, freshness, and redaction;
- preview coverage for restart, read-model rebuild, artifact replay, and release
  rollback recommendation;
- fail-closed coverage for missing snapshot, stale recovery point, scope
  mismatch, unapproved restore, actual execution claim, and redaction breach;
- release replay scope entries as validator executable replay.

Not included:

- automatic service restart;
- data restore execution;
- production order mutation or exchange state mutation;
- live exchange requests or adapter send;
- actual release rollback execution.

## Acceptance Criteria

- Every DR preview artifact must have source provenance, snapshot lineage, and
  audit trace.
- Every DR preview artifact must have snapshot refs, readback refs, affected
  scope, expected recovery point, operator approval status, freshness, and
  redaction evidence.
- Missing snapshot, stale recovery point, scope mismatch, unapproved restore, or
  actual execution claim fails closed.
- Unapproved restore/restart can only appear as blocked preview.
- Evidence must not contain secret, raw credential, signed payload, signature,
  raw order id, or unredacted trading-sensitive field values.
- DR preview cannot directly trigger service restart, data restore, artifact
  replay execution, release rollback execution, adapter send, live exchange
  request, production order mutation, or exchange state mutation.
