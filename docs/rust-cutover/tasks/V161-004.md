# V161-004 - Add non-marketable price safety preflight

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.1 guarded production mutation hardening
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Add a non-marketable price safety preflight to the v0.16 single `LIMIT` `GTC`
request builder because v0.16 intentionally has no automatic cancel path.

Plain Chinese summary: 这个任务只给 request builder 加“价格安全检查”。大白话：v0.16
没有自动撤单，所以构建单个 `LIMIT GTC` 请求对象前，必须有市场参考价、价格距离不能超限、
不能跨价差，并且 owner 必须确认知道没有自动撤单路径。

## Scope

Included:

- require market reference source evidence;
- require market reference price evidence;
- compute LIMIT price distance from the reference in basis points;
- block request object building when the reference is missing or invalid;
- block request object building when the LIMIT price would cross the spread;
- require owner confirmation of the no-cancel-path boundary;
- set manual-review and new-order block fields when price safety is not clean.

Not included:

- automatic cancel, replace, amend, flatten, or remediation;
- market data subscription or live spread probing;
- strategy-driven production execution;
- multi-order execution;
- Dashboard order controls;
- broad production trading platform capability expansion.

## Acceptance Criteria

- Safe non-marketable `LIMIT` fixture builds a redacted request object and records:
  - `non_marketable_price_preflight_ready=true`;
  - `price_safety_send_consideration_allowed=true`;
  - `manual_review_required=false`;
  - `new_orders_blocked=false`.
- Missing market reference blocks request object building and records:
  - `market_reference_source_missing`;
  - `manual_review_required=true`;
  - `new_orders_blocked=true`.
- Crossing/marketable LIMIT price blocks request object building and records:
  - `limit_price_would_cross_spread`;
  - `manual_review_required=true`;
  - `new_orders_blocked=true`.
- Missing owner no-cancel acknowledgement is treated as a missing gate.
