## Goal

Resolve the Trader Terminal blocker recorded in `project.html`: the six v0.28
read-only backend contracts exist as deterministic artifacts but are not
mounted as Dashboard HTTP routes.

中文摘要：本任务把 v0.28 已冻结的六个 Trader Terminal 只读合同投影为稳定
JSON DTO，并挂载到现有 Dashboard Axum 服务。它不修改 v0.32.0 冻结基线，
不增加订单、持仓、adapter、live exchange 或自动修复写能力。

## Dependencies

- `V280-007` / GitHub issue `#900` is closed.
- v0.32.0 remains the frozen backend baseline.
- v0.33.0 backend maintenance release is already published.

- `crates/cli/src/dashboard.rs`

- `docs/rust-cutover/tasks/TTR-001.md`

## Prohibited paths

- `docs/rust-cutover/release/v0_32_0_*`
- adapter, execution, risk, or trading-semantic implementation
- release manifests, tags, or publication workflows

## Scope

Included:

- mount the six `GET /api/v28/*` routes defined by V280-007;
- project stable DTOs from existing source-controlled v0.28 artifacts;
- enforce redaction and required-false operation/trading boundaries;
- fail closed when embedded source data is malformed or violates the contract;
- reject non-GET methods;
- add direct projection and HTTP route tests.

Not included:

- Trader Terminal UI or realtime streams;
- query parameters, pagination, external identity calls, or authorization;
- submit, cancel, retry, replace, amend, flatten, adapter send, or live exchange;
- product-grade live trading terminal claims.

## Acceptance criteria

- All six GET routes return JSON with their contract-required fields.
- Responses expose source, provenance, freshness, and redaction semantics.
- Operation and trading controls remain explicitly false.
- `POST`, `PUT`, `PATCH`, and `DELETE` cannot invoke the routes.
- Malformed, unredacted, and forbidden-control fixtures fail closed.
- Targeted Rust tests and `scripts/ai/verify_fast.sh` pass locally.
- No v0.32.0 frozen files or Python/tooling dependencies are added.
