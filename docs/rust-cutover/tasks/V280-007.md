## Goal

Close the backend API contract needed for later Trader Terminal and operations
product handoff. The task defines deterministic read-only backend API/artifact
contracts for backend closure status, provenance drill-down, audit entries,
telemetry health, permissions, and deployment state.

Plain Chinese summary: 本任务把 Trader Terminal 后续产品交接需要的 backend API
合同固化为 v0.28.0 runtime closure。它只定义 read-only API/artifact、response schema、
redaction、freshness、failure semantics 和 replay validator；不实现 Trader Terminal UI，
不开放订单票据、submit/cancel/retry/replace/amend/flatten 或任何 live trading controls。

## Scope

Included:

- Define stable read-only backend API/artifact contracts for:
  - backend closure status;
  - provenance drill-down;
  - audit entries;
  - telemetry health;
  - permissions;
  - deployment state.
- Define response schema, redaction, freshness, and failure semantics for every
  handoff endpoint.
- Add deterministic replay cases for ready, degraded, stale, missing source,
  malformed response schema, unredacted payload, and forbidden controls.
- Promote `trader_terminal_backend_api_contract_handoff` to `runtime-closed` in
  the v0.28 backend closure readiness matrix.

Not included:

- Trader Terminal frontend/product implementation;
- order ticket rendering or submit/cancel/retry/replace/amend/flatten controls;
- production order submission or mutation;
- adapter send or live exchange request;
- retry scheduler or automatic remediation;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- Frontend/product follow-up work can start from a stable read-only backend
  contract after v0.28.0.
- The contract validates deterministically without ad hoc evidence inspection.
- Every response contract defines schema, redaction, freshness, and failure
  semantics.
- Missing source references fail closed.
- Malformed response schema fails closed.
- Unredacted payloads fail closed.
- Any forbidden operation/trading control fails closed.
- `scripts/ai/verify_release.sh v28-trader-terminal-backend-api-contract-handoff`
  passes.
- `scripts/ai/verify_release.sh v28-backend-closure-boundary-contract` reports
  runtime-closed=8, evidence-only=2, blocked=1, deferred=1.
