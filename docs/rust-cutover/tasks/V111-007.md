# V111-007 Normalize read_allowed Contract Fields

## Goal

Normalize `read_allowed`, `contract_ready`, `online_execution_supported`,
`network_attempted`, and `account_read_attempted` semantics so offline contracts
cannot be mistaken for live online reads.

Plain Chinese summary: 这次不是开启生产读取，而是把 JSON 字段说清楚。
`read_allowed=true` 只保留为旧兼容的“离线合同就绪”信号；真正表示线上读取的字段是
`online_read_allowed=false`、`online_execution_supported=false`、
`network_attempted=false`。

## Scope

- Add `contract_ready` and `online_read_allowed` fields to the v0.11 production
  public read probe artifact.
- Add the same fields to the v0.11 authenticated account snapshot contract
  artifact.
- Preserve existing `read_allowed` for backward-compatible gates, but document
  it as local contract readiness rather than online execution permission.
- Extend tests and verify scripts to assert `online_read_allowed=false`.
