# V160-009 - Add production mutation audit trail artifact

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.0 minimum owner-approved production order mutation candidate
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Add the v0.16 production mutation audit trail artifact that links the
owner-approved request-builder, guarded-send, response-redaction, and
order-state readback evidence into one redacted closeout record.

Plain Chinese summary: 这个任务不是新增下单能力，而是把 v0.16 单笔候选链路的证据
串起来。大白话：它回答“这次候选单从审批、构造、发送保护、响应脱敏、订单状态读回到
失败/完成状态，有没有完整、可审计、无敏感信息的记录”。

## Scope

Included:

- add `live production-mutation-audit-trail`;
- write `ntpro.v160_production_mutation_audit_trail.v1` artifact;
- link request-builder, guarded-send, response-redaction, and order-state
  readback artifacts;
- include source runtime gate, signing approval, request preview hash, and
  kill-switch runtime gate paths;
- record approval state, guarded-send state, redaction state, readback state,
  kill-switch before/after state, and failure state;
- keep all persisted evidence redacted;
- prove default/offline audit creation keeps `request_sent=false` and
  `network_attempted=false`;
- keep retry, cancel, replace, amend, flatten, listenKey, and Dashboard order
  controls disabled.

Not included:

- new production send behavior;
- retry, cancel, replace, amend, correction, or flatten;
- Dashboard order controls;
- listenKey/WebSocket lifecycle;
- strategy-driven production trading;
- multi-venue or multi-account execution;
- trading engine semantic changes.

## Acceptance Criteria

- Missing owner confirmations produce `blocked_missing_gate`.
- Ready source artifacts produce `ready_redacted_audit_trail`.
- Ready audit artifact records:
  - `audit_trail_ready=true`;
  - `preview_hash=fnv1a64:<hash>`;
  - `signing_approval_status=ready_signing_material_approval`;
  - `runtime_gate_status=blocked_explicit_send_gate`;
  - `guarded_send_status=ready_guarded_send_path_offline_no_network`;
  - `response_redaction_status=ready_response_redacted`;
  - `order_state_readback_status=ready_offline_order_state_readback_contract`;
  - `kill_switch_checked_before_send=true`;
  - `kill_switch_checked_after_send=true`;
  - `kill_switch_blocked_send=false`;
  - `request_sent=false`;
  - `network_attempted=false`;
  - `source_artifact_issues=[]`;
  - `missing_cli_flags=[]`;
  - `failure_state=none_recorded`;
  - `signature_recorded=false`;
  - `signed_query_recorded=false`;
  - `signed_url_recorded=false`;
  - `raw_exchange_response_recorded=false`;
  - `response_body_recorded=false`;
  - `response_headers_recorded=false`;
  - `retry_attempted=false`;
  - `cancel_attempted=false`;
  - `replace_attempted=false`;
  - `amend_attempted=false`;
  - `flatten_attempted=false`;
  - `dashboard_order_controls_enabled=false`.
