## Goal

Bind release-publish-after-gate current-release checks to the published
`v0.29.0` release instead of proving the historical `v0.28.0` release by
default.

`ntpro-rust-only-v0.29.0`、hosted release gate `29091765148` 和 tag commit

v29 current binding。它不改变 runtime，不开放 submit、mutation、adapter send、
