# V090-009 Host Strategy Session Inside ntpro-node

Date: 2026-06-18
Executor: Codex
Owner role: Rust Core Runtime Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V090-008

## Goal

Make `ntpro-node` a headless Strategy Session runtime host.

## Automation Scope

This is a medium-risk automation slice because the node host must use
fixture/mock/sandbox inputs only and must not enable live exchange execution or
order submission.

## Scope

- `ntpro-node` reads strategy session config.
- Initialize `StrategySession`.
- Start fixture/mock market stream.
- Execute strategy loop.
- Write artifacts.
- Support graceful stop.

## Non-Goals

- No real order submission.
- No production connectivity.
- No systemd or Docker packaging.

## Acceptance

`ntpro-node --config configs/nodes/btc-ema-shadow.toml` can:

- start session;
- run strategy loop;
- write `session_status.json`;
- write signal / order intent / risk decision artifacts;
- write `stopped` status on shutdown.
