# V140-005 Reconciliation Golden Traces

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Add executable golden traces for live-alpha dry-run reconciliation and local
risk preflight failure modes.

Plain Chinese summary: 这个任务给 v0.14 补“可回放证据”。它证明本地 dry-run
订单和风控预检在不同异常场景下会输出稳定结果，并且所有 trace 都记录没有真实订单、
没有生产下单、没有生产改单、没有 execution adapter 调用。

## Scope

Included:

- add `tests/golden/live_alpha_reconciliation_schema.jsonl`;
- cover no open orders, existing open order, stale order-state read, account
  read failed, order-state read failed, kill switch active, and risk limit
  exceeded;
- add a `nautilus-cli` executable golden trace harness;
- wire the harness into `scripts/ai/run_golden_traces.sh`;
- update the golden trace release scope manifest;
- keep all replay paths local and CI-safe.

Not included:

- production order submission;
- production order mutation, cancel, replace, amend, retry, or correction;
- execution adapter calls;
- production network access;
- listenKey lifecycle;
- Dashboard order controls;
- real funds or real orders;
- auto-remediation.

## Acceptance

- Golden trace schema validation passes for the new trace file.
- The `nautilus-cli` harness replays all seven scenarios and matches expected
  events.
- Release scope manifest includes all new cases as executable replay.
- Traces record `production_orders_submitted=0`,
  `production_order_mutations_attempted=0`,
  `execution_adapter_called=false`, `order_endpoint_access_attempted=false`,
  `network_attempted=false`, `real_orders_submitted=false`, and
  `dashboard_order_controls_enabled=false`.
- `git diff --check` passes.
