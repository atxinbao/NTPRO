## Goal

Define the v0.30.0 Backend Production Go-Live Candidate boundary before any
candidate evidence is accepted.

Plain Chinese summary: 本任务定义 v0.30.0 的 backend go-live candidate 边界合同。
它只允许收集后续 go/no-go 审查需要的候选证据，不声明 backend_go_live=true，不开放默认
production execution，不开放 submit、订单 mutation、adapter send、live exchange
request、automatic remediation 或 Dashboard/Admin/Trader Terminal 交易控件。

## Dependency

- Depends on `V300-000` intake gate and its `start_gate_status = satisfied`
  proof.
- Hard-blocked by published v0.29.1 release evidence and closed v0.29.1
  milestone.
- Does not inherit submit, mutation, adapter-send, live-exchange, remediation,
  Dashboard/Admin/Trader Terminal trading-control, backend go-live, or
  product-grade terminal capability from v0.29.0 or v0.29.1.

## Scope

Included:

- Define backend production readiness, backend go-live candidate, and actual
  backend production go-live as separate terms.
- Define allowed candidate artifact classes and require them to be
  evidence-only with no runtime effects.
- Require owner/operator approval, freeze criteria, rollback readiness, audit
  retention, telemetry SLO gate, risk gate, release gate, and scoped
  enablement issue before any later enablement.
- Add a validator that rejects ambiguous `backend_go_live=true` claims and
  forbidden boundary flags.
- Add a release stage for the validator.

Not included:

- default production submit;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal operation controls or trading controls;
- actual backend production go-live;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- `backend_go_live=true` and equivalent ambiguous claims fail closed.
- Candidate language cannot be interpreted as product-grade live trading or
  default production execution.
- Every allowed candidate artifact remains evidence-only and requires a later
  scoped issue and go/no-go decision.
- Every forbidden boundary flag set to `true` or missing fails closed.
