## Goal

Implement executable replay coverage for multi-node orchestration and
control-plane gating under the v0.23.0 isolation contract.

Plain Chinese summary: 本任务把多账户、多策略、多 venue node 的 orchestration/control-plane
边界落到 Rust 可执行 replay。新增 fixture 证明 owner approval、risk gate、audit gate
必须按 `isolation_scope_key` 单 scope 消费；跨 account/strategy/venue node 的 routing
mismatch 会 fail closed；一个 approval 被两个 scope 共享会 fail closed；缺失
`isolation_scope_key` 也会 fail closed。本任务不新增真实 submit/cancel/replace/amend/
flatten 控件，不启用自动 cancel 或自动 remediation。

## Scope

Included:

- add V230 orchestration control-plane golden trace fixtures;
- add executable Rust projection replay for scoped orchestration intents;
- validate `account_key`, `strategy_key`, `venue_node_key`,
  `isolation_scope_key`, `approval_reference_id`, and
  `approval_consumption_scope_key`;
- prove approval consumption remains single-scope only;
- fail closed on cross-scope route mismatch;
- fail closed on shared approval consumption;
- fail closed on missing isolation scope identity;
- prove production submit, mutation-style controls, automatic remediation,
  Dashboard operation controls, and implicit cross-boundary operations remain
  disabled.

Not included:

- production submit/cancel/retry/replace/amend/flatten;
- automatic cancel or automatic remediation;
- Dashboard observability implementation;
- release publication changes.
