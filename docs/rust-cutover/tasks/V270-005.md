## Goal

Define long-run telemetry ingestion and SLO runtime evidence so Admin
Workbench and Dashboard can inspect telemetry health, freshness, gaps,
redaction, rollup status, and degradation reasons without triggering
automatic remediation, retry scheduling, adapter sends, live exchange access,
or trading controls.

Plain Chinese summary: 本任务定义 v27 long-run telemetry ingestion / SLO runtime
evidence。它只记录遥测来源合同、freshness、redaction、sampling window、gap、
SLO rollup、release/source drift，以及 Admin Workbench / Dashboard 的只读降级原因；
不会自动恢复、自动重试、发送 adapter、访问 live exchange、下单、改单或打开任何交易控件。

## Scope

Included:

- Define telemetry ingestion source contract, source freshness, source
  redaction, sampling window, gap, and SLO rollup semantics.
- Validate healthy, degraded gap, stale source, missing source, redaction
  breach, release/source drift, and forbidden operation boundary cases.
- Surface degradation reasons for Admin Workbench and Dashboard read models.
- Add golden trace rows and a release verifier that recomputes status from the
  trace.
- Register the trace rows in release replay scope as validator executable
  replay.

Not included:

- Production telemetry transport, long-running soak test infrastructure, or
  external observability backend ingestion.
- Automatic remediation, restart, retry scheduler, rollback, deploy, scaling,
  adapter send, live exchange request, or trading action.
- Dashboard/Admin operation controls or trading controls.

## Acceptance Criteria

- Telemetry/SLO validators cover healthy, degraded, stale, missing, drift,
  redaction breach, and forbidden-boundary cases.
- Missing telemetry source contract fails closed.
- Stale source and gap windows degrade read-only surfaces with explicit reasons.
- Release/source drift and redaction breach fail closed.
- Required-false operation boundary fields are explicit and missing/true values
  fail closed.
- No telemetry event can trigger automatic remediation, retry scheduler,
  adapter send, live exchange request, submit/mutation, or trading control.
- `scripts/ai/verify_release.sh v27-long-run-telemetry-slo-runtime-evidence`
  passes.
- `docs/rust-cutover/golden_trace/RELEASE_REPLAY_SCOPE.json` records the
  V270-005 cases as validator executable replay.
