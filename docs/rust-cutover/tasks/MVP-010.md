## 目标

完成 M3 最后一个产品缺口：让已建立 `operations_operator` 会话的控制中心用户，通过
版本化、可审计、fail-closed 的产品合同启动或停止单 Supervisor 管理的唯一 sandbox
节点。

## 产品合同

- 运维投影升级为 `ntpro.mvp_control_center_snapshot.v2`，只投影 `start` 和 `stop`；
- `stopped` 只允许 start，`running` 或 `paused` 只允许 stop，其他状态全部禁用；
- 版本化 POST 路由为
  `/api/mvp/v1/control-center/nodes/{node_id}/actions/{start|stop}`；
- 路由复用既有 Supervisor registry/store，不从浏览器直接修改运行时；
- 所有 Dashboard 生命周期入口共享同一串行锁；版本化 action 必须在锁内重新验证恰好一个
  sandbox 节点，且外部网络、外部 Venue 和真实订单边界均为 false；
- Supervisor 必须在 registry 文件锁内拒绝重复 stop marker，防止独立 store 入口重复成功；
- 响应使用 `ntpro.mvp_control_center_lifecycle_action.response.v1`，绑定 action、node、
  前后状态、时间、脱敏消息、错误码和 observability ref；
- 浏览器二次确认后执行，严格校验响应，再等待共享状态和运维投影重新对齐；
- 动作后对齐不仅要求三个投影彼此一致，还必须等于本次 start/stop 的目标生命周期；
- 缺失会话、机构角色、错误节点、错误状态、未知动作和非 POST 方法全部 fail closed。

## 非目标

- pause、resume、restart、数据/执行重连、重试或自动补救；
- 下单、撤单、改单、flatten、adapter send、外部 Venue 或真实资金；
- 生产 IAM、多节点或跨主机编排；
- 修改 v0.32.0 冻结文件；
- 在本 PR 中关闭 M3。
