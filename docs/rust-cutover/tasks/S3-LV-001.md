# S3-LV-001 - Live Venue、账户凭证与独立准入合同

Date: 2026-08-11

Owner role: Rust Product Surface Agent

Status: REVIEW_APPROVED

## 目标

为当前不可变 StrategyVersion 建立首个 Live 独立准入产品合同，让策略工作台用户看到真实
Binance Spot Venue 目标、账户绑定、凭证存在性、订单生命周期边界和全部阻断原因。

## 范围

- 新增 `GET /api/product/v1/strategies/{strategy_id}/versions/{version_id}/live-admission`；
- 配置生产 HTTP/WebSocket endpoint、市场数据与执行适配器引用、账户引用和凭证环境变量引用；
- 只检查凭证是否存在，不返回、记录或散列任何凭证值；
- 显式建模 submit、cancel、replace、fill reconciliation 和人工停机边界；
- OpenAPI、生成 TypeScript/Zod SDK、严格客户端、React Live 页面和真实浏览器验收；
- identity、endpoint、credential ref、权限 true、未知字段与方法漂移全部 fail closed。

## 非目标

- 不连接生产 Venue，不读取真实账户；
- 不创建、启动或停止 Live Run；
- 不提交、撤销、修改、替换真实订单，不处理真实成交；
- 不开放自动重试、自动补救、自动恢复或交易控件；
- 不修改任何 `docs/rust-cutover/release/v0_32_0_*` 文件。

## 完成条件

本任务为 high risk。必须通过 Rust、OpenAPI、前端、浏览器、冻结基线和治理验证，取得独立
Gatekeeper 的 `REVIEW_APPROVED`，通过 hosted checks 后手动合并；禁止 auto-merge。

冻结源受控触达范围：`crates/cli/src/dashboard/server.rs`、
`configs/nodes/btc-ema-shadow.toml`。两个文件必须登记最终 SHA-256，MVP 的 19 项禁止能力保持
不变。

`REVIEW_APPROVED`。当前等待 hosted checks 与手动合并。S3 milestone 保持开放，本任务不得
被解释为生产连接、真实交易或 S3 退出条件已经完成。
