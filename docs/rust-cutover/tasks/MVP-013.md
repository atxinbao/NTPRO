## 目标

完成 M4 最终验收，在同一候选提交上证明干净确定性闭环、单节点故障矩阵、双门户

单 sandbox 节点 MVP 冻结基线。

## 冻结合同

- `docs/product/mvp_freeze_manifest.json` 是 MVP 范围、拓扑、产品入口、验收入口、精确
  task/issue/PR 集合、关闭边界和冻结源 hash 的机器权威；
- `scripts/ai/check_mvp_freeze_baseline.sh` 对 exact 清单对象、13 个源文件、路线图、项目页
  和发布/回滚说明做 fail-closed 校验，并以 7 个不可跳过负向用例拒绝边界替换、提前
  完成 M4、source hash 漂移、缺失或非法 hash 类型；
- hosted smoke 必须在同一 final head 生成 deterministic、fault、institution browser、
  control browser 和 final summary 五类 artifact；
- backend performance 必须执行六组 same-runner 对比；
- 本任务合并即冻结 M4，不创建 tag/GitHub Release，不改变 v0.32.0/v0.33.0 发布事实。
