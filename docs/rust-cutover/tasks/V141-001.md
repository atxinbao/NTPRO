# V141-001 - Record owner-run order-state read-only evidence

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Add a v0.14.1 evidence validator for owner-run production order-state
read-only proof artifacts.

Plain Chinese summary: 这个任务不是新增实盘下单能力，而是把“owner 手动跑过生产订单状态只读
GET 后，证据包应该怎么验收”固定下来。默认脚本不联网、不需要真实账户；只有 owner 提供
证据目录时，才校验真实 owner-run artifact。

## Scope

Included:

- add `scripts/ai/verify_v141_order_state_owner_evidence.sh`;
- validate v0.14 order-state proof JSON artifacts for `GET /api/v3/openOrders`;
- allow optional `GET /api/v3/order` evidence when owner provides a known order
  identifier;
- require redaction markers for API key, secret, signature, signed query, and
  signed URL;
- require no production order submission, mutation, cancel/replace/amend,
  listenKey lifecycle, Dashboard order controls, automatic remediation, real
  orders, or production trading;
- write a redacted v0.14.1 evidence manifest.

Not included:

- production order submission;
- production cancel / replace / amend / retry / correction;
- listenKey lifecycle;
- signed WebSocket user stream runtime;
- Dashboard order controls or credential input;
- automatic remediation;
- real funds or production trading;
- changing Binance adapter, risk engine, execution engine, or order lifecycle
  semantics.

## Acceptance

- Default script run passes without credentials and writes
  `status=offline_fixture_contract_ok`.
- Owner evidence mode requires an artifact for `open_orders`.
- Successful owner-run artifacts may mark `values_are_exchange_truth=true`.
- Classified owner-run failures must keep `values_are_exchange_truth=false`.
- Artifacts must not persist API key, API secret, signature, signed query,
  signed URL, raw order list, or raw order response.
- No mutation/trading/dashboard-control markers may be true.
- Targeted script validation and diff hygiene pass.
