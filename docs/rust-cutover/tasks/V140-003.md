# V140-003 Live Alpha Dry-Run Order Gate

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Add an owner-gated live-alpha dry-run order gate artifact while keeping
production order submission and mutation disabled.

Plain Chinese summary: 这个任务只证明“实盘 Alpha 下单前的 dry-run gate”可以在本地
写出证据。它不是实盘下单、不是撤单、不是改单，也不会打开生产网络或调用 execution
adapter。

## Scope

Included:

- add `live production-live-alpha-dry-run-order-gate`;
- default path writes `blocked_missing_gate`;
- owner-gated dry-run path writes `ready_dry_run_no_submission`;
- record order intent fields as decimal strings;
- record explicit no-submission, no-mutation, no-listenKey, no-Dashboard-order
  controls, no-real-funds fields;
- add `scripts/ai/verify_v14_live_alpha_dry_run_order_gate.sh`;
- add targeted CLI parser and live artifact tests.

Not included:

- production order submission;
- production order mutation, cancel, replace, amend, retry, or correction;
- execution adapter submit/cancel/replace/amend calls;
- production network access;
- listenKey lifecycle;
- Dashboard order controls;
- real funds or real orders.

## Acceptance

- Default path is fail-closed and records `status=blocked_missing_gate`.
- Owner-gated dry-run path records `status=ready_dry_run_no_submission`.
- Artifact records `production_orders_submitted=0`,
  `production_order_mutations_attempted=0`,
  `execution_adapter_called=false`, `order_endpoint_access_attempted=false`,
  `network_attempted=false`, and `dashboard_order_controls_enabled=false`.
- Quantity and notional are preserved as decimal strings.
- Targeted tests, local verification script, formatter, and diff hygiene pass.
