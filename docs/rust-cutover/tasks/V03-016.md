Milestone: v0.3.0 Local Supervisor Control Console
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Control & Scope Agent
Risk: high

## Goal

Add the final v0.3.0 control-console release gate and readiness report.

Plain language: before publishing v0.3.0, prove that the local Supervisor
console can do the required controls and still does not claim production
trading.

## Dependencies

- `V03-015`

## Scope

- Add `scripts/ai/v03_supervisor_control_smoke.sh` if it does not already
  exist.
- Add the control smoke to `scripts/ai/verify_release.sh`.
- Produce the final v0.3.0 readiness report.
- Strictly report PASS or FAIL.
- Record that tag creation and GitHub Release publication still require
  explicit owner approval.

## Non-goals

- Do not create a release tag.
- Do not publish a GitHub Release.
- Do not declare production real-exchange readiness.
- Do not declare manual trading readiness.
- Do not bypass failing checks.

The readiness report must cite all V03-011 through V03-015 evidence. It may
declare PASS only if the control smoke and release gate pass.

## Verification criteria

- `scripts/ai/v03_supervisor_control_smoke.sh` passes.
- `scripts/ai/verify_release.sh` includes and runs the control smoke.
