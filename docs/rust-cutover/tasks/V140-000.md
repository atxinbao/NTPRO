# V140-000 - Production order-state read-only boundary

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Define the v0.14 production order-state read-only boundary before any code
tries to query production order state.

Plain Chinese summary: 这个任务只定边界。它说明 v0.14 以后最多可以 owner 手动开
gate，用生产 `GET` 只读查订单状态；但仍不允许生产下单、撤单、改单、重试、纠错、
listenKey、Dashboard 下单控件或实盘交易。

## Scope

Included:

- create `docs/rust-cutover/release/v0_14_0_order_state_readonly_boundary.md`;
- define the allowed production `GET` endpoint allowlist;
- define forbidden mutation, listenKey, Dashboard, and trading surfaces;
- define default offline/fail-closed artifact fields;
- add this task and evidence record.

Not included:

- implementing production order-state network calls;
- adding CLI commands for production order-state reads;
- adding Dashboard order-state panels;
- production order submission;
- production order mutation, cancel, replace, amend, retry, or correction;
- listenKey lifecycle or signed WebSocket user stream runtime;
- real funds or production trading.

## Acceptance

- Boundary document lists allowed `GET /api/v3/openOrders` and
  `GET /api/v3/order` only.
- Boundary document explicitly forbids `POST`, `PUT`, `PATCH`, and `DELETE`
  order endpoints.
- Boundary document includes no-production-mutation fields.
- Default posture remains offline/fail-closed.
- Evidence records grep and diff hygiene validation.
