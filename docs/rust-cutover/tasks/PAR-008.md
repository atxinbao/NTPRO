# PAR-008 Live CLI Ownership Boundary Split

Date: 2026-07-29
Executor: Codex
GitHub issue: #1176
Risk: high
Classification: separately-scoped-runtime-maintenance
Status: REVIEW_REQUIRED

## Goal

Split the oversized `crates/cli/src/live.rs` along existing ownership
boundaries without changing CLI commands, serialization, emitted artifacts, or
runtime behavior.

中文摘要：本任务把 live/sandbox 节点生命周期迁入独立 `node_runtime` 模块，并把
原内联测试迁入独立测试模块。CLI 分派、配置结构、历史工件、只读生产探针和冻结后
能力边界均保持不变。

## Scope

- move node start/stop orchestration, heartbeat, status, metrics, and shutdown
  handling into `crates/cli/src/live/node_runtime.rs`;
- move the inline live CLI test module into
  `crates/cli/src/live/tests.rs`;
- keep the top-level command dispatcher in `live/command.rs`;
- extend the retired mutation executor source guard across every production
  live module;
- add a structural regression for the new module boundaries;
- rebase the path-scoped runtime risk inventory after test ownership moves.

## Non-Goals

- no CLI option, command, help text, parser, schema, or output change;
- no trading-semantic, network, credential, signing, retry, or remediation
  change;
- no submit, cancel, mutation, adapter-send, live-exchange, or trading-control
  capability authorization;
- no edit to frozen `docs/rust-cutover/release/v0_32_0_*` files;
- no `dashboard.rs` split; PAR-009 owns that work.

## Behavior Contract

1. The full `nautilus-cli` library test set keeps the same command and artifact
   behavior.
2. Existing CLI help and parser tests pass without updating expected text or
   options.
3. Existing live/sandbox runtime tests emit the same status, metrics, summary,
   event, and shutdown contracts.
4. The production mutation executor absence guard scans all production live
   source modules after the split.
5. `live.rs` is materially smaller while the moved code remains inside explicit
   Rust modules.

## Acceptance

- `live.rs` line count decreases materially from the 36,780-line baseline;
- module ownership regression, complete CLI tests, both precision modes, and
  Clippy pass;
- CLI help/parser/runtime tests and golden replay pass without contract edits;
- runtime risk inventory, current governance, backend freeze, and fast
  verification pass;
- no frozen v0.32.0 file changes;
- independent review and all hosted checks approve the high-risk change.
