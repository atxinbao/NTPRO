# V091-008 Surface Artifact Errors In Supervisor And Dashboard

Date: 2026-06-18
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V091-007

## Goal

Make Supervisor and Dashboard show degraded health when Strategy Session
artifacts are missing, corrupt, or internally inconsistent.

## Scope

- Validate manifest and child artifacts in read-only status paths.
- Report degraded health instead of silently returning unknown values.
- Keep Dashboard read-only and do not add order controls.

## Acceptance

- Missing/corrupt manifest produces degraded status.
- Conflicting node/session/market state produces owner-visible degraded health.
- Dashboard remains read-only.
