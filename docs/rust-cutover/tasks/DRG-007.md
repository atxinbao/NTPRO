# DRG-007 - Live adapter cancellation proof closure

Milestone: v0.2 Design Readiness
Priority: P0
Owner role: Adapter & Integration Agent
Review role: Verification & Release Gatekeeper
Risk: high

## Goal

Close the live startup cancellation gate with mock or fixture evidence that
adapter connection futures clean up safely.

## Scope

- Build on `NAUDIT-006` evidence.
- Verify pending connect futures are cancelled on stop or shutdown.
- Prove resources are released and no half-connected state remains.
- Record which real adapters still need follow-up proof.

## Non-goals

- Do not connect to real exchanges.
- Do not implement dashboard UI or control API.
- Do not change adapter trading behavior without fixture evidence.

## Required evidence

```bash
cargo test -p nautilus-live
cargo check -p nautilus-live
scripts/ai/verify_fast.sh
```

## Acceptance

- `G6 Live cancellation proof` is `PASS`.
- Cancellation behavior has executable mock or fixture evidence.
- High-risk work stops at `REVIEW_REQUIRED`.
