## 目标

让普通用户使用同一不可变 StrategyVersion，只通过 production 页面完成 Demo 创建、启动、
运行观察、停止、结果冻结和 Backtest/Demo 比较，并在刷新或服务重启后安全读取终态结果。

## 范围

- 分别验证策略身份、节点状态和 Demo Run 列表，任何来源失败均 fail closed；
- Demo 创建、启动和停止由用户显式发起，失败时不自动重试；
- 修复并发 Supervisor 状态刷新导致 Demo ownership claim 早于来源基线的时间竞态；
- 使用真实 Supervisor、Sandbox node、Product API 和 production frontend bundle 验证生命周期；
- 验证停止后的页面刷新、直接 URL 和同一 workspace 服务重启读取；
- 验证终态 Demo 不会因服务重启自动启动，冻结结果哈希保持不变；
- 更新 Usable Product v1 Roadmap 和项目说明页状态。

## 非目标

- 不开放真实 Venue 订单 mutation、自动连续下单、改单或自动重试；
- 不把 Demo 的许可、凭证、状态或结果自动继承到 Live；
- 不建设多节点集群、远程调度或机构租户能力；
- 不修改 Product API schema、HTTP 路由或 Demo 工件格式；
- 不修改 v0.32.0 后端冻结发布文件。
