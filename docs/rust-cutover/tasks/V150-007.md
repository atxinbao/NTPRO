# V150-007 - Incident rollback artifact

Date: 2026-06-22
Executor: Codex
Milestone: v0.15.0
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Define local incident, rollback, and emergency-stop artifact contracts for the
v0.15 production live-alpha mutation dry-run line. These artifacts are manual
evidence only. They must not execute production cancel, correction, retry,
automatic remediation, real exchange mutation, network access, or production
adapter calls.

Plain Chinese summary: 这个任务不是做自动回滚，也不是做自动撤单。它只是定义三份
人工证据文件：事故计划、回滚计划、紧急停止计划。文件里可以写“人应该怎么处理”，
但不能让系统自动去交易所撤单、改单、重试、纠错或做任何真实 mutation。

## Scope

Allowed:

- Define `incident_plan.json` contract.
- Define `rollback_plan.json` contract.
- Define `emergency_stop.json` contract.
- Add a local verifier that accepts safe manual artifacts.
- Add negative validation that rejects forbidden automatic or production
  mutation fields.

Out of scope:

- Automatic rollback execution.
- Automatic cancel, replace, amend, retry, correction, or remediation.
- Production order submission.
- Production order mutation.
- Production HTTP request execution.
- Production adapter calls.
- listenKey lifecycle.
- Real funds.
- Production trading.
- Dashboard order controls.

## Acceptance

- The release contract documents the three artifact schemas.
- The verifier writes and validates safe sample artifacts.
- The verifier rejects:
  - `automatic_remediation_allowed=true`
  - production cancel/correction/retry allowed or attempted
  - real exchange mutation allowed or attempted
  - nonzero production order submission/mutation counters
  - `network_attempted=true`
  - `execution_adapter_called=true`
  - nested `executes_automatically=true`
- All valid artifacts record:
  - `manual_evidence_only=true`
  - `manual_operator_required=true`
  - `production_orders_submitted=0`
  - `production_order_mutations_attempted=0`
  - `network_attempted=false`
  - `execution_adapter_called=false`
