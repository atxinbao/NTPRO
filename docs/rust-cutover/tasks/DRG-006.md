# DRG-006 - Product-reachable panic classification and zero gate

Milestone: v0.2 Design Readiness
Priority: P0
Owner role: Rust Core Runtime Agent
Review role: Verification & Release Gatekeeper
Risk: high

## Goal

Classify every `panic!`, `todo!`, and `unimplemented!` under `crates/**`, then
eliminate product-reachable crash paths.

## Scope

- Scan all Rust crates for `panic!`, `todo!`, and `unimplemented!`.
- Classify each hit as:
  - test-only;
  - invariant panic;
  - unreachable by product path;
  - product-reachable.
- Convert product-reachable hits to explicit error, rejection, or unsupported
  status.
- Add focused regression tests for changed paths.

## Non-goals

- Do not change trading semantics beyond crash-to-error behavior.
- Do not remove tests.

## Required evidence

```bash
rg -n "panic!\\(|todo!\\(|unimplemented!\\(" crates
cargo test -p <changed-crate>
scripts/ai/verify_fast.sh
```

## Acceptance

- `G5 Runtime panic zero` is `PASS`.
- No product-reachable panic/todo/unimplemented remains unclassified or
  unresolved.
- High-risk work stops at `REVIEW_REQUIRED`.
