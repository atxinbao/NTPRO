## Goal

Audit the current NTPRO codebase and publish a standalone Chinese HTML report
that distinguishes verified release/runtime facts from static risks and
unverified future capabilities.

中文摘要：以当前 `main` 为基线审计 Rust workspace、运行时边界、依赖供应链、
测试治理和遗留风险。审计中确认的当前版本缺陷必须通过独立 issue/PR 修复；本任务
本身只提交报告和证据，不修改产品代码。

## Scope

- workspace architecture, package ownership, and large-module concentration;
- cache, runtime, API, adapter, storage, and trading-capability boundaries;
- risk inventory, ignored tests, and golden replay scope;
- dependency, workflow, release, Rust-only, and backend-freeze governance;
- current findings, completed remediations, and next-stage hard blockers;
- canonical audit-inventory reconciliation when the audit itself detects
  count-stable line/hash drift;
- desktop and mobile browser verification of the HTML report.

## Non-Goals

- no product code or runtime behavior change in the ACR-001 PR;
- no edit to frozen `docs/rust-cutover/release/v0_32_0_*` files;
- no claim that schema validation equals executable runtime replay;
- no production go-live or live-trading authorization;
- no unscoped repair of trading semantics represented by ignored tests.

## Acceptance

- the report cites the audited commit and measurable repository facts;
- every finding has severity, evidence type, disposition, and next action;
- CRF-001 and BFR-001 remediations are linked and verified;
- current backend closeout and future product capability claims are separated;
- the HTML is self-contained, responsive, printable, and has no external asset
  dependency;
- local governance checks and desktop/mobile browser QA pass.
