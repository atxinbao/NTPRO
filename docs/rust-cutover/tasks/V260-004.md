## Goal

Define the v0.26.0 deployment topology and environment provenance model so
deployment environment, configuration source, node topology, artifact digest,
release tag, and runtime boundary evidence are auditable.

Plain Chinese summary: 本任务定义 deployment topology 和 environment provenance
model。它覆盖 local/dev/staging/prod-like 环境分类、node role、artifact digest、
config source、secret redaction、release tag 和 runtime boundary 证据；这些证据只用于审计，
不代表生产部署自动化、real production trading 或 live trading readiness。

## Dependency

- Depends on `V260-001` product hardening boundary contract.
- Keeps the V260 evidence-only boundary intact.
- Does not deploy production environments.
- Does not add Kubernetes, Terraform, or other real deployment systems.
- Does not prove real-funds production readiness.

## Scope

Included:

- Define environment id, classification, truth source, node role, artifact
  digest, config source, secret redaction, release tag, and runtime boundary.
- Cover local, dev, staging, and prod-like classifications without claiming
  real production trading.
- Add fail-closed golden trace rows for missing digest, unredacted config,
  unknown environment truth, release tag mismatch, and cross-node scope
  mismatch.
- Add a verifier that recomputes deployment provenance status from the trace.
- Register the trace rows in release replay scope as validator executable
  replay.

Not included:

- production deployment automation;
- Kubernetes, Terraform, or any external deployment system;
- real-funds production readiness;
- adapter send or live exchange request;
- Dashboard trading controls.

## Acceptance Criteria

- Environment evidence missing artifact digest, config provenance, release tag,
  runtime boundary, or environment truth source fails closed.
- Secret, raw credential, signed payload, signed URL, or unredacted config must
  fail closed.
- Unknown environment truth fails closed.
- Release tag mismatch fails closed.
- Cross-node scope mismatch fails closed.
- v0.26.0 keeps adapter send and live exchange request disabled.
- `scripts/ai/verify_release.sh v26-deployment-provenance-model` passes.
- `docs/rust-cutover/golden_trace/RELEASE_REPLAY_SCOPE.json` records the
  V260-004 cases as validator executable replay.
