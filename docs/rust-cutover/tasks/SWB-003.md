## 目标

让策略工作台在节点停止、异常退出或运行态快照过期时，仍能读取经过身份、配置与内容哈希
校验的 Strategy 和 StrategyVersion；运行态 Run 与所有交易能力继续 fail closed。

## 范围

- 将静态策略目录校验与运行态 freshness 校验拆开；
- Strategy 与 StrategyVersion 仅引用实际参与校验的 identity/config 来源；
- Run、账户、Live 准入与 mutation 继续使用完整运行态校验；
- 总览将 Run 数据源错误显示为局部降级，不清空已验证策略和版本；
- 覆盖静态可读、运行态阻断、前端降级和真实浏览器回归。

## 非目标

- 不把异常退出但仍报告 `running` 的节点伪装成正常 `stopped`；
- 不修改 S3-LV-011 / Issue #1312；
- 不开放订单提交、改单、自动重试、自动补救或交易控件；
- 不修改 v0.32.0 冻结发布文件。
