## Goal

Add the v0.25.0 SLO freshness and fail-closed diagnostics gate for monitoring,
alert, incident, runbook/audit, and DR preview evidence.

Plain Chinese summary: 本任务给 v25 monitoring/incident/DR 只读证据增加 SLO、
freshness、staleness、source truth、release provenance 和 no-action 诊断门禁。超过
freshness threshold、缺组件、partial projection、unknown adapter truth、release
provenance drift 或任何 remediation/trading action flag 都不能显示 healthy，也不能触发
submit/cancel/retry/replace/amend/flatten/order-ticket 或自动恢复动作。

## Dependencies

- Depends on V250-001 through V250-006.
- Hard-blocked by v0.24.1 issue closeout and release evidence through
  `scripts/ai/verify_release.sh v25-intake-gate`.

## Scope

Included:

- Add Dashboard runtime fields for SLO/freshness diagnostics gate status.
- Require v25 components to expose freshness thresholds, SLO evidence,
  diagnostic severity, artifact-only source truth, matched release provenance,
  and explicit no-remediation/no-trading action flags.
- Fail closed or degrade for missing component, stale source, partial
  projection, unknown adapter truth, release provenance drift, and forbidden
  remediation/trading action flags.
- Add golden trace and release verifier coverage for positive and negative
  diagnostics gate cases.

Not included:

- Production alert paging or external notification delivery.
- Automated remediation, retry scheduler, scaling, restoration, or recovery.
- Submit, cancel, retry, replace, amend, flatten, order-ticket, adapter send,
  live exchange request, or trading strategy changes.

## Acceptance Criteria

- Exceeding freshness thresholds cannot render healthy.
- Unknown source/adapter truth degrades or fails closed and cannot claim
  exchange truth.
- Missing components, partial projections, and release provenance drift are
  visible in Dashboard diagnostics.
- Diagnostics evidence cannot enable remediation or trading action flags.
- `scripts/ai/verify_release.sh v25-slo-freshness-diagnostics-gate` passes.
