# V160-010 - Add failure-mode and no-retry semantics

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.0 minimum owner-approved production order mutation candidate
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Codify v0.16 failure behavior for the minimum production mutation candidate:
write redacted evidence and stop. No automatic retry, cancel, replace, amend,
correction, flatten, Dashboard order control, listenKey lifecycle, or strategy
continuation is allowed after failure evidence.

Plain Chinese summary: 这个任务不是修复失败，也不是自动补单。大白话：如果遇到超时、
4xx/5xx、响应格式异常、读回不一致、kill switch 状态变化，只能写证据并停住，不能
自动重试、撤单、改单、补救、继续跑策略。

## Scope

Included:

- add `live production-mutation-failure-semantics`;
- write `ntpro.v160_production_mutation_failure_semantics.v1` artifact;
- accept a ready V160-009 audit trail as input;
- classify these failure modes:
  - `timeout`;
  - `http-4xx`;
  - `http-5xx`;
  - `malformed-response`;
  - `readback-mismatch`;
  - `kill-switch-transition`;
- record `terminal_action=write_evidence_and_stop`;
- record no-retry and no-remediation counters as false/zero;
- keep Dashboard order controls and listenKey lifecycle disabled.

Not included:

- retry implementation;
- cancel, replace, amend, correction, flatten, or auto-remediation;
- Dashboard order controls;
- listenKey/WebSocket lifecycle;
- strategy continuation after failure;
- new production send behavior;
- trading engine semantic changes.

## Acceptance Criteria

- Missing owner confirmations produce `blocked_missing_gate`.
- Ready audit trail input plus confirmations produce
  `ready_failure_semantics_evidence`.
- Every supported failure mode records:
  - `terminal_action=write_evidence_and_stop`;
  - `evidence_written=true`;
  - `stop_after_evidence=true`;
  - `strategy_continuation_allowed=false`;
  - `retry_allowed=false`;
  - `retry_attempted=false`;
  - `retry_attempts=0`;
  - `max_retry_attempts=0`;
  - `cancel_attempted=false`;
  - `replace_attempted=false`;
  - `amend_attempted=false`;
  - `correction_attempted=false`;
  - `flatten_attempted=false`;
  - `remediation_attempted=false`;
  - `automatic_remediation_allowed=false`;
  - `dashboard_order_controls_enabled=false`;
  - `listen_key_lifecycle_allowed=false`;
  - `production_order_mutations_attempted=0`;
  - `listen_key_lifecycle_attempted=0`.
