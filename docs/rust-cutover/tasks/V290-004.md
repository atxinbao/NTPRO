## Goal

Move identity and permission sources from deterministic runtime closure toward
backend production-readiness evidence.

Plain Chinese summary: 本任务把 identity/permission source 从 v0.28 runtime closure
推进为 v0.29 backend production-readiness evidence。它定义 permission source config、
role mapping、freshness、revocation、provenance、redaction 和 fail-closed 要求，并用
source-controlled sandbox fixture 验证 read/admin permission checks；缺 provenance、
permission stale、role drift 或任何交易权限打开都会 fail closed。本任务不接入真实 IdP/SSO，
不授权 live operation，也不开放 submit/mutation/trading permission。

## Scope

Included:

- Define production-readiness permission source configuration and role mapping.
- Add deterministic validation for read/admin allowed checks.
- Fail closed on missing source provenance, stale permissions, role drift,
  revoked subject access, unredacted identity data, and forbidden trading
  permissions.
- Promote `permission_source_production_readiness` in the v0.29 readiness
  matrix to `production-ready` evidence.

Not included:

- live SSO/OAuth/SAML token verification;
- dynamic external IdP group sync;
- live operation authorization;
- production trading authorization;
- adapter send or live exchange request;
- Dashboard/Admin/Trader Terminal trading controls;
- backend go-live or product-grade terminal readiness claims.
