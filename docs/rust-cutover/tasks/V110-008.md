Status: BACKLOG

## Goal

Expose v0.11 production read-only and shadow evidence in Dashboard as read-only
status fields only.

Plain Chinese summary: 本任务只让 Dashboard 能“看见”v0.11 的 production
read-only/shadow 工件状态。Dashboard 只能显示账户快照、shadow intent、影子组合、
生命周期、reconciliation 和边界计数，不能出现下单、撤单、改单按钮，也不能输入或保存
凭证。

## Scope

- Add a read-only `production_shadow` snapshot section.
- Read local `artifact_root/v0_11` files when present:
  - `account_snapshot_redacted.json`;
  - `shadow_execution_intent.jsonl`;
  - `shadow_portfolio_snapshot.json`;
  - `order_lifecycle_state.jsonl`;
  - `reconciliation_events.jsonl`.
- Render production shadow status, artifact paths, and no-mutation counters in
  Dashboard.
- Add targeted Dashboard tests proving the section is read-only and does not
  expose forbidden keys or order controls.

## Non-Goals

- No production order submission.
- No production cancel, replace, amend, retry, or correction.
- No Dashboard order controls.
- No credential input, API key input, or secret persistence.
- No live exchange connection.
- No adapter behavior change.

## Acceptance

- Dashboard snapshot includes `production_shadow` read-only status entries when
  v0.11 artifacts exist.
- Dashboard renders the new section without action buttons.
- Targeted dashboard test passes.
- `cargo check -p nautilus-cli` passes.
- `scripts/ai/verify_fast.sh` passes.
- `git diff --check` passes.
- Boundary checks confirm no `submit_order`, `cancel_order`, `replace_order`,
  or `amend_order` controls were introduced.
