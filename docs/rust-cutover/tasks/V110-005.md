# V110-005 Define Minimal Shadow Portfolio Snapshot

Date: 2026-06-20
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V110-004

## Goal

Define the minimal v0.11 shadow portfolio snapshot contract for local
read-only/shadow evidence. The snapshot may reference production read-only
account context and local shadow intents, but it must not claim full production
portfolio parity.

Plain Chinese summary: 本任务只定义“影子组合快照”该怎么写证据。它可以记录余额、
仓位、敞口和 PnL 字段的最小形状，但这是本地 shadow 视图，不是真实生产组合账本，
不能说明已经可以实盘交易，也不能触发下单、撤单或改单。

## Scope

- Define the local `shadow_portfolio_snapshot` artifact contract.
- Include balances, positions, exposure, and PnL fields with explicit source
  and confidence metadata.
- Distinguish read-only production account references from local shadow state.
- Require no production order submission, no exchange mutation, and no Dashboard
  order controls.
- Document that unsupported calculations must be marked as unavailable rather
  than invented.

## Non-Goals

- No production trading portfolio consistency claim.
- No production order submission, cancel, replace, amend, retry, or correction.
- No fill reconciliation against live exchange execution.
- No automatic correction order.
- No Dashboard order controls.
- No changes to `crates/portfolio` runtime logic.

## Acceptance

- `docs/rust-cutover/release/v0_11_0_shadow_portfolio_snapshot.md` defines the
  minimal snapshot schema, fields, and boundaries.
- The release contract explicitly contains:
  - `schema_version=ntpro.v110_shadow_portfolio_snapshot.v1`;
  - `snapshot_mode=production_readonly_shadow`;
  - `balances`;
  - `positions`;
  - `exposure`;
  - `pnl`;
  - `production_orders_submitted=0`;
  - `production_order_mutations_attempted=0`;
  - `automatic_correction_orders_submitted=0`;
  - `dashboard_order_controls_enabled=false`;
  - `full_production_portfolio_parity_claimed=false`.
- Documentation states that unavailable PnL/exposure calculations must be
  represented as `status=unavailable` with a reason.
- Evidence records rg checks, `scripts/ai/verify_fast.sh`, and
  `git diff --check`.
