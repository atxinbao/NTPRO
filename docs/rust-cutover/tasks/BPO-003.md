## Goal

Extract two cohesive orchestration boundaries from the largest CLI source
files without changing CLI contracts, artifact schemas, runtime decisions, or
production capability boundaries.

Plain Chinese summary: 本任务只把现有 `live` 命令分派和 dashboard loopback HTTP
传输代码移动到明确的子模块。业务验证、快照投影、控制决策、schema 和交易能力边界
保持原样，不新增功能，也不启用 submit、mutation、adapter send、live request、
retry、remediation 或交易控件。

## Scope

- move top-level `LiveCommand` dispatch to `live/command.rs`;
- move dashboard server startup, route wiring, and HTTP adapters to
  `dashboard/server.rs`;
- retain all implementation functions, artifact construction, projection,
  and fail-closed decisions in the existing owner modules;
- verify CLI help, dashboard HTTP behavior, forbidden controls, and golden
  trace replay without changing expected output.

## Module Ownership

| Module | Owns | Explicitly does not own |
| --- | --- | --- |
| `live/command.rs` | `LiveCommand` enum dispatch | validation, artifacts, runtime behavior, capability decisions |
| `live.rs` | live validation and implementation behavior | top-level enum routing |
| `dashboard/server.rs` | loopback bind, routes, assets, HTTP request/response adaptation | snapshot projection and control policy |
| `dashboard.rs` | snapshot projection, schemas, lifecycle decisions, fail-closed controls, assets | server startup and route wiring |

Dependencies remain one-way from each child orchestration module to its parent
implementation. No new shared abstraction or public export is introduced.
