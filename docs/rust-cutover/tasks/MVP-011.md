## 目标

建立 M4 的第一个固定验收入口，在隔离临时目录中证明相同 Rust 回测输入产生相同结果，
并证明本地单 Supervisor + 单 sandbox 节点可以通过两个角色门户的稳定 API 完成只读状态
消费、operator stop/start 和最终回收。

## 验收合同

- 同一 engine-smoke 配置和 run id 在两个独立输出目录执行两次；
- 两个 `summary.txt` 必须字节一致并登记 sha256；
- MVP workspace 启动前必须不存在，运行时只能注册 `mvp-node-001`；
- 机构角色可以读取共享状态和事件关联，但生命周期动作返回 403；
- operator 完成 `running -> stopped -> running`，GET 动作入口返回 405；
- SIGINT 后最终 registry 和状态合同均为 stopped；
- 真实交易、订单修改、外部 Venue、retry 和 remediation 边界始终为 false；
- hosted smoke 上传无 token/cookie 的结构化 `result.json` 和脱敏日志。

本任务不修改 Rust 运行时或 API，不交付故障注入总矩阵、性能/浏览器总验收、M4 最终
冻结或版本发布，也不授权真实交易、多节点、生产 IAM、外部 Venue、自动重试或补救。
