# UPV1-002 - 真实本地历史数据目录

Date: 2026-08-26

Review role: Verification & Release Gatekeeper
Status: REVIEW_REQUIRED

## 目标

让策略工作台选择经过 Rust 校验的本地 Parquet QuoteTick 数据完成 Backtest，并把完整
数据来源冻结到不可变 Run，结束内置确定性数据作为唯一产品来源的状态。

## 范围

- 通过 workspace 父目录 capability 以 no-follow 方式固定 catalog 根目录，先复制到进程
  私有临时快照，再交给 `ParquetDataCatalog` 解析；
- 复用 `ParquetDataCatalog` 和 `BacktestNode`；执行引擎只接收已经固定在内存中的
  instrument 与 QuoteTick；
- 固定 `<workspace>/catalog` 为产品本地数据目录；
- Product API 返回兼容数据集、品种、Venue、时间范围、记录统计和 SHA-256；
- 策略工作台默认选择已验证的本地数据，也保留明确标识的内置确定性来源；
- 创建 Run 时复制并验证 Run 自有 no-follow catalog 快照；创建和复现时冻结数据引用、内容
  指纹和完整时间范围，BacktestNode 不再持有或重新打开可变化的 catalog 路径；
- Run 创建目录采用事务式 guard；只有已写入明确失败清单或完整成功工件时才保留，其他中途
  失败自动清理不完整目录；
- 缺失、损坏、特殊文件、错品种、错 Venue、错记录数、错时间范围或错指纹均 fail closed。
- 根目录或中间目录在校验期间被替换时，不得跟随替换后的路径或读取 workspace 外数据。

## 非目标

- 不下载或转换第三方市场数据；
- 不建设远程数据湖、数据上传页面或多租户目录；
- 不修改 EMA Cross 交易语义；
- 不开放外部 Venue、Live 订单、自动重试或自动补救；
- 不修改 v0.32.0 冻结发布文件。
