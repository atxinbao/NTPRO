# V091-005 Add Strategy Runtime Counters Snapshot

Date: 2026-06-18
Executor: Codex
Owner role: Rust Core Runtime Agent
Review role: Verification & Release Gatekeeper
Risk level: high
Status: BACKLOG
Depends on: V091-004

## Goal

Prevent heartbeat and status updates from resetting strategy runtime counters.

## Scope

- Add a shared `StrategyRuntimeCounters` snapshot for market events, signals,
  order intents, risk decisions, rejections, and actual submissions.
- Make heartbeat, NodeStatus, NodeMetrics, Supervisor, Dashboard, and summary
  artifacts read from the same counter source.
- Keep `actual_submission_count = 0` for v0.9.1.

## Acceptance

- Heartbeat never regresses signal, intent, risk decision, or rejection counts.
- Summary and live status agree on counters.
- No order submission counter can become non-zero in v0.9.1.
