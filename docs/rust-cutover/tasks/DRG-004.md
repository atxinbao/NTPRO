# DRG-004 - Core crates full targeted tests

Milestone: v0.2 Design Readiness
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Rust Core Runtime Agent
Risk: medium

## Goal

Prove the core Rust runtime modules pass targeted full tests before product
design starts.

## Scope

Run and record full targeted tests for:

- `nautilus-core`
- `nautilus-model`
- `nautilus-data`
- `nautilus-execution`
- `nautilus-risk`
- `nautilus-portfolio`
- `nautilus-backtest`
- `nautilus-live`

## Non-goals

- Do not skip failing tests.
- Do not treat `--lib` only evidence as full package evidence unless explicitly
  scoped and approved.

## Required evidence

```bash
cargo test -p nautilus-core
cargo test -p nautilus-model
cargo test -p nautilus-data
cargo test -p nautilus-execution
cargo test -p nautilus-risk
cargo test -p nautilus-portfolio
cargo test -p nautilus-backtest
cargo test -p nautilus-live
```

## Acceptance

- `G3 Core crate tests` is `PASS`.
- Every package listed above either passes or has a formal release-gate
  exception. Unknown or incomplete is `FAIL`.
