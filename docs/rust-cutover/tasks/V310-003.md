## Goal

Create the risk gate, audit gate, and go/no-go control contract for controlled
backend enablement.

Plain Chinese summary: 本任务定义 risk/audit/go-no-go 控制合同。缺失或陈旧的
risk/audit/go-no-go 输入必须 fail-closed；approved candidate 仍受 v31
non-execution 规则约束，不能单独授权下单或 mutation。

## Scope

- Require risk status, audit readiness, release identity, rollback readiness,
  and operator go/no-go evidence.
- Add deterministic reason codes for blocked, degraded, stale, and approved
  candidate states.
- Ensure go/no-go evidence does not authorize order submit or mutation by
  itself.

## Not Included

- No default production submit capability.
- No production order mutation.
- No adapter send or live exchange request.
- No retry scheduler or automatic remediation.
- No Dashboard/Admin/Trader Terminal trading controls.
- No backend go-live claim.
- No product-grade live trading terminal claim.
