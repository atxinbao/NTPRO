## Goal

Execute a real Binance testnet HTTP read-only connectivity probe only after
explicit opt-in, and write an auditable artifact for both success and failure
paths.

## Scope

- Open only an HTTP read-only testnet connectivity probe after all V070 network
  opt-in gates pass.
- Record `endpoint_class`, `latency_ms`, `status`, `error_code`,
  `network_attempted=true`, and `testnet_connection`.
- Preserve `real_orders_submitted=false`, `order_submission=disabled`,
  `values_recorded=false`, and `secrets_redacted=true`.
- Keep the default local and CI path offline and fail-closed.

## Non-goals

- Do not submit, cancel, replace, or amend orders.
- Do not connect to production Binance endpoints.
- Do not persist or print credential values.
- Do not implement WebSocket proof; that is V070-004.
- Do not make Dashboard start a probe; that is out of scope.
- Do not create a tag or GitHub Release.

## Required Evidence

- `cargo fmt --check`
- `cargo check -p nautilus-cli`
- `cargo test -p nautilus-cli workflow::tests::binance_testnet --lib`
- `scripts/ai/verify_v06_binance_testnet_dry_run.sh`

## Acceptance

- Without explicit opt-in, artifacts keep `network_attempted=false`.
- With explicit opt-in, HTTP probe artifacts set `network_attempted=true` and
  either `testnet_connection=true` or a stable `error_code`.
- Artifacts always keep `real_orders_submitted=false`,
  `order_submission=disabled`, `values_recorded=false`, and
  `secrets_redacted=true`.
- No order API, account trading path, or production endpoint is used.
