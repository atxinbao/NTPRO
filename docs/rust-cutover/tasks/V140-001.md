# V140-001 - Owner-gated production order-state GET proof

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Add owner-gated production order-state `GET` proof packaging while keeping
default local, PR, CI, and release execution offline and no-mutation.

Plain Chinese summary: 这个任务把 v0.14 的“生产订单状态只读 GET 证明”接进 CLI 和
验证脚本。默认运行不联网、不需要真实账户；只有 owner 明确设置 online gate 和只读 API
key/secret 后，才会尝试生产 `GET /api/v3/openOrders` 或 `GET /api/v3/order`。

## Scope

Included:

- add `live production-order-state-read-only-proof`;
- allow only signed production `GET /api/v3/openOrders` and `GET /api/v3/order`
  as order-state read-only endpoints in the central endpoint classifier;
- keep `POST`, `PUT`, `PATCH`, `DELETE`, listenKey, Dashboard order controls,
  and production trading forbidden;
- write redacted JSON proof artifacts;
- add `scripts/ai/verify_v14_order_state_readonly_proof.sh`;
- add targeted CLI/classifier tests and evidence.

Not included:

- production order submission;
- production cancel / replace / amend / retry / correction;
- listenKey lifecycle;
- signed WebSocket user stream runtime;
- Dashboard order controls or credential input;
- automatic remediation;
- real funds or production trading.

## Acceptance

- Default script run passes without production credentials and records
  `network_attempted=false`.
- Manual online path requires explicit v0.14 owner gates and env-only
  read-only credentials.
- Artifact records `production_order_submission_attempted=false` and
  `production_order_mutation_attempted=false`.
- Artifacts do not persist API key, API secret, signature, signed query, signed
  URL, or raw order payloads.
- Targeted tests and diff hygiene pass.
