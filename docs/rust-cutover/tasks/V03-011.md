# V03-011 - v0.3.0 supervisor control release contract

Milestone: v0.3.0 Local Supervisor Control Console
Priority: P0
Owner role: Control & Scope Agent
Review role: Verification & Release Gatekeeper
Risk: high

## Goal

Lock the v0.3.0 release standard before implementation starts.

Plain language: v0.3.0 should be published only if it proves the local
Supervisor console can start, stop, pause, resume, reconnect data, and
reconnect execution in the sandbox boundary.

## Dependencies

- `V03-010`

## Scope

- Record the upgraded v0.3.0 control-console release claim.
- Mark pause/resume/reconnect as v0.3.0 release blockers.
- Keep production trading, real accounts, real orders, and production reconnect
  out of scope.
- Define required smoke evidence and release gate updates.

## Non-goals

- Do not implement CLI commands.
- Do not implement Dashboard API handlers.
- Do not implement runtime control behavior.
- Do not create a release tag.
- Do not publish a GitHub Release.

- `docs/rust-cutover/scope/v0_3_supervisor_control_console.md` (REFERENCE):

- `docs/rust-cutover/tasks/V03-012.md` through `V03-016.md` (REFERENCE):
  follow-up tasks.

## Implementation guidance

Keep this task documentation-only. If the release claim changes again, update
the scope addendum before code tasks begin.

## Verification criteria

- Scope addendum exists and states the v0.3.0 required controls.
- The addendum states that pause/resume/reconnect are not production trading
  controls.
- The addendum states that v0.3.0 release is blocked until V03-011 through
  V03-016 pass.
