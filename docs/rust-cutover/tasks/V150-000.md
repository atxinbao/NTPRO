# V150-000 - Production Mutation Scope Decision

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Define the narrow v0.15 production mutation research scope without allowing
real production order submission or production order mutation.

Plain Chinese summary: 这个任务只定 v0.15 的边界。v0.15 可以研究“生产订单 mutation
请求预览”怎么安全地干跑，但不能真的把请求发给交易所。大白话：可以生成一张
“如果未来要下单，请求长什么样”的脱敏预览单，但现在不下单、不撤单、不改单、不重试、
不纠错、不碰真实资金。

## Scope

Included:

- create `docs/rust-cutover/release/v0_15_0_mutation_scope_decision.md`;
- define v0.15 as Guarded Live Alpha Mutation Scope + Execution Dry-Run
  Harness only;
- limit future dry-run preview research to one venue, one account label, one
  symbol, one order type, tiny notional cap, manual owner approval, and kill
  switch active by default;
- require no autonomous strategy execution;
- require no production order request to be sent;
- preserve no production mutation, no listenKey lifecycle, no real funds, no
  production trading, and no Dashboard order controls.

Not included:

- production order submission;
- production order mutation, cancel, replace, amend, retry, correction, or
  flatten;
- production order-test submission;
- any production HTTP request execution;
- execution adapter calls into production adapters;
- listenKey creation, keepalive, or close lifecycle;
- signed WebSocket user stream runtime;
- automatic production remediation;
- real funds;
- production trading;
- Dashboard order controls or credential input.

## Acceptance

- Scope document states v0.15 is dry-run request preview and mutation-scope
  research only.
- Scope document defines the one venue / one account label / one symbol / one
  order type / tiny notional / manual owner approval / kill switch boundary.
- Scope document records `request_sent=false`, `network_attempted=false`, and
  production mutation counters at zero by default.
- Evidence records positive scope markers and negative capability-claim guard.
- No runtime code or trading semantics are changed.
