## Goal

Define cancel / replace / amend preview evidence for v0.24.0 order control. The
preview produces auditable operation plans for existing orders, but it never
sends cancel, replace, amend, flatten, or adapter requests.

Plain Chinese summary: 本任务只定义 cancel / replace / amend preview 合约。
它要求每个预览都绑定 original order lineage、owner/policy approval、risk gate
和 audit gate；输出只读 no-send evidence，不触发真实撤单、改单、amend 或 flatten。

## Scope

- Define cancel intent, replace intent, and amend intent preview schemas.
- Bind every preview to original order lineage, owner/policy approval
  requirements, risk gate, and audit gate.
- Cover missing order lineage, cross-scope order reference, expired approval,
  and forbidden replace/amend/flatten operations.
- Output read-only preview evidence with an explicit no-send boundary.

## Non-Goals

- Do not send real cancel, replace, or amend requests.
- Do not implement flatten.
- Do not call execution adapters or exchange endpoints.
- Do not mutate production order state.
- Do not add Dashboard live order controls.

## Done Criteria

- Missing lineage and cross-scope order references fail closed.
- Expired approvals fail closed.
- Forbidden replace/amend/flatten requests fail closed.
- Replace and amend field changes are explicitly auditable.
- No runtime trading behavior, network call, adapter call, production order
  mutation, flatten capability, or Dashboard operation control is added.
