# MVP-001 - 单 Supervisor + 单节点可运行产品闭环

Date: 2026-07-31

Review role: Verification & Release Gatekeeper
Status: REVIEW_REQUIRED

## 目标

把现有 Supervisor、`ntpro-node`、策略会话和 Dashboard 串成一个正式的单节点
MVP 启动入口。用户不再需要手工执行注册节点、启动节点和启动 Dashboard 三套命令。

## 范围

- 新增 `nautilus mvp serve`；
- 在一个独立工作区内注册并启动唯一一个本地沙盒节点；
- 复用现有 Dashboard HTTP 服务；
- Ctrl-C、Dashboard 启动失败和正常退出时停止节点；
- 保持节点、策略实例和前端工作空间身份独立；
- 增加 CLI、生命周期和失败清理测试。

## 非目标

- 多节点或跨主机调度；
- 新的交易、订单、适配器或网络能力；
- 完整机构工作台或完整控制中心；
- 修改 `docs/rust-cutover/release/v0_32_0_*`。
