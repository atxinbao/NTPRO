# V130-002 - Long-running shadow session process with heartbeat / stop / stale-data handling

Date: 2026-06-21
Executor: Codex

## Goal

Add a v0.13 guarded-live-alpha preflight shadow session process that can run
locally with heartbeat evidence, owner stop handling, and stale-data detection.

Plain Chinese summary: 这个任务不是开启实盘下单。它只是把 v0.12 的一次性
shadow session artifact 往前推进成一个本地可控的 preflight loop：能持续写
heartbeat，看到 stop-file 会停，发现输入 shadow portfolio 太旧会停。

## Scope

Included:

- `nautilus live production-shadow-preflight-session`;
- local JSONL event output with schema
  `ntpro.v130_shadow_preflight_session_event.v1`;
- bounded heartbeat loop for CI and local operation;
- owner stop-file handling;
- stale shadow portfolio runtime detection;
- explicit no-production-mutation counters on every event.

Not included:

- production order submission;
- production order cancel / replace / amend / retry / correction;
- production order-state reads;
- listenKey lifecycle management;
- production WebSocket user stream runtime;
- Dashboard order controls;
- automatic remediation;
- real funds or production trading.
