# DRG-003 - Full verification gate

Milestone: v0.2 Design Readiness
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Control & Scope
Risk: medium

## Goal

Make the full local verification path green before product design depends on
runtime claims.

## Scope

- Run formatting, workspace check, clippy, `verify_fast`, and `verify_full`.
- Remove timeout or skipped-required-step ambiguity.
- Document any slow path, but do not count skipped required checks as passing.

## Non-goals

- Do not weaken verification scripts.
- Do not delete tests to make verification green.

## Required evidence

```bash
cargo fmt --check
cargo check --workspace --features "arrow,ffi,high-precision,streaming,defi"
cargo clippy --workspace --lib --tests --features "arrow,ffi,high-precision,streaming,defi" -- -D warnings
scripts/ai/verify_fast.sh
scripts/ai/verify_full.sh
```

## Acceptance

- `G2 Full verification` is `PASS`.
- Required checks pass without timeout.
- Any optional check is clearly labeled optional and not counted as gate proof.
