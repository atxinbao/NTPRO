# V03-012 - pause/resume node control

Milestone: v0.3.0 Local Supervisor Control Console
Priority: P0
Owner role: Rust Core Runtime Agent
Review role: Verification & Release Gatekeeper
Risk: high

## Goal

Implement local sandbox-only pause and resume control for supervisor-managed
nodes.

Plain language: users should be able to pause a local sandbox node without
killing the process, then resume it back to running.

## Dependencies

- `V03-011`

## Scope

- Add explicit local pause/resume control semantics.
- Expose supervisor CLI commands or equivalent local control path.
- Keep node heartbeat, status, metrics, logs, and stop behavior responsive
  while paused.
- Update node status/metrics so the Dashboard can show paused/resumed state.
- Add regression tests for pause/resume state transitions.

## Non-goals

- Do not use OS-level `SIGSTOP` / `SIGCONT` as the product control.
- Do not pause or resume real exchange connectivity.
- Do not submit, modify, or cancel real orders.
- Do not implement production strategy hot reload.
- Do not create a release tag or GitHub Release.

## Implementation guidance

The control must be application-level and sandbox-only. If the runtime cannot
pause a subsystem yet, expose a deterministic local paused state with a clear
unsupported detail for any subsystem that cannot be paused safely.

## Verification criteria

- `start -> pause -> status paused -> resume -> status running -> stop` passes
  in a local sandbox test.
- Stop still works while a node is paused.
- Status and metrics record pause/resume transitions.
- Real orders remain disabled.
