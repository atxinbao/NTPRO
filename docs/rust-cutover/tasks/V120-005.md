## Goal

Add a local v0.12 persistent shadow strategy session artifact that records
start, heartbeat, artifact-gap, and stop markers from read-only shadow runtime
inputs.

Plain Chinese summary: 这次不是让策略开始真实交易，也不是让 Dashboard 可以下单。它只是
把本地 shadow portfolio runtime 和可选 strategy session 状态整理成
`shadow_strategy_session.jsonl`，让用户能看到一个 shadow 策略会话是否在持续刷新、
有没有缺口、有没有被本地停止。

## Scope

- Add `live production-shadow-strategy-session`.
- Read v0.12 `shadow_portfolio_runtime.json`.
- Optionally read an existing `strategy/session_status.json`.
- Write `v0_12/shadow_strategy_session.jsonl` events.
- Record start, heartbeat, optional artifact-gap, and stop markers.
- Reject shadow portfolio inputs that contain production order submission,
  production mutation, correction order, real order, Dashboard order control, or
  exchange-truth claims.
- Add targeted tests and a release verification script.

## Non-Goals

- No production order submission.
- No production cancel, replace, amend, retry, correction, or listenKey
  lifecycle mutation.
- No production order-state read.
- No real-funds trading.
- No Dashboard order controls.
- No strategy alpha claim.
- No change to existing StrategySession trading semantics.
- No change to `crates/live` node runtime behavior beyond the CLI artifact
  surface.
