## 目标

新增独立机构工作台浏览器入口，使机构业务用户通过
`ntpro.mvp_shared_status_api.v1` 查看单节点 MVP 的策略、账户、交易和风险状态，
不继承运维控制台的节点操作或任何交易控件。

## 接口与路由

```text
GET /institution-workbench
GET /assets/institution-workbench.css
GET /assets/institution-workbench.js
GET /api/mvp/v1/status
```

浏览器数据层只允许最后一个共享 API 请求。上述四个路由仅支持 GET；HEAD、POST、
PUT、PATCH、DELETE、OPTIONS、CONNECT 和 TRACE 均由 Axum 返回 405。
