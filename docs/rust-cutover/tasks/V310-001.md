## Goal

Define the production enablement boundary and explicit scoped approval contract
for v0.31.0.

Plain Chinese summary: 本任务把 v0.31.0 的生产启用边界写成可验证合同。没有
source-controlled scoped approval 必须 fail-closed；任何继承 submit、mutation、
adapter send、live exchange、automatic remediation 或交易控件的尝试也必须
fail-closed。

## Scope

- Define what backend production enablement candidate means and what it does
  not permit.
- Require owner/operator scoped approval before any enablement path can proceed.
- Encode non-inheritance for submit, mutation, adapter send, live exchange,
  automatic remediation, retry scheduler, and trading controls.
- Add deterministic negative cases for inherited execution attempts.

## Not Included

- No default production submit capability.
- No production order mutation.
- No adapter send or live exchange request.
- No retry scheduler or automatic remediation.
- No Dashboard/Admin/Trader Terminal trading controls.
- No backend go-live claim.
- No product-grade live trading terminal claim.
