Milestone: v0.2 Local Multi-Node Runtime Foundation
Priority: P0
Owner role: Control & Scope Agent
Review role: Verification & Release Gatekeeper
Risk: medium

## Goal

Redefine v0.2 as Local Multi-Node Runtime Foundation only after DRG-010 PASS. Update scope docs so old v0.2.0 roadmap exclusions no longer conflict with the new supervisor/node foundation plan.

## Dependencies

- `DRG-010`

## Scope

- Keep v0.2 scoped to Local Multi-Node Runtime Foundation.
- Use sandbox, mock, or fixture evidence by default.
- Preserve DRG-010 boundaries and do not claim release readiness from this task alone.
- Rewrite or supersede the older v0.2 roadmap so it no longer conflicts with the local multi-node runtime foundation scope.
- Record the scope decision before implementation tasks start.

## Non-goals

- Do not start Dashboard UI implementation from this task.
- Do not add production real-exchange connectivity from this task.
- Do not implement manual order entry from this task.
- Do not create release tags or publish GitHub Releases.
- Do not claim v0.2 release readiness unless this is V02-010 and all required evidence passes.
