# V110-004 Define Production Shadow Execution Intent Contract

Date: 2026-06-20
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V110-003

## Goal

Define the v0.11 production shadow execution intent artifact contract. The
contract allows NTPRO to evaluate real production market/account context later,
but the output remains a local shadow intent and must never become an exchange
order in this task.

Plain Chinese summary: 本任务只定义“生产 shadow 执行意图”的本地证据格式。它可以
表达“如果未来要下单，会是什么意图”，但在 v0.11 里必须停在本地 JSON/JSONL，
不能发送到交易所，不能创建订单，不能撤单或改单，也不能给 Dashboard 加下单按钮。

## Scope

- Define the local `shadow_execution_intent` artifact contract.
- Require every shadow intent to record `actual_submission=false`.
- Require aggregate evidence to record `production_orders_submitted=0`.
- Record intended symbol, side, order type, quantity/notional, source signal,
  account context reference, market context reference, and risk context.
- Keep the contract compatible with read-only production account snapshots and
  local shadow portfolio snapshots.

## Non-Goals

- No production order submission.
- No production cancel, replace, amend, retry, or correction orders.
- No execution adapter call.
- No exchange order endpoint access.
- No request signing, signed query, signed URL, or secret persistence.
- No production order lifecycle parity claim.
- No Dashboard order controls.

## Acceptance

- `docs/rust-cutover/release/v0_11_0_shadow_execution_intent.md` defines the
  schema, fields, and boundary.
- The release contract explicitly contains:
  - `schema_version=ntpro.v110_shadow_execution_intent.v1`;
  - `actual_submission=false`;
  - `submission_allowed=false`;
  - `production_orders_submitted=0`;
  - `production_order_mutation_attempted=false`;
  - `order_endpoint_access_attempted=false`;
  - `execution_adapter_called=false`;
  - `dashboard_order_controls_enabled=false`.
- Documentation states that shadow intents are local artifacts, not exchange
  orders.
- Evidence records rg checks, `scripts/ai/verify_fast.sh`, and
  `git diff --check`.
