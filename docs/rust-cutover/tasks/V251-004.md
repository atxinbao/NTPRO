# V251-004 v25 Dashboard source_ref path anchor integrity gate

Date: 2026-07-06
Executor: Codex
GitHub issue: `#809`
Milestone: `v0.25.1`
Status: LOCAL VALIDATION PASSED

## Goal

Harden the v25 Dashboard monitoring surface verifier so component `source_ref`
values must resolve to real repository artifacts and anchors, not merely be
non-empty strings.

Plain Chinese summary: 本任务增强 v25 Dashboard monitoring surface 的
`source_ref` 校验。以前只确认字段非空；现在会解析本地路径、JSONL case anchor、
Markdown heading anchor，并阻断坏路径、坏 anchor、空引用和跨版本引用。它只改
release gate 和证据，不改变 Dashboard 运行时，不新增任何交易操作入口。

## Scope

- Extend `scripts/ai/verify_v25_dashboard_monitoring_surface.sh` to resolve
  monitoring, alert, incident, runbook, and DR preview component `source_ref`
  values.
- Validate repository-relative paths, JSONL case anchors, Markdown anchors, and
  v25 release contract refs.
- Add fail-closed self-tests for bad path, bad JSONL anchor, bad Markdown
  anchor, empty `source_ref`, cross-version ref, and forbidden Dashboard
  trading control.
- Add `scripts/ai/verify_release.sh v25.1-dashboard-source-ref-integrity` as
  the v0.25.1 validation entrypoint.
- Record the post-release hardening in the v25 release manifest and Dashboard
  monitoring surface docs.

## Non-Goals

- No Dashboard runtime behavior change.
- No submit, cancel, retry, replace, amend, flatten, or order-ticket control.
- No live control API, adapter send, live exchange request, or production order
  mutation.
- No product-grade live trading terminal claim.

## Done Criteria

- v25 Dashboard source refs are not accepted solely because they are non-empty.
- Valid JSONL and Markdown anchors resolve to actual source artifacts or v25
  release contracts.
- Malformed, stale, empty, or cross-version source refs fail closed.
- Dashboard remains read-only and exposes no trading controls.
