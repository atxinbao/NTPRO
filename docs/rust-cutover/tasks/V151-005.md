# V151-005 - Deny production order-test request preview

Date: 2026-06-23
Executor: Codex
Milestone: v0.15.1 mutation dry-run semantics / endpoint scope hardening
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Clarify the v0.15.1 production live-alpha mutation preview boundary by denying
`POST /api/v3/order/test` for production request preview. Only
`POST /api/v3/order` remains in the production redacted request-preview scope.

Plain Chinese summary: 生产 live-alpha request preview 暂时只允许预览
`POST /api/v3/order` 的红acted metadata；`POST /api/v3/order/test` 在生产 preview
里先拒绝，避免 release 文案和实际行为混在一起。testnet/sandbox 的 order-test 行为不动。

## Scope

Included:

- classify production `POST /api/v3/order/test` as forbidden, even under owner
  manual scope;
- keep production `POST /api/v3/order` as the only request-preview candidate;
- keep testnet/sandbox signed order-test preview behavior unchanged;
- add CLI/script regression coverage for production order-test denial;
- align v0.15 release-facing scope wording.

Not included:

- production order submission;
- production order-test submission;
- production HTTP request execution;
- production execution adapter calls;
- real funds;
- production trading;
- Dashboard order controls;
- testnet/sandbox behavior changes.

## Acceptance Criteria

- Endpoint classifier denies production `POST /api/v3/order/test` under owner
  manual scope.
- Production live-alpha request preview rejects `/api/v3/order/test`.
- Production live-alpha request preview still allows `/api/v3/order` under all
  existing dry-run gates.
- Testnet/sandbox order-test preview behavior remains unchanged.
- All paths preserve:
  - `request_sent=false`
  - `network_attempted=false`
  - `production_orders_submitted=0`
  - `production_order_mutations_attempted=0`
  - `execution_adapter_called=false`
  - `dashboard_order_controls_enabled=false`
