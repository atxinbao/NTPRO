## Goal

Define monitoring, alerting, and incident readiness for the v0.29 backend
production readiness line.

Plain Chinese summary: 本任务把 monitoring/alert/incident readiness 推进为
v0.29 backend production-readiness evidence。它定义 alert taxonomy、severity、
owner routing、acknowledgement、SLO breach handling、audit requirements 和
manual incident handoff，并用 deterministic readiness replay 验证状态迁移；stale
alert source、missing owner routing、missing acknowledgement semantics、missing
audit requirements、unsafe auto-remediation claim 或 forbidden operation boundary
都会 fail closed。本任务不生成真实生产 incident，不触发自动 remediation 或交易动作。

- Builds on `V250-001`, `V250-002`, and `V250-003` monitoring, alert, and

## Scope

Included:

- Define alert taxonomy, severity, owner routing, acknowledgement semantics,
  SLO breach handling, audit requirements, and escalation handoff.
- Add deterministic readiness validation for alert/incident state transitions.
- Fail closed on stale alert sources, missing owner routing, missing
  acknowledgement semantics, missing audit requirements, unsafe
  auto-remediation claims, and forbidden operation boundaries.

Not included:

- production incident generation;
- external paging or ticket mutation;
- automatic remediation or strategy stop;
- adapter send or live exchange request;
- Dashboard/Admin/Trader Terminal trading controls;
- backend go-live or product-grade terminal readiness claims.
