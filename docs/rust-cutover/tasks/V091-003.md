# V091-003 Persistent StrategySession Lifecycle

Date: 2026-06-18
Executor: Codex
Owner role: Rust Core Runtime Agent
Review role: Verification & Release Gatekeeper
Risk level: high
Status: BACKLOG
Depends on: V091-002

## Goal

Make StrategySession lifecycle semantics persistent while the node is running,
instead of stopping immediately after a bounded fixture batch.

## Scope

- Keep the session in `running` while the node is running.
- Transition to `paused`, `risk_halted`, `stopping`, or `stopped` only because
  of explicit lifecycle input or terminal shutdown.
- Preserve the no-order boundary.

## Acceptance

- `node running -> strategy session running`.
- `node stopped -> strategy session stopped`.
- The session does not enter `stopped` before the node enters shutdown wait.
- No exchange adapter execution is introduced.
