backend-freeze, release-surface, and release-publication authority chain while
preserving positive and deterministic fail-closed coverage.

- add a scoped current-authority no-Python drift guard to hosted smoke;

- deleting historical `verify_v*.sh` release gates;
- removing Python packaging, CI, or security jobs owned by PTC-007;
- changing runtime, trading semantics, public API, or capability boundaries.

## Acceptance

- release publication fake matrix and live v0.32.0 guard pass;
