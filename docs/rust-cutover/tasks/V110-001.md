# V110-001 Centralize Endpoint Classifier Design

Date: 2026-06-19
Executor: Codex
Owner role: Control & Scope Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V110-000

## Goal

Design a central endpoint classifier for sandbox, testnet, production
read-only, production authenticated read-only, WebSocket, and forbidden
production mutation endpoints.

Plain Chinese summary: 本任务只设计 endpoint 分类规则。以后代码看到
`demo-api.binance.com`、`testnet.binance.vision`、`api.binance.com` 或 WebSocket
地址时，必须先分类；生产只读可以被显式 gate 放行，生产写操作必须失败关闭。

## Scope

- Define endpoint classes.
- Define method/path classification.
- Define artifact fields for classifier evidence.
- Define fail-closed defaults.
- Define how v0.10 sandbox proof and v0.11 production read-only are separated.

## Non-Goals

- No Rust implementation.
- No network calls.
- No credentials.
- No production order submit/cancel/replace/amend.
- No Dashboard order controls.

## Acceptance

- Create `docs/rust-cutover/release/v0_11_0_endpoint_classifier.md`.
- Record evidence in `docs/rust-cutover/evidence/V110-001.md`.
- Classify `demo-api.binance.com`, `testnet.binance.vision`,
  `api.binance.com`, and WebSocket endpoints.
- State clearly that production mutation endpoints are forbidden in v0.11.
