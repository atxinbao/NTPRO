# V160-008 - Add kill-switch enforcement around send

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.0 minimum owner-approved production order mutation candidate
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Harden the v0.16 guarded production HTTP send path so it records kill-switch
checks immediately around send consideration and blocks when the kill-switch
runtime gate is not open or the kill switch is active.

Plain Chinese summary: 这个任务不是新增下单能力，而是给已经存在的 guarded-send
通道再加一道“发送前后 kill switch 检查”。大白话：只要 kill switch 是打开状态，
或者 runtime gate 不是 open，就算其它 owner gate 齐全，也不能进入单次发送路径。

## Scope

Included:

- require `--kill-switch-runtime-gate` on `live production-mutation-guarded-send`;
- record pre-send and post-send kill-switch evidence in the guarded-send artifact;
- block guarded send when the kill switch is active or the runtime gate is not
  open;
- keep default/offline behavior at `request_sent=false` and `network_attempted=false`;
- add a V160-008 verifier for the around-send kill-switch contract.

Not included:

- new strategy live-trading behavior;
- retry, cancel, replace, amend, correction, or flatten;
- Dashboard order controls;
- listenKey/WebSocket lifecycle;
- additional venues, accounts, or order types.

## Acceptance Criteria

- Ready offline guarded-send artifact records:
  - `kill_switch_enforcement_ready=true`;
  - `kill_switch_checked_before_send=true`;
  - `kill_switch_checked_after_send=true`;
  - `pre_send_kill_switch_runtime_gate_open=true`;
  - `pre_send_kill_switch_active=false`;
  - `post_send_kill_switch_runtime_gate_open=true`;
  - `post_send_kill_switch_active=false`;
  - `kill_switch_blocked_send=false`;
  - `request_sent=false`;
  - `network_attempted=false`.
- Active kill-switch fixture records:
  - `status=blocked_kill_switch_enforcement`;
  - `kill_switch_enforcement_ready=false`;
  - `kill_switch_blocked_send=true`;
  - `request_sent=false`;
  - `network_attempted=false`.
