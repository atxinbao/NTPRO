## Goal

Move the current release surface from `v0.30.0` to `v0.31.0` and make default
release-surface guards validate the current published v31 surface.

Plain Chinese summary: 本任务把 README、ROADMAP、versioning 和 release surface guard
的默认 current release 从 v0.30.0 切到 `ntpro-rust-only-v0.31.0`。`v0.31.1` 是下一
release governance closeout patch，`v0.32.0` 是后端收尾版本但必须等待 v0.31.1 发布证据。
本任务不开放 backend go-live、submit、mutation、adapter send、live exchange 或交易控件。

## Dependency

- Depends on V311-001 / #1036 source-controlled v0.31.0 closeout evidence.
- Part of the v0.31.1 release governance closeout patch.
- Blocks v0.32.0 backend production closeout until all V311 issues close and
  `ntpro-rust-only-v0.31.1` release evidence is published.

## Scope

Included:

- Update README current source tag, latest formal release, current capability,
  next patch, and next capability wording to v31/v31.1/v32.
- Update ROADMAP current public source release and published capability track
  ordering to make v0.31.0 current.
- Update `docs/versioning.md` current release, active patch, next capability,
  and release tag examples.
- Update `scripts/ai/check_release_surface_current.sh` defaults to
  v0.31.0/v0.31.1/v0.32.0.
- Keep release index wording compatible with the default current-release guard.

Not included:

- GitHub Release body hash reconciliation for v0.31.0, tracked by V311-003.
- backend go-live;
- production submit or production order mutation;
- execution adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal trading controls;
- product-grade live trading claim.
