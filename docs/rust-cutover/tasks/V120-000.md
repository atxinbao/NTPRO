## Goal

Define the `v0.12.0` Production Online Read-Only + Persistent Shadow boundary
before any runtime implementation work starts.

Plain Chinese summary: 这次只先把 v0.12.0 的边界定死。v0.12.0 可以准备进入
生产环境的“在线只读证明”和“持久 shadow 运行”，但不能下生产订单，不能撤单、改单、
重连用户数据流，也不能让 Dashboard 出现生产下单控件。

## Scope

- Add the `v0_12_0_boundary.md` release boundary.
- Allow only explicitly owner-gated `GET` production read-only paths.
- Define public read-only and authenticated account snapshot boundaries.
- Define artifact counters that prove production mutation remains disabled.
- Define the task ladder for V120-001 through V120-009.

## Non-Goals

- No runtime code change.
- No production network request.
- No credential loading or signing implementation.
- No production order submission.
- No production cancel, replace, amend, retry, or correction order.
- No `/api/v3/userDataStream` or listenKey lifecycle mutation.
- No production open-order or order-state reads.
- No Dashboard order, cancel, replace, amend, retry, reconnect, or credential
  input controls.
- No GitHub Release or tag creation.

## Endpoint Boundary

The only production online paths that may be discussed by v0.12 tasks are:

| Method | Path | Purpose | Owner gate required |
| --- | --- | --- | --- |
| `GET` | `/api/v3/time` | Public production server-time proof. | Yes |
| `GET` | `/api/v3/exchangeInfo` | Public production exchange metadata proof. | Yes |
| `GET` | `/api/v3/account` | Authenticated production account snapshot proof. | Yes |

Everything else is denied until a later owner-approved scope decision.

## Forbidden Surfaces

The following are explicitly out of scope for v0.12.0:

- `POST`, `DELETE`, `PATCH`, or `PUT` production Binance requests.
- `/api/v3/order`, `/api/v3/order/test`, `/api/v3/openOrders`,
  `/api/v3/allOrders`, `/api/v3/orderList`, `/api/v3/openOrderList`, and
  `/api/v3/allOrderList`.
- `/api/v3/userDataStream` listenKey creation, keepalive, and close paths.
- margin, futures, transfer, withdrawal, deposit, account settings, or any
  expanded account mutation surface.
- strategy-driven production execution.
- automatic production reconciliation that submits, cancels, replaces, amends,
  retries, or corrects exchange orders.
- raw API key, raw API secret, raw signature, signed URL, signed query string,
  raw account response, or raw balance value persistence.
