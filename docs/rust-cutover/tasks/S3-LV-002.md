# S3-LV-002 - 生产网络连接与认证账户只读接入

Date: 2026-08-11
Executor: Codex
GitHub issue: #1290
Risk: critical
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Status: REVIEW_APPROVED

## 目标

为当前不可变 StrategyVersion 建立用户显式触发的 Binance Spot 生产账户只读检查，让策略
工作台验证生产网络、认证凭证和账户响应形状，同时保持全部真实订单和账户变更能力关闭。

## 范围

- 新增 `POST /api/product/v1/strategies/{strategy_id}/versions/{version_id}/live-account/actions/refresh`；
- 复用现有 Binance `/api/v3/account` 签名只读实现，不新增第二套 HTTP、签名或凭证组件；
- 认证 HTTP 禁止 3xx 重定向，避免 API Key、签名查询或 Referer 离开固定生产 endpoint；
- 仅在源能力、五项运行门禁和两个环境凭证同时满足时执行一次读取；
- 仅机构用户可触发刷新；Operator 继续只能读取共享 GET 产品资源；
- 在阻塞线程执行同步网络读取，不阻塞 Axum async worker；
- 响应只返回状态码、延迟和结构摘要，不返回凭证、签名、查询、URL、资产名、余额或权限值；
- OpenAPI、生成 TypeScript/Zod SDK、严格客户端、React 页面和真实浏览器验收同步更新；
- 缺失门禁、缺失凭证、错误方法、错误 body、身份漂移和响应边界漂移全部 fail closed。
- 页面加载刷新次数必须为 0，用户每次点击只能发起 1 次请求。

## 非目标

- 不在页面加载、定时查询或失败后自动发起生产网络请求；
- 不创建、启动或停止 Live Run；
- 不访问订单 endpoint，不提交、撤销、修改、替换订单；
- 不开放自动重试、自动补救、自动恢复或交易控件；
- 不记录原始账户响应、余额、权限、UID、请求头、签名、签名查询或签名 URL；
- 不修改任何 `docs/rust-cutover/release/v0_32_0_*` 文件。

## 完成条件

本任务为 critical risk。必须通过 Rust、OpenAPI、前端、浏览器、冻结基线和治理验证，取得
独立 Gatekeeper 的 `REVIEW_APPROVED`，通过 hosted checks 后手动合并；禁止 auto-merge。

冻结源受控触达范围：`crates/cli/src/dashboard/server.rs`、
`configs/nodes/btc-ema-shadow.toml`。两个文件必须登记最终 SHA-256，MVP 的 19 项禁止能力保持
不变。

真实下单、Live Run 或 S3 退出条件已经完成。
