# V131-006 - Dashboard preflight readiness panel

Date: 2026-06-22
Executor: Codex

## Goal

Add a read-only Dashboard preflight readiness panel for v0.13.1 Guarded Live
Alpha Preflight hardening.

Plain Chinese summary: 这个任务让 Dashboard 能看到 v0.13 预检相关状态：owner proof
pack、kill switch、bounded shadow preflight、Decimal boundary 和
no-production-mutation gate。它只是状态面板，不增加下单、撤单、改单、订单状态读取、
listenKey 或凭证输入。

## Scope

Included:

- add `preflight_readiness` to the Dashboard snapshot DTO;
- derive v0.13 readiness from existing local Production Shadow and kill-switch
  evidence;
- render a read-only "预检就绪" Dashboard section;
- keep v0.11/v0.12 Production Shadow out of the v0.13.1 readiness claim;
- test the v0.13 kill-switch fixture readiness projection.

Not included:

- production order submission;
- production cancel / replace / amend / retry / correction;
- production order-state reads;
- listenKey lifecycle management;
- signed WebSocket user stream runtime;
- Dashboard order controls or credential entry;
- automatic remediation;
- real funds or production trading.

## Acceptance

- Dashboard snapshot includes stable `preflight_readiness` shape.
- v0.13 kill-switch artifacts produce a read-only readiness row.
- Readiness row exposes owner proof pack, kill switch, bounded shadow
  preflight, Decimal boundary, and no-production-mutation status.
- Dashboard forbidden order-control boundary remains enforced.
- v0.13 no-production-mutation gate passes.
- Diff hygiene passes: `git diff --check`.
