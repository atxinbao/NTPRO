# DRG-005 - Real minimal CLI product paths

Milestone: v0.2 Design Readiness
Priority: P0
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk: high

## Goal

Promote CLI product commands from metadata-only, simulated, or deferred status
to real minimal Rust product paths where v0.2 wants to make product claims.

## Scope

- Implement or explicitly scope:
  - `nautilus backtest run`
  - `nautilus live validate`
  - `nautilus live run`
  - `nautilus data load`
- Keep `config validate`, `data inspect`, `data validate`, and `sandbox run`
  aligned with the CLI capability matrix.
- Remove `not implemented yet` from any command that is claimed as a product
  path.

## Non-goals

- Do not implement dashboard UI.
- Do not connect to real exchanges.
- Do not change trading semantics without golden trace evidence.

## Required evidence

- CLI help output for touched commands.
- Targeted `cargo test -p nautilus-cli`.
- Runtime smoke or explicit product-scope decision for each promoted command.
- `scripts/ai/verify_fast.sh`.

## Acceptance

- `G4 Product CLI paths` is `PASS`.
- No product-claimed CLI command is only a stub or simulated artifact.
- High-risk work stops at `REVIEW_REQUIRED`.
