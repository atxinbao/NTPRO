# S1-BT-003 - Backtest 交易、持仓与收益明细

Date: 2026-08-09
Executor: Codex
GitHub issue: #1274
Risk: high
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Status: REVIEW_APPROVED_HOSTED_PENDING

## 目标

把同一次 `BacktestEngine` 执行产生的 fill、最终持仓和账户余额时间序列写入独立的
不可变 `details.json`，通过严格校验的只读 Product API 提供给策略工作台 Run 详情页。

## 范围

- 从 BacktestEngine cache 投影 fill 级交易、最终持仓和账户余额时间序列；
- 保持 `summary.json` 的 `ntpro.backtest_result.v1` 聚合合同不变；
- 新增 `ntpro.backtest_details.v1`，与 `summary.json` 来自同一次引擎执行；
- Run 配置记录 details 引用与 SHA-256，读取前校验文件类型、containment、哈希和身份；
- 新增 `GET /api/product/v1/runs/{run_id}/report` 及 OpenAPI/TypeScript/Zod 合同；
- 策略工作台 Run 详情展示交易、持仓和收益曲线；
- 增加确定性、篡改、缺失、符号链接、错误方法、角色与浏览器测试。

## 非目标

- 不实现 Run 比较、复现、日志或风险事件明细；
- 不创建 Demo 或 Live Run，不连接外部 Venue，不提交真实订单；
- 不修改 BacktestEngine 撮合、账户、持仓或统计语义；
- 不修改 v0.32.0 发布冻结文件。

## Post-freeze 例外

`crates/cli/src/dashboard/server.rs` 是 MVP frozen source。Issue #1274 登记了独立的
post-freeze 产品扩展：仅新增受既有产品角色保护的只读 report 路由，并更新 freeze
manifest 中该文件的精确 SHA-256。MVP 拓扑、退出条件和禁止能力边界保持不变。

## 完成条件

本任务为 high risk。必须通过本地 Rust、API 合同、前端、浏览器与治理验证，取得独立
Gatekeeper 的 `REVIEW_APPROVED`，通过 hosted checks 后手动合并；禁止 auto-merge。
