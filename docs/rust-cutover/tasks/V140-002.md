# V140-002 Supervisor-Managed Long-Running Shadow Runtime

Date: 2026-06-22
Executor: Codex

## Goal

Upgrade the bounded local shadow preflight evidence into supervisor-managed
runtime evidence for a long-running local shadow node.

## Scope

- Add read-only supervisor status reporting for the shadow runtime surface.
- Preserve the existing `supervisor start/stop/status/metrics` lifecycle.
- Treat graceful external shutdown/SIGTERM with a stopped status artifact as a
  stopped supervisor process instead of stale.
- Add local verification for start, stop, restart, SIGTERM, stale-data halt, and
  no-production-mutation invariants.

## Out Of Scope

- No production order submission.
- No production order mutation, cancel, replace, amend, retry, or correction.
- No listenKey lifecycle.
- No real funds.
- No production trading enablement.
- No Dashboard order controls.
- No auto-remediation.

## Acceptance

- `supervisor shadow-runtime` reports process, strategy, and shadow preflight
  status from local artifacts.
- A supervisor-managed `ntpro-node` shadow config can start, stop, restart, and
  recover a graceful SIGTERM stop.
- Stale shadow portfolio runtime data halts the local shadow preflight flow.
- Verification proves `production_order_mutations_attempted=0`,
  `production_orders_submitted=0`, and
  `dashboard_order_controls_enabled=false`.
