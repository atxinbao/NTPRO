# V270-009 v27 release publication guard version support

Date: 2026-07-08
Executor: Codex
GitHub issue: `#883`
Milestone: `v0.27.0`
Risk: medium
Owner role: Verification & Release Gatekeeper
Review role: Rust Product Surface Agent
Auto-merge: allowed after local validation and hosted checks pass

## Goal

Add explicit `v0.27.0` support to the release publication guard so the formal
`ntpro-rust-only-v0.27.0` tag gate can pass after the V270 issue set and
milestone are closed.

Plain Chinese summary: 本任务修复 v0.27.0 正式 tag-gate 的最后发布治理阻塞。
`release-publication-guard` 之前只支持到 v0.26.1，导致
`NTPRO_RELEASE_GATE=1 scripts/ai/verify_release.sh v27-release-gates` 在所有
v27 子 gate 通过后仍以 `unsupported release publication guard version: v0.27.0`
失败。本任务只补发布校验矩阵和 V270 scope 证据，不新增下单、改单、adapter send、
live exchange request、retry scheduler、automatic remediation、Dashboard/Admin
交易控件或产品级实盘交易终端声明。

## Dependency

- Depends on `V270-008` and issue `#861` being merged.
- Depends on the discovered tag-gate failure from
  `NTPRO_RELEASE_GATE=1 scripts/ai/verify_release.sh v27-release-gates`.
- Must land before the public `ntpro-rust-only-v0.27.0` GitHub Release is
  published.

## Scope

Included:

- Add `v0.27.0` to `scripts/ai/check_github_release_published.sh`.
- Require the v27 release-note markers in the publication guard.
- Add V270-009 to v0.27.0 release notes, readiness, manifest evidence, and
  release gate issue/evidence counts.
- Keep tag-gate mode requiring V270 issue closeout and a closed `v0.27.0`
  milestone.
- Keep publication governance gate-before-publish.

Not included:

- No v0.27.0 tag push in this PR.
- No GitHub Release publication in this PR.
- No runtime behavior change.
- No production order submission or mutation.
- No execution adapter send or live exchange request.
- No retry scheduler.
- No automatic remediation runtime.
- No Dashboard/Admin order, approval, cancel, retry, submit, replace, amend,
  flatten, remediation, order-ticket, or live trading controls.
- No product-grade live trading terminal claim.

## Acceptance Criteria

- `scripts/ai/check_github_release_published.sh` accepts `v0.27.0` and checks
  v27 release body markers.
- V270 release scope is consistently counted as 10 issues/evidence files:
  `V270-000` through `V270-009`.
- `NTPRO_RELEASE_GATE=1 scripts/ai/verify_release.sh v27-release-gates` passes
  when the local release tag points at HEAD and issue `#883` plus the
  `v0.27.0` milestone are closed.
- `NTPRO_RELEASE_GATE=1 scripts/ai/verify_release.sh v27-strict-provenance`
  passes under the same tag/HEAD binding.
