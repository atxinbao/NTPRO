# V06-002 - testnet credential policy

Milestone: v0.6.0 Binance testnet dry-run foundation
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Rust Product Surface Agent
Risk: medium

## Goal

Define the Binance testnet credential policy without storing credential values.

## Scope

- Use environment variable names in config.
- Write credential policy artifacts.
- Record whether env vars are present without recording values.

## Non-goals

- Do not add secrets to config files.
- Do not print API keys.
- Do not require credentials for the dry-run smoke.

## Required evidence

- Credential policy artifact records `values_recorded=false`.
- Evidence file exists at `docs/rust-cutover/evidence/V06-002.md`.
