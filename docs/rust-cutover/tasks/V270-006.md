## Goal

Bridge the v0.27.0 Admin Workbench and Dashboard to product-operations runtime
integration state as a read-only/admin surface. The bridge displays identity,
audit storage, deployment orchestration, telemetry/SLO, and runtime boundary
state without enabling trading, remediation, retry, adapter, live exchange, or
operation controls.

Plain Chinese summary: 本任务新增 v27 Admin Workbench runtime state bridge
只读证据面。它展示 identity/permission、audit storage、deployment orchestration、
telemetry/SLO 和 runtime integration boundary 状态，并对 stale artifact、缺组件、
provenance malformed、redaction breach、runtime drift、forbidden controls 做降级或
fail closed；不会新增下单、改单、adapter send、live exchange request、retry scheduler、
automatic remediation、Dashboard/Admin trading controls 或 product-grade terminal claim。

## Scope

Included:

- Define Admin Workbench / Dashboard read-only runtime state bridge contract.
- Require identity, audit storage, deployment orchestration, telemetry/SLO, and
  runtime boundary components.
- Add artifact ingestion hardening for stale artifacts, missing components,
  malformed provenance, redaction breach, runtime/source drift, and forbidden
  control markers.
- Add golden trace rows and a release verifier for ready, degraded, and
  fail-closed bridge states.
- Register the trace rows in release replay scope as validator executable
  replay.

Not included:

- Real Admin Workbench UI implementation beyond release evidence contract.
- Runtime mutation, operation execution, remediation, retry scheduling, adapter
  sends, live exchange requests, or production trading controls.
- Product-grade live trading terminal readiness claim.

## Acceptance Criteria

- Admin Workbench and Dashboard state show v27 runtime integration evidence
  without operation, remediation, adapter, live exchange, or trading controls.
- Ready, degraded, and fail-closed states are covered by validator replay.
- Bad artifacts fail closed and expose blocking reasons.
- Stale artifacts degrade with explicit reasons.
- Required-false control fields are explicit; missing/true values fail closed.
- `scripts/ai/verify_release.sh v27-admin-workbench-runtime-state-bridge`
  passes.
- `docs/rust-cutover/golden_trace/RELEASE_REPLAY_SCOPE.json` records the
