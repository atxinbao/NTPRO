# V260-009 - v26 release golden-trace file gate correction

Date: 2026-07-07
Executor: Codex
GitHub issue: #837
Milestone: v0.26.0

## Goal

Fix the v0.26.0 hosted release gate failure in `full-golden-traces-files`
without changing runtime behavior.

## Context

The first hosted `ntpro-rust-only-v0.26.0` release gate run failed because the
generic golden trace file validation stage scans top-level `tests/golden/*.jsonl`
files and expects every row to use `schema_version = golden-trace-v1`.

`tests/golden/v260_release_gates_strict_provenance.jsonl` is not a runtime
golden trace. It is a release-provenance fixture consumed by
`scripts/ai/verify_v26_release_gates.sh` and
`scripts/ai/verify_v26_strict_provenance.sh`.

## Scope

- Move the v26 release-provenance JSONL fixture under a versioned subdirectory.
- Update all script, manifest, release-scope, and evidence references.
- Keep top-level `tests/golden/*.jsonl` reserved for common golden-trace-v1
  fixtures.
- Do not change runtime, adapter, Dashboard, order, or public API behavior.

## Acceptance

- `scripts/ai/verify_full.sh golden-traces-files` passes.
- `scripts/ai/verify_release.sh v26-release-gates` passes.
- `scripts/ai/verify_release.sh v26-strict-provenance` passes.
- Hosted `Rust Cutover Release Gate` for `ntpro-rust-only-v0.26.0` succeeds
  after the corrective PR merges and the tag is updated.
