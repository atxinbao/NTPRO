## Acceptance

- Boundary document exists.
- Initial allowlist only permits `GET /api/v3/account` on Binance testnet.
- Denylist includes order submission/cancel/replace/amend, listenKey/user-data
  stream mutation, production endpoints, and broader account mutation surfaces.

  balances, UID, and account-identifying fields in artifacts/logs/docs/PR body.
- Dashboard remains artifact-read-only and cannot start probes.
- No capability expansion is claimed.
