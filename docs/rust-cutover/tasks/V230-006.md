## Goal

Add executable replay and render smoke coverage for the v0.23.0 Dashboard /
Workbench observability surface across account, strategy, and venue node
dimensions.

Plain Chinese summary: 本任务把多账户、多策略、多 venue node 的 Dashboard /
Workbench observability 边界落到可执行 replay 和真实 renderer smoke。Dashboard 可以
只读聚合，并按 `account_key`、`strategy_key`、`venue_node_key`、`isolation_scope_key`
显示和过滤状态、风险、告警、审计/provenance、生命周期证据；跨 scope 标签错配会
fail closed，缺失身份会降级为 unavailable。本任务不新增真实 submit/cancel/retry/
replace/amend/flatten 控件，不新增 order ticket，不改变 release publication flow。

## Scope

Included:

- add V230 dashboard observability golden trace fixtures;
- add executable Rust projection replay for scoped Dashboard rows;
- validate visible account, strategy, venue node, isolation scope, and
  provenance labels;
- prove filter/drill-down output remains isolated to the selected scope;
- fail closed on visible label/component cross-scope mismatch;
- degrade unavailable when required identity labels are missing;
- add a real Dashboard JavaScript render smoke over a two-row scoped runtime
  snapshot;
- prove forbidden operation controls remain absent and required operation
  boundary fields are explicitly available `false`.

Not included:

- production submit/cancel/retry/replace/amend/flatten;
- order ticket enablement;
- Dashboard mutation controls;
- release publication changes.

## Acceptance Criteria

- `tests/golden/read_model_dashboard_observability_schema.jsonl` includes
  multi-scope, filtered drill-down, cross-scope label mismatch, and missing
  identity cases.
- `crates/cli/tests/golden_trace_read_model_projection.rs` replays the V230
  Dashboard observability cases through Rust projection logic.
- `docs/rust-cutover/golden_trace/RELEASE_REPLAY_SCOPE.json` records the V230
  Dashboard observability cases as executable replay.
- `tests/golden/v230/dashboard_observability_snapshot.json` and
  `scripts/ai/verify_v23_dashboard_observability_smoke.sh` exercise the real
  Dashboard renderer over two scoped rows.
- Release/evidence docs record the read-only aggregation, isolated filters,
  missing identity degradation, and forbidden-controls boundary.
