# V140-007 v0.14 Release Gates

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Wire v0.14 release gates for offline fail-closed behavior, owner-gated
production order-state read-only proof, live-alpha dry-run order gate, local
risk preflight, supervisor shadow runtime, and no-production-mutation evidence.

Plain Chinese summary: 这个任务把 v0.14 的发布门禁接起来。它验证“默认离线、
fail-closed、只读查询要 owner 手动开 gate、live-alpha 只能 dry-run、不允许真实下单
或改单”。它不是实盘下单版本。

## Scope

Included:

- add `scripts/ai/verify_v14_release_gates.sh`;
- expose `scripts/ai/verify_release.sh v14-release-gates`;
- add `release-v14-release-gates` to the release-tag workflow matrix;
- add PR smoke classification and step coverage for v14 release gate changes;
- validate v14 order-state read-only proof default offline behavior;
- validate v14 supervisor shadow runtime;
- validate v14 live-alpha dry-run order gate;
- validate v14 live-alpha risk preflight;
- validate live-alpha reconciliation golden traces.

Not included:

- production order submission;
- production cancel, replace, amend, retry, correction, or flatten;
- execution adapter calls for live-alpha dry-run;
- production network by default;
- listenKey lifecycle;
- Dashboard order controls;
- credential entry;
- auto-remediation or reconnect behavior;
- release tag creation or GitHub Release publication.
