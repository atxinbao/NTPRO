## Implementation guidance

PR gate should include fmt, workspace check, clippy, tests, v02 two-node smoke, and security audit where feasible. Tag workflow must trigger on ntpro-rust-only-v* and run scripts/ai/verify_release.sh.

## Verification criteria

- `GitHub workflow syntax review`
- `scripts/ai/verify_fast.sh`
- `git diff --check`

Evidence must record changed files, commands run, command output summary, behavior impact, public API impact, migration note status, rollback plan, and a plain Chinese non-expert summary.
