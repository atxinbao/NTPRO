# TCG-001 Clean obsolete root TOML configuration

Date: 2026-07-28
Executor: Codex
GitHub issue: `#1159`
Risk: medium
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Auto-merge: not requested
Status: `READY_FOR_PR`

## Goal

清理根目录中没有活动消费者的 TOML 配置，并统一 rustup 与仓库脚本读取的 Rust
工具链版本。

## Scope

- 删除未被 workflow、脚本、hook 或已安装工具使用的 `.taplo.toml`；
- 删除未被 workflow、脚本、hook 或已安装工具使用的 `.typos.toml`；
- 将 `rust-toolchain.toml` 标准化为固定 `channel = "1.95.0"`；
- 更新 `scripts/rust-toolchain.sh` 读取并校验标准 channel；
- 清理 `.taplo.toml` ownership，并为 `tools.toml`、`osv-scanner.toml`
  补充 ownership。

## Not in scope

- Cargo workspace、依赖或编译 profile；
- Clippy、rustfmt、cargo-deny、OSV 或工具版本策略；
- runtime、API、adapter、schema、存储或交易语义；
- v0.32.0 冻结发布文件。

## Acceptance criteria

- 根目录不再包含 `.taplo.toml` 和 `.typos.toml`；
- 无目录 override 时，rustup 从文件解析出 Rust `1.95.0`；
- `scripts/rust-toolchain.sh` 输出 `1.95.0` 并拒绝浮动 channel；
- Cargo metadata、fmt、Clippy、安全审计和当前治理检查通过；
- 无生成缓存或 v0.32.0 冻结文件差异。
