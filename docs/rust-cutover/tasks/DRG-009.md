# DRG-009 - Executable trace gate

Milestone: v0.2 Design Readiness
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Rust Core Runtime Agent
Risk: high

## Goal

Promote the required v0.2 trace areas from plans or schema-only rows into
executable passing evidence.

## Scope

Add or verify executable traces for:

- backtest;
- live/sandbox lifecycle;
- data source;
- execution order lifecycle;
- risk rejection;
- adapter payload.

## Non-goals

- Do not connect to real exchanges.
- Do not change trading semantics without trace review.
- Do not treat schema-only trace rows as executable evidence.

## Required evidence

- `scripts/ai/run_golden_traces.sh` or equivalent trace commands.
- Targeted cargo tests for each new trace harness.
- `scripts/ai/verify_fast.sh`.

## Acceptance

- `G8 Executable trace evidence` is `PASS`.
- Every product-claimed trace area has a repeatable local command and passing
  output.
- High-risk work stops at `REVIEW_REQUIRED`.
