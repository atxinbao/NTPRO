# V170-003 - Add reconciliation classifier

Date: 2026-06-24
Executor: Codex
Milestone: v0.17.0 production reconciliation and orphan recovery
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Classify local-vs-exchange order state outcomes for one v0.16 production
mutation candidate lineage using the v0.17 exchange readback mapper artifact.

Plain Chinese summary: 这个任务只做“对账分类”。大白话：它把本地账本和交易所只读回查
对起来，判断是本地已发送但交易所未知、新单、成交、撤销、拒单、缺失，还是本地没发送但
交易所看到了订单。它只产出证据，不自动补单、撤单、重试或修复。

## Scope

Included:

- add `live production-mutation-reconciliation-classifier`;
- consume one v0.17 exchange readback mapper artifact;
- emit one reconciliation classifier artifact;
- classify:
  - `local_sent_exchange_unknown`;
  - `local_sent_exchange_new`;
  - `local_sent_exchange_filled`;
  - `local_sent_exchange_canceled`;
  - `local_sent_exchange_rejected`;
  - `local_sent_exchange_missing`;
  - `local_no_send_exchange_order_seen`;
  - `readback_failed`;
- mark ambiguous/non-terminal/failure outcomes as manual-review-required and
  new-orders-blocked;
- keep retries, cancels, remediation, and Dashboard order controls disabled.

Not included:

- orphan order detection;
- owner-approved cancel recovery;
- restart recovery;
- network readback execution;
- automatic cancel, retry, replace, amend, correction, flatten, or remediation;
- Dashboard order/cancel controls;
- multi-account or multi-venue reconciliation;
- release tag creation.

## Acceptance Criteria

- Classifier artifact uses
  `schema_version=ntpro.v170_production_mutation_reconciliation_classifier.v1`.
- Ready classifier sets `reconciliation_classified=true`.
- Ready classifier keeps `orphan_risk_detected=false`.
- All eight required outcomes are covered by fixtures.
- `local_sent_exchange_unknown`, `local_sent_exchange_new`,
  `local_sent_exchange_missing`, `local_no_send_exchange_order_seen`, and
  `readback_failed` require manual review and block new orders.
- `local_sent_exchange_filled`, `local_sent_exchange_canceled`, and
  `local_sent_exchange_rejected` do not require automatic recovery.
- API keys, secrets, signatures, signed query/URL, raw exchange response,
  response body, and response headers are not persisted.
- Duplicate submit, retry, cancel, remediation, and Dashboard order controls
  remain disabled.
