## Goal

Define deterministic order slicing preview evidence for v0.24.0 order control.
The preview accepts a parent intent plus slicing policy and emits a replayable
child-order plan, but it never submits, signs, schedules, or routes child
orders.

Plain Chinese summary: 本任务只定义 order slicing preview 证据。它把 parent
intent 和 slicing policy 转成确定性的 child-order 预览计划，并记录 notional、
rounding、risk policy refs；不做真实拆单调度，不生成 signed request，不调用
execution adapter。

## Scope

- Define slicing input: parent intent, max child size, min interval,
  venue/account/strategy scope, and isolation scope.
- Output deterministic child-order preview plan, notional totals, rounding
  evidence, and risk policy references.
- Cover invalid size, precision mismatch, scope mismatch, missing policy, and
  forbidden market/limit combination cases.
- Add golden trace coverage and a fail-closed release verification stage.

## Non-Goals

- Do not dispatch or schedule real child orders.
- Do not implement TWAP or VWAP live scheduler.
- Do not call execution adapters or exchange endpoints.
- Do not add submit, cancel, retry, replace, amend, or flatten capability.
- Do not add Dashboard live order controls.

## Done Criteria

- Child plan quantity, notional, interval, and rounding evidence are
  deterministic and replayable.
- Every child order is preview-only and contains no signed request or exchange
  order identifier.
- Invalid size, precision mismatch, missing policy, scope mismatch, and
  forbidden market/limit combinations fail closed.
- No runtime trading behavior, network call, adapter call, production order
  mutation, or Dashboard operation control is added.
