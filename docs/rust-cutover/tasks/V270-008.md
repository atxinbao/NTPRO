## Acceptance Criteria

- `scripts/ai/verify_release.sh` exposes `v27-release-gates` and
  `v27-strict-provenance`.
- v27 release gates fail when V270 evidence, v0.26.1 dependency proof, release
  replay scope, gate scripts, or required-false boundary flags are missing.
- Tag-gate mode requires issue `#861` closed, the v0.27.0 milestone closed, and
  HEAD matching the local `ntpro-rust-only-v0.27.0` tag.

  workflow, and publish workflow to the same source tree.

  V270-008 release governance cases as validator executable replay.
