# V05-006 - Dashboard artifact reader

Milestone: v0.5.0 local Binance sandbox workflow artifacts
Priority: P0
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk: medium

## Goal

Expose V05 workflow manifests in the local Dashboard snapshot API.

## Scope

- Read local `workflows/*/manifest.json` artifacts.
- Populate `workflow_artifacts` in the Dashboard snapshot.
- Represent invalid manifests as explicit gaps.

## Non-goals

- Do not run workflows from the Dashboard.
- Do not connect to Binance.
- Do not submit real orders.

## Required evidence

- Dashboard snapshot test covers valid workflow manifest discovery.
- Dashboard snapshot test covers invalid manifest gap handling.
- Evidence file exists at `docs/rust-cutover/evidence/V05-006.md`.
