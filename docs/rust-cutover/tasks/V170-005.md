# V170-005 - Define owner-approved cancel recovery boundary

Date: 2026-06-24
Executor: Codex
Milestone: v0.17.0 production reconciliation and orphan recovery
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Define the owner-approved cancel recovery boundary after orphan risk detection
without enabling cancel execution in v0.17.0.

Plain Chinese summary: 这个任务只定规则。大白话：v0.17 可以说明“以后如果要安全撤孤儿单，
应该先做预览、风控、人工确认、脱敏和审计”；但本版本不发撤单请求，不做自动撤单，也不
加 Dashboard 撤单按钮。

## Scope

Included:

- create `docs/rust-cutover/scope/v0_17_cancel_recovery_boundary.md`;
- define cancel request preview contract;
- define cancel risk gate contract;
- define manual owner approval contract;
- define cancel response redaction/audit contract;
- explicitly defer actual cancel execution to a later version.

Not included:

- `DELETE /api/v3/order`;
- cancel execution;
- automatic cancel, retry, replace, amend, correction, flatten, or remediation;
- Dashboard order/cancel controls;
- code-level cancel fixtures or CLI cancel command;
- release tag creation.

## Acceptance Criteria

- The scope document states `actual_cancel_send_allowed=false`.
- The scope document states `automatic_cancel_allowed=false`.
- The scope document states `dashboard_cancel_controls_enabled=false`.
- The future cancel flow requires owner manual approval and one candidate only.
- The future cancel flow requires redaction before persistence.
- Actual cancel execution is explicitly deferred to `v0.17.1` or `v0.18.0`.
- No product capability claim says v0.17.0 can cancel orders.
