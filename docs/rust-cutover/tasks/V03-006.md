# V03-006 - Overview and Nodes UI

Milestone: v0.3 Dashboard MVP
Priority: P1
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk: medium

## Goal

Implement the Dashboard Overview and Nodes UI using static HTML, CSS, and
JavaScript.

Plain language: the first screen should immediately show whether NTPRO is alive
and what each local node is doing.

## Dependencies

- `V03-005`

## Scope

- Render Overview from `DashboardSnapshot`.
- Render Nodes list and node detail summary.
- Show:
  - supervisor registry path;
  - node total;
  - running, stopped, error, stale, and unknown counts;
  - sandbox-only status;
  - `external_venue_connection`;
  - `real_orders_submitted`;
  - latest transition;
  - latest redacted error.
- For each node, show:
  - `node_id`;
  - lifecycle state;
  - process state;
  - pid;
  - config path;
  - artifact root;
  - start/stop timestamps;
  - last transition;
  - last error.

## Non-goals

- Do not add a frontend framework.
- Do not build a marketing page.
- Do not render manual order controls.
- Do not render raw logs, raw stack traces, raw venue payloads, raw account
  objects, or secrets.

## Related files

## Implementation guidance

This is an operational UI, not a landing page. Use dense, scannable tables or
panels. Keep text inside controls and cards from overlapping at desktop and
mobile widths.

## Verification criteria

- Browser or Playwright opens the local dashboard.
- Overview renders from real snapshot JSON.
- Two sandbox nodes can be shown at once.
- Node state changes after refresh are visible.
- No visible overlap at desktop and mobile widths.
- No unsupported trading controls are displayed as active.
