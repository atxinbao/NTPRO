## Goal

Define readback and audit evidence for the v0.24.0 order-control preview line.
The evidence ties preview inputs, decision outputs, policy refs, risk refs,
readback refs, audit refs, provenance refs, and scope keys into one replayable
read-only closeout record.

Plain Chinese summary: 本任务只定义 order-control preview 的 readback/audit
证据闭环。它把 preview input、decision output、policy、risk、readback、
audit、provenance 和 scope key 绑在一起；缺任何关键证据都 fail closed；不会
读取真实交易所订单、不会调用 adapter、不会修改订单状态。

## Scope

- Define readback artifact binding for preview inputs, decision outputs,
  policy refs, risk refs, audit refs, provenance refs, and scope keys.
- Define audit closeout states: `ready_preview`, `blocked`,
  `degraded_unavailable`, and `fail_closed`.
- Cover missing readback, missing audit, missing provenance, stale source,
  redaction breach, cross-scope mismatch, and degraded unavailable cases.
- Keep Dashboard consumption limited to redacted read-only audit evidence.

## Non-Goals

- Do not claim exchange truth.
- Do not extend real order state reads.
- Do not call execution adapters or exchange endpoints.
- Do not mutate production order state.
- Do not add Dashboard live operation controls.

## Done Criteria

- Missing readback, audit, or provenance fails closed.
- Stale source provenance fails closed.
- Redaction breach fails closed.
- Cross-scope mismatch is blocked before any ready preview.
- Degraded unavailable records redacted audit evidence without exchange truth.
- No runtime trading behavior, network call, adapter call, production order
  mutation, real order state read expansion, or Dashboard operation control is
  added.
