# V03-001 - Scope decision / Dashboard system-status MVP

Milestone: v0.3 Dashboard MVP
Priority: P0
Owner role: Control & Scope Agent
Review role: Verification & Release Gatekeeper
Risk: low

## Goal

Lock v0.3 as a local Dashboard MVP for NTPRO system status.

Plain language: v0.3 should answer:

```text
Is the system alive?
Which nodes are running?
Are data sources, execution gateways, risk, modules, logs, and metrics visible?
Can the operator start or stop a local sandbox node?
```

## Dependencies

- `ntpro-rust-only-v0.2.0`
- `V02-010`
- `NDASH-001`

## Scope

- Create the active v0.3 scope decision.
- Define v0.3 as a local system status cockpit.
- Define required panels:
  - Overview;
  - Nodes;
  - Data Sources;
  - Execution;
  - Risk;
  - Logs / Metrics;
  - Runtime Modules.
- Define start/stop as the only implemented lifecycle controls for v0.3.
- Record that pause/resume/reconnect controls are disabled or unsupported.
- Record the V03 task sequence.

## Non-goals

- Do not implement dashboard runtime code in this task.
- Do not add HTTP endpoints in this task.
- Do not add a frontend framework.
- Do not add real exchange connectivity.
- Do not add manual order entry, order modification, or order cancellation.
- Do not create release tags or publish GitHub Releases.
