## Goal

Model the operator approval, production freeze, and change-window lifecycle
required before controlled backend enablement.

Plain Chinese summary: 本任务定义 operator approval、production freeze 和
change-window lifecycle。启用候选不能在批准窗口外继续；active freeze、过期批准、
撤销批准和 release mismatch 都必须 fail-closed。

## Scope

- Define approval states, freeze states, change-window evidence, expiry, and
  revocation.
- Require immutable evidence for who approved, what was approved, and which
  release/build it applies to.
- Add fail-closed behavior for expired approval, mismatched release, revoked
  approval, outside-window execution, and active freeze.

- No adapter send or live exchange request.
- No retry scheduler or automatic remediation.
