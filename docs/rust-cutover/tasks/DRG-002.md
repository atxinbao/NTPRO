# DRG-002 - Toolchain default convergence

Milestone: v0.2 Design Readiness
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Control & Scope
Risk: medium

## Goal

Ensure ordinary local Cargo commands inside the repository use Rust `1.95.0`,
not the older Homebrew compiler.

## Scope

- Verify `cargo -V`, `rustc -V`, and `rustup show active-toolchain`.
- Fix or document PATH/override behavior so developers do not accidentally use
  Rust `1.87.0`.
- Keep verification scripts aligned with `scripts/ai/toolchain_env.sh`.
- Update toolchain docs if the setup path changes.

## Non-goals

- Do not change Rust dependency versions.
- Do not weaken the workspace `rust-version`.

## Required evidence

- `cargo -V`
- `rustc -V`
- `rustup show active-toolchain`
- `scripts/ai/verify_fast.sh`

## Acceptance

- `G1 Toolchain consistency` is `PASS`.
- Plain `cargo` and `rustc` resolve to Rust `1.95.0` inside the repo.
