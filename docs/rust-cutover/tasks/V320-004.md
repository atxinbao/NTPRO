## Goal

Close backend production configuration and venue readiness with explicit
environment provenance and fail-closed credential boundaries.

Plain Chinese summary: 本任务定义 v0.32.0 后端收尾所需的 production config、venue
readiness、credential provenance 和 environment provenance 合同。陈旧、缺失、环境
不匹配、venue 不匹配、credential scope mismatch、缺失脱敏或原始 secret/signature/
credential/payload 持久化都必须 fail-closed；本任务不授权 adapter send、live
exchange request、submit、mutation、frontend completion、backend go-live 或交易控件。

## Scope

Included:

- Define production config readiness schema for environment, venue,
  account/strategy scope, operator ownership, release identity, and config
  digest.
- Define credential provenance without persisting secrets, signatures, raw
  credentials, or unrestricted payloads.
- Define venue readiness and environment mismatch rejection.
- Add negative cases for missing config, wrong environment, stale venue
  readiness, credential scope mismatch, missing redaction, and raw secret or
  unrestricted payload persistence.

Not included:

- new venue adapter behavior;
- default production submit;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal operation controls or trading controls;
- backend go-live execution;
- product-grade live trading terminal readiness.

## Acceptance Criteria

- Backend closeout blocks on stale, missing, wrong-environment, or wrong-venue
  evidence.
- Credential evidence is provenance-bound and redacted without broadening scope.
- No secrets, signatures, raw credentials, or unrestricted payloads are
  persisted.
- Config readiness does not authorize adapter send or live exchange requests.
