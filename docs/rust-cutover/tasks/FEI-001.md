## 依赖

## 目标

将 `apps/strategy-workbench/` 的 Vite 生产构建接入 Rust/Axum，使同一 Rust 进程提供
React 页面、hash 静态资产、只读 API 和本地访问控制；生产运行不依赖 Node.js。

## 范围

- 为 `mvp serve` 与 `dashboard serve` 增加显式 `--strategy-workbench-dist` 输入；
- 启动前验证 React 入口、资产目录和 index 引用的 hash JS/CSS；
- 使用 `tower-http` 的 `ServeFile` / `ServeDir` 提供标准静态文件服务；
- `/strategy-workbench/*` 支持 SPA 深层路由刷新；
- `/strategy-workbench/assets/*` 不存在时返回 404，`/api/*` 不进入 SPA fallback；
- 所有策略工作台路径保持机构用户访问控制、token 清理、私有响应头和 GET-only；
- 删除旧 Rust 内嵌 HTML、CSS、JavaScript 和对应 VM 合同测试；
- Rust route tests、前端 gate、真实 Axum 生产 bundle 浏览器 smoke 覆盖桌面和移动端。

## 非目标

- 不新增 Strategy、StrategyVersion 或 Run 产品 API；
- 不新增 Backtest、Demo 或 Live 写操作；
- 不开放真实 Venue、订单提交、修改、重试或自动补救；
- 不提交 `dist/`、`node_modules/` 或浏览器结果；
- 不修改 `docs/rust-cutover/release/v0_32_0_*`。
