# V281-009 v28.1 prepublish live-current require semantics

Date: 2026-07-09
Executor: Codex
GitHub issue: #946
Milestone: v0.28.1
Status: LOCAL VALIDATION PASSED

## Goal

Fix the v0.28.1 tag gate prepublication path so intentionally disabling
current-release live proof also disables the release-gate requirement for that
live proof. This keeps tag-stage validation offline before the public
`ntpro-rust-only-v0.28.1` GitHub Release exists, while preserving live current
proof for post-publication verification.

Plain Chinese summary: 本任务修复 v0.28.1 tag gate 的发布前语义。发布前阶段没有公开
v0.28.1 Release，因此可以关闭 live current proof；关闭时必须同时关闭 require 标志，避免
`live_current_disabled` 被 release gate 当成失败。发布后 current-release live proof 仍然保留。

## Scope

- Set `NTPRO_RELEASE_PUBLISH_AFTER_GATE_REQUIRE_LIVE_CURRENT=0` whenever the
  prepublication tag gate sets `NTPRO_RELEASE_PUBLISH_AFTER_GATE_LIVE_CURRENT=0`.
- Cover both the standalone `release-publish-after-gate` workflow matrix stage
  and the aggregate `v28.1-release-gates` script path.
- Register `V281-009` / #946 in the v0.28.1 release manifest, readiness report,
  strict provenance, v29 intake gate, and release index.

## Non-goals

- No submit, order mutation, adapter send, live exchange request, retry
  scheduler, automatic remediation, Dashboard/Admin/Trader Terminal trading
  controls, or product-grade live trading terminal claim.
