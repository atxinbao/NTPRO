# V140-006 Dashboard Live Alpha Dry-run Panel

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Add a read-only Dashboard panel for v0.14 live-alpha dry-run readiness and
reconciliation state.

Plain Chinese summary: 这个任务让 Supervisor Dashboard 能看见 v0.14
live-alpha dry-run 的关键状态。它只读本地工件，展示 dry-run gate、风控预检、
kill switch、order-state read、reconciliation 和无真实交易边界，不提供任何下单、
撤单、改单、重连或密钥录入控件。

## Scope

Included:

- add a `live_alpha_dry_run` section to the dashboard snapshot DTO;
- render a read-only `Live Alpha Dry-run` Dashboard panel;
- read conventional node artifacts from `v0_14/live_alpha_dry_run_order_gate.json`;
- read conventional node artifacts from `v0_14/live_alpha_risk_preflight.json`;
- show readiness ready/blocked, missing gates, risk decision, risk reasons,
  kill switch state, order-state read freshness, open-order count, and
  reconciliation status;
- show no-mutation evidence fields such as production order submissions,
  production order mutations, execution adapter call, order endpoint access,
  network attempt, dashboard order controls, real orders, and exchange-truth
  value flags.

Not included:

- production order submission;
- production order cancel, replace, amend, retry, correction, or flatten;
- execution adapter calls;
- production network actions;
- listenKey lifecycle;
- Dashboard order controls;
- credential entry;
- auto-remediation or reconnect behavior;
- trading semantic changes.

## Acceptance

- Dashboard snapshot serializes a stable `live_alpha_dry_run` top-level key.
- Dashboard shell includes a `live-alpha-dry-run` mount and `renderLiveAlphaDryRun`.
- v0.14 artifacts populate the panel as healthy when the dry-run gate is ready,
  local risk preflight approves, and all no-mutation fields remain false/zero.
- Any production mutation, real order, network attempt, execution adapter call,
  or Dashboard order-control flag degrades the panel.
- Existing Dashboard forbidden control checks remain green.
- `git diff --check` passes.
