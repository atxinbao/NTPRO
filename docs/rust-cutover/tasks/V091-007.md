## Goal

Add a Strategy Session manifest so the artifact set can be audited as a coherent
unit.

## Scope

- Add `strategy/manifest.json` with schema version
  `ntpro.v091_strategy_session_manifest.v1`.
- Record artifact list, record counts, checksums, state, created timestamp, and
  updated timestamp.
- Write child artifacts first, then summary, then manifest last.

## Acceptance

- Manifest records all v0.9.1 Strategy Session child artifacts.
- Missing or corrupted child artifact is detectable.
- Manifest does not contain secrets or exchange order identifiers.
