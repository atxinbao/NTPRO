## Goal

Add the v0.11 authenticated production read-only account snapshot contract with
env-only credentials, redacted artifacts, and no account mutation or order
endpoint access.

Plain Chinese summary: 本任务只增加“生产认证只读账户快照”的本地契约。它会记录
未来读取 `GET /api/v3/account` 所需的 gate、env-only 凭证状态和红action要求，
但默认不联网、不签名、不写出 API key/secret、不访问订单 endpoint、不下单、不撤单、
不改单，也不开放 Dashboard 下单控制。

## Scope

- Add a Rust CLI command for authenticated production account snapshot contract artifacts.
- Support only `GET /api/v3/account` as a read-only contract shape.
- Keep default execution offline and fail-closed.
- Record only env variable names and credential presence, never credential values.
- Add redaction tests and local verification.

## Non-Goals

- No online production account read.
- No production order submission.
- No production cancel, replace, amend, retry, or correction orders.
- No `/api/v3/openOrders` or other order endpoint access in this task.
- No raw API key, API secret, signature, signed query, or signed URL persistence.
- No Dashboard order controls.
- No production trading readiness claim.
