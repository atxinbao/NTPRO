container, and CI execution surfaces while preserving current Rust build,
test, docs, security, CLI, and backend-freeze authority.

- delete `pyproject.toml`, `uv.lock`, local `.venv`, and obsolete test scripts;
- remove wheel, sdist, PyPI, legacy container, and package-publication actions,

- retain Rust workspace build/test/docs, CLI binary, Miri, DST, golden trace,
  release publication, and security audit workflows;
- update current CI and security documentation.

- deleting or rewriting historical `docs/rust-cutover/` evidence;
- changing runtime, public API, trading semantics, adapters, or backend

- auto-merging this high-risk PR.

- tracked Python source files, `pyproject.toml`, and `uv.lock` are absent;
- local `.venv` and Python caches are absent;
- supported Make, workflow, action, hook, and script surfaces do not install or
  execute Python tooling;
- no wheel, sdist, PyPI, or Python container publication path remains;
- retained Rust workflows parse and their referenced scripts exist;
- current Rust smoke, security, docs, CLI, and backend-freeze gates pass;
