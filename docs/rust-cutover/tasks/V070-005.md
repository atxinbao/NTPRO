# V070-005 - Display V07 real testnet probe artifacts in Dashboard read-only mode

Milestone: v0.7.0 deferred queue

Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk: medium

Risk override: the owner approved V070-003 through V070-007 for automated
execution and auto-merge on 2026-06-14. Dashboard work must remain read-only and
artifact-only.

## Goal

Display V07 probe artifacts in the local Dashboard without starting probes,
reading credentials, or exposing control actions.

## Scope

- Read existing artifact files only.
- Display `network_permission_requested`, `network_attempted`,
  `testnet_connection`, `probe_status`, `latency_ms`, `endpoint_class`,
  `credential_policy`, `values_recorded=false`, `secrets_redacted=true`,
  `real_orders_submitted=false`, and `order_submission=disabled`.
- Keep the Dashboard a viewer for evidence, not a connection control surface.

## Non-goals

- Do not start HTTP or WebSocket probes from Dashboard code.
- Do not read environment variables or credential values.
- Do not display API key or API secret values.
- Do not add connect, disconnect, order, cancel, amend, or production controls.
- Do not create a tag or GitHub Release.

## Required Evidence

- `cargo fmt --check`
- `cargo check -p nautilus-cli`
- Dashboard-targeted CLI tests
- artifact fixture or workflow output proving V07 fields render/read correctly
- secret scan for Dashboard output and docs
- `git diff --check`

## Acceptance

- Dashboard can consume and display V07 probe artifact fields.
- Dashboard does not start probes, read credentials, or show secret values.
- Dashboard still states no orders, no production trading, and no real funds.
