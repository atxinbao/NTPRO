# V031-003 - hosted release gate triage and evidence closeout

Milestone: v0.3.1 Local Supervisor Control Console Hardening
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Control & Scope Agent
Risk: medium

## Goal

Close the hosted GitHub Actions evidence gap for the release gate and document
the actual remote result that blocks a clean patch release.

Plain language: stop saying remote CI is merely unconfirmed when the hosted gate
already has a concrete result.

## Dependencies

- `V031-002`

## Scope

- Record the current hosted release-gate run state for the relevant tag or
  branch.
- Capture workflow name, run id, commit sha, trigger type, and conclusion.
- If the hosted gate failed because of environment or toolchain instability,
  document that exact failure mode and the follow-up action.
- Update release-facing evidence so local PASS and hosted status do not
  contradict each other silently.

## Non-goals

- Do not fabricate a hosted PASS result.
- Do not create a release tag.
- Do not publish a GitHub Release.

## Related files

- `.github/workflows/**` (REFERENCE): hosted workflow definitions.
- `docs/rust-cutover/release/v0_3_0_supervisor_control_readiness_report.md`
  (REFERENCE): current release narrative.
- `docs/rust-cutover/evidence/V031-003.md` (CREATE): hosted evidence closeout.

## Implementation guidance

Prefer direct GitHub evidence over indirect combined-status inference. If the
root cause is a hosted linker or runner failure, say that concretely.

## Verification criteria

- Evidence names the exact hosted workflow run and conclusion.
- Evidence distinguishes local verification status from hosted run status.
- Evidence records the next action needed before a clean v0.3.1 release claim.

## Required commands

```bash
gh run list --repo atxinbao/NTPRO --limit 20
gh run view <run-id> --repo atxinbao/NTPRO --log-failed
git diff --check
```

## Evidence required

Create `docs/rust-cutover/evidence/V031-003.md` with:

- task ID;
- plain Chinese summary;
- workflow name;
- run id;
- commit sha;
- trigger type;
- hosted PASS/FAIL result;
- failure summary or closure result;
- rollback plan.
