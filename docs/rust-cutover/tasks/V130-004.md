# V130-004 - Kill switch dry-run and manual approval artifact contract

Date: 2026-06-21
Executor: Codex

## Goal

Define and verify the v0.13 kill-switch dry-run and manual approval artifact
contract for Guarded Live Alpha Preflight.

Plain Chinese summary: 这个任务不是允许实盘下单。它只是让系统能产出一份本地
JSON 证据：kill switch 做过 dry-run，人工批准记录可以被审计，但生产下单、撤单、
改单、订单状态读取、listenKey、Dashboard 下单控件仍然全部关闭。

## Scope

Included:

- `nautilus live production-kill-switch-approval-artifact`;
- schema `ntpro.v130_kill_switch_approval_artifact.v1`;
- local kill-switch dry-run state;
- manual approval state: `pending`, `approved`, or `rejected`;
- explicit confirmation flags for dry-run-only, no production mutation, and
  disabled Dashboard order controls;
- local artifact validation script
  `scripts/ai/verify_v13_kill_switch_approval_artifact.sh`;
- release/evidence documentation for the v0.13 no-mutation boundary.

Not included:

- production order submission;
- production cancel / replace / amend / retry / correction;
- production order-state reads;
- listenKey lifecycle management;
- signed WebSocket user stream runtime;
- Dashboard order controls or credential entry;
- automatic remediation;
- real funds or production trading.
