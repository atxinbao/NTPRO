# V160-011 - Add Dashboard read-only production mutation evidence panel

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.0 minimum owner-approved production order mutation candidate
Risk: medium

## Goal

Expose the v0.16 production mutation candidate evidence in the local Dashboard
snapshot as read-only status.

Plain Chinese summary: 这个任务不是给 Dashboard 加下单按钮。大白话：它只是让
Supervisor Dashboard 能看见 v0.16 单笔候选链路的证据，例如审批、runtime gate、
请求构造、send path、响应脱敏、readback、审计链路和失败处理状态。

## Scope

Included:

- add a Dashboard snapshot section for v0.16 production mutation evidence;
- read local v0.16 JSON artifacts from each node artifact root;
- display approval, signing-material, request-builder, guarded-send,
  response-redaction, readback, audit-trail, and failure-semantics status;
- keep Dashboard rendering read-only;
- add tests and a local verifier.

Not included:

- Dashboard order controls;
- Dashboard credential input;
- production order submit/cancel/replace/amend/retry controls;
- strategy-driven production execution;
- new production network behavior.
