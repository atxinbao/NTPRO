`owner-run-not-executed` from `owner-run-executed-classified`.

证据槽，明确当前有没有执行过、执行后要怎样分类。

## Scope

- define the owner-run evidence slot;
- document `owner-run-not-executed`;
- document `owner-run-executed-classified`;
- list required evidence for an executed owner run:
  - manual-online guarded send artifact;
  - HTTP status and redacted response artifact;
  - order-state readback artifact;
  - audit trail artifact;
  - failure/no-retry semantics;
  - no retry/cancel/remediation evidence;
- create the v0.16.1 readiness accounting anchor.

Not included:

- new CLI behavior;

- cancel, replace, amend, flatten, retry, or remediation;
- release tag creation.
