# V03-010 - Dashboard smoke and v0.3 readiness report

Milestone: v0.3 Dashboard MVP
Priority: P1
Owner role: Verification & Release Gatekeeper
Review role: Control & Scope Agent
Risk: medium

## Goal

Create the final v0.3 Dashboard MVP smoke and readiness report.

Plain language: prove that the local Dashboard can show two sandbox nodes and
the required system status panels, then declare PASS or FAIL strictly.

## Dependencies

- `V03-009`

## Scope

- Add a repeatable local dashboard smoke script.
- Start or reuse two local sandbox supervisor-managed nodes.
- Start the local dashboard server.
- Open the dashboard with Browser or Playwright.
- Verify:
  - Overview;
  - Nodes;
  - Data Sources;
  - Execution;
  - Risk;
  - Logs / Metrics;
  - Runtime Modules;
  - gaps;
  - start/stop controls.
- Capture browser verification evidence.
- Create the final readiness report:

```text
docs/rust-cutover/release/v0_3_dashboard_mvp_readiness_report.md
```

## Non-goals

- Do not create a release tag.
- Do not publish a GitHub Release.
- Do not declare production real-exchange readiness.
- Do not declare manual trading readiness.
- Do not expand v0.3 beyond the Dashboard MVP scope.

## Implementation guidance

Use strict PASS/FAIL language. The readiness report may declare Dashboard MVP
PASS only if all scoped V03 tasks have evidence and all required validation
passes or documented exceptions are accepted by the gatekeeper role.

## Verification criteria

- `scripts/ai/v03_dashboard_smoke.sh` passes.
- `scripts/ai/v02_two_node_supervisor_smoke.sh` passes.
- Browser or Playwright confirms the dashboard page opens and renders real local
  state.
- Browser or Playwright verifies desktop and mobile layouts have no obvious
  overlap.
- `cargo check -p nautilus-cli` passes.
- `cargo test -p nautilus-cli dashboard --lib` passes.
- `cargo test -p nautilus-cli supervisor --lib` passes.
- `scripts/ai/check_rust_only_runtime.sh` passes.
- Readiness report includes explicit out-of-scope list.
