# V150-001 - Production Mutation Endpoint Classifier Gate

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Classify v0.15 production mutation endpoints as forbidden, scope candidate, or
owner-approved manual request-preview only while preserving default deny
behavior.

Plain Chinese summary: 这个任务只改 endpoint classifier。`POST /api/v3/order` 和
`POST /api/v3/order/test` 默认只能被识别成“v0.15 干跑请求预览候选”，不能执行。只有显式
owner/manual preview 上下文才允许生成 request preview 分类，而且仍然不能发请求、不能下单、
不能撤改、不能调用生产 adapter。

## Scope

Included:

- add classifier classes for:
  - `production_mutation_scope_candidate`;
  - `production_mutation_owner_approved_manual_only`;
- add `EndpointDecision::AllowRequestPreviewOnly`;
- add `request_preview_allowed` to classified endpoint output;
- classify `POST /api/v3/order` and `POST /api/v3/order/test` as default-denied
  preview candidates;
- expose an owner/manual classifier context for future dry-run request preview
  code;
- keep DELETE/PUT/PATCH/listenKey and unknown production mutation surfaces
  forbidden;
- add targeted classifier tests.

Not included:

- building a request preview artifact;
- signing production request metadata;
- sending production HTTP requests;
- production order submission;
- production order mutation, cancel, replace, amend, retry, correction, or
  flatten;
- execution adapter calls;
- listenKey lifecycle;
- real funds;
- production trading;
- Dashboard order controls.

## Acceptance

- Default `POST /api/v3/order` classification returns
  `production_mutation_scope_candidate`, `decision=Deny`, and
  `request_preview_allowed=false`.
- Owner/manual signed preview context can return
  `production_mutation_owner_approved_manual_only`,
  `decision=AllowRequestPreviewOnly`, and `request_preview_allowed=true`.
- Unsigned preview context remains denied.
- DELETE order and listenKey mutation surfaces remain
  `production_mutation_forbidden`.
- `mutation_allowed=false` and `dashboard_order_controls_allowed=false` for all
  mutation-scope classifications.
- Targeted classifier tests, cargo check, clippy, fast verification, formatter,
  and diff hygiene pass.
