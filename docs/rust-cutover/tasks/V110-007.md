# V110-007 Define Reconciliation Event Model for Production Read-Only Shadow

Date: 2026-06-20
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V110-006

## Goal

Define a v0.11 event-driven reconciliation model for production read-only and
shadow evidence. The model separates observed production account/order state
from executable order control and must never create automatic correction orders.

Plain Chinese summary: 本任务只定义“只读 reconciliation 事件”怎么记证据。它可以记录
看到的账户/订单状态、孤儿观察、风险暂停、人工处理线索，但不能自动下纠错单，不能
自动撤单、改单或补单。

## Scope

- Define the local `reconciliation_events` artifact contract.
- Include event types for read-only observations, shadow mismatches, orphan
  observations, degraded status, risk halt, and manual remediation evidence.
- Require all remediation to be manual evidence only in v0.11.
- Keep production order mutation counters at zero.
- Document that observed production state is not executable control authority.

## Non-Goals

- No automatic correction order.
- No production order submission.
- No production cancel, replace, amend, retry, or correction.
- No exchange write endpoint access.
- No live fill reconciliation implementation.
- No Dashboard order controls.

## Acceptance

- `docs/rust-cutover/release/v0_11_0_reconciliation_event_model.md` defines the
  event model, event types, severity, allowed actions, and forbidden actions.
- The release contract explicitly contains:
  - `schema_version=ntpro.v110_reconciliation_event.v1`;
  - `event_type=observed_account_state|observed_order_state|shadow_mismatch|orphan_observation|risk_halt|manual_remediation_required`;
  - `automatic_correction_orders_submitted=0`;
  - `production_orders_submitted=0`;
  - `production_order_mutations_attempted=0`;
  - `cancel_replace_amend_attempted=false`;
  - `dashboard_order_controls_enabled=false`.
- Documentation states that reconciliation events can only produce local
  evidence, degraded status, risk halt, or manual remediation instructions.
- Evidence records rg checks, `scripts/ai/verify_fast.sh`, and
  `git diff --check`.
