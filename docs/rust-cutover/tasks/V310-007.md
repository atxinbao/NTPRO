## Goal

Expose controlled backend enablement state through a read model and read-only
Admin Workbench bridge.

Plain Chinese summary: 本任务让 operator/admin 可以只读查看 enablement candidate
状态，包括 approval、risk/audit、canary、rollback、telemetry/SLO 和 boundary flags。
缺失或 malformed state artifact 必须降级或 fail-closed，不能出现操作控件。

## Scope

- Define enablement state, approval state, risk/audit state, canary state,
  rollback state, telemetry/SLO state, and boundary flags.
- Provide read-only artifact ingestion and rendering evidence for
  admin/operator visibility.
- Preserve disabled operation controls and no order-ticket/trading controls.

## Not Included

- No default production submit capability.
- No production order mutation.
- No adapter send or live exchange request.
- No retry scheduler or automatic remediation.
- No automatic recovery.
- No Dashboard/Admin/Trader Terminal trading controls.
- No product-grade live trading claim.
