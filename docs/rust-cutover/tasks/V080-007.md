# V080-007 Add v0.8 release gate wiring

Date: 2026-06-16
Executor: Codex
Owner role: Verification & Release Gatekeeper
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: AUTO_MERGE_ELIGIBLE_AFTER_OWNER_DOWNGRADE

## Goal

Make the v0.8 authenticated read-only proof track release-grade without making
default CI or release runs depend on real Binance credentials or network access.

Plain language: release gates should prove that v0.8 stays offline by default,
does not leak synthetic secrets, and only allows a real authenticated Binance
testnet account-shape proof when a human explicitly opens the manual online
gate.

## Scope

- Add `scripts/ai/verify_v08_authenticated_readonly_gate.sh`.
- Keep default mode as CI-safe preflight:
  - synthetic env-only credentials are present;
  - `NTPRO_ALLOW_TESTNET_NETWORK` is unset;
  - no socket is opened;
  - no real credentials are required;
  - synthetic credential/signature markers are scanned for leaks.
- Keep real online mode explicit:
  - requires `NTPRO_V08_MANUAL_ONLINE=1`;
  - requires `NTPRO_ALLOW_TESTNET_NETWORK=1`;
  - requires `BINANCE_TESTNET_API_KEY`;
  - requires `BINANCE_TESTNET_API_SECRET`;
  - permits only authenticated read-only `GET /api/v3/account` on Binance testnet.
- Wire release verification stages:
  - `v08-default-offline-gate`;
  - `v08-authenticated-readonly-preflight`.
- Wire hosted release tag workflow for the same default offline/preflight stages.
- Wire PR smoke so v08 script/workflow/config changes run v08 gates.

## Non-Goals

- No default real Binance network in CI.
- No real credential requirement in CI.
- No production Binance connectivity.
- No order submission, cancel, replace, amend, or account mutation.
- No balances/uid/raw account body persistence.
- No GitHub secret setup.

## Acceptance

- `verify_release.sh` exposes `v08-default-offline-gate`.
- `verify_release.sh` exposes `v08-authenticated-readonly-preflight`.
- Release tag workflow includes both v08 stages.
- PR smoke runs both v08 gates when v08 scripts/workflow/config files change.
- Default authenticated preflight passes without real credentials and without
  network access.
- Manual online mode is explicit opt-in only and fails unless required env vars
  are present.
