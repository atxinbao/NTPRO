# V141-006 Dashboard Order-State Read-Only Panel

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Promote the v0.14 production order-state read-only proof into the Dashboard
live-alpha readiness surface as a read-only status panel.

Plain Chinese summary: Dashboard 现在要能看见生产订单状态只读证据。它只展示
`openOrders` / order-state proof 的读取结果、端点、shape、订单数量和生命周期状态，
不提供下单、撤单、改单、重试或重连按钮。

## Scope

Included:

- read `v0_14/production_order_state_readonly_proof.json` from each node artifact root;
- expose order-state read status, endpoint, network/read attempts, shape validation,
  open order count, non-empty observation, lifecycle readiness, truth source, and proof path;
- render these values in the existing Dashboard live-alpha dry-run table;
- keep dry-run boundary fields separate from order-state read-only proof fields;
- add Dashboard unit coverage for empty `openOrders` as readable but not lifecycle-ready.

Not included:

- production order submission;
- production order mutation, cancel, replace, amend, retry, or correction;
- listenKey lifecycle;
- Dashboard order controls;
- reconnect/pause/resume controls;
- trading semantics changes;
- network execution from Dashboard.

## Acceptance

- Dashboard snapshot contains order-state proof fields when the proof artifact exists.
- Empty `openOrders` renders as endpoint readable and shape validated with open order count `0`.
- Empty `openOrders` does not claim order lifecycle readiness.
- Proof `network_attempted=true` is displayed as order-state read evidence and does not
  poison the existing dry-run `network_attempted` boundary.
- Production order/cancel/replace/amend/retry controls remain absent.
