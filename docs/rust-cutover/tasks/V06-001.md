# V06-001 - Binance Testnet Runtime Foundation

Milestone: v0.6.0 Binance testnet dry-run foundation
Priority: P0
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk: medium

## Goal

Introduce the Binance testnet workflow foundation as an offline Rust CLI
artifact path.

## Scope

- Add `binance-testnet` as a workflow kind.
- Generate local foundation artifacts for config, credentials policy,
  connectivity contract, order lifecycle, reconciliation, summary, events, and
  manifest.
- Keep network and real order submission disabled by default.

## Non-goals

- Do not connect to Binance testnet.
- Do not persist credentials.
- Do not submit real orders.
- Do not claim production trading readiness.

## Required evidence

- `cargo test -p nautilus-cli workflow --lib` passes.
- Evidence file exists at `docs/rust-cutover/evidence/V06-001.md`.
