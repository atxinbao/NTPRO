# V150-003 - Execution adapter isolation layer

Date: 2026-06-22
Executor: Codex
Milestone: v0.15.0
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Add a production live-alpha execution dry-run isolation layer that proves a
strategy intent can only reach a local dry-run execution adapter artifact. It
must not instantiate production adapters, call production adapters, open network
connections, or submit/mutate production orders.

Plain Chinese summary: 这个任务只做“隔离层证明”。策略意图可以走到本地
dry-run execution adapter，并写出 JSON 证据；但不能碰真实交易所 adapter，不能发
网络请求，不能真实下单、撤单、改单，也不能打开 Dashboard 下单按钮。

## Scope

Allowed:

- Add a Rust CLI command for v0.15 production live-alpha execution dry-run
  isolation.
- Reuse existing local artifacts:
  - v0.14 dry-run order gate.
  - v0.14 risk preflight.
  - v0.15 request preview.
- Write a stable JSON artifact proving:
  - dry-run adapter path is the only reachable execution path;
  - production adapter is not instantiated or called;
  - production mutation counters remain zero.
- Add local and CI-safe verification.

Out of scope:

- Production execution adapter implementation.
- Production adapter instantiation or calls.
- Network requests.
- Production order submit, cancel, replace, amend, retry, correction, or
  automatic remediation.
- listenKey lifecycle.
- Dashboard order controls.
- Trading semantic changes in `crates/execution` or live runtime.

## Acceptance

- `live production-live-alpha-execution-dry-run` writes an isolation artifact.
- Ready path records:
  - `dry_run_execution_adapter_called=true`
  - `dry_run_execution_adapter_wrote_artifact=true`
  - `real_execution_adapter_called=false`
  - `production_adapter_instantiated=false`
  - `production_adapter_called=false`
  - `strategy_intent_reaches_production_adapter=false`
  - `request_sent=false`
  - `network_attempted=false`
  - `production_orders_submitted=0`
  - `production_order_mutations_attempted=0`
  - `dashboard_order_controls_enabled=false`
- Missing owner gates produce a blocked artifact and do not route to the
  dry-run adapter.
- Source artifact issues block the isolation artifact instead of falling through
  to any adapter path.
