# DRG-001 - State convergence and readiness report refresh

Milestone: v0.2 Design Readiness
Priority: P0
Owner role: Control & Scope
Review role: Verification & Release Gatekeeper
Risk: medium

## Goal

Make repository task state, Shrimp task state, GitHub PR/issue state, leases,
and readiness docs agree before any product design work starts.

## Scope

- Sync `.agentflow/state/task_status.json` with merged PR reality.
- Close or explain stale `PR_OPEN`, `REVIEW_REQUIRED`, and `TODO` states.
- Clean stale leases only when their work is merged or explicitly blocked.
- Refresh `docs/rust-cutover/release/v0_2_readiness_report.md`.
- Record whether `NAUDIT-006` is completed, blocked, or still gating DRG.

## Non-goals

- Do not implement runtime behavior.
- Do not create tags or GitHub Releases.
- Do not modify trading logic.

## Required evidence

- `git status --short --branch`
- `gh pr list --state open`
- `gh issue list --state open`
- Shrimp `list_tasks`
- `scripts/ai/validate_agentflow_roles.py`
- `scripts/ai/verify_fast.sh`

## Acceptance

- `G0 State consistency` is `PASS`.
- No stale completed work remains marked as `PR_OPEN` or `REVIEW_REQUIRED`.
- Any remaining blocker has an explicit owner, risk, and next action.
