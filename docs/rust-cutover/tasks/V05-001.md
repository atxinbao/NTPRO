# V05-001 - workflow CLI contract

Milestone: v0.5.0 local Binance sandbox workflow artifacts
Priority: P0
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk: medium

## Goal

Expose a Rust CLI workflow command for the local Binance sandbox workflow.

## Scope

- Add `nautilus workflow run`.
- Support `--workflow binance-sandbox`, `--run-id`, and `--output`.
- Keep the command sandbox-only and artifact-oriented.

## Non-goals

- Do not connect to real Binance.
- Do not submit real orders.
- Do not claim testnet or production trading support.

## Required evidence

- CLI help includes `workflow run`.
- Parser accepts the workflow options.
- Evidence file exists at `docs/rust-cutover/evidence/V05-001.md`.
