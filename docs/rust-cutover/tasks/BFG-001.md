# BFG-001 v0.32.0 backend freeze registry and governance policy

Date: 2026-07-15
Executor: Codex
GitHub issue: #1068
Milestone: backend-freeze-governance
Status: READY FOR PR

## Goal

Freeze `ntpro-rust-only-v0.32.0` as the NTPRO backend baseline and add a
machine-readable registry plus a human-readable governance policy for all
post-baseline work.

Plain Chinese summary: 本任务把已发布的 v0.32.0 固定为后端基线冻结点。后续清理、
前端和产品工作在基线后的治理层进行，不改写已发布 tag、release 或 v0.32.0 release
package。默认不创建 v0.32.1；只有基线证据被证明失效时，才能单独提出修复版本。

## Dependency

None. This is the root task for GitHub issue #1068 and milestone #31.

## Scope

Included:

- register the published tag object, peeled commit, GitHub Release, hosted gate,
  milestone, exact issue set, source evidence hashes, and boundary flags;
- define immutable baseline, errata, exception, and v0.33+ intake rules;
- provide a governance index for later BFG tasks.

Not included:

- modifying any `v0_32_0_*` release file;
- publishing a v0.32.1 backend patch;
- changing runtime behavior, trading semantics, public APIs, or production
  execution authority.

## Acceptance Criteria

- `backend_freeze_registry.json` parses and pins the live v0.32.0 facts.
- Every v0.32.0 manifest boundary flag remains explicit `false`.
- The policy requires `source_tree_plus_github_remote` reconstruction.
- The policy routes documentary corrections through post-baseline errata.
- v0.33+ is separately scoped and inherits no forbidden backend capability.

Local validation passed. The registry matches the v0.32.0 release manifest,
all registered source hashes match, the GitHub publication guard reconstructs
the published release, and both v32 release gates and strict provenance pass.
