## Goal

Remove confirmed repository filesystem noise while retaining untracked or
ignored state whose ownership or reconstruction cost requires a later decision.

Plain Chinese summary: 本任务只删除 8 个 Finder `.DS_Store`。本地审查报告
`project.html` 继续保留并加入本地 exclude；`.agentflow`、`.codex`、
`.understand-anything` 和大型测试数据都不删除，也不进入 PR。

## Dependency

BFH-001 (`#1112`) is closed through merged PR `#1127`.

## Scope

- remove all `.DS_Store` files outside pruned repository metadata/build paths;
- inspect and classify `project.html`;
- add a local-only exclude for retained `project.html`;
- record ownership and size for ignored local analysis and large-test-data
  paths;
- update the hygiene authority map with the resolved disposition.

## Not In Scope

- tracked source, docs, fixtures, schemas, or release evidence deletion;
- deletion of local analysis directories or ignored large test data;
- `git clean -fxd`, `make distclean`, or any broad untracked-file deletion;
- runtime or public API changes.

## Acceptance Criteria

- `.DS_Store` recount is zero;
- `project.html` is retained, classified, and excluded locally;
- no tracked source or user-owned local path is deleted;
- tracked PR files contain only task, evidence, and authority-map updates;
- the backend freeze gate passes.
