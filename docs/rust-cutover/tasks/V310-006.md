## Goal

Require telemetry, SLO, and incident readiness before controlled backend
production enablement can be considered.

Plain Chinese summary: 本任务把 telemetry freshness、SLO health、alert routing、
incident owner 和 escalation readiness 作为 v31 enablement candidate 的前置门禁。
缺失/陈旧 observability、SLO degraded、incident active 都必须 fail-closed。

## Scope

- Define telemetry freshness, SLO health, alert routing, incident owner, and
  escalation readiness evidence.
- Add candidate states for healthy, degraded, stale, missing, and
  incident-active.
- Require fail-closed behavior when observability or incident response is not
  ready.

## Not Included

- No default production submit capability.
- No production order mutation.
- No adapter send or live exchange request.
- No retry scheduler or automatic remediation.
- No automatic recovery.
- No Dashboard/Admin/Trader Terminal trading controls.
- No product-grade live trading claim.
