## Goal

Make release body hash semantics explicit so raw body hashes and normalized
content hashes cannot be confused during release audits.

Plain Chinese summary: 本任务明确 release body 的验收规则是 normalized SHA-256，
不是 raw SHA-256。它修正文档和 guard 输出，让审计者能看出 raw hash 只是诊断值，
normalized hash 才是发布通过条件。它不改变 runtime，也不新增交易能力。
