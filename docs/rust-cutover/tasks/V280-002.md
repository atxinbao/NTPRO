## Goal

Move external identity and permission integration from foundation evidence to a
deterministic backend closure artifact with replayable read/admin permission
validation.

Plain Chinese summary: 本任务把 identity/permission runtime closure 固化成一个可复放的
backend artifact。它只允许 read/admin 权限，验证 identity source、permission mapping、
freshness、provenance、redaction 和 lineage；权限漂移、过期来源、缺 provenance、交易权限打开
都会 fail closed。本任务不接入真实外部 IdP/SSO，不授权 live operation，也不开放任何交易控制。

## Dependency

- Depends on `V280-001` backend closure boundary contract and readiness matrix.
- Depends on `V280-000` v0.27.1 release dependency proof.
- Uses `V270-002` identity/permission foundation and `V260-002` permission
  boundary as historical evidence.
- Does not inherit any submit, mutation, adapter-send, live-exchange,
  remediation, Dashboard/Admin trading-control, or product-grade terminal
  capability.

## Scope

Included:

- Define a deterministic identity/permission runtime artifact path.
- Define identity source ingestion requirements.
- Define permission mapping, freshness, provenance, redaction, and lineage
  requirements.
- Replay allowed read/admin permissions.
- Fail closed on missing provenance, stale source, permission drift, and
  forbidden trading permission.
- Document unsupported external IdP/SSO behavior.
- Promote `identity_permission_runtime_closure` to `runtime-closed` in the
  v0.28.0 backend closure readiness matrix.

Not included:

- live SSO/OAuth/SAML token verification;
- dynamic external IdP group sync;
- production order submission;
- cancel, replace, amend, flatten, or any production order mutation;
- execution adapter call, adapter send, or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin trading controls;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- Identity/permission state can be replayed through a deterministic backend
  artifact path.
- Permission drift, stale source, missing provenance, and forbidden trading
  permission fail closed.
- Allowed read/admin permissions replay successfully.
- No live operation authorization is implied.
- `scripts/ai/verify_release.sh v28-identity-permission-runtime-closure`
  passes.
- `scripts/ai/verify_release.sh v28-backend-closure-boundary-contract` passes
  after the matrix promotion.
