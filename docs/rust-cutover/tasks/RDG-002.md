# RDG-002 Compress and localize the root README

Date: 2026-07-28
Executor: Codex
GitHub issue: `#1157`
Risk: medium
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Auto-merge: not requested
Status: `READY_FOR_PR`

## Goal

把根目录 `README.md` 从历史发布流水账压缩为中文项目入口，保留项目定位、
正式版本、能力边界、运行方式、验证命令和权威文档导航。

## Scope

- 中文化 README 主体；
- 删除重复历史版本清单、重复能力描述和过时发布说明；
- 保留 release-surface 与 backend-freeze 机器标记；
- 将历史、路线、发布证据和详细治理内容指向权威文档。

## Not in scope

- 运行时、API、交易语义、adapter、schema 或存储变更；
- tag、GitHub Release、milestone 或 workflow 变更；
- 修改 `docs/rust-cutover/release/v0_32_0_*`；
- 改写历史 evidence。

## Acceptance criteria

- README 主体为中文，行数和字节数显著减少；
- 当前版本、能力边界、快速开始和文档导航完整；
- README 本地链接有效；
- current-governance、backend-freeze、docs/examples 和 Rust-only 检查通过；
- 根目录文档集合不变，无生成物残留。
