# V140-004 Risk Preflight for Hypothetical Live Order

Date: 2026-06-22
Executor: Codex
Risk: medium

## Goal

Add a local risk preflight artifact for hypothetical live-alpha orders while
keeping execution disabled.

Plain Chinese summary: 这个任务只判断“如果未来要下这笔实盘 Alpha 订单，当前风控干跑是否
会放行”。它只读本地 JSON，输出 `dry_run_approved` 或 `dry_run_rejected`，同时固定输出
`execution_decision=blocked_no_production_mutation`。它不会调用交易网关，也不会提交、撤销或修改真实订单。

## Scope

Included:

- add `live production-live-alpha-risk-preflight`;
- read the V140-003 dry-run order gate artifact;
- read a local v0.14 risk preflight input JSON;
- output `risk_decision=dry_run_approved|dry_run_rejected`;
- output `execution_decision=blocked_no_production_mutation`;
- reject kill switch, stale market, account read failure, order-state read
  failure, order notional limit, position limit, open-order limit, and clock
  skew limit;
- record no-execution/no-production-mutation counters;
- add `scripts/ai/verify_v14_live_alpha_risk_preflight.sh`;
- add targeted parser and live tests.

Not included:

- production order submission;
- production order mutation, cancel, replace, amend, retry, or correction;
- execution adapter calls;
- network access;
- listenKey lifecycle;
- Dashboard order controls;
- real funds or real orders.

## Acceptance

- Approved path writes `risk_decision=dry_run_approved`,
  `execution_decision=blocked_no_production_mutation`, and no rejection
  reasons.
- Rejected path covers kill switch active, stale market, account read failed,
  order-state read failed, notional limit, position limit, and open-order limit.
- Artifact records `execution_adapter_called=false`,
  `order_endpoint_access_attempted=false`, `production_orders_submitted=0`,
  `production_order_mutations_attempted=0`, `network_attempted=false`, and
  `dashboard_order_controls_enabled=false`.
- Targeted tests, local verification script, formatter, and diff hygiene pass.
