# V150-006 - Dry-run mutation golden traces

Date: 2026-06-22
Executor: Codex
Milestone: v0.15.0
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Add executable golden traces for the v0.15 production live-alpha mutation
dry-run path. The traces must cover rejection and preflight states before any
production order submission, production order mutation, network access,
production execution adapter call, listenKey lifecycle, real funds, production
trading, or Dashboard order control path.

Plain Chinese summary: 这个任务不是开放实盘下单，而是给 v0.15 的“实盘 mutation
干跑链路”补金标准回放。每条 trace 都要证明：被挡住或只走本地 dry-run adapter，
不会真实下单、不会改单/撤单、不会联网、不会碰生产 adapter。

## Scope

Allowed:

- Add `tests/golden/live_alpha_mutation_dry_run_schema.jsonl`.
- Add an executable Rust replay harness for those traces.
- Register the new trace cases in the golden trace release scope manifest.
- Wire the replay harness into local full verification and release gate stages.
- Cover:
  - kill switch active
  - missing approval
  - approval expired
  - symbol not allowlisted
  - notional too large
  - order-state stale
  - account unreadable
  - network disabled
  - Dashboard control attempted

Out of scope:

- Production order submission.
- Production cancel, replace, amend, retry, correction, or remediation.
- Production HTTP request execution.
- Production adapter implementation, instantiation, or call.
- listenKey lifecycle.
- Real funds.
- Production trading.
- Dashboard order controls.
- Trading semantic changes in live runtime, risk, portfolio, execution, or
  adapters.

## Acceptance

- Golden trace JSONL validates under the shared golden trace schema.
- The Rust replay harness executes all nine trace cases through the CLI.
- Each replayed expected event proves:
  - `production_orders_submitted=0`
  - `production_order_mutations_attempted=0`
  - `network_attempted=false`
  - `execution_adapter_called=false`
- `run_golden_traces.sh` runs the new replay harness by default.
- `verify_full.sh golden-traces-live-alpha-mutation-dry-run` runs the new replay
  harness.
- `RELEASE_REPLAY_SCOPE.json` includes all new cases as executable replay.
- PR hosted smoke runs the new replay harness when V150-006 files change.
