# V090-006 Define and Write Order Intent Artifact Contract

Date: 2026-06-18
Executor: Codex
Owner role: Rust Core Runtime Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V090-005

## Goal

Allow strategies to produce order intents while v0.9.0 still forbids exchange
order submission.

## Automation Scope

This is a medium-risk automation slice because order intents are artifacts only.
They must not be exchange orders and must not invoke submit/cancel/replace/amend
APIs.

## Artifact

```text
strategy/order_intent.jsonl
schema_version = ntpro.v09_order_intent.v1
```

## Hard Rule

v0.9.0 order intents may only flow into risk decision. They must not enter an
execution adapter.

## Acceptance

- Signal can become order intent.
- `order_intent.submission_allowed = false`.
- No exchange order API is called.
