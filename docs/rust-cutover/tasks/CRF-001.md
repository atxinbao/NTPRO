# CRF-001 Cache Market-Data Persistence Fail-Closed

Date: 2026-07-29
Executor: Codex
GitHub issue: #1164
Risk: high
Classification: baseline-preserving-governance
Status: READY_FOR_REVIEW

## Goal

Eliminate silent success when `CacheConfig.save_market_data=true` and a
single market-data update cannot be persisted by the configured backing
database.

中文摘要：缓存配置要求落盘时，单条 mark price、index price、funding rate
和 instrument status 必须真正调用数据库适配器；不支持或写入失败时必须返回错误，
不能只写内存后向调用方报告成功。

## Scope

- add source-compatible default persistence methods for mark price, index price,
  and instrument status;
- route single funding-rate writes through the existing database adapter method;
- preserve memory-only behavior when no database is configured;
- add regression tests for unsupported adapters and database failures.

## Non-Goals

- no database schema or storage implementation expansion;
- no change to market-data values or trading semantics;
- no edit to frozen `docs/rust-cutover/release/v0_32_0_*` files;
- no production capability or release claim.

## Acceptance

- unsupported persistence returns a descriptive error;
- a failed persistence attempt does not mutate the in-memory cache;
- single funding-rate database failures are propagated;
- targeted tests, formatting, Clippy, and governance checks pass.
