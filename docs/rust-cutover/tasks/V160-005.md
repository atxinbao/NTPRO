# V160-005 - Add guarded production HTTP send path

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.0 minimum owner-approved production order mutation candidate
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Add the single v0.16 guarded HTTP send path for the minimum owner-approved
production order mutation candidate.

Plain Chinese summary: 这个任务加的是“最后真正可能发出 HTTP 下单请求的受控通道”。
大白话：默认情况下它只检查 send path，绝不联网；只有 owner 显式加
`--manual-online`，同时 CLI 确认和环境变量 gate 全部打开，才允许尝试一次单笔极小
`LIMIT GTC` 生产 HTTP 请求。它不是策略实盘交易入口。

## Scope

Included:

- add `live production-mutation-guarded-send`;
- write `ntpro.v160_production_mutation_guarded_send.v1` artifact;
- accept ready v0.16 request-builder artifact and v0.15 production request
  preview as inputs;
- prove the default/offline path evaluates the guarded send state with
  `request_sent=false` and `network_attempted=false`;
- require explicit `--manual-online` before any network attempt;
- require owner CLI confirmations for single-shot, tiny notional, no retry,
  no secret persistence, response redaction, Dashboard controls disabled, and
  no listenKey lifecycle;
- require env gates for production signing material and production HTTP send
  before manual-online can read credentials;
- execute at most one `POST /api/v3/order` attempt in manual owner mode;
- record only status code, latency, and redacted error classification after a
  manual send attempt;
- keep API key value, API secret value, signature, signed query, signed URL,
  raw request body, and raw exchange response unpersisted.

Not included:

- strategy-driven live trading;
- automatic production order submission;
- MARKET orders;
- cancel, replace, amend, retry, correction, or flatten;
- multi-order execution;
- response body persistence;
- post-submit order-state readback;
- listenKey/WebSocket user stream lifecycle;
- Dashboard order controls;
- multi-venue or multi-account execution;
- trading engine semantic changes.

## Acceptance Criteria

- Missing owner confirmations produce `blocked_missing_gate`.
- Ready offline source artifacts produce
  `ready_guarded_send_path_offline_no_network`.
- Manual-online without env gates produces `blocked_missing_manual_online_gate`.
- Ready offline artifact records:
  - `guarded_send_ready=true`;
  - `send_path_evaluated=true`;
  - `manual_online_requested=false`;
  - `single_shot_send_allowed=false`;
  - `request_builder_status=ready_request_object_built_no_send`;
  - `request_object_built=true`;
  - `request_method=POST`;
  - `request_target=/api/v3/order`;
  - `order_type=LIMIT`;
  - `time_in_force=GTC`;
  - `request_sent=false`;
  - `network_attempted=false`;
  - `production_order_submission_allowed=false`;
  - `production_order_mutation_allowed=false`;
  - `production_order_state_reads_allowed=false`;
  - `listen_key_lifecycle_allowed=false`;
  - `production_order_submissions_attempted=0`;
  - `production_orders_submitted=0`;
  - `production_order_mutations_attempted=0`;
  - `retry_attempted=false`;
  - `cancel_attempted=false`;
  - `replace_attempted=false`;
  - `amend_attempted=false`;
  - `flatten_attempted=false`;
  - `dashboard_order_controls_enabled=false`;
  - `api_key_value_recorded=false`;
  - `api_secret_value_recorded=false`;
  - `signature_recorded=false`;
  - `signed_query_recorded=false`;
  - `signed_url_recorded=false`;
  - `raw_exchange_response_recorded=false`.
