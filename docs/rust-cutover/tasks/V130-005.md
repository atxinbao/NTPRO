# V130-005 - Trader/Ops Dashboard Control Boundary

Date: 2026-06-21
Executor: Codex

## Goal

Define and verify the v0.13 trader/ops Dashboard control boundary for Guarded
Live Alpha Preflight.

Plain Chinese summary: 这个任务不是做交易终端下单按钮。它只是把 Dashboard
在 v0.13 能做和不能做的事写清楚：交易员能看状态和证据，运维能做本地节点生命周期
控制；生产下单、撤单、改单、重试、纠错、listenKey、密钥输入、真实资金交易控件仍然
全部没有。

## Scope

Included:

- trader-visible read-only status boundary for local, shadow, and proof
  artifacts;
- ops-visible local supervisor lifecycle controls:
  `start`, `stop`, `pause`, `resume`, `reconnect_data`,
  `reconnect_execution`;
- explicit documentation that v0.13 Dashboard reconnect controls only record
  local sandbox unsupported status and do not reconnect production venues;
- Dashboard unit tests proving forbidden order-control action names and routes
  remain absent;
- local verification script
  `scripts/ai/verify_v13_dashboard_control_boundary.sh`;
- release/evidence documentation for the v0.13 Dashboard no-mutation boundary.

Not included:

- production order submission;
- production cancel / replace / amend / retry / correction;
- production order-state reads;
- listenKey lifecycle management;
- signed WebSocket user stream runtime;
- Dashboard credential entry;
- Dashboard order, cancel, replace, amend, retry, correction, flatten, or
  production reconnect controls;
- automatic remediation;
- real funds or production trading.

## Acceptance

- Dashboard boundary tests pass:
  `cargo test -p nautilus-cli dashboard_trader_ops_boundary --lib`.
- HTTP forbidden route test passes:
  `cargo test -p nautilus-cli dashboard_http_server_rejects_v13_production_order_control_routes --lib`.
- Local boundary gate passes:
  `scripts/ai/verify_v13_dashboard_control_boundary.sh`.
- Fast gate passes: `scripts/ai/verify_fast.sh`.
- Diff hygiene passes: `git diff --check`.
