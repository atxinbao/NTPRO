# V091-002 Unify StrategyNode Config Validation

Date: 2026-06-18
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V091-001

## Goal

Make CLI `config validate --kind strategy-session` and `ntpro-node` runtime
load the same `StrategyNodeConfig` contract.

## Scope

- Introduce or consolidate shared config types for node, strategy, market,
  shadow execution, and risk config.
- Ensure CLI validation and node runtime call the same load/validate path.
- Require `node_id`, disabled order submission, and v0.9.1 risk defaults.
- Reject multi-symbol configs until V091 explicitly supports them.

## Acceptance

- A config that passes CLI validation can start the v0.9.1 node path.
- A config that fails node runtime validation also fails CLI validation.
- Multi-symbol strategy configs fail with a clear message.
- No Binance network or order submission path is enabled.
