# V241-005 - Dashboard artifact ingestion hardening

Date: 2026-07-05
Executor: Codex
GitHub issue: #774
Milestone: v0.24.1
Status: IMPLEMENTED

## Goal

Harden the Dashboard read-model artifact ingestion path for v24 order-control
preview data. The gate must prove malformed, malicious, stale, scope-mismatched,
or unredacted artifacts do not render as ready and do not expose operation
controls.

Plain Chinese summary: 本任务强化 Dashboard 读取 v24 order-control preview
artifact 的真实路径。恶意 artifact 即使把 submit、order ticket 或 manual submit
边界写成 `true`，Dashboard runtime 也会 fail closed；stale、缺失 provenance、
scope mismatch、缺失 redaction 都不能显示成 ready。界面仍然只读，不新增任何下单、
撤单、重试、replace、amend、flatten 或订单票据控件。

## Scope

- Add v24 artifact-ingestion diagnostics in `crates/cli/src/dashboard.rs`.
