# RDG-001 Consolidate the root documentation surface

Date: 2026-07-28
Executor: Codex
GitHub issue: `#1155`
Risk: medium
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Auto-merge: not requested
Status: `READY_FOR_PR`

## Goal

Align the NTPRO repository root with the QSTR project-document pattern while
preserving active governance, legal, product, and audit authority.

中文摘要：根目录 Markdown 收敛为 `AGENTS.md` 和 `README.md`，项目定义与项目
变更分别由 tracked `project.html` 和 `changelog.html` 承接。其他根级 Markdown
根据职责迁入 `.github/`、`docs/product/`、`docs/governance/`、开发指南、归档或
Rust cutover evidence，不直接丢弃仍有审计价值的内容。

## Dependencies

- PDG-001 / GitHub issue `#1153` is closed through merged PR `#1154`.
- v0.32.0 remains the frozen backend baseline.

## Scope

- move ten root Markdown files to canonical subdirectories;
- add and cross-link the two root HTML project pages;
- update README with the root documentation contract;
- update active links, CODEOWNERS, Rust governance defaults, and shell guards;
- enforce the exact root documentation surface in Rust docs governance;
- preserve historical release and verification records outside the root.

## Not in scope

- runtime, adapter, persistence, schema, precision, or trading semantics;
- release tag, manifest, milestone, or workflow changes;
- modifying `docs/rust-cutover/release/v0_32_0_*`;
- treating HTML product architecture as implementation evidence.

## Acceptance criteria

- root `*.md` files are exactly `AGENTS.md` and `README.md`;
- `project.html` and `changelog.html` are tracked, Chinese, responsive, and
  cross-linked;
- all active moved-document links resolve;
- current governance consumes relocated roadmap and contributing paths;
- archived release and verification history remains available;
- targeted Rust tests, docs/examples, current governance, backend freeze,
  Rust-only, HTML smoke, and diff checks pass;
- no generated build or analysis artifact remains.
