# V061-005 - Audit manifest child artifacts in Dashboard health evaluation

Milestone: v0.6.1 offline hardening
Priority: P0
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk: medium

## Goal

Make the local Dashboard evaluate workflow artifact health from the manifest and
the manifest's referenced child artifacts, not from manifest top-level fields
alone.

## Scope

- Parse `manifest.artifacts[]` in Dashboard workflow artifact reader.
- Check referenced child artifact files exist.
- Check JSON child artifacts parse and expose the expected `schema_version`.
- Check JSONL child artifacts parse line-by-line and expose the expected
  `schema_version`.
- Record Dashboard gaps for missing, invalid, or schema-mismatched child
  artifacts.
- Degrade the workflow health when child artifact audit fails.
- Keep the v0.6 dry-run verification script aligned with the child-artifact
  schema contract.

## Non-goals

- Do not connect to Binance testnet.
- Do not submit orders.
- Do not read secrets.
- Do not redesign the workflow artifact format.
- Do not implement the shared DTO extraction reserved for V061-007.
- Do not change supervisor control semantics.

## Required Evidence

- Deleting `testnet/credential_policy.json` or referencing it without the file
  creates a Dashboard gap and degrades workflow health.
- Breaking `events.jsonl` creates a Dashboard gap and degrades workflow health.
- `cargo test -p nautilus-cli dashboard --lib` passes.
- `scripts/ai/verify_v06_binance_testnet_dry_run.sh` passes.
- `scripts/ai/verify_fast.sh` passes.
- `git diff --check` passes.
