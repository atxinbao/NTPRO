# V110-006 Define Order Lifecycle State Model for Shadow/Read-Only Paths

Date: 2026-06-20
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V110-005

## Goal

Define a standard v0.11 order lifecycle state model for local shadow/read-only
evidence. The model records how shadow intents move through validation and
risk/readiness decisions, but it must not enable production order mutation.

Plain Chinese summary: 本任务只定义“影子/只读订单生命周期状态”怎么记证据。它可以
把本地 shadow intent 标成 Created、Validated、PreflightPassed、Rejected 等状态，
但不能把这些状态当成真实交易所订单状态，不能下单、撤单或改单。

## Scope

- Define the local `order_lifecycle_state` artifact contract.
- Define states for shadow/read-only evidence:
  - `Created`
  - `Validated`
  - `PreflightPassed`
  - `ShadowSubmitted`
  - `Rejected`
  - `ObservedOnly`
  - `Orphaned`
  - `Halted`
- Require every lifecycle event to record `actual_submission=false`.
- Require production mutation counters to remain zero.
- Document that exchange submit/cancel/replace remains disabled in v0.11.

## Non-Goals

- No production order submission.
- No production cancel, replace, amend, retry, or correction orders.
- No exchange order lifecycle parity claim.
- No fill lifecycle implementation.
- No adapter behavior change.
- No Dashboard order controls.

## Acceptance

- `docs/rust-cutover/release/v0_11_0_order_lifecycle_state_model.md` defines
  the state model, allowed transitions, forbidden transitions, and boundary.
- The release contract explicitly contains:
  - `schema_version=ntpro.v110_order_lifecycle_state.v1`;
  - `actual_submission=false`;
  - `production_orders_submitted=0`;
  - `production_order_mutations_attempted=0`;
  - `exchange_order_id_recorded=false`;
  - `venue_order_id_recorded=false`;
  - `dashboard_order_controls_enabled=false`.
- Documentation states that `ShadowSubmitted` means submitted to the local
  shadow ledger only, not to an exchange.
- Evidence records rg checks, `scripts/ai/verify_fast.sh`, and
  `git diff --check`.
