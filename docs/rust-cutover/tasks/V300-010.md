## Goal

Create go/no-go runbook and live readiness decision record for the v0.30.0
backend go-live candidate foundation.

Plain Chinese summary: 本任务为 v0.30.0 建立 go/no-go runbook 和 live readiness
decision record。它定义 required inputs、decision owners、checklist gates、
freeze/abort criteria 和 rollback references，并产出 ready、degraded、blocked、
aborted 四类 deterministic decision records。Ready 只表示 candidate-ready，不表示
actual production go-live，也不会开启 production execution。

## Scope

Included:

- Define required inputs, decision owners, checklist gates, freeze/abort
  criteria, and rollback references.
- Define deterministic decision record artifacts for ready, degraded, blocked,
  and aborted outcomes.
- Prove missing, stale, blocked, and active-freeze states fail closed.
- Add deterministic JSON and executable verifier.

Not included:

- actual backend production go-live;
- default production submit;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler;
- automatic remediation;
- Dashboard/Admin/Trader Terminal operation controls or trading controls;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- Decision record fails closed when any required gate is missing, stale, or
  blocked.
- Ready outcome means candidate-ready only, not actual production go-live.
- The go/no-go record cannot itself enable production execution.
