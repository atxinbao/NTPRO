# V150-009 v0.15 Release Gates

Date: 2026-06-22
Executor: Codex
Risk: medium
Auto-merge: allowed

## Goal

Wire the v0.15 mutation-scope and execution dry-run harness into local release
verification, PR smoke, and tag-triggered release gates.

Plain Chinese summary: 这个任务是把 v0.15 的发布门禁接起来。它不是开放实盘下单，
也不是开放撤单、改单、重试或修正。它只证明 v0.15 仍然停在“请求预览 + dry-run
执行证据 + 人工审批 + kill switch + Dashboard 只读查看”的边界内。

## Scope

Allowed:

- add an aggregate v0.15 release gate script;
- add `verify_release.sh v15-release-gates`;
- run the v0.15 dry-run, approval, isolation, kill-switch, rollback, Dashboard,
  and golden trace checks together;
- wire the aggregate gate into PR smoke and the tag release workflow.

Not allowed:

- production order submission;
- production cancel, replace, amend, retry, correction, flatten, or remediation;
- production execution adapter calls;
- network access by default automation;
- listenKey lifecycle;
- real funds;
- production trading;
- Dashboard order controls;
- trading semantic changes.

## Acceptance

The task is done when:

- `scripts/ai/verify_v15_release_gates.sh` exists and passes locally;
- `scripts/ai/verify_release.sh v15-release-gates` passes locally using release
  binaries;
- `.github/workflows/rust-cutover-smoke.yml` runs the v15 aggregate gate for
  relevant PR changes;
- `.github/workflows/release-tag.yml` includes the v15 aggregate gate;
- the gate fails if logs show request sending, network access, production order
  submission, production order mutation, production adapter calls, real funds,
  production trading, or Dashboard order controls;
- release evidence is recorded under `docs/rust-cutover/evidence/V150-009.md`.
