# S1-BT-004 - Backtest 风险、回撤、运行记录与来源明细

Date: 2026-08-09
Executor: Codex
GitHub issue: #1276
Risk: high
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Status: DONE

## 目标

把同一次 `BacktestEngine` 执行产生的风险、回撤、结构化运行记录和来源链写入独立的
不可变 `analysis.json`，通过严格校验的只读 Product API 提供给策略工作台 Run 详情页。

## 范围

- 保持 `summary.json` 和 `details.json` 既有 v1 合同不变；
- 新增 `ntpro.backtest_analysis.v1`，绑定同次执行的 summary/details SHA-256；
- 从账户权益序列确定性计算逐点回撤与最大回撤摘要；
- 从运行边界、权益、成交与持仓投影有序结构化事件，不抓取终端 stdout；
- 新增 `GET /api/product/v1/runs/{run_id}/analysis` 及 OpenAPI/TypeScript/Zod 合同；
- 策略工作台展示风险摘要、回撤曲线、运行记录和来源哈希；
- 增加确定性、篡改、缺失、符号链接、错误方法、角色与浏览器测试。

## 非目标

- 不实现多 Run 比较或确定性复现入口；
- 不创建 Demo 或 Live Run，不连接外部 Venue，不提交真实订单；
- 不修改 BacktestEngine 撮合、账户、持仓或现有统计语义；
- 不修改 v0.32.0 发布冻结文件。

## Post-freeze 例外

`crates/cli/src/dashboard/server.rs` 是 MVP frozen source。Issue #1276 登记独立的
post-freeze 产品扩展：仅新增受既有产品角色保护的只读 analysis 路由，并更新 freeze
manifest 中该文件的精确 SHA-256。MVP 拓扑、退出条件和禁止能力边界保持不变。

## 完成条件

本任务为 high risk。必须通过本地 Rust、API 合同、前端、浏览器与治理验证，取得独立
Gatekeeper 的 `REVIEW_APPROVED`，通过 hosted checks 后手动合并；禁止 auto-merge。
