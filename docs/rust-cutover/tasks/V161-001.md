# V161-001 - Clarify guarded send counters

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.1 guarded production mutation hardening
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Clarify the v0.16 guarded-send evidence counters without expanding the
minimum owner-approved production order mutation candidate capability.

Plain Chinese summary: 这个任务只把“有没有尝试、有没有发 HTTP、有没有收到交易所
ack、有没有确认提交、是否代表平台实盘已开启”这些字段拆清楚。大白话：它不新增下单
能力，只修正证据口径，避免看到 `request_sent=true` 却不知道到底算不算提交。

## Scope

Included:

- keep the existing guarded-send artifact schema version;
- keep default/offline guarded-send behavior unchanged;
- add explicit fields for request attempt, HTTP send attempt, exchange ack,
  exchange order id/status observation, confirmed submission, and platform
  trading enabled semantics;
- keep `production_trading_enabled=false` for the single guarded-send candidate;
- count a successful HTTP 2xx guarded-send result as exchange acknowledgement
  and one confirmed production order submission;
- keep exchange order id/status observation false in the guarded-send artifact,
  because response body persistence remains forbidden there;
- update the v0.16 guarded-send verifier to assert the default/offline and
  blocked paths remain no-send/no-network/no-order.

Not included:

- strategy-driven production execution;
- multi-order or batch production execution;
- MARKET orders;
- cancel, replace, amend, retry, correction, flatten, or remediation;
- Dashboard order controls;
- response body persistence in guarded-send artifacts;
- production trading platform capability claim.

## Acceptance Criteria

- Default/offline guarded-send artifact records:
  - `request_sent=false`;
  - `production_order_request_attempted=false`;
  - `http_send_attempted=false`;
  - `exchange_ack_observed=false`;
  - `exchange_order_id_observed=false`;
  - `exchange_order_status_observed=false`;
  - `confirmed_production_order_submission=false`;
  - `production_order_submissions_attempted=0`;
  - `production_orders_submitted=0`;
  - `production_order_mutations_attempted=0`;
  - `platform_production_trading_enabled=false`;
  - `production_trading_enabled=false`.
- Manual-online failure without exchange acknowledgement can record an attempt
  without claiming a confirmed submission.
- Manual-online mocked/unit HTTP 2xx acknowledgement records one confirmed
  production order submission.
- Existing response redaction and audit artifacts continue to consume the
  guarded-send counters without enabling platform trading.
