# V111-003 Add Production Shadow Manifest Contract

Date: 2026-06-20
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V111-002

## Goal

Define and validate `v0_11/manifest.json` for production shadow artifacts with
schema, paths, record counts, checksums, required/optional flags, and
`generated_at` metadata.

Plain Chinese summary: 这次给 v0.11 production shadow 工件加一个“目录清单”。
Dashboard 可以看 manifest 里的文件路径、记录数和 checksum，确认本地 shadow 证据是否
完整；但它仍然不联网、不读取生产、不下单。

## Scope

- Add the v0.11.1 production shadow manifest release contract.
- Make Dashboard read and audit `artifact_root/v0_11/manifest.json` when present.
- Keep old direct artifact display working when the manifest is absent.
- Add tests for valid manifest display and checksum mismatch degradation.
- Wire the manifest test into the existing v11 offline release gate script.

## Non-Goals

- No production network connection.
- No production online read runtime.
- No production order submission.
- No production cancel, replace, amend, retry, or correction.
- No Dashboard order controls.
- No raw production account payload persistence.
- No credentials, signed queries, or signed URL persistence.
- No new release tag or GitHub Release publication.

## Acceptance

- `docs/rust-cutover/release/v0_11_1_production_shadow_manifest.md` defines the
  manifest schema and boundary.
- Dashboard exposes manifest status, manifest artifact count, and manifest path
  in the production shadow snapshot.
- Dashboard marks production shadow degraded when manifest child artifact
  checksums do not match.
- `cargo test -p nautilus-cli production_shadow --lib` passes.
- `scripts/ai/verify_v11_offline_release_gates.sh` includes the manifest test.
- `scripts/ai/verify_fast.sh` passes.
- `git diff --check` passes.
