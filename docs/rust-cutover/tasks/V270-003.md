## Goal

Define the v0.27.0 persistent operation audit storage integration foundation.
The task adds an append-only audit sink contract, storage provenance, retention
metadata, and store/source reconciliation evidence without turning audit records
into operation execution.

Plain Chinese summary: 本任务定义 v0.27.0 的 persistent operation audit storage
foundation。它只验证 append-only audit sink、storage provenance、actor/role/scope、
sequence/hash lineage、redaction、retention metadata 和 store/source drift；不新增真实
操作执行、remediation、adapter send、live exchange request、Dashboard controls 或
product-grade live trading terminal 声明。

## Dependency

- Depends on `V270-001` product operations runtime integration boundary
  contract.
- Depends on `V270-002` external identity and permission integration
  foundation for actor/role/scope evidence.
- Uses `V260-003` operation audit trail as the immutable audit chain baseline.
- Does not implement an external audit database or execute audit actions.

## Scope

Included:

- Define append-only audit sink contract and storage provenance.
- Define persistent record fields for actor, role, scope, source event,
  sequence/hash lineage, redaction status, retention metadata, and store/source
  reconciliation.
- Add fail-closed cases for missing lineage, mutable storage claims, missing
  retention metadata, unredacted payloads, store/source drift, and forbidden
  operation triggers.
- Add a verifier that recomputes persistent audit storage status from the
  trace.
- Record the trace rows in the release replay scope as validator executable
  replay.

Not included:

- external audit database implementation;
- operation intent execution;
- live control API;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard operation controls or Dashboard trading controls.

## Acceptance Criteria

- Valid storage evidence is accepted only when append-only sink provenance,
  actor/role/scope, sequence/hash lineage, redaction, retention metadata, and
  store/source reconciliation are complete.
- Missing lineage fails closed.
- Mutable storage claims fail closed.
- Missing retention metadata fails closed.
- Unredacted payloads fail closed.
- Store/source drift fails closed.
- Any audit record that triggers remediation, trading mutation, adapter send,
  live exchange request, retry scheduler, or Dashboard controls fails closed.
- `scripts/ai/verify_release.sh v27-persistent-audit-storage-foundation`
  passes.
- `docs/rust-cutover/golden_trace/RELEASE_REPLAY_SCOPE.json` records the
  V270-003 cases as validator executable replay.
