## 目标

把 S3-LV-001 至 S3-LV-010 的合并事实、真实 Live 产品路径、异常恢复测试和禁止能力边界

1. 真实账户、生产 Venue、三角色审批、单笔订单与交易所回报是否形成受控端到端产品路径？
2. 断连、重复或倒退回报、部分成交、状态漂移、中断恢复和完整工作区回滚是否 fail closed？
3. Backtest/Demo 是否不能继承 Live 权限，连续下单、追加订单、改单、自动重试和自动恢复是否
   继续关闭？
4. 十个交付 Issue、对应 PR、task/evidence、Roadmap 与项目页面状态是否一致？

## 范围

- 新增 S3 closeout manifest、source guard 与负向自测；

## 强制边界

- 不修改 Rust、前端、OpenAPI、节点配置或交易行为；
- 不访问真实 Binance endpoint，不发送真实订单；
- 不新增连续下单、追加订单、改单、批量操作、自动重试、自动修复或自动恢复；
- 不修改 `docs/rust-cutover/release/v0_32_0_*`；
- 任何退出条件缺少源码或测试证据时保持 S3 milestone 开放并登记后续阻断任务。

  只剩 S3-LV-011。

尚未满足。真实资金账户的受控端到端交易必须由 S3-LV-011 在 owner 明确授权后单独验收。
