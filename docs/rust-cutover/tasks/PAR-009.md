# PAR-009 Dashboard CLI Ownership Boundary Split

Date: 2026-07-29
Executor: Codex
GitHub issue: #1177
Risk: high
Classification: separately-scoped-runtime-maintenance
Status: REVIEW_REQUIRED

## Goal

Split the oversized `crates/cli/src/dashboard.rs` along its existing rendering,
transport, read-model, API, and test ownership boundaries without changing
routes, schemas, serialized values, rendered assets, or fail-closed behavior.

中文摘要：本任务把 HTML、CSS、JavaScript 静态渲染资源迁入独立
`rendering` 模块，并把原内联测试迁入独立测试模块。HTTP 路由、read-model
投影、只读 API 和禁止交易控件的边界保持不变。

## Scope

- move static dashboard HTML, CSS, and JavaScript into
  `crates/cli/src/dashboard/rendering.rs`;
- move the inline dashboard tests into
  `crates/cli/src/dashboard/tests.rs`;
- retain HTTP transport and route ownership in `dashboard/server.rs`;
- retain v0.28 read-only API ownership in `dashboard/trader_terminal_api.rs`;
- add a structural regression for the module boundaries;
- rebase the path-scoped runtime risk inventory after test ownership moves.

## Non-Goals

- no route, HTTP method, API, schema, snapshot, or rendered asset change;
- no read-model projection or trading-semantic change;
- no submit, cancel, mutation, adapter-send, live-exchange, retry,
  remediation, or trading-control capability authorization;
- no edit to frozen `docs/rust-cutover/release/v0_32_0_*` files;
- no unrelated source ownership split.

## Behavior Contract

1. Static HTML, CSS, and JavaScript bytes remain unchanged.
2. Dashboard snapshot serialization and read-model projection remain unchanged.
3. Existing HTTP routes, methods, response contracts, and negative behavior
   remain unchanged.
4. Forbidden controls and unredacted fields continue to fail closed.
5. The parent module remains the read-model/projection owner while rendering,
   transport, API, and tests have explicit modules.

## Acceptance

- `dashboard.rs` line count decreases materially from the 25,680-line baseline;
- mechanical extraction and reconstruction prove move-only fidelity;
- complete `nautilus-cli` tests pass in standard and high precision;
- renderer, forbidden-control, and HTTP negative regressions pass;
- Clippy, golden replay, runtime risk inventory, current governance, backend
  freeze, and fast verification pass;
- no frozen v0.32.0 file changes;
- independent review and all hosted checks approve the high-risk change.
