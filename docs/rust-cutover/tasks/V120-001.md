## Goal

Add the v0.12 owner-gated production public read-only online probe for
allowlisted Binance Spot production public `GET` endpoints.

Plain Chinese summary: 这次让 `live production-public-read-probe --manual-online`
在所有 owner gate 都打开时，能够真正尝试生产 Binance 公开只读 `GET`。默认本地、
PR、CI 仍然不联网；没有 `NTPRO_V12_MANUAL_ONLINE=1` 时必须写
`network_attempted=false` 的证据。

## Scope

- Preserve the v0.11 blocked and offline-ready contract paths.
- Add the v0.12 manual-online schema for public production online reads.
- Require explicit CLI gates and env gates before any production HTTP request.
- Attempt only allowlisted unauthenticated `GET` public endpoints.
- Record bounded response metadata only.
- Add `scripts/ai/verify_v12_public_online_read_probe.sh`.

## Non-Goals

- No authenticated production account read.
- No credential loading.
- No signed request.
- No account endpoint access.
- No order endpoint access.
- No production order submission.
- No production cancel, replace, amend, retry, correction, or listenKey
  lifecycle mutation.
- No Dashboard action controls.
- No release tag or GitHub Release publication.

## Gates

The manual online path may attempt a production public `GET` only when all gates
are true:

```text
--manual-online
--allow-production-public-read
--confirm-read-only
--confirm-no-order-mutation
NTPRO_ALLOW_PRODUCTION_PUBLIC_READ=1
NTPRO_CONFIRM_PRODUCTION_PUBLIC_READ_ONLY=1
NTPRO_CONFIRM_NO_PRODUCTION_ORDER_MUTATION=1
NTPRO_V12_MANUAL_ONLINE=1
```

Default and CI-safe preflight paths must keep:

```text
network_attempted=false
production_public_online_read_attempted=false
credentials_used=false
account_mutation_attempted=false
production_order_submission_attempted=false
production_order_mutation_attempted=false
dashboard_order_controls_enabled=false
```
