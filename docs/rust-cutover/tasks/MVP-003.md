## 目标

建立 Rust 生成的 `ntpro.mvp_identity_contract.v1`，把策略版本、回测运行、
Supervisor 节点、策略实例、沙盒账户、Venue 和环境稳定关联，为 M0 后续四轴状态
合同和 M2 只读接口提供唯一身份基础。

## 范围

- 从节点配置的 `[mvp]` 段读取显式 MVP 元数据；
- 保持 Supervisor `node_id` 与策略 `strategy_instance_id` 独立；
- 校验必填身份、Venue 一致性和 sandbox 环境；
- `mvp serve` 启动成功后原子写入 `mvp/identity_contract.json`；
- 所有交易、变更、重试和补救边界保持 false；
- 增加正向和 fail-closed Rust 测试及迁移说明。

## 非目标

- 四轴状态聚合、HTTP API、前端页面或多节点编排；
- 真实交易或任何生产适配器行为；
- 修改 v0.32.0 冻结发布文件。
