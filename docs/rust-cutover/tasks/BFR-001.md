# BFR-001 Block Legacy Production Mutation Network Paths

Date: 2026-07-29
Executor: Codex
GitHub issue: #1166
Risk: critical
Classification: baseline-preserving-governance
Status: READY_FOR_REVIEW

## Goal

Make the post-v0.32.0 backend freeze enforceable at the current CLI runtime
boundary by rejecting legacy manual-online production mutation commands before
they can read artifacts, credentials, or invoke HTTP executors.

中文摘要：当前发行版保留了历史生产下单和实际撤单工件链，但后端冻结策略不再授权
真实交易写入。本任务保留离线审计能力，同时让两个 `manual_online` 入口在最外层
runtime wrapper 立即失败，无法继续读取签名材料或访问交易所。

## Scope

- block `ProductionMutationGuardedSend` when `manual_online=true`;
- block `ProductionMutationActualCancelSingleShot` when `manual_online=true`;
- preserve both commands in offline artifact-evaluation mode;
- add fail-closed ordering tests and a migration note.

## Non-Goals

- no change to production read-only probes;
- no deletion or rewrite of historical release evidence;
- no edit to frozen `docs/rust-cutover/release/v0_32_0_*` files;
- no submit, cancel, retry, recovery, or remediation capability.

## Acceptance

- both manual-online commands fail before file and environment reads;
- no output artifact or network attempt is produced by the blocked path;
- offline artifact evaluation remains covered;
- CLI tests, Clippy, current governance, and backend freeze checks pass.
