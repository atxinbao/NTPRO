# V061-006 - Add v0.6 workflow smoke to PR-stage CI

Milestone: v0.6.1 offline hardening
Priority: P0
Owner role: Verification & Release Gatekeeper
Review role: Control & Scope Agent
Risk: low

## Goal

Run the v0.6 Binance testnet dry-run smoke during PR checks whenever the PR
touches the workflow/dashboard/option files, v0.6 config, v0.6 dry-run script,
or v0.6 user guide.

## Scope

- Update PR-stage `Rust Cutover Smoke` changed-file classification.
- Add an explicit `v06-binance-testnet-dry-run-smoke` step.
- Keep the formal release gate unchanged.
- Keep the v0.6 smoke offline-only.

## Non-goals

- Do not change the v0.6 workflow artifact writer.
- Do not change Dashboard behavior.
- Do not connect to Binance testnet.
- Do not submit orders.
- Do not replace `scripts/ai/verify_release.sh`.

## Trigger Paths

- `crates/cli/src/workflow.rs`
- `crates/cli/src/dashboard.rs`
- `crates/cli/src/opt.rs`
- `examples/rust/binance/testnet_dry_run.toml`
- `scripts/ai/verify_v06_binance_testnet_dry_run.sh`
- `docs/rust-cutover/product/V06_BINANCE_TESTNET_DRY_RUN_USER_GUIDE.md`

## Required Evidence

- Workflow syntax parses.
- The changed-file classifier marks a representative v0.6 path as requiring
  `v06_smoke=true`.
- `scripts/ai/verify_v06_binance_testnet_dry_run.sh` passes.
- `scripts/ai/verify_fast.sh` passes.
- `git diff --check` passes.
