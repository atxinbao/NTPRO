# V160-012 - Add v0.16 release gates

Date: 2026-06-23
Executor: Codex
Milestone: v0.16.0 minimum owner-approved production order mutation candidate
Risk: medium

## Goal

Wire the v0.16 production mutation candidate gates into local release
verification, PR smoke, and tag-triggered release verification while preserving
default offline fail-closed execution.

Plain Chinese summary: 这个任务是把 v0.16 发版门禁接起来。大白话：发版检查会把
runtime gate、signing approval、request builder、guarded send、response
redaction、order-state readback、kill switch、audit trail、failure/no-retry 和
Dashboard 只读证据串起来跑一遍。但默认仍然不联网、不发生产请求、不真实下单。

## Scope

Included:

- add `scripts/ai/verify_v16_release_gates.sh`;
- add `v16-release-gates` to `scripts/ai/verify_release.sh`;
- add a tag release workflow stage for v0.16 release gates;
- add PR smoke changed-file classification and stage for v0.16 release gates;
- check existing v0.16 release/evidence documents exist and carry boundary
  markers;
- scan gate logs for forbidden default production mutation markers.

Not included:

- production network execution in CI;
- real credential usage;
- production order submission in default gates;
- retry, cancel, replace, amend, correction, flatten, or remediation;
- Dashboard order controls;
- v0.16 release notes or readiness report.
