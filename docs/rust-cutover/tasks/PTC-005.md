Date: 2026-07-16
Executor: Codex
GitHub issue: #1100
Risk: medium

## Goal

Retire five unreachable Python control/inventory helpers without losing active
task governance or historical Cython inventory evidence.

## Scope

- remove legacy lease, role validation, dispatch, PR closeout, and Cython
  inventory Python implementations;
- make GitHub issues, labels, branches, PRs, and hosted checks the only active
  control authority;
- retain the historical Cython CSV and all historical cutover evidence;
- add a deterministic Rust retirement guard to hosted smoke.

## Prohibited

- modifying `docs/rust-cutover/release/v0_32_0_*`;
- deleting or text-cleaning historical evidence;
- changing runtime, public API, trading semantics, or backend boundaries;
- introducing local queue mutation or a replacement custom dispatcher.

## Acceptance

- all five Python files are absent;
- Make, workflows, actions, supported scripts, and current protocol docs do not
  call them;
- current task intake and closeout use documented standard `git`, `gh`, and
  optional `jq` commands;
- `cython_inventory.csv` remains byte-identical at 244 lines;
- local and hosted retirement gates pass.
