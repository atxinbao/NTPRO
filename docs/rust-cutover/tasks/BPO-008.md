# BPO-008 Tag-Push Publication Binding

Date: 2026-07-21
Executor: Codex
GitHub issue: #1141
Milestone: v0.33.0-backend-maintenance
Risk: critical
Classification: v33-separately-scoped
Status: REVIEW_REQUIRED

## Goal

Require v0.33.0 publication authority to come from the successful release gate
triggered by the exact release tag push, not from a manual run sharing the same
commit SHA.

中文摘要：PR #1140 合并后复核发现，原发布脚本只核对 workflow 名和 commit SHA，
理论上同一个 SHA 的手动 run 也可能被当成发布依据。本任务增加 event 和 tag ref 核验，
必须是 `push` 且 ref 正好是 `ntpro-rust-only-v0.33.0` 才能发布。

## Scope

- validate gate `event=push`;
- validate gate `headBranch=ntpro-rust-only-v0.33.0`;
- reject `workflow_dispatch` and mismatched refs in deterministic tests;
- register #1141 and its PR in the v0.33.0 exact release scope;
- merge before tag creation.

## Non-Goals

- no runtime, adapter, API, schema, or trading behavior change;
- no edit to frozen `docs/rust-cutover/release/v0_32_0_*` files;
- no new tag, release, optimization, or capability.

## Acceptance

- valid tag push, exact tag ref, and exact SHA path passes;
- manual run and mismatched ref paths fail closed;
- all v33, current-governance, backend-freeze, and publication tests pass;
- independent review and hosted checks pass before merge;
- v0.33.0 tag and Release remain absent until merge.
