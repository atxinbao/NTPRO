# V230-007 - v0.23.0 release gates and strict provenance

Date: 2026-07-03
Executor: Codex
GitHub issue: `#718`
Milestone: `v0.23.0`
Risk: critical release governance
Owner role: Verification & Release Gatekeeper
Review role: Control & Scope Agent
Auto-merge: allowed after local validation and hosted checks pass

## Goal

Prepare and verify the `v0.23.0` release package, including release notes,
readiness report, machine-readable manifest, release gates, strict provenance,
and post-gate publication evidence.

Plain Chinese summary: 本任务是 `v0.23.0` 的最终发布收口。它把 V230-000 到
V230-006 的证据纳入 release notes、readiness report、manifest、release gates 和
strict provenance，并要求公开 GitHub Release 必须在 hosted release gate 成功之后
发布。

## Scope

Included:

- add `v0.23.0` release notes, readiness report, release manifest, task file,
  and evidence ledger;
- add dedicated `v0.23.0` release gate and strict provenance scripts;
- wire the new stages into `scripts/ai/verify_release.sh`;
- wire the new hosted release stages into `.github/workflows/release-tag.yml`;
- update current release surface docs from `v0.22.1` to `v0.23.0`;
- verify V230-000 through V230-006 evidence, identity boundary rules,
  executable replay coverage, Dashboard render smoke, and gate-before-publish
  governance.

Not included:

- production submit capability;
- production order mutation expansion;
- product-grade live trading terminal claims;
- Dashboard operation controls;
- weakening v0.22.x read-only/control boundary evidence;
- public release publication before hosted release gate success.

## Acceptance Criteria

- `docs/rust-cutover/release/v0_23_0_release_notes.md` records the final
  release boundary and validation commands.
- `docs/rust-cutover/release/v0_23_0_readiness_report.md` records readiness,
  issue dependency, and publication-order evidence requirements.
- `docs/rust-cutover/release/v0_23_0_release_manifest.json` records the V230
  evidence chain, boundary flags, gates, and next-track metadata.
- `scripts/ai/verify_release.sh v23-release-gates` passes locally and in the
  hosted release gate.
- `scripts/ai/verify_release.sh v23-strict-provenance` passes locally and in
  the hosted release gate.
- The `ntpro-rust-only-v0.23.0` public GitHub Release is published only after a
  successful hosted `Rust Cutover Release Gate` run for the same tag commit.
