## Goal

Define the v0.32.0 backend production closeout boundary and scoped
authorization contract before any backend closeout execution evidence can be
accepted.

Plain Chinese summary: 本任务定义 v0.32.0 作为后端收尾版本的边界合同。它只建立
Backend Production Closeout 的 scoped authorization 规则，不授权实际生产执行，
不开放 submit、mutation、adapter send、live exchange request、retry scheduler、
automatic remediation、Dashboard/Admin/Trader Terminal 交易控件、frontend
completion、backend go-live 或产品级实盘交易终端声明。

## Scope

Included:

- Define backend service closeout separately from frontend completion,
  product-grade live trading terminal readiness, and actual production trading
  execution.
- Define owner/operator scoped authorization as required source-controlled
  evidence for any later backend production execution path.
- Define required approval scope fields, allowed closeout-only requested
  capabilities, forbidden trading/exchange/control capabilities, and
  revocation conditions.
- Keep scoped authorization as evidence only until downstream V320 gates prove
  approval/freeze/change-window, risk/audit/go-no-go, config/venue provenance,
  rollback/DR, telemetry/SLO, read model/admin bridge, fail-closed negative
  tests, release gates, and strict provenance.
- Add a deterministic validator and release stage.

Not included:

- default production submit;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal operation controls or trading controls;
- frontend completion;
- backend go-live execution;
- product-grade live trading terminal readiness.

## Acceptance Criteria

- Missing scoped authorization fails closed.
- Unscoped/default production execution fails closed.
- Forbidden requested capabilities fail closed.
- Revoked, expired, digest-mismatched, or scope-drifted authorization fails
  closed.
- Scoped authorization alone records evidence but still blocks execution until
  downstream V320 gates are complete.
- Every inherited/default runtime or trading boundary flag is explicitly false.
