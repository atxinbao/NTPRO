# V080-002 Implement Env-Only Secret Loading and Redaction Guard

Date: 2026-06-16
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: high
Status: REVIEW_REQUIRED_AFTER_PR

## Goal

Add the credential safety foundation for future authenticated Binance testnet
read-only probes: credentials may be read from environment variables only, and
artifacts may record presence only, never values.

## Scope

- Add an env-only credential helper for Binance testnet workflow credentials.
- Record API key / secret presence booleans only.
- Add fail-closed artifact state when either credential is missing.
- Guard testnet workflow artifact writes against accidental synthetic secret
  value leaks.
- Add tests proving missing credentials fail closed and synthetic secrets are
  blocked or absent from written artifacts.

## Non-Goals

- No request signing.
- No authenticated network call.
- No real Binance account response.
- No `X-MBX-APIKEY` header construction.
- No HMAC signature artifact.
- No raw signed query string artifact.
- No raw response body artifact.
- No order submission, cancel, replace, amend, or account mutation.
- No production Binance connectivity.
- No real funds.
- No production trading.

## Acceptance

- Credentials are loaded only from configured environment variable names.
- Artifact schema records env var names and present/absent booleans only.
- Missing API key or secret sets authenticated read-only probe fail-closed state.
- Synthetic API key/secret values do not appear in credential policy artifacts.
- The redaction guard blocks a synthetic secret leak before writing an artifact.
- Existing offline/testnet workflow behavior remains unchanged.
- PR stops at `REVIEW_REQUIRED`; no auto-merge.
