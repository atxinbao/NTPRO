# S1-BT-005 - Backtest 多 Run 比较与确定性复现

Date: 2026-08-09
Executor: Codex
GitHub issue: #1278
Risk: high
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Status: REVIEW_APPROVED_HOSTED_PENDING

## 目标

让策略工作台用户选择 2 至 4 个可信 Backtest Run，查看参数、收益、风险与来源差异，并从
动态 Run 的不可变请求配置显式创建新的确定性复现 Run 和可审计证明。

## 范围

- 新增 `GET /api/product/v1/run-comparisons?run_ids=...`，服务端独立验证每个 Run 的
  summary、details、analysis 和来源哈希；
- 允许同一 Strategy 的版本、参数或数据不同，但必须报告数据、标的、币种与直接可比性；
- 每个新动态 Run 持久化并哈希绑定完整 `strategy-version.json`；历史 Run 按自己的不可变
  StrategyVersion 快照验证，不依赖当前默认版本；
- 新增 `POST /api/product/v1/runs/{run_id}/reproduction`，仅接受路径与请求体身份一致且
  `deterministic_replay=true` 的显式请求；
- 从不可变 `request.toml` 重建输入并重新执行同一 `BacktestEngine`，创建新 Run，不覆盖源
  Run；
- 持久化 `reproduction.json`，独立重算输入和输出语义指纹，读取时再次校验全部产物；
- 同步 OpenAPI、生成 TypeScript/Zod SDK、严格 Product client、工作台比较页和 Run 证明区；
- 增加 Rust 正负路径、真实 v1/v2 比较与复现、角色矩阵、客户端单次 POST、组件和
  Playwright 双视口验证。

## 非目标

- 不开放 Demo、Live、外部 Venue 或真实订单；
- 不实现自动重试、自动补救、自动恢复、参数优化器或排行榜；
- 不覆盖、修改或删除源 Run；
- 不修改 v0.32.0 发布冻结文件。

## Post-freeze 例外

`crates/cli/src/dashboard/server.rs` 是 MVP frozen source。Issue #1278 登记独立的 post-freeze
产品扩展：仅新增受既有产品访问控制保护的 Backtest 比较 GET 路由和显式复现 GET/POST
路由，并更新 freeze manifest 的精确 SHA-256。MVP 拓扑和 19 项禁止能力边界保持不变。

## 完成条件

Gatekeeper 的 `REVIEW_APPROVED`，通过 hosted checks 后手动合并；禁止 auto-merge。
