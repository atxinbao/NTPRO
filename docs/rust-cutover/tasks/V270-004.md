## Goal

Define the v0.27.0 deployment, upgrade, rollback, and post-check runtime
orchestration foundation while remaining gated and preview-first. The task
turns v26 deployment provenance and runbook evidence into a runtime state model
without executing deploy, rollback, remediation, or trading operations.

Plain Chinese summary: 本任务定义 v0.27.0 的 deployment / upgrade / rollback runtime
orchestration foundation。它只产出 deploy、upgrade、rollback、post-check 的
preview-first 状态模型，并要求 owner approval、release gate evidence、environment
provenance、rollback plan lineage；不自动部署、不自动回滚、不触发 automatic
remediation、adapter send、live exchange request、Dashboard controls 或真实交易操作。

## Dependency

- Depends on `V270-001` product operations runtime integration boundary
  contract.
- Depends on `V270-002` external identity and permission foundation.
- Depends on `V270-003` persistent audit storage foundation.
- Uses `V260-004` deployment provenance and `V260-005` upgrade/rollback runbook
  evidence as the source evidence baseline.
- Does not enable deploy/rollback execution.

## Scope

Included:

- Define runtime orchestration state model for deploy, upgrade, rollback, and
  post-checks.
- Require owner approval, release gate evidence, environment provenance, and
  rollback plan lineage.
- Add fail-closed cases for stale environment provenance, missing approval,
  tag/source mismatch, failed preflight, unsafe automation request, and
  forbidden operation boundary opening.
- Add a verifier that recomputes orchestration status from the trace.
- Record the trace rows in the release replay scope as validator executable
  replay.

Not included:

- automatic deploy execution;
- automatic rollback execution;
- automatic remediation;
- production order mutation;
- adapter send or live exchange request;
- Dashboard operation controls or Dashboard trading controls;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- Ready state is accepted only when all state records are preview-only and
  backed by fresh environment provenance, owner approval, release gate evidence,
  and rollback plan lineage.
- Stale environment provenance fails closed.
- Missing owner approval yields blocked preview only.
- Tag/source mismatch fails closed.
- Failed preflight fails closed.
- Unsafe automation request fails closed.
- Any deploy/rollback execution, remediation, trading operation, adapter send,
  live exchange request, retry scheduler, or Dashboard control fails closed.
- `scripts/ai/verify_release.sh v27-deployment-orchestration-foundation`
  passes.
- `docs/rust-cutover/golden_trace/RELEASE_REPLAY_SCOPE.json` records the
  V270-004 cases as validator executable replay.
