## Goal

Define the v0.26.0 operator permission model and role boundary evidence for
future product workbench hardening. The permission model is evidence-only and
does not grant live operation authorization.

Plain Chinese summary: 本任务定义 v0.26.0 的 operator permission model。它覆盖
viewer、operator、release gatekeeper、incident owner、auditor 等角色，明确 role、
scope、approval、provenance 和 deny-by-default 规则；所有权限证据只用于只读展示和审计，
不等于 submit/cancel/retry/replace/amend/flatten 或生产交易授权。

## Dependency

- Depends on `V260-001` product hardening boundary contract.
- Keeps the V260-001 `product_hardening_foundation_only` boundary intact.
- Does not integrate SSO/IAM or any external identity provider.
- Does not change owner approval lifecycle runtime behavior.

## Scope

Included:

- Define operator roles, role scopes, approval requirements, and deny-by-default
  permission rules.
- Add golden trace rows for a valid role matrix, missing role/scope/provenance,
  missing required permission, cross-scope permission, expired approval, role
  escalation, and forbidden trading controls.
- Add a verifier that recomputes effective permission status from the trace.
- Register the trace rows in release replay scope as validator executable
  replay.

Not included:

- live submit/cancel/retry/replace/amend/flatten authorization;
- production trading authorization;
- Dashboard trading controls;
- external SSO/IAM integration;
- runtime changes to the owner approval lifecycle.

## Acceptance Criteria

- Missing role, scope, or provenance fails closed.
- Missing required role permission fails closed.
- Cross-scope permission evidence fails closed.
- Expired approval evidence fails closed.
- Role escalation evidence fails closed.
- Any role opening submit, cancel, retry, replace, amend, flatten, adapter send,
  live exchange request, or Dashboard trading controls fails closed.
- `scripts/ai/verify_release.sh v26-operator-permission-model` passes.
- `docs/rust-cutover/golden_trace/RELEASE_REPLAY_SCOPE.json` records the
  V260-002 cases as validator executable replay.
