## Goal

Create canary execution preflight evidence for the backend go-live candidate
without default production execution.

Plain Chinese summary: 本任务为 v0.30.0 建立 canary execution preflight 和
no-default-execution gate。它可以验证 canary eligibility、preflight checks、
stale-source rejection、abort criteria、operator acknowledgement 和 evidence links，
但不会执行 production canary action；任何 execution=true 或 live exchange side
effect 都会 fail closed。

## Dependency

- Depends on `V300-002` production deployment plan and environment readiness.
- Depends on `V300-003` runtime enablement boundary and controlled feature
  flags.
- Depends on `V300-004` operator approval freeze and change-window lifecycle.
- Hard-blocked by published v0.29.1 release evidence and closed v0.29.1
  milestone.

## Scope

Included:

- Define canary eligibility, preflight checks, stale-source rejection, abort
  criteria, and operator acknowledgement.
- Prove no-default-execution blocks canary execution unless a later explicit
  scope allows it.
- Link canary readiness to deployment, telemetry, incident, and rollback
  evidence.
- Reject execution=true and live exchange side effects.
- Add deterministic JSON and executable verifier.

Not included:

- production canary action execution;
- production runtime enablement;
- default production submit;
- production order mutation;
- adapter send or live exchange request;
- retry scheduler or automatic remediation;
- Dashboard/Admin/Trader Terminal operation controls or trading controls;
- product-grade live trading terminal readiness claims.

## Acceptance Criteria

- Canary preflight can be validated without executing production canary
  actions.
- Missing eligibility, stale source, missing operator acknowledgement, missing
  linked evidence, or missing abort criteria fails closed.
- Any accidental `execution=true` or live exchange side effect fails closed.
- No-default-execution gate remains closed.
