## Goal

Add the v0.12 owner-gated authenticated production account snapshot online proof
for Binance Spot production `GET /api/v3/account`.

Plain Chinese summary: 这次让 `live production-account-snapshot-contract
--manual-online` 在所有 owner gate 和只读 API 凭据都打开时，能够真正尝试生产
Binance 的账户快照只读 `GET`。默认本地、PR、CI 仍然不联网；没有
`NTPRO_V12_MANUAL_ONLINE=1` 时必须写 `network_attempted=false` 的证据。

## Scope

- Preserve the v0.11 blocked and offline-ready account snapshot contract paths.
- Add the v0.12 manual-online schema for authenticated production account reads.
- Require explicit CLI gates and env gates before any production signed request.
- Attempt only allowlisted signed `GET /api/v3/account`.
- Record bounded response metadata only.
- Add `scripts/ai/verify_v12_authenticated_account_snapshot_online_read.sh`.

## Non-Goals

- No production order submission.
- No production cancel, replace, amend, retry, correction, or listenKey
  lifecycle mutation.
- No production order-state reads.
- No raw account response persistence.
- No raw balances, UID, headers, API key, secret, signature, signed query, or
  signed URL persistence.
- No Dashboard action controls.
- No release tag or GitHub Release publication.

## Gates

The manual online path may attempt a production authenticated `GET` only when all
gates are true:

```text
--manual-online
--allow-production-authenticated-read
--confirm-owner-approved-read-only
--confirm-no-order-mutation
--confirm-no-secret-persistence
NTPRO_ALLOW_PRODUCTION_AUTHENTICATED_READ=1
NTPRO_OWNER_APPROVED_PRODUCTION_READ_ONLY=1
NTPRO_CONFIRM_PRODUCTION_ACCOUNT_NO_ORDER_MUTATION=1
NTPRO_CONFIRM_NO_SECRET_PERSISTENCE=1
NTPRO_V12_MANUAL_ONLINE=1
BINANCE_PRODUCTION_READONLY_API_KEY=<read-only key>
BINANCE_PRODUCTION_READONLY_API_SECRET=<read-only secret>
```

Default and CI-safe preflight paths must keep:

```text
network_attempted=false
account_read_attempted=false
account_mutation_attempted=false
order_endpoint_access_attempted=false
production_order_submission_attempted=false
production_order_mutation_attempted=false
dashboard_order_controls_enabled=false
signature_recorded=false
signed_query_recorded=false
signed_url_recorded=false
```
