# V111-004 Harden Dashboard Production Shadow Health

Date: 2026-06-20
Executor: Codex
Owner role: Rust Product Surface Agent
Review role: Verification & Release Gatekeeper
Risk level: medium
Status: BACKLOG
Depends on: V111-003

## Goal

Make Dashboard degrade production shadow health for missing required artifacts,
invalid JSON/JSONL, schema mismatch, missing required counters, or any forbidden
counter/control violation.

Plain Chinese summary: 这次加固 Dashboard 的 production shadow 健康判断。不能只看
“最后一条 JSONL”；只要任意一条记录出现生产提交、生产变更、Dashboard 下单控件，
或者 required artifact 缺失/坏 JSON/schema 不对，都要显示 degraded。

## Scope

- Audit the five v0.11 production shadow required artifacts directly:
  - `account_snapshot_redacted.json`;
  - `shadow_execution_intent.jsonl`;
  - `shadow_portfolio_snapshot.json`;
  - `order_lifecycle_state.jsonl`;
  - `reconciliation_events.jsonl`.
- Scan every non-empty JSONL record for boundary violations.
- Degrade health for missing required artifacts, invalid JSON/JSONL, schema
  mismatch, missing required counters/flags, non-zero mutation/submission
  counters, or true order-control flags.
- Keep manifest audit behavior from V111-003 intact.

## Non-Goals

- No production network connection.
- No production online read runtime.
- No production order submission.
- No production cancel, replace, amend, retry, or correction.
- No Dashboard order controls.
- No raw production account payload persistence.
- No credentials, signed queries, or signed URL persistence.
- No new release tag or GitHub Release publication.

## Acceptance

- Dashboard health degrades when a required production shadow artifact is
  missing.
- Dashboard health scans all JSONL records and degrades even if the latest JSONL
  record is valid but an earlier record violates the boundary.
- Dashboard health degrades for invalid JSON/JSONL, schema mismatch, missing
  required fields, and forbidden counters/flags.
- `cargo test -p nautilus-cli production_shadow --lib` passes.
- `scripts/ai/verify_release.sh v11-offline-release-gates` passes.
- `scripts/ai/verify_fast.sh` passes.
- `git diff --check` passes.

## Automation Approval

This task is marked `autoMergeAllowed=true` in Shrimp. It is offline Dashboard
health hardening only and does not add production network access, credentials
use, order mutation, or Dashboard order controls.
