# V151-003 - Default mutation preview signing to synthetic material

Date: 2026-06-23
Executor: Codex
Milestone: v0.15.1 mutation dry-run semantics / approval / evidence hardening
Risk: medium
Auto-merge: allowed after local validation and hosted smoke PASS

## Goal

Harden the v0.15 production live-alpha request-preview signing path so the
default dry-run preview uses synthetic signing material and never reads
production signing environment variables unless the owner explicitly selects
production live-alpha material and opens both signing-material gates.

Plain Chinese summary: 默认请求预览只用假的 synthetic 签名材料，不读生产 key/secret。
只有 owner 明确选择 `production_live_alpha`，并且两个环境变量 gate 都是 `1`，才允许读取
生产 signing env 做内存签名预览。这个任务仍然不联网、不发生产请求、不真实下单。

## Scope

Included:

- add `credential_material=synthetic|production_live_alpha` to request-preview
  artifacts;
- default request preview signing material to `synthetic`;
- require both production signing material gates before reading production
  key/secret env values:
  - `NTPRO_ALLOW_PRODUCTION_MUTATION_SIGNING_MATERIAL=1`
  - `NTPRO_OWNER_APPROVED_MUTATION_SIGNING_DRY_RUN=1`
- record signing-material gate state in the redacted preview artifact;
- keep signatures, signed queries, signed URLs, raw bodies, API key values, and
  API secret values memory-only and redacted.

Not included:

- production order submission;
- production order-test submission;
- production HTTP request execution;
- production execution adapter calls;
- real funds;
- production trading;
- Dashboard order controls;
- durable credential storage.

## Acceptance Criteria

- Default request preview succeeds with `credential_material=synthetic`.
- Default request preview does not read production signing env values.
- `credential_material=production_live_alpha` fails closed unless both signing
  material gate env vars are set to `1`.
- Production live-alpha signing env values are read only after both gates are
  open.
- Artifacts never persist secrets, signatures, signed query strings, signed
  URLs, raw request bodies, or raw query values.
- All paths preserve:
  - `request_sent=false`
  - `network_attempted=false`
  - `production_orders_submitted=0`
  - `production_order_mutations_attempted=0`
  - `dashboard_order_controls_enabled=false`
