Residual risk

遗留风险不是 28,975 个“缺陷”

风险清单是文本信号和所有权盘点，用于趋势治理与聚焦审查。它包含测试断言、生成代码和 FFI 合法不变量。真正需要优先处理的是可达 runtime、交易语义、持久化一致性和边界绕过，而不是机械清零。
